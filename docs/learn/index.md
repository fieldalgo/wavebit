# Learn

Work through a complete calculation before looking up individual options in the
[user guide](../guide/README.md). Executable lessons live in the repository so you
can change the geometry, inspect intermediate arrays and compare refinements.

| Learning path | Topics |
| --- | --- |
| [RCWA notebooks](https://github.com/fieldalgo/wavebit/tree/develop/tutorials) | First solve, differentiation, precision, factorization, lattice and illumination. |
| [FDTD introduction](../guide/time-domain.md) | Pulse duration, spatial refinement, diffraction and material response. |
| [General FDTD introduction](../guide/general-fdtd.md) | Explicit domains, sources and monitors. |
| [Worked examples](https://github.com/fieldalgo/wavebit/tree/develop/examples) | Runnable applications and optimization problems. |

Read the [coordinate and amplitude conventions](../conventions.md) before comparing
solvers. Equal power does not imply equal complex amplitudes: their reference planes,
lateral origin and polarization basis must also agree.
