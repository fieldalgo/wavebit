# Learn

These lessons connect the physical model, discretization, solver output and convergence checks. Read them in sequence or choose the section matching the calculation you are making.

- [RCWA fundamentals](fundamentals/index.md): twenty chapters and three detailed appendices, from periodic scattering to fields, differentiation and wavevector branch selection.
- [Normal-vector factorization](nvf/index.md): fifteen chapters on boundary continuity, Fourier products, projector construction and convergence.
- [FDTD learning path](fdtd/index.md): domains, sources, monitors, transient error and cross-solver comparisons.
- [Runnable teaching examples](examples.md) accompany the RCWA lessons.

English is the canonical documentation language. The language switch opens the same page in Korean where a full translation is available and identifies English fallback pages. Source provenance and historical measurement limits are recorded in the [learning import record](../development/learning-provenance.md).
