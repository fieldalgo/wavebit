| 현재 규약 | 의미 |
| --- | --- |
| 재료 | 상대 유전율과 상대 투자율, 공유되는 물리 응답 모델 |
| 페이저 | `exp(-i omega t)`, 양의 허수부 epsilon은 수동(passive) 전기 손실입니다 |
| 주기 적층 좌표 | 아래에서 위로 가는 층 순서, 바닥에서 z=0, +z가 위쪽, 가로 방향 셀은 중심 정렬 |

| 공개 필드 성분 | `(Ex,Ey,Ez,Hx,Hy,Hz)`, E는 V/m, H는 A/m. 필드 관측값의 `units`는 존재하는 각 성분과 `'coordinates'`를 단위에 대응시킵니다 |
| 단위 레이블 | `_units`로 끝나는 키, 단위마다 철자 하나(`'V*s/m'`, `'J/Hz'`, `'m^2'`), 무차원은 `'1'` |
| 회절 축 | 파장, 차수 v, 차수 u. 유효성은 결과 안에 남습니다 |
| 회절 진폭 | `amplitude_ratio_s`, `amplitude_ratio_p`(각 차수 자신의 출사 s/p 좌표계)와 `amplitude_ratio_xyz`(직교 좌표, 마지막 xyz 축)는 한 차수의 출사 전기장을 입사파의 전기장으로 나눈 값입니다. 무차원(`'1'`)이며 소스 진폭에 따라 변하지 않습니다. `field_s`, `field_p`, `field_xyz`는 이 비율에 `reference['incident_field']`를 곱한 값, 즉 V/m 단위의 출사 필드이며, 구동이 연속파인 곳(`rcwa`, `fdtd.periodic`)에서 정의되고 펄스 구동(`fdtd`)에서는 None입니다. `efficiency`는 출사 전력을 입사 전력으로 나눈 값입니다. `power`는 정의된 곳에서 `reference['power_units']`(W, 또는 불변 축을 가로지르는 W/m) 단위이며 소스 진폭의 제곱에 비례합니다. `RawDiffractionSpectrum`은 비율이 아니라 V*s/m 단위의 펄스 스펙트럼 `spectrum_s/_p/_xyz`를 담습니다 |
| 회절 기준 | 모든 솔버의 `DiffractionOrders.reference`는 `port`(면: `'top'`/`'bottom'`, FDTD에서는 `'z+'` 형식), `wave`(`'reflected'`/`'transmitted'`), `plane`, `lateral_origin`, `amplitude_ratio_units`(`'1'`), 구동(`rcwa`와 `fdtd.periodic`의 연속파에는 V/m 단위 `incident_field`, `fdtd`의 펄스에는 파장마다 값 하나인 V*s/m 단위 `incident_spectrum`), `cell_measure`, `invariant_axes`를 각각의 `_units` 레이블과 함께 제공하며, 전력이 정의되는 곳에서는 `incident_power`와 `power_units`도 제공합니다 |
| 솔버 비교 | 기준 평면, 가로 원점, 편광 좌표계가 일치한 뒤에 진폭비, 효율, 전력, 필드를 비교하세요. 한 생산자의 `incident_field`(V/m)를 다른 생산자의 `incident_spectrum`(V*s/m)으로 나누지 마세요. 서로 다른 물리량입니다 |

옛 매개변수를 옮기기 전에 [현재 생애주기](../../guide/common/lifecycle.md)와 [마이그레이션](../../migration/index.md)을 보세요. FDTD 전류 모멘트(A·m 또는 V·m)는 RCWA 전기 쌍극자 모멘트(C·m)와 다릅니다.

## 이전 인터페이스의 계약과 근거

이 아래는 2026-08-12에 처음 작성되고 이후 개정된, 확립된 호환성 계약을 기록합니다. 그 측정된 검사와 과거 매개변수 이름은 재현성에 여전히 쓸모가 있지만, 위의 현재 선언보다 우선하지 않습니다.

## 시간과 손실

| | 규약 |
| --- | --- |
| 시간 인자 | `e^{-iωt}` — 물리적 필드는 `Re[E(r) e^{-iωt}]`입니다 |
| 손실 | `Im(eps) > 0`, 동등하게 `Im(n) > 0` — 굴절률 표가 쓰는 부호(`n + 1j*k`)입니다 |
| 이득 | `Im(eps) < 0`. 이때 계산은 정당하게 `R + T > 1`을 반환할 수 있으며, 라이브러리의 어느 부분도 이를 오류로 취급하지 않습니다. 이득 반공간은 Maystre의 근을 취하는데, 이는 약하고 통상적인 이득에 대한 답입니다 -- 문헌에서는 논란이 있으며, 일부 강한 분산 능동 매질에는 틀린 근입니다([branch-cuts.md](../../theory/rcwa/branch-cuts.md#gain-near-grazing)). 유한한 빔의 응답이 빔 폭에 따라 달라지는 스치듯 입사 근처에서는 계산이 `GainCutoffWarning` 경고를 냅니다. 전파하는 능동 **이중 음수(double negative)** 매질은 거부됩니다. 단일 주파수 규칙으로는 그 근을 고를 수 없기 때문입니다([negative-index-media.md](../../theory/rcwa/negative-index-media.md)) |

fmmax와 같은 규약입니다. RETICOLO의 효율과 진폭은 변환 없이 이 규약과 일치합니다
(RETICOLO 골든 값으로 4e-14까지 고정). 이 라이브러리가 반환하는 모든 복소
진폭은 이 규약을 따릅니다. `e^{+jωt}` 출처(옛 논문, `n - jk`로 쓰는 meent 시절 스크립트)에서
인용한 결과는 우리 값의 켤레 복소수입니다.

## 재료 — 재료 숫자가 뜻하는 것

**스크립트가 쓰는 모든 재료 값은 상대 유전율**이며, 그 옆의 모든 투자율도
상대값입니다. 복소수는 평범한 경우입니다. 위 표와 같이 `Im(eps) > 0`은 손실입니다.

이 페이지에서 이름만이 아니라 *값*이 바뀐 항목은 이것 하나입니다(2026-08-20).
이전에는 모든 재료 슬롯이 굴절률을 받았는데, 스크립트가 한쪽에 쓴 숫자는
다른 쪽에도 여전히 합법적인 값입니다 — 그래서 옛 철자는 받아들이지 않고 키워드
단계에서 거부합니다. 아래의 "퇴역한 철자"를 보세요.

`Material`은 재료 하나를 담는 타입입니다.

```python
wavebit.Material(epsilon, mu=None)
```

불변(frozen)이며, 자식이 `(epsilon, mu)`인 등록된 JAX pytree입니다 — 재료는
정당한 설계 변수이므로, 불투명한 잎이 아니라 tracer를 담고 그래디언트를 전달합니다.
재료를 받는 곳이라면 어디서든 **맨 숫자는 `Material(epsilon=x)`의 약식**입니다.
비자성이 압도적인 기본값이며, 쓰는 데 아무 비용이 들지 않습니다.

장면은 네 키워드로 기술합니다.

| 키워드 | 담는 것 |
| --- | --- |
| `structure` | 층 적층, 첫 축이 층 축(layer-major) — 아래 두 인코딩 중 하나 |
| `top`, `bot` | 두 반공간 재료: `Material`, 또는 맨 상대 유전율 |
| `mu` | **래스터 경로 전용**: `structure` 옆에 두는 투자율 필드 `(n_layers, Ny, Nx)`. 형상 경로에서 이 이름을 쓰면 무시되지 않고 거부됩니다 — 그 경로에서 투자율은 영역을 채우는 `Material`에 속합니다 |
| `thickness` | 층별 두께, 공유 길이 단위 |

`structure`의 *타입*이 모델링 경로를 고릅니다. 별도의 모드 스위치는 없습니다.

| 인코딩 | `structure` |
| --- | --- |
| 래스터 | **상대 유전율**의 ndarray `(n_layers, Ny, Nx)` — 픽셀마다 표본 하나 |
| 해석적 | `[dict(background=..., shapes=[dict(type=..., cx=..., cy=..., lx=..., ly=..., angle=..., material=...)]), ...]` |

세 번째 인코딩 `[[background, [['rectangle', cx, cy, lx, ly, material, angle], ...]], ...]`는
블록 모델러였으며, 2026-08-26부터 이름으로 거부됩니다.

영역을 무엇이 채우는지 말하는 세 방법 중 둘 — 매개변수 층의 `background`와
각 형상의 `material` — 은 **할당**입니다. 즉 한 영역에 있는 물질의 이름이며, 매질은
유전율과 투자율을 모두 가지므로 하나의 타입이 그 쌍을 담습니다. 래스터는
세 번째 방법으로, 할당이 전혀 아니라 **표본화된 필드**, 즉 픽셀마다 숫자 하나입니다.
위상 최적화가 래스터를 찾는 이유가 바로 이것입니다. 필드에는 물리량이 하나만 들어 있으므로,
래스터의 투자율은 객체의 두 번째 슬롯이 아니라 두 번째 배열(`mu=`)입니다.

### 퇴역한 철자와, 이름으로 거부한 이유

| 퇴역 | 현재 | 가리키는 것 |
| --- | --- | --- |
| `ucell` | `structure` | 층 적층 |
| `n_top` / `n_bot` | `top` / `bot` | 두 반공간 재료 |
| `n_base` / `base` (매개변수 층 키) | `background` | 층의 배경 재료 |
| `n_index` (매개변수 형상 키) | `material` | 형상의 재료 |
| `ucell_materials` | — | 삭제됨. 모든 백엔드가 할당했지만 아무것도 읽지 않았습니다 |

2026-08-26까지 이들은 모두 예외를 일으키며 대체 이름을 알려 주었고, **또한** 그와 함께
물리량이 바뀌었다고 말했습니다. 핵심은 그 두 번째 부분이었습니다. 키워드 이름만 바꾸고
숫자를 그대로 둔 사용자의 실수는 이후 단계의 어떤 것도 알아챌 수 없습니다. `3.5`는 완벽하게 정상적인 유전율이므로
계산은 실행되고, 에너지를 보존하며, 다른 질문에 답합니다 — 모든 재료 리터럴을 예전의
굴절률 그대로 둔 README 빠른 시작은 `R`의 합이 0.1753인데, 마이그레이션된
장면은 0.2053을 주며, 경고는 없습니다. 둘이 가까운 것은 논증을 위해 일부러 고른 것입니다. 시끄럽게 깨지는
마이그레이션은 스스로 드러나지만, 절단 흔들림 정도 크기의 차이는 그대로
믿어집니다. 여기서는 조용히 넘어갈 수 없으므로 거부를 택합니다. 2026-08-26부터 이 철자들은
이름으로 거부되는 대신 삭제되었습니다. 각 입구는 이제 그 철자를 실제 정체, 즉 알 수 없는 키워드,
층 키 또는 형상 키로 보고하며, 굴절률처럼 쓰인 이름(`solve()`에 넘긴 `n_top`, 형상 안의
`n_index`)에는 여전히 모든 재료 슬롯이 상대 유전율을 받는다고 알려 줍니다.

다른 물리량을 가진 호출자를 위해 두 변환 함수를 내보냅니다.

| 함수 | 값 |
| --- | --- |
| `wavebit.eps_from_refractive_index(n, mu=...)` | 등방성 재료에서 `n**2 / mu`. `mu`를 생략하면 `n**2`(상대 투자율 1)입니다. 굴절률과 투자율은 같은 파장에 대한 값이어야 합니다. 결과 `Material`에도 같은 `mu`를 할당하세요. |
| `wavebit.refractive_index_from_eps(eps)` | **주(principal)** 근이며 항상 복소수입니다. 수동 매질은 `Im(eps) >= 0`, 즉 닫힌 위쪽 반평면에 있고, 그 주근은 `Im(n) >= 0` — 역시 손실입니다. 위험은 0의 음수 쪽입니다. `complex(-2, +0.0)`은 `+1.414j`(감쇠, 올바름)를, `complex(-2, -0.0)`은 `-1.414j`(이득)를 줍니다 -- 0은 `complex()`로 명시하세요. 식 `-2 - 0j`의 허수부는 Python 3.12와 3.13에서는 `+0.0`이지만 3.14부터는 `-0.0`이기 때문입니다(3.14는 실수-복소수 혼합 연산의 실수 피연산자를 float로 변환합니다, CPython gh-69639) -- 그리고 산술 연산을 거친 무손실 값은 `4 - 1e-18j`로 나올 수 있습니다. 어느 쪽도 보정하지 않습니다. 반올림 오차와 의도적인 능동 매질을 구별할 방법이 없기 때문입니다. 근을 취하기 전에 직접 `Im(eps)`를 음수가 아니게 유지하세요. 이 경계는 모든 백엔드에서 같습니다. JAX 자체의 `sqrt(complex(-1, -0.0))`는 `+1j`(JAX 0.11.0)인 반면 NumPy, PyTorch, `cmath`는 `-1j`를 주며, `refractive_index_from_eps`는 그 지점에서 JAX의 근을 뒤집습니다([negative-index-media.md](../../theory/rcwa/negative-index-media.md) §15) |

자성 매질의 굴절률은 `sqrt(eps)*sqrt(mu)`이며, 각 근은 Maystre의 절단 위에 있습니다(모든
수동 인자에 대해서는 주근). 모든 통상 매질에서는 비트 단위까지 주근 `refractive_index_from_eps(eps*mu)`와
같고, 음의 위상 속도 매질에서는 그 정확한 부호 반전입니다 --
모든 수동 이중 음수 매질(`Re(eps) < 0`이고 `Re(mu) < 0`)과 수동 자성 금속이
여기에 해당하며 -- 이들의 주근은 이득으로 읽히기 때문입니다. 이득 금속 인자(`Re < 0`, `Im < 0`)는 두 근이
달라지는 유일한 곳이며, 거기서 자성 매질의 굴절률은 -- `mu = 1`을 명시한 경우도 포함해 --
비자성 `refractive_index_from_eps`의 부호 반전일 수 있습니다.
솔버의 `n_top` / `n_bot`은 그 부호 있는 굴절률입니다. [negative-index-media.md](../../theory/rcwa/negative-index-media.md)
§6이 어떤 매질의 부호를 뒤집는지와 그 이유를 설명합니다.

### 굴절률이 여전히 맞는 물리량인 곳

이 뒤집기는 *재료 슬롯*이 무엇을 담는지에 관한 것이며, 물리의 이름을 바꾸지는 않습니다. 굴절률은
스넬의 법칙과 반공간 관계식 `n**2 = eps*mu`에서 여전히 올바른 물리량이며,
음의 굴절률 매질에서는 `n`의 부호가 음수입니다. 흡수하는 입사 매질에서의 실수 각도는
[Real-angle incidence](#real-angle-incidence)에 설명된 대로 완전한 복소수 `eps*mu`를 사용합니다.

구체적으로, `n_top`과 `n_bot`은 여전히 존재하며 여전히 굴절률을 뜻합니다 —
**유도된 읽기 전용** 속성으로서입니다. `top`에 할당하면 재료가 저장되고
`n_top = sqrt(eps)*sqrt(mu)`(위에서 말한 부호 있는 값)가 갱신됩니다. `n_top`에 할당하면 예외가 발생합니다. 한
매질을 두 철자로 쓰고 그 둘이 어긋날 수 있는 상태야말로 이 타입이 없애려고 존재하는 상태입니다.

## Geometry and propagation

공개 직교 좌표계는 **오른손 좌표계이며 +z가 위쪽**입니다. 유한 적층의 아래 계면은
**z=0**이고 위 계면은 **z=h_total**이며, 여기서 `h_total=sum(thickness)`입니다.
`bot`은 `z<0`을, `top`은 `z>h_total`을 차지합니다. 이 반공간들은
유한 층 목록의 항목이 아닙니다.

층은 **아래에서 위로** 나열합니다. `structure[0]`은 `bot`에 인접하고,
`structure[-1]`은 `top`에 인접합니다. `thickness[i]`, 래스터 `mu[i]`, 텐서 컨볼루션
적층, `Stack.layers[i]`는 모두 같은 층을 기술합니다. 그 층의 아래쪽과 위쪽 높이는
`sum(thickness[:i])`와 `sum(thickness[:i+1])`입니다. 목록 끝에 층을 추가하면 위쪽으로 쌓입니다.

`incidence_side='top'`(기본값)은 빛을 아래쪽으로 보내고(양의 굴절률 매질에서 전파하는 파동은
`kz<0`), `incidence_side='bottom'`은 위쪽으로 보냅니다(`kz>0`). 빛이 들어오는 매질이 음의 굴절률
매질이면 위상, 따라서 `Re(kz)`는 반대 방향으로 진행하지만 빛 자체는 여전히 아래나
위로 갑니다. 어느 쪽도 기하, 인덱싱, 반환되는 필드 축을 바꾸지 않습니다. `theta`는 선택한 면의 안쪽 법선에서 잽니다.
위쪽에서는 `-z`, 아래쪽에서는 `+z`입니다. `theta`와 `phi`는 입사광이 구조를 향해
진행하는 방향이며, `phi`는 고정된 공개 좌표계에서 `+x`에서 `+y` 쪽으로 잽니다.
무손실 매질에서 실수 입사각이면
`k/k0 = n_inc * (sin(theta)*cos(phi), sin(theta)*sin(phi), sigma*cos(theta))`이며,
위쪽 입사는 `sigma=-1`, 아래쪽 입사는 `+1`이고 `n_inc`는 **부호 있는** 굴절률입니다.
음의 굴절률 매질(`n_inc < 0`)에서는 파동 벡터가 그 위상과 마찬가지로 빛의 진행 방향과 반대를 가리킵니다.
일반적인(흡수하는) 경우의 서술은 [Real-angle incidence](#real-angle-incidence)에 있습니다.

다른 방법으로, `theta`/`phi` 없이 실수 `kx`/`ky`를 역길이 단위로 직접
지정할 수 있습니다. 생략한 성분은 0입니다. 이 값들은 회절 차수 오프셋을 더하기 전 입사파의
직교 좌표 각파수이며, 파장 스윕 동안 고정됩니다. 법선 성분은
입사 쪽 가지를 써서 `kz² = (2*pi/wavelength)²*epsilon*mu - kx² - ky²`로부터 정해집니다.
재료는 여전히 필요합니다. `order_kxy()`는 차수별 k를 k0로 나눈 값을 보고하므로,
그 출력은 직접 입력과 단위가 다릅니다. [방향 입력](../../guide/rcwa/light.md#two-ways-to-specify-direction)을 보세요.

결과는 입사 기준으로 남습니다. `R`은 빛이 들어온 반공간으로 돌아가고 `T`는
반대쪽 반공간으로 나갑니다. 반사 진폭은 빛이 들어오는 계면을, 투과 진폭은
반대쪽 계면을 기준으로 합니다.

개수로 지정한 필드 표본은 높이가 증가하는 순서, 즉 아래에서 위로 진행합니다. 명시적
`sample_z` 값은 아래 계면에서 잰 절대 높이이며 호출자가 준
순서를 유지합니다. 내부 계면은 **위쪽** 층에 속합니다. 아래쪽 한계에는 `z-delta`를 쓰세요.
개수가 2 이상이면 양쪽 한계를 모두 포함하고, 개수가 1이면 각 층의 아래 면을 선택합니다.
위쪽 끝점 `h_total`은 마지막 유한
층에 속합니다. 이 규칙은 조명 방향과 무관합니다.

예를 들어 `thickness=[100., 200., 50.]`은 층 구간 `[0,100]`, `[100,300]`,
`[300,350]`을 줍니다. 첫 층은 기판 쪽에, 마지막 층은 상부 매질(superstrate) 쪽에 있습니다.

### Updating a pre-release downward-positive scene

이 규약은 2026-09-21에 위에서 아래로 가는 입력과 아래쪽이 양수인 깊이를 대체했습니다.
층 목록 **과** 그에 대응하는 모든 두께/재료 적층을 뒤집으세요. 이전의 깊이 `d`는
높이 `h_total-d`가 됩니다. 균일한 개수 격자도 z를 따라 뒤집힙니다. 이전의 아래쪽 좌표계에서
필드를 비교할 때는 `E -> (Ex,Ey,-Ez)`와 `H -> (-Hx,-Hy,Hz)`를 씁니다. 그 좌표계로 표현된 텐서는
`Q @ tensor @ Q`, `Q=diag(1,1,-1)`로 변환되며, xz/yz/zx/zy 성분의
부호가 바뀝니다. 스칼라와 면내 블록은 바뀌지 않습니다. 이 z 거울 비교를 쓸 때 x/y 패턴을 반사하거나 phi를
바꾸지 마세요. 저수준 전파 커널은 자체적인
시작/끝 방향을 유지하며, 엔진이 그 포트를 공개 아래/위 매질에 연결합니다.

직렬화된 `JobSpec` 문서는 **버전 10**을 씁니다. 이전 버전은 거부됩니다.
버전 번호만 바꾸면 비대칭 물리 적층이 조용히 뒤집힐 수 있기 때문입니다.

한 층 안에서 배열은 이미지 규약을 따릅니다. 래스터 `structure`의 행 `0`은 모든 빌더와
재구성된 필드 셀 모두에서 셀의 **아래쪽** — `-y` 끝, `y = -Py/2 + Py/(2*Ny)` 위치 — 입니다.
(2026-08-31까지는 "행 `0`은 `y = 0`"이라고 적혀 있었는데, 이는 두 가지 면에서 동시에
느슨했습니다. 당시에도 행 0의 중심은 `y = 0`에 있지 않았고, 지금은 셀이
원점을 중심으로 놓입니다.) 필드를 관례적인 방향으로 그리기 위한
뒤집기는 데이터가 아니라 그리기(`plot_field`)에 속합니다.

**재구성된 필드도 같은 위쪽 양수 xyz 좌표계를 씁니다.** 진공에서
`H = khat × E`이며, 위쪽 전력은 `Sz>0`, 아래쪽 전력은 `Sz<0`입니다. 따라서 통상적인
위쪽 입사는 음의 순 z 플럭스를, 아래쪽 입사는 양의 플럭스를 운반합니다.
exp(-i omega t) 시간 규약과 exp(+i k.r) 공간 규약은 바뀌지 않았습니다.
`tests/rcwa/test_vertical_coordinates.py`의 평면파와 계면 테스트가 이
서술들을 NumPy, JAX, PyTorch, 양쪽 입사 방향, 지원되는 모든 경로에서 검사합니다.

## 단위와 각도

`wavelength`, `period`, `thickness`와 매개변수 형상 좌표(`cx`, `lx`,
…)는 **사용자가 고른 하나의 길이 단위**를 공유합니다 — 솔버의 어느 부분도 nm를 가정하지 않습니다. 형상
좌표는 주기의 분율이 아니라 절대 길이입니다.

### 원점 하나: 셀은 원점을 중심으로 놓입니다

이 라이브러리가 받거나 돌려주는 모든 좌표는 **셀의 중심**
`0.5*(a1 + a2)`에서 잽니다. 따라서 중심에 놓인 형상은 `0`이며, `0.5*(a1 + a2)`를 손으로 쓸 일은 없습니다.

| 위치 | `0`이 뜻하는 것 |
| --- | --- |
| 형상의 `cx` / `cy` | 셀의 중심 — 이를 생략했을 때의 의미이기도 합니다 |
| `reconstruct_field`의 `sample_x` / `sample_y` | 같은 점. *개수*로 주면 셀 전체 `[-period/2, +period/2]`에 걸칩니다 |
| `wavebit.meshgrid_xy`의 `X` / `Y` | 같은 점. `structure[layer][j, i]`는 `u = (i+0.5)/Nx`, `v = (j+0.5)/Ny`에 대해 `r = (u - 0.5) * a1 + (v - 0.5) * a2`에 놓입니다 |
| `plot_structure`가 그리는 축 | 같은 점. 축은 `-P/2`에서 `+P/2`까지입니다 |

`sample_z`는 예외이며, 의도된 것입니다. `z`는 주기적이지 않고 적층에는 구별되는
점이 *있으므로*, 이는 아래 계면에서 잰 절대 높이입니다([Geometry and propagation](#geometry-and-propagation)
참고).

이것은 S4의 규약(*"the unit cell is the Wigner-Seitz cell centered at the origin"*)이자
Meep의 규약입니다. 2026-08-31에 도입되었습니다. 그 전에는 원점이 셀의 모서리였으며,
README와 `oblique-lattice.md` 모두 래스터 예제를 셀 중심을 손으로
계산하는 것으로 시작했습니다. 내부적으로 푸리에 계산 장치는 여전히 `[0, 1]` 범위의 `u, v`에 대해 적분하며,
`wavebit.lattice.sample_grid`가 그 내부 모서리 좌표계입니다. 사용자 대상 코드에서
이를 쓰면 구조가 반 주기만큼 조용히 잘못 놓입니다.

2026-09-28부터 공개된 모든 푸리에 연산자도 중심을 씁니다.
`coeff_g = (1/A) ∫ eps(r) exp(-i g·r) dr`이며, `r`은 이 원점에서 잽니다.
`eps_conv_matrices()`, `mu_conv_matrices()`, 공개 NVF 빌더, `solve_conv()`의 입력은
그 좌표계를 공유합니다. `ConvMatrices.from_energy()`는 입력의 좌표계를
보존하므로, 그 출력을 `solve_conv()`에 쓰려면 중심 좌표계 계수를 넣으세요.
비공개 빌더와 `_solve_conv()`는 커널의 모서리 좌표계를 씁니다. 두 좌표계 사이에서
연산자를 다시 표현하려면 `C * np.outer(d, d)`를 쓰세요. 여기서 `d = (-1.)**(m+n)`이며 유지
차수 레이블 순서를 따릅니다. 구현은 이 `D C D` 닮음 변환에 정확한 부호 뒤집기를 씁니다.
통상의 `solve()`는 전적으로 비공개 경로에 머뭅니다.

2026-09-27부터 모든 차수별 물리량의 **위상**도 여기를 기준으로 합니다.
진폭(`r_s` .. `t_p`, `r_xyz` / `t_xyz`, `order()`), `excitation` 가중치,
산란 행렬의 포트 변수, 그리고 통상 입사가 단위 크기가 되는 점,
즉 빛이 들어오는 면의 `x = y = 0`([the result surface](#the-result-surface)의
위상 기준 항목)이 그렇습니다. 공개 컨볼루션 행렬도
2026-09-28에 뒤따랐으므로, 모든 공개 차수별 위상과 공개된 모든 푸리에 계수가
여기를 기준으로 합니다. 중심은 사용자가 쓴 기저에 속합니다. 행렬식이 ±1인(unimodular) 기저 변환
`(a1, a2) -> (a1, a1 + a2)`는 `(a1 + a2)/2`를 `a1/2`만큼 옮깁니다.
같은 공개 숫자 — 형상 중심, 표본점 — 를 유지하면 위상 기준을 포함해 장면 전체가
평행 이동하므로 필드는 바뀌지 않습니다. 같은 물리적 결정을 같은
물리적 점에서 표본화하면(형상과 표본을 `-a1/2`만큼 이동) `theta != 0`에서 필드가
`exp(-1j k_inc . a1/2)`만큼 달라지며, 효율은 달라지지 않습니다. 두 서술 모두 절단이
수렴할 때 성립합니다. 두 기저는 서로 다른 차수 집합을 유지하기 때문입니다.

모든 각도는 **라디안**입니다.

| 각도 | 의미 |
| --- | --- |
| `theta` | 입사 **빛**의 극각으로, 입사 매질의 안쪽 법선에서 잽니다. 굴절률 부호와 관계없이, 무손실 매질에서 빛의 전력이 진행하는 방향입니다. 실수 각도는 표면을 따라 균일한 입사 세기를 지정합니다. [Real-angle incidence](#real-angle-incidence)를 보세요 |
| `phi` | 입사광 방향의 방위각으로, `+x` 축에서 잽니다 |
| `psi` | 편광: **k**에 수직인 평면에서 p 방향으로부터 잰 **E**의 각도. `psi = pi/2`는 순수 s(TE 유사), `psi = 0`은 순수 p(TM 유사)입니다. **실수** — 복소수 `psi`는 거부됩니다. 아래를 보세요 |
| `chi` | 타원율 각도: `tan(chi)`는 편광 타원의 단축/장축 비이며 그 부호는 회전 방향입니다(`chi > 0`은 `(1, -1j)`처럼 돕니다. 아래의 "원형 편광 상태가 도는 방향"을 보세요). `chi = 0`은 선형(`psi` 표기), `|chi| = pi/4`는 원형입니다. `psi`처럼 실수입니다. 이 이름을 쓰면 `(psi, chi)` 좌표계가 선택됩니다 — 아래를 보세요 |
| `tetm` (1D 전용) | `'te'` / `'tm'` — 각도가 아니라 **선언**입니다. 이 문제에 편광 자유도와 방위각 자유도가 없다는 뜻이며, 그 덕분에 순수 1D TE/TM 정식화가 합법이 됩니다(측정상 conical보다 2-4배 빠름). 2D 셀에서, `truncation_order[1] != 0`과 함께, 또는 0이 아닌 `phi` / `psi` / `polarization` 옆에서는 거부됩니다. 또한 순수 1D 경로를 탈 수 없는 모든 계산에서 이름으로 거부됩니다 — 형상 구조, 텐서 재료, `solve_conv`에 넘긴 z 행, `formulation='first_order'`, 또는 순수 계산이 아닌 계산 뒤에 구조가 없는 경우입니다(구조를 갖지 않은 솔버는 마지막 계산이 취한 레이아웃을 유지하며, 계산한 적이 없으면 2D입니다. 유지된 순수 레이아웃은 그것을 고른 래스터가 검사받았던 것처럼 `phi`, `ky`, 셀의 기울기, `truncation_order[1]`을 다시 검사합니다). 2026-09-27부터입니다. 그 전에는 텐서를 제외한 모든 경우가 계산 깊은 곳에서 `TypeError`를 일으켰거나 — 생성 후에 `tetm`을 할당한 경우 — 어느 쪽을 지정했든 s 빛에 대한 답을 냈습니다. 이 선언 아래에서 `psi`는 `None`으로 읽힙니다 — 선언으로 없앤 자유도는 기본값을 갖는 것이 아니라 존재하지 않습니다. `phi = 0`에서 `polarization=(1, 0)` / `(0, 1)`이 하는 것과 정확히 같은 빛을 비추고 같은 것을 보고하며, 그 차이는 ~1e-14입니다. 같은 차수별 s/p 좌표계의 같은 진폭, 같은 `excitation` 가중치, 같은 단위 E 입사 필드입니다. 그 산란 행렬은 같은 포트 변수로 표현된 conical 산란 행렬의 s-s / p-p *블록*입니다. 이것이 담지 않는 것은 다른 편광입니다. `s_inc` / `p_inc`는 `None`이며, 교차 편광 진폭은 conical 경로에서 ~1e-16인 곳에서 정확히 0입니다. 2026-09-27부터입니다. 그 전에는 모든 차수에서 `E_y` / `H_y`를 인용했고(`kx = 0`을 가로질러 입사 차수와 반대편의 모든 차수에서 부호가 달랐습니다), 어떤 각도에서든 `+y`로 조명했으며, TM 입력은 단위 `H_y`였습니다. 현재의 `PlaneWave(polarization='s')` / `'p'`는 같은 빛에 답하는 곳이면 어디서든 같은 순수 경로를 타며, 절대 거부되지 않습니다(2026-11-03부터. ### Real-angle incidence

실수 `theta`와 `phi`에서 입사파는 **구조 표면을 따라 균일한 세기**를 가집니다.
즉 두 가로 성분 `kx`, `ky`가 모두 실수입니다. `theta`와 `phi`는 가상의 외부 매질이 아니라
빛이 들어오는 반공간 자체를 기준으로 합니다. 이는 단일
평면파를 기술합니다. `excitation`으로 공급한 여러 파동은 한 셀 안에서 간섭할 수 있으며,
가로 파동 벡터가 실수이면 그 세기는 셀마다 반복됩니다.

등방성 입사 재료에 대해 `epsilon_r * mu_r = a + i*b`,
`k0 = 2*pi/wavelength`로 쓰고, 부호 있는 굴절률
`n = sqrt(epsilon_r)*sqrt(mu_r)`에 대해 `s = sign(Re(n))`으로 씁니다(이중 음수 매질 같은
음의 위상 속도 매질을 제외한 모든 매질에서 `+1`). 위상 크기 `N = |Re(k)|/k0`는 다음과 같습니다.

$$
N^2 = \frac{a + \sqrt{a^2 + b^2/\cos^2\theta}}{2},
\qquad
k_x=s\,k_0N\sin\theta\cos\phi,\quad
k_y=s\,k_0N\sin\theta\sin\phi.
$$

따라서 `theta`와 `phi`는 **`s * Re(k)` 방향**의 각도, 즉 입사파의 위상
방향을 빛이 가는 쪽을 가리키도록 돌린 것입니다. 양의 굴절률 매질에서는 그것이 위상
방향 자체이며, 흡수 매질에서의 실수 각도 입사가 도입된 이후 이 각도가 줄곧 뜻해 온 것입니다.
음의 굴절률 매질에서는 위상이 전력과 반대 방향으로 진행하므로(V. G. Veselago,
Sov. Phys. Usp. 10, 509 (1968)), 같은 빛의 면내 파동 벡터는
`phi + pi` 방향입니다. 굴절률 부호와 관계없이 **무손실** 매질에서 `s * Re(k)`는 포인팅 벡터의
방향이고, `theta`는 정확히 입사 전력이 진행하는 방향이며, 공식은
부호 있는 `n`에 대해 `kx = k0*n*sin(theta)*cos(phi)`로 줄어듭니다. Veselago와
J. B. Pendry(Phys. Rev. Lett. 85, 3966 (2000))가 쓴 형태의 스넬의 법칙입니다. `n = -sqrt(2)`에서 20도로
유리에 비추면 빛은 -18.81도로 나갑니다.

이는 Wavebit이 고른 규약입니다 -- 입사 전력의 방향, 즉 포인팅 벡터로,
무손실 매질에서는 정확하고 흡수 매질에서는 `s * Re(k)`의 각도입니다 -- 인과율에 관한
서술이 아닙니다. 음의 굴절률에 대한 인과율 기반 판정 기준은 군속도를 검사하는데, 군속도는
포인팅 벡터가 아닙니다(P. Kinsler and M. W. McCall, Phys. Rev. Lett. 101, 167401 (2008)).
이중 음수 매질 내부의 입사각을 정의하는 출판된 문헌은 찾지 못했습니다. PyMoosh
(D. Langevin et al., J. Opt. Soc. Am. B 41, A67 (2024))는 대신 위상의 각도를 취하므로,
무손실 이중 음수 매질에서 주어진 `theta`에 대한 그 `kx`는 Wavebit의 값의 부호 반전입니다(흡수하는
이중 음수 매질에서는 복소수이며 실수부의 부호가 반대입니다). 두 솔버는 `theta`가 아니라
`kx`로 비교하세요([`negative-index-media.md`](../../theory/rcwa/negative-index-media.md) §7).

`N`은 안쪽 법선 성분을 `q/k0 = N*cos(theta) + i*alpha`(
`s = -1`이면 `-N*cos(theta) + i*alpha`)로 쓰고 분산 관계의 두 부분을 모두 부과해 얻습니다.
`N**2 - alpha**2 = a`, `2*s*N*cos(theta)*alpha = b`입니다(`b`는 `N`에 제곱으로만 들어가므로 `N` 하나가
두 부호 모두에 쓰이며, 모든 수동 매질에서 `alpha`는 양수로 나옵니다). 완전한 복소수
재료를 사용합니다. 이것은 `sqrt(real(epsilon_r))`가 아닙니다. 법선
파동 벡터는 `kz**2 = k0**2*epsilon_r*mu_r - kx**2 - ky**2`를 만족하며 반공간 자신의
근입니다(Maystre의 절단, 또는 이중 음수 매질에서는 그 거울상: [`branch-cuts.md`](../../theory/rcwa/branch-cuts.md)
§8, §9). 따라서 굴절률 부호와 관계없이 흡수 매질에서 입사파는 구조를 향해 감쇠합니다.
통상 매질의 입사 `kz`는 위쪽 입사에서 음수, 아래쪽 입사에서 양수입니다.
음의 굴절률 매질에서는 그 실수부의 부호가 반대입니다. 결과는 각
출사 차수의 법선 성분을 같은 직교 좌표 부호로 `DiffractionOrders.k_normal`에 보고합니다.
통상 매질에서 위쪽 포트로 나가는 차수는 `Re(k_normal) > 0`이고 아래쪽으로 나가는 차수는 `< 0`입니다.

**흡수** 매질에서 포인팅 벡터는 손실과 편광으로 정해지는 양만큼 `s * Re(k)`에서
벗어나며, 각도는 이를 되돌리려 하지 않습니다(편광에 따라 달라지는 전력 방향으로는
두 편광 모두에 대해 하나의 `k_par`를 고정할 수 없습니다). 45.8도에서 `epsilon_r = 2+0.5i`는
p 빛을 44.1도로, s 빛을 45.8도로 운반합니다. 금속(`-10+1i`)은 p 빛을
법선 너머 -45.5도로 운반합니다([`negative-index-media.md`](../../theory/rcwa/negative-index-media.md) §7에
표가 있습니다). 흡수 매질의 실수 각도 정의는 `abs(theta) < pi/2`를 요구합니다. 그 파동 벡터는
스치듯 입사에서 발산합니다. 파동을 전혀 운반하지 않는 입사 매질(`b = 0`, `a <= 0`)에는 실수
각도가 없으며, 실수 각도를 주면 거부됩니다.

**범위.** 실수 `theta`는 안쪽 법선에서 재므로 `[-pi/2, pi/2]` 안에 있습니다.
직각을 넘으면 빛은 구조에서 멀어지는 쪽으로 진행할 것입니다. 검사는
`abs(theta) > float32(pi/2)`인 실수 `theta`를 `source.direction`과 함께 거부합니다(이 경계는 단정밀도
스치듯 입사각을 허용합니다). `phi`에서의 `theta = -t`는 `phi + pi`에서의 `theta = t`의 파동 벡터입니다.
`abs(Re(theta)) >= float32(pi/2)`에서 엔진은 법선 양쪽 모두에서 `sin(theta)`를 스치듯 입사 값으로
고정하며, 검사가 읽을 수 없는 추적된(traced) 각도도 같은 처리를 받습니다. 2026-11-09까지는
`-pi/2`를 넘는 음의 각도는 대신 `sin`으로 접혔고(`theta = -2`가 `-(pi - 2)`로 조명됨),
양의 각도는 스치듯 입사 값으로 고정되었습니다. 이 경계는
`src/wavebit/_common/conventions.py`의 `REAL_THETA_LIMIT`입니다.

**음의 굴절률 입사 쪽.** `Re(eps) < 0`, `Re(mu) < 0`이고
`Re(eps*mu) > 0`인 반공간은 빛이 들어오는 쪽이든 아니든 계산됩니다. 그 근은 Maystre 절단의 거울상(감쇠하는
근, 무손실 전파 차수에서 `Re(kz) < 0`)이고 그 굴절률은 Veselago의 음의 굴절률입니다
(`branch-cuts.md` §9, [`negative-index-media.md`](../../theory/rcwa/negative-index-media.md) §5와 §6. 같은 문서
§7은 `theta`가 위상의 방향이 아니라 빛의 방향을 가리키는 이유도 설명합니다). 정확히
`theta = 0`에서 차수별 좌표계는 `k_par` 방향의 극한 `theta -> 0+`를 취하며, 이는 그곳에서
`phi + pi`이므로 입사 필드는 수직 입사를 지나며 연속입니다. 능동 매질
(`Im(eps) < 0` 또는 `Im(mu) < 0`)은 설정되는 곳에서 거부됩니다.

**0이 아닌 허수부**를 가진 각도는 고급 조명을 위해 형식적인
`kx/k0 = n*sin(theta)*cos(phi)`, `ky/k0 = n*sin(theta)*sin(phi)`
매개변수화를 같은 부호 있는 `n`으로 유지합니다. 이 복소수
매개변수는 실수 각도의 의미를 갖지 않습니다. `0.4+0j` 같은 값은 실수 각도입니다.
무손실 매질에서는 `Im(theta) -> 0`일 때 둘이 만나지만, 흡수 매질에서는 실수 각도 경계를 가로질러
서로의 해석적 연속이 아닙니다(`N` 대 복소수
`n`). 실수 각도 모델을 미분할 때는 실수 각도 변수를 쓰세요.

그 매개변수화가 가로 파동 벡터에 0이 아닌
허수부를 남기면 입사 세기가 표면을 따라 변합니다. 소멸파
입사 `theta = pi/2 + 1j*alpha`는 그런 경우가 아닙니다. 그 `kx`는 실수입니다
(아래 참고). 이때 차수별 `R`과 `T`는 입사 전력의 분율이 아니라
형식적인 비율이며, 무손실 적층에서 그 합이 1을 넘을 수 있습니다. `power_entering`과
`absorption`은 NaN이며, 그런 계산마다
`wavebit.rcwa.diagnostics.ComplexIncidenceWarning`이 발생합니다.
복소수 `kx`에서 출사 매질이 `kz`의 어느 근을 취하는지는 규약이며,
다른 솔버는 다르게 고릅니다(`docs/validation/rcwa/time-convention-audit.md` §9). 이것이
복소수 가로 파동 벡터로 가는 유일한 경로입니다. 직접 지정한 `kx`/`ky`는
실수여야 하며, 복소수를 거부할 때 이 경로를 알려 줍니다. `ky = 0`이면
`theta = arcsin(kx/(k0*n))`, `phi = 0`입니다. 직접 지정한 `kx`/`ky`는 각도를 갖지 않으며 입사 매질이 무엇이든
주어진 그대로 받아들여집니다. `kx = ky = 0`에서 그 s/p 기저는 방위각 0을 씁니다.

**소멸파 입사**는 입사 매질의 빛선(light line) 너머의 실수 `kx = n*cosh(alpha)`를 가집니다.
무손실 입사 매질에서 그 `kz`는 허수이므로 입사파는 법선 방향 전력을 운반하지 않고
아무것도 그것으로 나눌 수 없습니다. `R`, `T`와 그 s/p 부분, `power_entering`,
`absorption`은 NaN입니다. 진폭과 필드는 변경 없이 반환됩니다.

W 단위의 포트 전력은 비율이 아니며, `rcwa.run` 결과는 이를 유지합니다. 빛은
먼 쪽에 실제로 도달합니다. 입사파와 정반사파는 각각 법선 방향 전력을 운반하지 않지만, 그
간섭은 운반하며, 무손실 적층에서 빛이 들어오는 면을 지나는 순 플럭스는
투과 전력과 같습니다. 좌절된 내부 전반사(frustrated total internal reflection)와 같습니다. 파장별 두 플래그가
`metadata`에서 어떤 값이 존재하는지 알려 줍니다. 회절 출력이 없는 실행을 위해 `diagnostics`도
이를 `port_power_defined`와 `efficiency_defined`로 담습니다.

| | `power_defined` | `efficiency_defined` |
| --- | --- | --- |
| 실수 `kx`, 전파하는 입사 | true | true |
| 소멸파 입사 | true | false |
| 복소수 `kx` | false | false |

`power_defined`는 포트 전력을 제어합니다. 복소수 `kx`에는 균일 세기 셀 적분이 없습니다.
`efficiency_defined`는 `efficiency`, `reference['incident_power']`, `power_entering`,
`absorption`을 제어하며 `power_defined`를 함의합니다. `incident_power`는 입사파의 참값 0이 아니라
NaN입니다. 포트 전력은 파동별이어서 터널링된 전력을 운반하는 간섭을
빠뜨리기 때문입니다. `incident - reflected - transmitted`는 이를 음의 흡수로 읽게 됩니다.
W 값은 적층의 입사 면에서의 단위 진폭당 값입니다. 그 진폭을 적층에서
거리 `d`만큼 더 먼 곳에서 선언하면 값이 `exp(-2*Im(kz)*d)`배가 되며, 여기서 `kz`는 입사
매질의 법선 파수입니다. p 빛에서 `|E|`는 진폭의
`sqrt(cosh(2*alpha))`배입니다. 참된 효율에는 전파하는 입사파가 필요합니다.
예를 들어 프리즘 매질을 입사 반공간으로 쓰면 되며, 이 솔버는 그 경우를 정확히 계산합니다.

이 판정은 정확한 0이 아니라 반올림 하한입니다. 배정밀도에서 `cos(pi/2)`는 `6.1e-17`이므로,
`kx`에는 가로 방향 판정이 반올림으로 받아들이는 허수부가 남고,
이는 `Re(kz)`를 `6e-17*|kx|` 근처에 남깁니다. 그 값으로 나누면 `T`가 한때 `1e16` 근처로 나왔고,
그 부호는 `alpha`의 부호로 정해졌습니다([#84](https://github.com/fieldalgo/wavebit/issues/84)).
NaN에는 경고가 따르지 않습니다. NaN이 스스로를 표시하기 때문이며, 경고를 낼 수 없는 `jax.jit` 계산도
같은 값을 표시합니다. 전력을 운반하지 않는 차수를 조명하는 `excitation`이나 직접 지정한 `kx`/`ky`는
그 값을 읽을 수 있는 곳이면 어디서든 대신 거부됩니다. `jax.jit` 아래에서는 어느 거부도
실행될 수 없습니다. 계산은 같은 방식으로 표시되고, 커널은 0인 입사
전력 대신 1로 나눕니다. 따라서 플래그로 선택하는 손실 `jnp.where(efficiency_defined, T, 0)`은
그곳에서 NaN이 아니라 0의 그래디언트를 가지며, 입사 전력이 있는 계산은 자신의 값과
그래디언트를 유지합니다. 이 소멸파 빛이 중요한, 적층 내부에서
방출되는 빛은 다른 계산입니다
([#85](https://github.com/fieldalgo/wavebit/issues/85)).

`order_kxy()`는 유지된 각 차수에 대한 역격자 이동을 포함해 **`k0`로 나눈** 파동 벡터를
반환합니다. 물리적 역길이 단위가 필요하면 `2*pi/wavelength`를
곱하세요. 예시는 [빛 입력](../../guide/rcwa/light.md#what-theta-and-phi-mean)을
보세요.

### 일반(타원) 편광

`polarization = (a_s, a_p)`는 입사 편광을 복소수 **E-필드 진폭** 쌍으로 기술하며,
`psi` 및 반환되는 진폭과 같은 (s, p) 기저를 씁니다.
`(1, 0)`은 순수 s, `(0, 1)`은 순수 p이며, `psi = v`는 정확히
`polarization = (sin(v), cos(v))`입니다. 이 쌍이 더해 주는 것은 `psi`로는 쓸 수 없는
상대 위상입니다 — `(1, -1j)/sqrt(2)`와 `(1, +1j)/sqrt(2)`가 두 원형 편광 상태입니다.

- `psi`와 `polarization`은 상호 배타적입니다. 둘 다 지정하면 덮어쓰기가 아니라
  오류입니다.
- 쌍은 유클리드 노름으로 나뉘므로, 사용자가
  `|a_s|^2 + |a_p|^2 = 1`을 맞출 필요는 없습니다. 전체 위상은 유지됩니다. 이 계수
  정규화가 물리적 전력을 1로 맞추지는 않습니다. 솔버는 매질, 편광, 조명된 차수를 써서
  입사 전력을 따로 계산한 뒤, 반사 전력과 투과 전력을 그 값으로 나눕니다.
- 쌍이 주어진 1D 구조는 conical 경로로 계산됩니다(순수 1D TE/TM 경로는
  구성상 단일 편광입니다). 답은 같은 물리이며 비용은 conical의 비용입니다.
- **복소수 `psi`는 거부되며, 이 중 어느 것으로 가는 지름길도 아닙니다.** `(sin, cos)`는
  실수 각도에서만 단위 쌍입니다. `Im(psi) = b`이면 입사 플럭스가 `cosh(2b)`가 되고
  모든 효율이 그 인자를 갖게 됩니다 — 흡수 적층에서는 이것이 보이지 않으며, 측정된 사례는
  올바른 답 `0.647`에 대해 `R + T = 0.998`을 반환했습니다. 원형 편광 상태에 도달할 수도 없습니다.
  `a_s/a_p = tan(psi)`인데 `tan(z) = ±i`에는 해가 없으므로(이는 `exp(±iz) = 0`으로
  줄어듭니다), 원형 편광 상태는 정확히 `tan`이 빠뜨리는 두 값입니다 — `Im(psi) -> ±inf`일 때만
  다가가며, 진폭은 같은 속도로 발산합니다. 이 때문에 `psi`는 실수 dtype으로 저장됩니다.
  복소수 값이 기능인(소멸파 입사) `theta`와 다른 점입니다. 자동 미분의 잎 변수도 그에 따라 실수입니다.

#### 정준 좌표: `(psi, chi)`

쌍이 규범적인 표기이지만, *움직일* 때 쓸 표기는 아닙니다. 편광 상태에는 정확히
두 자유도가 있고, `(psi, chi)`는 그 표준 좌표입니다. `2*psi`와
`2*chi`는 푸앵카레 구면의 경도와 위도이므로, 두 각도는 모든 상태를
한 번씩 덮으며 정규화할 것이 없습니다.

```
a_s = sin(psi)*cos(chi) + i*cos(psi)*sin(chi)
a_p = cos(psi)*cos(chi) - i*sin(psi)*sin(chi)
```

`chi = 0`은 `(sin psi, cos psi)`를 돌려줍니다 — 이 좌표계는 자신이 확장하는 각도를 포함합니다 — 그리고
`chi = ±pi/4`는 두 원형 편광 상태를 줍니다. 이 좌표가 담지 않는 것은 전체 위상인데,
이는 쌍에는 있고 상태에는 없는 세 번째 실수입니다. 그래서 쌍이 규범으로
남고, `chi`가 `tetm`과 그렇듯 둘이 상호 배타적입니다.

둘을 모두 두는 이유는 최적화입니다. 쌍의 네 실수 중 둘은 구조적으로
무의미합니다. 전체 크기는 나눠져 사라지고, 전체 위상은 어떤 전력도 움직이지 못합니다.
`(psi, chi) = (0.4, -0.2)`에서 2D 격자로 측정한 값은 다음과 같습니다.

| 방향 | `d(sum T)/d` |
| --- | --- |
| `psi` | `+0.048772` |
| `chi` | `+0.075185` |
| 쌍의 전체 크기 | `2.4e-16` |
| 쌍의 전체 위상 | `-1.8e-16` |

따라서 날 것의 쌍에 대한 최적화기는 차원의 절반을 답을 바꿀 수 없는 방향에
쓰는 반면, `(psi, chi)`는 평범한 제약 없는 2D 문제입니다. 두 좌표 모두
모든 백엔드에서 미분 가능하며 JAX에서 둘 다 pytree 자식입니다.

`chi = 0`은 정확히 `psi` 표기입니다 — 단지 같은 값이 아니라 비트 단위로 동일합니다. 두 각도 형식은
구성상 단위 크기이므로(`cos^2(chi) + sin^2(chi) = 1`) 어느 쪽도 정규화하지 않습니다.
스스로 계산한 노름으로 나누면 오차를 없앨 수는 없고 더할 수만 있습니다(`sqrt(...)`는
각도에서 최대 반 ulp, 좌표계에서 최대 1.5 ulp만큼 `1.0`을 벗어납니다). **직접 쓴
`polarization` 쌍만 정규화합니다.** 라이브러리가 고르지 않은 크기를 담을 수 있는 것은 그것뿐이기 때문입니다.

#### 원형 편광 상태가 도는 방향

위의 행들은 일부러 "왼쪽"이나 "오른쪽"이라고 말하지 않습니다. 두 명명 진영이
*같은 물리적 필드*에 대해 서로 다르게 말하기 때문입니다(광학은 수신자의 관점에서,
IEEE는 소스의 관점에서 손잡이를 정하므로 광학의 RCP가 **곧** IEEE의 LHCP입니다). 그래서 API는
날 것의 쌍을 받고, 이 생태계의 모든 솔버도 그렇게 합니다. 하지만 물리적 회전
자체는 이 페이지가 이미 고정한 규약으로 완전히 결정되므로, 여기 적습니다.

유도, `phi = 0`인 수직 입사에서: (s, p) 기저는 직교 좌표로
`E = (E_x, E_y) = (-a_p, a_s)`에 대응합니다(
`tests/rcwa/test_uniform_anisotropic.py`에서 측정한 보정: `t_s = E_y`, `t_p = -E_x`). 그러면 쌍
`(1, -1j)/sqrt(2)`는 전역 위상을 제외하면 `E ∝ x̂ - i·ŷ`이며, 이 라이브러리의
`e^{-iωt}`에서는 다음과 같습니다.

```
E(t) = Re[(x̂ - i·ŷ)·e^{-iωt}] ∝ x̂·cos(ωt) - ŷ·sin(ωt)
```

그 회전 벡터는 `-ẑ`입니다. 위쪽 입사에서 파동은 `-z`로 진행하므로 둘은
평행합니다. 아래쪽 입사에서 파동은 `+z`로 진행하므로 반평행합니다. 위의
직교 좌표 수직 입사 기저는 양쪽에서 같으므로, 진행 방향에 대한 손잡이는
조명 방향에 따라 달라집니다. 명시하면 다음과 같습니다.

| 쌍 | 회전 벡터 | 위쪽 입사 (`k` 아래 방향) | 아래쪽 입사 (`k` 위 방향) |
| --- | --- | --- | --- |
| `(1, -1j)/sqrt(2)` | `-z` | k와 평행: 광학 LCP, IEEE RHCP | k와 반평행: 광학 RCP, IEEE LHCP |
| `(1, +1j)/sqrt(2)` | `+z` | k와 반평행: 광학 RCP, IEEE LHCP | k와 평행: 광학 LCP, IEEE RHCP |

`chi`는 `psi`와 상관없이 같은 표를 따릅니다. `chi > 0`은 `(1, -1j)/sqrt(2)`처럼,
`chi < 0`은 `(1, +1j)/sqrt(2)`처럼 돕니다(수직 입사에서 이 좌표계의 회전 벡터는
`-sin(2*chi) ẑ` 방향입니다).

2026-09-21까지는 `+z`가 적층 안쪽 아래를 가리켰고 위쪽 입사는 `+z`로 진행했으므로,
위쪽 열이 반대로 읽혔습니다. `(1, -1j)/sqrt(2)`는 반평행, 광학 RCP였습니다.
`+z`가 위를 향하게 되었을 때 진폭은 바뀌지 않았습니다. 바뀐 것은 좌표계이며, 그와 함께 모든 쌍이 가리키는 물리적
필드도 바뀌었습니다. 튜토리얼 6은 테스트 모음이 통과한 상태로 2026-09-27까지 옛 이름을 유지했습니다.

세 개의 고정점이 이 문단을 한 번 유도하고 표류하게 두는 대신 정직하게 유지합니다. 위의 기저
보정, 자이로트로픽(gyrotropic) 고유 상태 테스트
(`tests/rcwa/test_polarization.py::test_each_circular_pair_is_one_faraday_eigenstate`) —
`eps = [[ε_d, iγ], [-iγ, ε_d]]`인 층에서 `(1, -1j)/sqrt(2)`가 `ε_d + γ`를 보는 상태임을
고정합니다 — 그리고 필드에서 측정한 표 자체
(`tests/rcwa/test_polarization.py::test_a_circular_state_turns_as_the_table_says`와
`::test_the_solved_field_turns_the_same_way`)입니다. 후자는 한 주기 동안 추적한 `Re[E e^{-iωt}]`를
양쪽에서 포인팅 벡터와 비교합니다. 거울 반사된 좌표계를 볼 수 있는 것은 세 번째뿐입니다. 앞의
둘은 `xy` 평면에 있고, 좌표계를 `z -> -z`로 다시 이름 붙여도 그대로이기 때문입니다. 이는
모든 진폭, 효율, 회전(curl) 잔차가 그대로인 것과 같지만, 모든 헬리시티는 뒤집힙니다.
그리고 흔한 경계면 경고는 다른 모든 진폭과 마찬가지로 존스 벡터에도 그대로 적용됩니다.
`e^{+jωt}` 출처에서 인용한 쌍은 우리 쌍의 켤레 복소수이며, 그
손잡이 레이블도 함께 뒤집힙니다.

## 회절 차수

유지 차수는 `m = -half_width_u..half_width_u`, `n = -half_width_v..half_width_v`이며, 양의 변을 가진
축 정렬 셀에서 정규화된 면내 파동 벡터는 `kx_m/k0 = kx_inc/k0 + m*lambda/period_x`입니다
(`ky_n`도 마찬가지). 음의 변을 가진 대각 기저를 포함한 다른 모든 기저에서는
차수 `(m, n)`이 쓰인 그대로의 기저에 대해 `k_inc + m*b1 + n*b2`를 가집니다. 입사 성분은
[Real-angle incidence](#real-angle-incidence)를 따르며, 위쪽 입사에는 `top`, 아래쪽 입사에는 `bot`을
씁니다. 무손실 입사 매질에서는 이것이 부호 있는 `n_inc`를 쓰는 통상의
`kx_inc/k0 = n_inc*sin(theta)*cos(phi)`입니다. 차수별
배열의 모양은 `(n_orders_v, n_orders_u)`입니다 — **`y`가 먼저이며, `truncation_order=[x, y]` 입력
순서의 전치입니다** — 입사 차수는 중앙 `[half_width_v, half_width_u]`에 있고 `m`은
마지막 축을 따라 증가합니다.

`result.order(m, n)`은 모든 차수별 물리량을 차수 인덱스 자체로 인덱싱하므로,
사용자 코드는 앞 문단을 알 필요가 없습니다.

### 두 규칙과, 둘이 만나는 곳

전체 공개 인터페이스에서 측정해 보면, 규칙은 정확히 둘이며 어느 쪽에도 예외가 없습니다.

| | 순서 |
|---|---|
| **배열 축** | `v`가 먼저 — `structure`, `meshgrid_xy`, `R`, `T`, `r_s`, `reconstruct_field`, `slice_structure`, 그리고 `S11`의 평탄화 인덱스 |
| **손으로 쓰는 쌍** | `x`가 먼저 — `period`, `truncation_order`, `order(m, n)`(그 `m`은 `u`) |

어느 쪽도 이 패키지가 고른 것이 아닙니다. 배열 축은 numpy의 것입니다 — 행이 먼저이며, 이는
`np.meshgrid`의 기본 동작이자 행렬을 타이핑할 때의 순서이므로, 적어 놓은 래스터는
그것이 나타내는 그림처럼 읽힙니다. 손으로 쓰는 쌍은 사람들이 타이핑하는 방식이며, 쌍을 받는
모든 솔버가 x를 먼저 받습니다.

둘은 `truncation_order`에서 만나며, 그 만남이 독자가 실수하는 곳입니다.
`truncation_order=[4, 1]`은 `R.shape == (3, 9)`를 줍니다. 앞의 4가 **뒤쪽** 축의 크기를 정합니다.
`[5, 2] -> (5, 11)` 같은 숫자에서는 더 헷갈립니다. 반복된 5가 잘못된 해석을
확인해 주는 것처럼 보이기 때문입니다.

두 끝에서 두 가지가 이를 해결합니다. 어느 쪽도 배열을 옮기지 않습니다.

```python
truncation_order = dict(u=4, v=1)      # no position to misread
period           = dict(x=700., y=1100.)

r.orders_u                             # [-4 .. 4], the order each *column* of R is
r.orders_v                             # [-1, 0, 1], the order each *row* is
R.shape == (len(r.orders_v), len(r.orders_u))
```

레이블을 잘못된 방향으로 짝지으면 그럴듯한 숫자가 아니라 길이 불일치가 납니다.
레이블은 **유지된** 창에서 읽으므로, 창을 옮기거나 넓힌 `excitation`은
이미 반영되어 있습니다.

`x`와 `y` 대신 `u`와 `v`를 쓰는 이유는 차수 축이 셀을 따르기 때문입니다. `u`는
`a1`을 따라, `v`는 `a2`를 따라 진행하며, 직사각형 셀에서는 이들이 *곧* x와 y입니다 — 60도 육각 격자에서
`m += 1`은 `(dkx, dky)`를 `(+0.600, -0.346)`만큼 옮기며, 어느 축 방향도 아닙니다. 따라서
`truncation_order=dict(x=, y=)`는 기울어진 셀에서 `AxisNameWarning`과 함께 `u`/`v`로 읽힙니다. 계산은
요청한 그대로이고 이름만 틀렸을 뿐입니다. `period`에는 그런 주석이 필요 없습니다 — 이는 셀의 축 정렬
표기이며, 기울어진 셀은 대신 `lattice=`로 들어옵니다.

## The result surface

**대문자는 전력, 소문자는 진폭입니다.**

| 이름 | 의미 |
| --- | --- |
| `R`, `T` | 차수별 회절 효율: 입사 매질로 돌아오는 전력 / 먼 쪽으로 나가는 전력을 입사 전력에 대한 분율로 나타낸 값 |
| `R_s`, `R_p`, `T_s`, `T_p` | 같은 값을 출사 편광별로 분해한 것. `R = R_s + R_p` |
| `power_entering` | 입사/반사 간섭을 포함해 유한 적층으로 들어가는 스칼라 순 전력을, 빛이 들어오는 계면에서의 입사파만의 전력으로 나눈 값 |
| `absorption` | 모든 유한 층에서 흡수된 스칼라 전력을 입사파만의 전력으로 나눈 값: `power_entering - T.sum()`. 두 반공간은 제외합니다 |
| `r_s`, `r_p`, `t_s`, `t_p` | 복소 **프레넬 진폭**: 단위 입사 E-필드에 대한 E-필드 비율로, 교과서의 프레넬/Airy 계수와 직접 비교할 수 있습니다(흡수 매질을 포함해 그 계수에 대해 1e-12까지 고정) |
| `r_xyz`, `t_xyz` | 같은 출사파를 **직교 좌표 E 벡터**로 나타낸 것으로, 모양은 `(n_orders_v, n_orders_u, 3)`이며 `(Ex, Ey, Ez)`가 마지막입니다. 고정된 공개 좌표계에서 `r_s * s_hat + r_p * p_hat`입니다. 차수별 좌표계가 없으므로 한 차수의 `kx`가 0을 가로지르는 곳에서도 연속입니다 |
| `incident`, `s_inc`, `p_inc` | 실제 입사 상태에 대한 응답과, 결합된 계산으로 구한 순수 s 및 순수 p 변형. 편광을 생략하면 순수 s가 선택되며 `incident`도 여전히 채워집니다 |

`result.r_s`, `result.r_p`, `result.t_s`, `result.t_p`는 `result.incident`의 해당
배열을 복사하지 않고 읽습니다. `result.R`과 `result.T`도
`result.incident`를 읽습니다. 진폭의 접미사는 출사 편광을 가리키며,
`result.s_inc`와 `result.p_inc`는 입사 편광을 가리킵니다.

수동으로 구성한 `Result(incident=None, s_inc=..., p_inc=...)`만이
사용 가능한 변형들의 전력을 평균합니다. 그 직접 진폭 속성은 오류를 일으킵니다.
비간섭성 전력 평균에는 단일한 복소 전기장 진폭이 없기 때문입니다.

**이 행들 중 어느 것이 존재하는지는 `answers`가 선언하는 것이며**, 위 표는 기본값
(`answers='amplitude'`)의 전체입니다. `answers='efficiency'`는 `R`, `T`,
`power_entering`, `absorption`을 유지하고, `s_inc` / `p_inc`를 포함한 다른
모든 슬롯을 `None`으로 둡니다 — 따라서 그 단계에는 취할
비편광 평균이 없으며 `incident`가 유일한 입사입니다. `answers='field'`는 여기에 아무것도
더하지 않습니다. 그것이 더하는 것은 `reconstruct_field`가 따라가는 층별 상태로, 결과
인터페이스의 일부가 전혀 아니며, 그보다 낮은 단계에서는 재구성이 제공되지 않고 이름으로
거부됩니다. 단계는 단조적이므로 낮은 단계는 언제나 *더 작은* 답이지 다른
답이 아닙니다 — 허용 오차가 아니라 비트 단위로 고정되어 있습니다.

진폭의 세부 사항을, 나중에 발견할 필요가 없도록 한 번에 적어 둡니다.

- 각 차수는 모든 경로에서 — 2026-09-27부터는 순수 1D `tetm` 경로도
  포함해 — **자신의** s/p 좌표계, 즉 표준 좌표계로 인용됩니다. `s_hat = z_hat x k_hat_par`이며,
  `k_par`는 그 차수의 면내 파동 벡터입니다. `p_hat`은 면내 부분으로 정해지며, 이 부분은
  파동이 진행하는 매질에서 `k_hat_par` 방향이고 길이가 `cos(theta_m)`입니다 —
  빛이 어느 쪽에서 들어오든 **반사 차수는 `+`, 투과 차수와 입사파는 `-`** 입니다
  (소멸 차수에서는 감쇠하는 가지로 연속 연장됩니다). 그 덕분에
  위의 원형 편광 유도가 쓰는 것처럼 수직 입사 기저가 양쪽에서 `E = (-a_p, a_s)`가 됩니다.
  그 대가는 삼중항의 손잡이이며, 이는 입사 쪽을 따릅니다.
  아래에서 비추면 `p_hat = k_hat x s_hat`(따라서 `(s_hat, p_hat, k_hat)`은 오른손계)이고,
  위에서 비추면 `p_hat = s_hat x k_hat`입니다. 2026-09-21에 `+z`가 위를 향하게 되었을 때 진폭은
  움직이지 않았습니다(그 변경 전후로 바이트 단위 동일). 이 문장은 예전에 양쪽 모두에 대해
  "오른손계"라고 했는데, 이는 이전의 아래쪽 좌표계에서는 위쪽 입사에 대해 참이었고
  그 이후로는 아래쪽 입사에 대해 참입니다. 재구성된 필드에 대해, 양쪽과 네 진폭 모두를
  `tests/rcwa/test_amplitude_sp_frame.py`에서 고정합니다.
  2026-08-16까지는 conical과 2D 경로에서 `Re(kx) < 0`인 모든 차수가 *뒤집힌* 좌표계
  (`-s_hat`, `-p_hat`)로 돌아왔습니다 — `|r|^2`인 `R`/`T`에서도,
  재구성된 필드에서도 보이지 않았으므로, 이 프로젝트의 모든 골든 값에서도 보이지 않았습니다.
  [`amplitude-sp-frame.md`](../../theory/rcwa/amplitude-sp-frame.md)를 보세요.
- **`ky == 0` 행에서**(`tetm`이든 아니든 `phi = 0`의 모든 1D 계산) `s_hat_m`은
  `sign(Re kx_m) * y_hat`입니다 — `kx_m == 0`에서는 `+y_hat`, 즉 원점 규칙입니다 — 그리고 `p_hat_m`도
  함께 뒤집힙니다. 따라서 한 차수의 `r_s` / `r_p`는 자신의 `kx`가 0을 가로지르는 곳에서 부호가 바뀌는 반면
  `R`은 매끄럽게 지나갑니다. 그곳에서 `k_par`가 0을 지나고 `z_hat x k_hat_par`에는 극한이 없기 때문입니다.
  그 계단은 물리가 아니라 좌표계의 특이점이며, `r_xyz`는 그곳에서 연속입니다. 정확한 산술에서
  `kx`가 0인 차수 — 수직 회절: 직접 지정한 `kx = 2*pi/P`,
  또는 `theta = asin(lambda/P)`는 차수 `-1`을 그곳에 놓습니다 — 는 그 점 위에 놓이며, 계산이 그 점의 어느
  쪽에 떨어지는지는 반올림이 정합니다. 같은 입력이 NumPy와
  JAX에서는 `kx(-1) = +0.0`을, Torch에서는 `-5.6e-17`을 주며, Torch에서는 `theta = asin(lambda/P)`와
  `theta = asin(0.375)`가 반대쪽에 떨어집니다(
  `tests/rcwa/test_amplitude_sp_frame.py`의 격자에서 측정). 따라서 그런 차수에서 `r_s` / `r_p`는
  순수 경로에서와 마찬가지로 conical 경로에서도 백엔드 사이에서, 그리고 같은 입력의 다른 표기 사이에서
  부호가 다를 수 있습니다. `R` / `T`는 다르지 않으며, 그곳에서 읽어야 할 물리량인 `r_xyz`도
  다르지 않습니다. `theta = 0`에서는 입사
  차수가 그 점 위에 놓이며, `theta`가 0을 가로지를 때 입사 필드 자체가 뒤집힙니다
  (`s_hat_inc`가 `-y`에서 `+y`로 바뀜). 연속적인 필드를 원하는, `theta = 0`을 지나는 스윕은
  `sign(Re kx_inc)`, 즉 차수 0의 `kx`를 곱합니다 — 이 값은 `(centre, half) = result.order_window[0]`에 대해
  `solver.order_kxy()[0]`의 인덱스 `half - centre`에 있으며, 이 인덱스가 `n // 2`인 것은
  어떤 `excitation`도 창을 옮기지 않았을 때뿐입니다. 거울 대칭 격자에서
  `theta = 0`이면 이로 인해 `r_{-m} = -r_{+m}`이 됩니다. 순수 1D 경로는 2026-09-27까지 모든 차수에서
  `E_y` / `H_y`를 인용했으며(`new = sign(kx_m) * sign(kx_inc) * old`), RETICOLO 자체의
  1D 경로는 지금도 그렇게 합니다. 그 1D 진폭과 conical 진폭은 정확히 그 인자만큼 다릅니다.
- `excitation` 가중치는 모든 경로에서 **자기 차수의** `s_hat`(s) 또는 `p_hat`(p)에
  곱해집니다 — 따라서 `ky == 0` 행에서 `kx < 0`인 조명 차수는 s 필드가
  `-y` 방향으로 도착합니다. 순수 1D 경로도 2026-09-27부터 같게 동작합니다. 그 전에는 모든
  조명 차수에 `+y`를 곱했는데, 조명 차수 집합이 `kx = 0`의 양쪽에 걸치면 이는 다른 빛입니다. 가중치는
  빛이 들어오는 면의 `x = y = 0`에서 그 평면파의 진폭입니다 — 
  `rcwa.IncidentOrders(weights=...)`가 받는 가중치이며, 같은 빛입니다(2026-09-27부터. 아래의 위상
  기준을 보세요).
- 산란 행렬의 **s** 블록은 진폭을 담습니다. `S11 @ delta`는 `r_s`, `S21 @ delta`는
  `t_s`입니다. **p** 블록은 포트 변수 — p 파동의 자기장,
  자신의 매질에서 `-1j * (n/mu) * a_p` — 를 담으므로 `S11 @ delta`는 `-r_p`이고(그 필드는
  위로 가는 파동에서 뒤집힙니다) `S21 @ delta`는 `t_p * (n/mu)_exit / (n/mu)_lit`입니다. 모든
  경로에서 같습니다. 순수 1D 행렬은 `phi = 0`에서 conical 행렬의 s-s(TE) 또는 p-p(TM) 블록이며,
  그 포트가 어느 쪽인지 알려 줍니다. `Port.channel`은 그곳에서 `'te'` / `'tm'`이고 모든 결합
  경로에서 `'sp'`이며, `cascade`는 두 채널을 잇는 것을 거부합니다.
- `theta = 0`에서 0차 차수에는 방향을 취할 면내 파동 벡터가 없으므로,
  `phi`가 방향을 제공합니다 — 선이 아니라 **방향**으로서 — 즉 `k_par` 자신의
  방향의 극한 `theta -> 0+`입니다. `phi` 자체이거나, 음의 굴절률 입사 쪽에서는 `phi + pi`입니다. 그곳에서 `k_par`는
  빛과 반대를 가리키기 때문입니다(그래서 그곳에서도 필드가 수직 입사를 지나며 연속입니다). 따라서 `phi`와 `phi + pi`는
  같은 `psi`에 대해 부호가 반대인 입사 필드를 기술하며, 계산은 그에 맞춰
  부호가 반전된 필드와 진폭을 반환합니다. 둘은 그 부호를 제외하고만 같은 조명입니다.
  동등하게, `(phi + pi, psi)`는 `(phi, polarization=(-a_s, -a_p))`입니다.
  2026-08-16까지는 두 표기가 일치하지 않았고, `phi + pi` 표기는 조용히
  `phi`에 대한 답을 냈습니다.
- p 부호 규약은 수직 입사의 단일 계면이
  `r_p = (n2 - n1)/(n2 + n1) = -r_s`(비자성 매질)를 주는 규약이며, 이중 음수 매질과 자성 금속을
  포함한 모든 매질에서 `r_p = -r_s`, `t_p = t_s`입니다. `p_hat` 안의 모든 `n`은
  부호 있는 굴절률이므로 `n/mu`의 실수부는 양수로 유지됩니다.
- `r_xyz` / `t_xyz`는 같은 파동의 좌표계 없는 표기로, `r_s`와 정확히 같게 단위 입사 진폭당 값이며,
  공개 좌표계(`+z` 위쪽)에서 표현됩니다.

  ```text
  r_xyz[m] = r_s[m] * s_hat_m + r_p[m] * p_hat_m^ref     (incidence medium n_i, kz_i)
  t_xyz[m] = t_s[m] * s_hat_m + t_p[m] * p_hat_m^trn     (exit medium n_t, kz_t)

  s_hat      = (-s, c, 0)                                 (c, s) = the order's azimuth
  p_hat^ref  = ( kz_i c/n_i,  kz_i s/n_i, d*rho/n_i)      in-plane +cos(theta_m) k_hat_par
  p_hat^trn  = (-kz_t c/n_t, -kz_t s/n_t, d*rho/n_t)      in-plane -cos(theta_m) k_hat_par
  rho = kx c + ky s,   d = -1 lit from the top, +1 from the bottom
  ```

  각 `p_hat`은 손실 매질을 포함해 켤레를 취하지 않는 의미에서 자신의 `k = (kx, ky, +-kz)`에
  수직입니다. 이들은 `r_s`의 위상 기준을 공유합니다 — `z` 방향으로는 입사 쪽과 먼 쪽
  계면, 가로 방향으로는 셀 **중심**(아래 참고)입니다. 빛이 들어오는 면의 출사 E는 공개 좌표에서
  `sum_m r_xyz[m] exp(1j k_m . x)`입니다 — 그리고 `ky == 0` 행에서 한 차수의 `kx`가 0을 가로지르는 곳,
  즉 `r_s`가 뒤집히는 곳에서 연속입니다. 입사 차수 자신의
  교차(`theta`가 0을 지남)는 여전히 이들을 뒤집습니다. 그것은 인용 좌표계가 아니라 입사가
  바뀌는 것이기 때문입니다. 자기장 벡터는 제공하지 않습니다. 그것은
  Z0 단위에서 `(k/k0) x E / mu`이며 `k/k0 = (kx, ky, +-kz)`입니다 — `kz`는 계산에서 읽고, 절대
  다시 쓰지 마세요 — 그리고 `boundary_fields(part='outgoing')`가 이를 공간에서 반환합니다. RETICOLO의 `res2`는
  차수별로 같은 직교 좌표 물리량 E와 H를 반환합니다.
- 위상 기준: `r`은 입사 쪽 계면에서, `t`는 먼 쪽 계면에서 잽니다(기본 조명에서는 각각 위와
  아래). **가로 방향으로는 셀 중심**, 즉 모든 공개 좌표의 원점인 `x = y =
  0`이며, 이는 모든 통상 계산에 적용됩니다 — 순수 1D TE/TM,
  conical, 두 정식화 중 어느 쪽의 2D, ETM과 SMM, 양쪽 입사, 모든 셀:
  - 빛이 들어오는 면의 입사 필드는 `sum_m w_m e_m exp(1j k_m . x)`이며, `w`는
    `excitation` 가중치(기본값은 정반사 차수의 단위 파동 하나)이고 `e_m`은 그
    차수 자신의 `s_hat` / `p_hat` 조합입니다. **중심에서 단위 크기**입니다. 이것은
    `IncidentOrders(weights=w)`의 필드이며, 기본적으로 `PlaneWave`의 필드입니다.
  - 빛이 들어오는 면의 출사 필드는 `sum_m r_xyz[m] exp(1j k_m . x)`이고, `t_xyz`는 먼 면에서
    같습니다. 모든 진폭은 중심에 대한 공개 필드의 푸리에
    계수입니다.
  - 산란 행렬은 같은 변수로 들어오는 포트 진폭을 나가는 포트 진폭에 대응시킵니다 —
    그 포트 변수도 중심을 기준으로 하므로, 위의 블록 해석
    (`S11 @ delta`는 `r_s`, p 블록에서는 `-r_p`)이 모든 차수에서 성립합니다.
  - 모든 필드 출력 — 솔버와 결과의 `reconstruct_field`,
    `boundary_fields`, `solve_field`, `plot_field` — 은 그
    입사의 물리적 필드입니다.

  2026-09-27까지 통상 경로는 이 모두를 셀 **모서리**, 즉 계산이 적분을 시작하는 푸리에
  원점을 기준으로 했습니다. 중심에 대해 차수 `(m, n)`은 모든 셀에서
  `exp(1j k_mn . (a1 + a2)/2) = exp(1j k_inc . (a1 + a2)/2) (-1)**(m + n)`을 가지므로,
  단일 파동에서는 `m + n`이 홀수인 모든 진폭의 부호가 그날 바뀌었고, 조명 차수들의 홀짝이 섞이는 곳에서는
  `excitation` 물리가 바뀌었으며, 필드는
  `exp(-1j k_inc . (a1 + a2)/2)`만큼 바뀌었습니다. 단일 파동의 `R`과 `T`는 움직이지 않았습니다
  (`amplitude-sp-frame.md` §7). 커널은 여전히 모서리에서 적분하며
  `solver.T1` / `layer_info_list`는 모서리 좌표계의
  `epz_conv_i`를 포함해 커널 자신의 상태입니다. 엔진이 입구에서 변환합니다.
  복소수 `theta`에서는 입사파가 표면을 따라 균일하지 않으며, "중심에서 단위 크기"는
  그곳에서의 크기를 고정합니다 — 손실 있는 상부 매질에서 `theta = 0.3 + 0.1j`인 TE 장면에서는 모서리에서보다
  7.70배 작습니다.
- 실수 가로 파동 벡터에서 `R`과 `T`는 각각의 반사/투과
  전력을 빛이 들어오는 계면에서의 입사파 전력으로 나눈 값입니다. 이는
  흡수하는 입사 매질에도 적용됩니다. `T`는 흡수하는 출사 매질 안 무한히 먼 곳까지 살아남는 전력이 아니라
  반대쪽 계면을 지나는 전력을 가리킵니다.
  입사/반사 간섭은 `power_entering`에 기여합니다. 유한 적층의
  흡수는 `result.absorption = result.power_entering - result.T.sum()`입니다.
  무손실 입사 매질과 전파하는 조명에서는
  `power_entering = 1 - R.sum()`이므로 `absorption = 1 - R.sum() - T.sum()`이 됩니다.
  이 흡수는 유한 적층에도 순 흡수나 이득이 없을 때만 0입니다.
  일반적인 복소수 가로 파동 벡터의 셀 적분 전력은 이
  정의 밖에 있습니다. 그 경우 `power_entering`과 `absorption`은 `NaN`을 반환합니다.
  복소수 각도 진폭 계산은 별개로 남습니다.
- 공개 인터페이스에는 날 것의 "경계 변수"가 없습니다. (첫 릴리스 전에는
  p 진폭이 `/(-i*n_top)` 각주가 필요한 자기장 경계 변수로 노출되어 있었습니다. 이들은
  별칭 없이 완전히 이름이 바뀌고 정규화되었습니다 —
  meent 시절의 효율 이름 `de_ri`/`de_ti`도 포함해서입니다.)

## 백엔드 이름

| `backend` | 계산하는 라이브러리 |
| --- | --- |
| `'numpy'` (기본값) | NumPy — 자동 미분 없음 |
| `'jax'` | JAX — 미분 가능. `jax.jit`는 고정된 기하를 받습니다 |
| `'torch'` | PyTorch — 즉시 실행(eager) 방식으로 미분 가능 |

각 이름은 그 라이브러리의 import 이름이며, 받아들이는 유일한 철자입니다. 백엔드를 받는
모든 입구 -- `wavebit.rcwa`(키워드 또는 첫 위치 인자), 솔버 클래스
(키워드 또는 `solver.backend = ...`), `CoherentSolver`, `meshgrid_xy` / `meshgrid_uv`, 그리고
spec의 `numerics.backend` -- 는 그 외의 것(`'JAX'`, `'pytorch'`, `True`, 정수)을
이름 목록과 함께 거부합니다. `wavebit.Backend`는 같은 셋을 `str` 열거형으로 제공하므로
`Backend.JAX == 'jax'`이며, `solver.backend`는 그 멤버를 담습니다. 이 이름들은 2026-10-11까지
정수 `0` / `1` / `2`였습니다.
