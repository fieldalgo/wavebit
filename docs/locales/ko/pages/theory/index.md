# 이론과 검증

수학적 명제와, 그것을 시험하는 데 쓴 수치적 근거를 구분합니다.

- [RCWA 이론](rcwa/index.md)은 푸리에, 재료, 파동 규약을 유도합니다.
- [RCWA 검증](../validation/rcwa/index.md)은 수렴, 비교, 아직 풀리지 않은 한계를 보고합니다.
- [FDTD 검증](../validation/fdtd/index.md)은 공간·시간 이산화, 소스, 재료와 경계를 검사합니다.
- [설계 제안](../design/index.md)은 의도한 변경을 기록합니다. 제안은 지원되는 API 계약이 아닙니다.
