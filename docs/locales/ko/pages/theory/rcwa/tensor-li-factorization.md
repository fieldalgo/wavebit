# 이방성 재료의 Li 인수분해

> **과거 API:** 이 페이지에서 `wavebit.compat`을 쓰는 코드 조각과 설명은 과거 체크아웃이 필요합니다.
> 이 네임스페이스는 현재 설치본에 없으며, 퇴역 직전 기준은
> [리비전 `3c8a50f8`](https://github.com/fieldalgo/wavebit/tree/3c8a50f8a6506240169538957e99648a4b18ca3a)입니다.
> 기록된 실험은 각자 인용한 커밋과 환경으로 재현하세요. 그 측정은 다시 실행하지 않았습니다.


완전한 유전율·투자율 텐서에 연속 데카르트 푸리에 인수분해를 쓰려면 `factorization='li'`로
설정하세요. 텐서 입력의 기본값은 NVF입니다.
두 선택 모두 z와 분리된 텐서에는 다섯 칸을, 완전한 텐서에는 아홉 칸을 내보냅니다. 예제는
이전 인터페이스, 즉 2026-10-13부터 `wavebit.compat.legacy`였던 인터페이스를 씁니다. 공개 모듈은
`rcwa.Numerics(factorization='li')`로 같은 빌더를 선택합니다.

```python
from wavebit.compat import legacy as wavebit

crystal = wavebit.Material(epsilon=[2.25, 4., 2.8]).rotated(0.3, axis='y')
solver = wavebit.rcwa(
    wavelength=730., period=(600., 600.), thickness=[173.],
    structure=[dict(background=1., shapes=[
        dict(type='rectangle', lx=240., ly=300., material=crystal),
    ])],
    factorization='li', truncation_order=dict(x=3, y=3),
)
result = solver.solve()
```

## 지원하는 입력

- 축에 정렬된 직사각형 셀. 따라서 격자의 u/v가 데카르트 x/y와 일치합니다.
- `fourier_coefficients='sampled'`(기본값) 또는 `'integrated'`를 쓰는 텐서 래스터.
  둘 다 주어진 조각별 상수 픽셀을 기술합니다. integrated 빌더는
  모든 픽셀과 각 픽셀의 독립적인 미분을 유지합니다.
- `'integrated'` 계수를 쓰고, 경계를 포함해 한 셀 안에 완전히 들어가는 축 정렬 직사각형 칠하기.
  주기의 정수배만큼 떨어진 곳에 쓴 직사각형은 셀 안에서 읽습니다(계획에 접기가 기록됩니다).
  셀 경계를 가로지르는 직사각형은 어디에 쓰든 거부합니다. 나중 직사각형이 앞선 직사각형 위에 칠해집니다.
  경계는 살아 있는 직사각형 좌표를 따르며, 법선 격자는 쓰지 않습니다.
- 독립적인 xy/yx/xz/yz/zx/zy 성분을 포함한 완전한 복소 3×3 epsilon과 mu.
- 정확한 스케일된 항등 블록을 통한 균일한 완전 텐서. 어느 쪽 양이든 z 결합이 있으면
  1차 솔버가 선택되며, 층 연결은 ETM 또는 SMM으로 합니다.

Li는 NVF 법선장이나 프로젝터 설정을 읽지 않습니다. 명시적인 NVF 설정은
거부합니다. 고정 중첩만 구성합니다(모든 칸에서 v가 u 안쪽).
`li_nesting='fixed'`는 받아들이고, `li_nesting='symmetric'`은 이름을 밝혀 거부합니다. 일반적인 곡선 형상이나 회전한 형상, 사각이 아닌 셀에는 NVF를 쓰세요.
이방성 반공간은 여전히 공개 재료 인터페이스 밖에 있습니다.

## 구성

평면 경계면에서 `D = εE`일 때 접선 방향 E와 법선 방향 D는 연속입니다.
재료 연산자의 법선 블록과 접선 블록을 다음과 같이 쓰면

```text
Dₙ = a Eₙ + b Eₜ
Dₜ = c Eₙ + d Eₜ
```

불연속인 법선 필드를 소거할 수 있습니다.

```text
Eₙ = a⁻¹ Dₙ − a⁻¹ b Eₜ
Dₜ = c a⁻¹ Dₙ + (d − c a⁻¹ b) Eₜ
```

이 교환은 자기 자신이 역연산입니다. 구현은 y 변수를 교환하고,
v 방향으로 푸리에 변환한 뒤, 다시 교환합니다. 그런 다음 결과로 얻은 행렬값 블록으로
u 방향에서 같은 과정을 반복하며, 곱셈 순서를 보존합니다.
완전한 텐서에서는 두 접선 성분이 각 교환에 참여하며,
zz 연산자에는 x와 y를 통한 결합이 들어갑니다. z와 분리된 텐서에서는
E_z가 수직 벽에 접선이므로 zz가 direct 규칙으로 줄어듭니다.

이것은 스칼라 경로의 고정 중첩에서의 Li의 연속 2차원 구성입니다.
모든 성분에서 v가 안쪽, u가 바깥쪽입니다. 다른 중첩은
다른 유한 절단 근사를 줍니다. 각 칸 자신의 inverse 규칙 축을 안쪽에 두는 스칼라 경로의
`'symmetric'` 중첩은 여기서 대응하는 텐서 구성이 없습니다. 스칼라로 줄어드는 텐서 성분은
고정 중첩의 스칼라 Li 행렬을 그대로 되찾습니다.
[Li, *Fourier Modal Method*, §§13.3.3.1 및 13.4.3, Eq. (13.132)](https://www.fresnel.fr/files/gratings/Second-Edition/GratingsTheoryandNumericApplicationsSecondEdition.pdf#page=572)를 참고하세요.

이 수학적 참고문헌을 바탕으로 독립적으로 작성한 구현입니다.
참고 소프트웨어, 소스 코드, 추가 의존성은 포함하지 않습니다. 1차원 행 변환은
스칼라 Li 빌더를 Li의 논문으로부터 다시 작성하기 전까지(2026-09-25) 스칼라 모듈의 예전
푸리에 보조 함수를 호출했습니다. 그 이후로는 다시 작성한 급수로 실행되며, `LICENSE`에 그 이력이 기록되어 있습니다.

## 미분과 검증

NumPy, JAX, PyTorch는 같은 빌더를 씁니다. 래스터 값은 법선을 구성하거나
고정하지 않고도 미분할 수 있습니다. 직사각형 형상의 미분을 구하려면
JAX 추적 전에 `freeze_geometry()`를 호출하고 저장된 경계 순서를 재생하세요.
위치, 길이, 주기, 재료 값은 살아 있는 상태로 남습니다. 직사각형 경계 순서나
칠하기 위상이 바뀌면 다시 고정하세요. 고정된 Li 기록과 NVF 기록은
서로 바꿔 쓸 수 없습니다.

`tests/rcwa/test_tensor_li.py`는 스칼라로의 환원, 독립적인 정확한 줄무늬
관계, 줄무늬 NVF와 비교한 복소 반사/투과 진폭, 래스터 입력과 비교한 자성 칠하기,
무손실/수동 동작, 백엔드 간 일치, 재료·형상 그래디언트의 유한 차분 검사를 확인합니다.
`tests/references/test_tensor_li_golden.py`는 패턴이 있는 자이로트로픽 기둥 세 개를
푸리에 차수 14에서 기존의 독립적인 fmmax 데이터와 비교합니다.
더 가까운 저장된 정식화와의 R/T 최대 차이는
1.29e-6, 3.10e-6, 1.24e-5이며, 저장된 두 정식화끼리는 각각
4.84e-6, 2.97e-5, 1.67e-4만큼 다릅니다. 이 기준값의 퍼짐이
테스트 허용 오차를 정하고 정확도 주장의 한계를 정합니다.
이 검사를 통과하더라도 새 구조에서는 여전히 푸리에 차수를 수렴시켜야 합니다.

완전 텐서 검증, 필드 재구성, 모드 선택과 수렴은
[완전 텐서 패턴](../../guide/rcwa/full-tensor-patterns.md)에서 설명합니다.
