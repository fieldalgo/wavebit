## 요약

1. `epxy`라는 이름의 칸이 담는 값은 `eps_xy`가 아니라 **`-eps_xy`** 입니다. `epyx`도 마찬가지이며 —
   2026-08-13에 z 행에 접근할 수 있게 된 뒤로는 `epxz`, `epyz`, `epzx`, `epzy`도 그렇습니다. **모든
   비대각 칸은 해당 성분의 음수를 담으며**, 여섯 칸 모두에 같은 규칙 하나가 적용됩니다. 공개
   시그니처의 어디에도 그렇다는 말은 없습니다.
2. 그 부호를 거꾸로 넣어도 **모든 전력 효율에는 보이지 않습니다** — R, T, 동일 편광, 교차 편광과
   합계가 모두 비트 단위로 같습니다. 복소 진폭만 바뀝니다.
3. 더 심각하게 — 그리고 이것은 **이제 수정되었습니다** — `layer_modes_2d` 안의 두 블록은 예전에
   비대각 쌍을 *같은* 순서로 담고 있었으므로, *비대칭* 텐서(`eps_xy != eps_yx`, 즉 자이로트로피)는
   고유값은 한 매질에서, 자기장은 그 매질의 전치에서 가져왔습니다. 측정 오차는 3.6e-2이며,
   자이로트로피 세기에 대해 1차입니다. 수리는 `Omega_R` 안에서만 쌍을 맞바꿉니다.
4. **배포된 어떤 코드 경로도 3번에 닿을 수 없었고, 수리로 영향을 받는 경로도 없습니다.** 라이브러리가
   만드는 모든 텐서는 대칭이며, 대칭인 쌍에서는 순서가 아무 효과도 없습니다 — 실제 격자에서 비트
   단위로 같음을 확인했습니다. 이것은 미래 기능을 가로막는 잠재 결함이었지, 배포된 어떤 것에서도
   틀린 숫자였던 적은 없습니다.

아래의 모든 내용은 결함이 있는 상태에서 측정한 그대로 적었습니다. 이것은 의도적입니다. 그 수치들이
이 수리가 옳은 이유이며, 실패가 어떤 모습이었는지에 대한 유일한 기록이기 때문입니다.

## 1. 다섯 칸이란 무엇인가

이 문서 전체에서 **블록**은 부분 행렬 — `solve_2d.py::_block`이 조립하는 것 — 을 뜻하며,
`modeling='block'` 경로를 뜻하지 않습니다. 여기서는 모델러에 관한 내용이 전혀 없습니다.

2D 모드 연산자는 다섯 개의 유전율 블록을 읽습니다. 이들은 다음과 같은 텐서에 대응합니다.

```
                       E_x         E_y         E_z
                  ┌───────────┬───────────┬───────────┐
          D_x     │    epx    │   epxy    │     ·     │
                  ├───────────┼───────────┼───────────┤
          D_y     │   epyx    │    epy    │     ·     │
                  ├───────────┼───────────┼───────────┤
          D_z     │     ·     │     ·     │  epz_i⁻¹  │
                  └───────────┴───────────┴───────────┘

     named cell  = a block layer_modes_2d actually reads
     ·           = assumed zero; there is no slot for it
```

그리고 이들은 공개 진입점을 통해 셀 중심 기준의 연산자로 들어옵니다.

```python
res = mee.solve_conv(epx_conv_all, epy_conv_all, epz_conv_i_all,
                     epxy_conv_all, epyx_conv_all)
```

docstring은 마지막 두 개를 "선택적인 비대각 유전율 블록"이라고 부릅니다. 이 문서는 바로 그 표현을
바로잡기 위해 존재합니다. 그것들은 비대각 유전율이 아닙니다. 그 음수입니다.

## 2. 이름을 믿지 말고 부호를 유도하기

누구의 말도 그대로 믿을 필요가 없습니다 — 규약은 `Kx = Ky = 0`이 되어 연산자 전체가 줄어드는 수직
입사에서 코드로부터 바로 나옵니다.

`layer_modes_2d`가 만드는 것에서 시작합니다.

```python
B  = Kx @ epz_conv_i @ Kx - I          #  ->  -I     when Kx = 0
D  = Ky @ epz_conv_i @ Ky - I          #  ->  -I     when Ky = 0
Cc = Kx @ epz_conv_i @ Ky              #  ->   0
E  = Ky @ epz_conv_i @ Kx              #  ->   0

Omega2_LR = [[Ky Ky + B epx - Cc epyx,   Cc epy - Kx Ky - B epxy],
             [E epx - Ky Kx - D epyx,    Kx Kx + D epy - E epxy]]
```

`B = D = -I`와 `Cc = E = Kx = Ky = 0`을 대입하면 `K`가 들어 있는 항은 모두 사라집니다.

```
                    ┌                  ┐
     Omega2_LR  =   │  -epx     epxy   │
                    │   epyx   -epy    │
                    └                  ┘
```

이제 물리를 들여옵니다. 모드는 `exp(-k0 q z)`로 변하므로 `d²E/dz²`는 `k0² q²`를 기여하고, `z`
방향 전파에 대한 파동 방정식은 `d²E/dz² = -k0² eps E`입니다. 따라서 다음과 같습니다.

```
     q² = eigenvalue of Omega2_LR         and         Omega2_LR = -eps_tensor
```

텐서를 바로 읽어 냅니다.

```
                 ┌                  ┐
     eps_t  =    │   epx    -epxy   │            eps_xx = epx     eps_xy = -epxy
                 │  -epyx    epy    │            eps_yy = epy     eps_yx = -epyx
                 └                  ┘
```

**칸에는 음수가 들어갑니다.** 이것은 `_nvf_assemble`과 일치합니다. 이 함수는
`(eps_xx, eps_yy, inv(⟦eps⟧), -eps_xy, -eps_xy)`를 반환합니다 — 부호 반전은 들어오는 길에 거기서
적용되며, 그 뒤로 하류의 모든 소비자는 이를 전제로 작성되었습니다.

(그 튜플은 이 문서를 작성할 때 `(eps_xx, eps_yy, -eps_xy, -eps_xy, inv(⟦eps⟧))` 순서였고,
빌더와 `solve_conv`가 일치하도록 2026-08-18에 순서를 바꿨습니다. §7.1을 보세요. 이 문서의 주제인
*부호* 규약은 전혀 바뀌지 않았습니다.)

따라서 균일 층에 대해 손으로 채운 올바른 호출은 다음과 같습니다.

```python
I = np.eye(n_orders, dtype=np.complex128)

epx   = np.stack([eps_xx * I])
epy   = np.stack([eps_yy * I])
epxy  = np.stack([-eps_xy * I])        # <-- negate
epyx  = np.stack([-eps_yx * I])        # <-- negate
epz_i = np.stack([np.linalg.inv(eps_zz * I)])
```

### 2.1 그리고 같은 규칙이 적용되는 z 행

`layer_modes_2d`에는 부호를 유도할 z 행 칸이 없습니다 — z 행을 채우면 아예 다른 연산자
(`solve_2d_first_order.py::layer_matrix_first_order`, 텐서를 쓰인 그대로 읽습니다)가 선택됩니다.
그래서 이 네 칸의 규약은 강제된 것이 아니라 *선택한* 것이며, 다음과 맞추도록 선택했습니다.

```python
epxz  = np.stack([-eps_xz * I])        # <-- negate, same as the pair above
epyz  = np.stack([-eps_yz * I])
epzx  = np.stack([-eps_zx * I])
epzy  = np.stack([-eps_zy * I])
```

다른 방법 — z 행에는 성분 그대로, 면내 쌍에는 부호를 뒤집은 값 — 은 한 호출에 두 규약을 넣게 되며,
이는 놀라운 규약 하나보다 더 나쁜 함정입니다. `epz_i`는 어느 쪽이든 예외로 남습니다. 이것은 부호
반전이 아니라 *역*이며, `E_z`를 소거하는 데 필요한 형태가 그것이기 때문입니다.

면내 쌍과 달리, 여기서 틀린 부호는 전력 효율에 보이지 **않는 것이 아닙니다**(§3은 특히 그 쌍에
관한 내용입니다). `tests/rcwa/test_anisotropic_berreman.py`는 이 네 칸을 텐서를 그대로 받는 기준
솔버와 비교해 판정하므로, 반대로 채운 칸은 거기서 실패합니다.

## 3. 틀린 부호가 스스로 드러나지 않는 이유

부호 반전을 잊고 `+eps_xy`를 넘겼다고 해 봅시다. 실제로 기술한 것은 광축을 **x축에 대해 거울상으로
뒤집은** 같은 재료입니다.

```
     what you meant                    what you described

        y                                  y
        │    ╱ axis at +30°                │
        │   ╱                              │
        │  ╱                               │  ╲
        │ ╱                                │   ╲
        └──────── x                        └────╲─── x
                                               axis at -30°
```

그 거울상 구조는 완전히 타당한 물리적 구조이며, 수직 입사에서 **전력 효율이 정확히 같습니다**.
30° 파장판에서 측정한 결과:

| 양 | `-eps_xy` (올바름) | `+eps_xy` (틀림) | 차이 |
|---|---|---|---|
| `de_ti_s` (동일 편광) | 0.715686772101 | 0.715686772101 | 0 |
| `de_ti_p` (교차 편광) | 0.182714043398 | 0.182714043398 | 6.9e-17 |
| `de_ri_s`, `de_ri_p` | — | — | 0 |
| `T_s` (진폭) | -0.718451-0.446672j | -0.718451-0.446672j | 0 |
| **`T_p` (진폭)** | **+0.203278+0.376021j** | **-0.203278-0.376021j** | **부호 뒤집힘** |

모든 효율이 기계 정밀도 수준의 0까지 일치합니다. 복소 `T_p`만 움직이며, 정확히 부호만큼 움직입니다 —
`|T_p|²`는 거울상을 볼 수 없지만 `T_p`는 볼 수 있기 때문입니다. (표는 2026-08-10의 이름을 씁니다.
2026-08-12부터 복소 진폭은 소문자 `t_s` / `t_p`이고, `T_s` / `T_p`는 예전에 `de_ti_s` / `de_ti_p`였던
차수별 효율을 가리킵니다.)

> **손으로 채운 텐서를 무엇과든 비교해 확인한다면, 진폭을 확인하세요.** R과 T 수치로 만든 검증은
> 구조적으로 이것을 잡아낼 수 없습니다.

이것은 `test_off_diagonal_sign_shows_up_in_the_amplitude_only`로 고정되어 있습니다.

## 4. 더 깊은 문제: 두 블록이 서로 어긋났다

위의 내용은 모두 *사용자의* 부호에 관한 것입니다. 이 절은 코드의 부호에 관한 것입니다.

`layer_modes_2d`는 **두** 블록을 만들고 이들을 서로 다른 용도로 씁니다.

```
     Omega2_LR   ──eig──►   q²  and  W        the modal constants and the E-field modes
     Omega_R     ────────►  V = (Omega_R @ W) / q        the H-field
```

이것은 RCWA의 표준 `P·Q` 구조입니다. 2차 방정식은 `d²E/dz² = P Q E`이고, 코드는 곱 `P·Q`를 전개한
형태로 `Omega2_LR`에 적고, `H`를 복원할 수 있도록 오른쪽 인자를 `Omega_R`로 따로 보관합니다. 이것이
**하나의** 매질을 기술하려면 두 블록이 실제로 인수분해되어야 합니다.

```
     Omega2_LR  =  Omega_L @ Omega_R          with Omega_L built from geometry ALONE
                                              (Kx, Ky, epz_i — never the in-plane eps)
```

`Omega_L`에 대한 이 요구가 검사의 전부입니다. `Omega_L`은 파동 연산자에서 재료가 아니라 전파에 관해
아는 부분입니다. 그것이 `epx`나 `epxy`에 의존하는 것으로 드러난다면, 두 블록은 한 대상의 두 인자가
아닙니다.

이제 각 블록이 비대각 쌍을 어떻게 담는지 보세요.

```
     Omega2_LR = [[ ... - Cc @ epyx ,   ... - B  @ epxy ],
                  [ ... - D  @ epyx ,   ... - E  @ epxy ]]
                            ▲                     ▲
                          epyx                  epxy

     Omega_R   = [[ -Kx Ky + epxy   ,   Kx Kx - epy    ],
                  [  epx - Ky Ky    ,   Ky Kx - epyx   ]]
                            ▲                     ▲
                          epxy                  epyx      ◄── the other way round
```

`Omega_L = Omega2_LR @ inv(Omega_R)`를 기호로 계산하면 불일치가 바로 드러납니다.
수직 입사에서, 스칼라 성분으로:

```
                                 ┌                                             ┐
                             1   │ epx (epyx - epxy)      -epx epy + epxy²     │
     Omega_L =  ─────────────── ·│                                             │
                epx epy - epxy epyx  │ epx epy - epyx²      epy (epyx - epxy)  │
                                 └                                             ┘
```

`Omega_L`이 기하에만 의존하려면 대각 성분이 사라져야 하며, 그러려면 다음이 필요합니다.

```
     epx · (epyx - epxy) = 0        ⟺        epxy = epyx
```

**인수분해는 비대각 쌍이 대칭일 때, 그리고 그때에만 유효합니다.** 비대칭 쌍에서는 `Omega_L`이
유전율 자체에 의존하게 되는데 — 파동 방정식의 인수분해는 그런 의존성을 가질 수 없습니다.

### 수리, 그리고 그것이 일반적이라는 점

**`Omega_R` 안에서만** `epxy`와 `epyx`를 맞바꾸면

```python
Omega_R = _block(xp, [
    [-Kx @ Ky + epyx_conv, Kx @ Kx - epy_conv],     # epyx here
    [epx_conv - Ky @ Ky,   Ky @ Kx - epxy_conv],    # epxy here
])
```

**임의의** 텐서와 **모든** 입사각에 대해(위의 수직 입사 특수 경우만이 아니라) `Omega_L`이 기호적으로
순수한 기하가 됩니다.

```
                    ┌                                        ┐
     Omega_L  =     │  -Kx Ky epz_i        Kx² epz_i - 1     │
                    │  -Ky² epz_i + 1      Kx Ky epz_i       │
                    └                                        ┘
```

`epx`도, `epy`도, `epxy`도, `epyx`도 없습니다. 인자라면 바로 이런 모습이어야 합니다.

## 5. 측정한 비용

물리적 검사는 자이로트로픽 판 — 존재하는 가장 단순한 비대칭 텐서 — 입니다.

```
              ┌                     ┐
     eps  =   │  eo     i·g     0   │        eo = 2.25,  g = 0.45
              │ -i·g    eo      0   │        thickness 220 nm, lambda 600 nm
              │  0       0     eo   │        normal incidence, vacuum both sides
              └                     ┘
```

그 정확한 답에는 솔버가 필요 없습니다. 고유 상태는 **원편광**이고 계면이 이를 보존하므로, 각 원편광
성분은 독립적인 스칼라 패브리–페로입니다.

```
     v₊ = (1, -i)/√2   sees   n₊ = √(eo + g)  ─┐
                                               ├─►  T = t₊ P₊ + t₋ P₋
     v₋ = (1, +i)/√2   sees   n₋ = √(eo - g)  ─┘
```

투과 존스 행렬 전체를 비교하면:

| | 정확한 답 대비 최대 절대 오차 |
|---|---|
| **배포된 그대로** | **3.581e-2** |
| `Omega_R`에서 쌍을 맞바꾼 경우 | **6.474e-16** |

그리고 오차는 `g`에 대해 1차이므로, 약한 자이로트로피에서도 사라지지 않습니다.

| `g` | 0.01 | 0.05 | 0.10 | 0.20 | 0.45 | 0.80 |
|---|---|---|---|---|---|---|
| 오차 | 1.1e-3 | 5.6e-3 | 1.1e-2 | 2.0e-2 | 3.6e-2 | 1.2e-1 |

### 이것을 알아차리기 어려운 이유

배포된 답은 확인해 볼 생각이 들 만한 모든 성질을 유지합니다.

```
     diagonal degenerate     J[0,0] - J[1,1]  =  1e-16     ✓ still gyrotropic in form
     off-diagonal antisym.   J[0,1] + J[1,0]  =  4e-16     ✓
     energy conserved        R + T            =  1 ± 1e-12 ✓
     rotation sense          matches +g, not -g            ✓
     magnitude                                             ✗  ← only this is wrong
```

## 5.1 외부 기준과 다시 비교한 측정

위의 모든 내용은 층이 균일하고 텐서가 단순하기 때문에만 존재하는 닫힌 형식과, 코드 내부의 항등식에
기대고 있습니다. 어느 것도 외부 검사가 아니므로, 그 논증은 한 정식화가 스스로와 대화한 것이었습니다.

Berreman의 4x4 방법이 외부 검사입니다. 이 방법은 `E_z`와 `H_z`를 소거하고 횡방향 필드를 1차 연립계
`d/dz (Ex, Ey, Hx, Hy) = i k0 M (Ex, Ey, Hx, Hy)`로 적분하므로, 균일 층은 행렬 지수 함수이고 적층은
그들의 곱입니다. 푸리에 차수도, 고유 모드도, s/p 회전도, 전달 재귀도 없습니다 — RCWA와 공유하는
대수가 전혀 없습니다.

먼저 배포된 경로가 만들 수 있는 텐서(등방성, 흡수, 대각, 이축, 회전한 단축, 세 층)에 대해 수직과
비스듬한 입사로 검증했습니다: **최대 7.8e-16**. 그런 다음에야 비대칭 경우에 적용했습니다.

| 구성 | 배포된 그대로 | `Omega_R`에서 쌍을 맞바꿈 |
|---|---|---|
| 자이로트로픽 판, 수직 | 5.2e-2 | 3.6e-16 |
| 자이로트로픽 판, 15 / 30 / 45 / 60 / 75 deg | 7.8e-3 … 1.9e-1 | ≤ 1.1e-15 |
| 일반 비대칭, 복소, 0과 40 deg | 2.6e-2 … 8.4e-1 | ≤ 2.0e-15 |
| 다층 (gyro / 등방성 / gyro, 그리고 4층) | 8.5e-3 … 1.8e-1 | ≤ 1.6e-15 |
| 28 deg에서 두께 40 … 1500 nm | 1.5e-2 … 1.3e-1 | ≤ 1.6e-15 |

시도한 모든 비대칭 구성이 모든 각도에서, 쌍을 맞바꾸면 기준값에 정확히 들어옵니다. wavebit의 채널별
s/p 위상(출력에 `diag(1, -i)`, 입력에 `diag(1, -1)`, 대칭 경우에 맞춰 구함)을 빼면 복소 존스 행렬도
~1e-15까지 일치합니다.

이번 검사로 두 가지를 바로잡아야 했습니다.

* **여기서는 전력 효율이 구분해 냅니다.** §3은 *부호* 오류가 R과 T에서 숨는 것을 보여 주며, 그것은
  여전히 참입니다 — 하지만 그것은 거울상으로 뒤집힌 광축에 관한 진술이지 순서 결함에 관한 진술이
  아닙니다. 비대칭 텐서에서는 효율이 그냥 틀리므로, 구분 기준이 규약과 무관해지고 §6의 진폭 논증보다
  훨씬 확인하기 쉽습니다.
* **온사거 상반성은 구분하지 못합니다.** `T(-g) = T(g)^T`는 맞바꾼 코드뿐 아니라 배포된 코드에서도
  5.7e-16까지 성립합니다. 그럴듯해 보이는 대칭 검사가 틀린 답에서 통과합니다.

`tests/rcwa/test_anisotropic_berreman.py`로 고정되어 있습니다.

## 6. 시간 규약의 부산물이 아니다

합리적인 반론이 있습니다. 이 저장소는 `e^{-iwt}`에 `Im(n) > 0`을 손실로 쓰며
([`conventions.py`](https://github.com/fieldalgo/wavebit/blob/main/src/wavebit/_common/conventions.py)), 어느 원편광 상태가 어느 쪽인지는
손잡이 규약이 정합니다. 위의 기준이 단순히 손잡이를 잘못 잡은 것은 아닐까요?

아닙니다. 서로 독립적인 두 가지 이유가 있습니다.

**첫째, 손잡이 오류는 `g -> -g`로 이름을 바꿀 수 있을 뿐입니다.** 그러니 `g`를 연속적으로 훑으며
배포된 출력이 *어떤* `g`에 대해서든 정확한 자이로트로픽 답인지 물어보세요.

| | [-1, 1] 전체에서 가장 잘 맞는 `g` | 그 점에서의 잔차 |
|---|---|---|
| 배포된 그대로 | +0.4264 | 3.176e-2 — 결코 맞지 않음 |
| 맞바꿈 | +0.45000 | 6.474e-16 — 정확 |

배포된 출력은 *어떤* 이름 바꾸기로도 올바른 자이로트로픽 답이 아닙니다. 맞바꾼 출력은 넘겨받은
텐서에 정확히 들어옵니다.

**둘째, §4의 `Omega_L` 논증에는 물리가 전혀 없습니다.** 그것은 코드 자신의 두 행렬에 관한 대수적
항등식입니다. 거기에는 시간 규약도, 손잡이도, 필드도 없습니다 — 두 인자의 곱이 두 인자의 곱이어야
한다는 요구뿐입니다.

### 규약이 여전히 열어 두는 것

`e^{-iwt}` 아래에서 `[[eo, i·g], [-i·g, eo]]`가 어떤 물리적 자화 방향을 뜻하는지는 이 중 어느 것으로도
정해지지 **않습니다**. 검증된 것은 솔버가 넘겨받은 텐서를 재현한다는 점입니다. 그 텐서를 실제 재료의
Verdet 상수와 자기장 방향에 대응시키는 것은 별개의 질문이며, 패러데이 아이솔레이터를 만드는 사람은
누구든 그 질문에 답해야 할 것입니다.

## 7. 배포된 것은 영향을 받지 않았다

이 문서를 작성할 때 라이브러리의 모든 생산자는 비대각 값을 **두 번** 반환했습니다.
지금은 함수 하나가 스칼라 NVF 텐서를 만들며, 모든 경로가 그 함수에 닿습니다.

```
     factorization.py::_nvf_assemble       return eps_xx, eps_yy, inv(ep_dir), -eps_xy, -eps_yx
     factorization.py::nvf_conv_matrices   (raster: calls _nvf_assemble; so does
                                            nvf_conv_matrices_integrated)
     parametric.py::nvf_from_coeffs        (shapes: delegates to _nvf_assemble)
     boundary.py                           (painted overlaps: funnels into nvf_from_coeffs)
                                                                         └────┬─────┘
                                                        one object unless the projector is
                                                        asymmetric, so the ordering cannot matter
```

그리고 Li 경로는 `None`을 넘기며, `solve_2d`가 이를 0으로 바꿉니다. 이 대칭은 우연이 아닙니다.
`_nvf_assemble` 안의 ½ 대칭화에서 오며, 그 대칭화는 대칭화하지 않은 곱이 에르미트가 아니기 때문에
존재합니다. (형상 경로의 모듈은 이 문서를 작성할 때 `analytic.py`였고, 2026-09-03에
`parametric.py`가 되었으며, 그 `nvf_from_coeffs`는 inverse 규칙 하한이 위임하도록 만들기 전까지
닫기의 자체 사본을 지니고 있었습니다.
[`nvf-metal-inverse-rule.md`](nvf-metal-inverse-rule.md)를 보세요.)

그 뒤에 추가된 두 경로는 실제로 쌍에 서로 다른 두 값을 넣으며, 둘 다 §4의 수리에 의존합니다.
`nvf_projector='circular'`(2026-09-02)는 `_nvf_assemble`에 `C_yx = C_xy^H` — `conj(p_xy)`의 합성곱
행렬, 즉 `C_xy`의 켤레 *전치* — 를 넘기므로 `eps_yx`가 따로 만들어집니다. 텐서 재료는
Popov–Nevière 경로로 닫히며, 그 `eps_xy`와 `eps_yx`는 텐서 자신의 두 블록입니다.

논증이 아니라 검증했습니다 — 실제 2D 교차 격자(Si 기둥, 주기 400 nm, 높이 300 nm,
lambda 900 nm, `theta = 12°`, `phi = 33°`, `psi = 21°`, `truncation_order = (6, 6)`, 유지 차수 169개)를
배포된 연산자와 맞바꾼 연산자로 풀었습니다.

| 인수분해 | 최대 Δ`de_ri` | 최대 Δ`de_ti` | 비트 단위로 같음 |
|---|---|---|---|
| `li` | 0.000e+00 | 0.000e+00 | 예 |
| `nvf` | 0.000e+00 | 0.000e+00 | 예 |

"1e-15까지 일치"가 아니라 — 동일합니다. 전체 검증 모음(1066개 테스트)도 마찬가지로 움직이지 않습니다.

**정리하면, 이 문서를 작성할 때 이 결함에는 일부러 비대칭으로 만든 텐서를 `solve_conv`를 통해 손으로
넣어야만 닿을 수 있었습니다.** 위의 두 경로는 §4의 수리 이후인 지금 이 지점에 닿습니다. 손으로 처음
여기에 닿을 사람은 자이로트로피를 시도하는 사람일 것이며 — 그 자화가 적층 법선이 아니라 면 안에
놓인다면, 그 사람은 동시에 §2.1의 z 행 네 칸도 채우게 될 것입니다.

## 7.1 칸의 *순서*는 2026-08-18에 바뀌었고, 부호 규약은 바뀌지 않았다

위의 모든 내용은 어떤 **값**이 칸에 들어가는지에 관한 것입니다. 별개의 결함은 어떤 **위치**에
관한 것이었으며 — §1의 `solve_conv` 호출이 두 문제에 닿는 진입점이므로 여기에 적어 둘 가치가
있습니다.

빌더들은 다섯 칸을 `(epx, epy, epxy, epyx, epz_i)`로 반환해, 면내 2x2 블록을 묶고 뒤집은 zz 행렬을
마지막에 두었습니다. `solve_conv`는 `(epx, epy, epz_i, epxy, epyx)`를 받으며, 그 순서는
강제됩니다. `epz_i`는 `E_z`를 소거하므로 모든 풀이에 필요한 반면 비대각 쌍은 기본값이 `None`이고,
Python은 기본값이 있는 매개변수 뒤에 필수 매개변수를 받아들이지 않습니다. 그래서

```python
res = mee._solve_conv(*to_conv_mat_raster_pn_eps(tensor, truncation_order, truncation_order))
```

는 `epz_i`를 `epxy` 칸에 넣었습니다. (위의 방법은 비공개 빌더의 모서리 기준 출력에 비공개 입구를
씁니다. 이 경위는 바뀌지 않은 칸 순서에 관한 것입니다.) 아무 예외도 발생하지 않았습니다. 손실 없는
수동 기둥에서 이 호출은 합이 `R + T = 1.61`인 그럴듯한 효율 한 벌을 반환했는데, 같은 구조를 올바르게
풀면 `1.0000000000`입니다 — 일반적인 결과 경고 하나만 떴고, 그 경고는 그 뒤 제거되었습니다
([`result-guards.md`](../../reference/common/result-guards.md)). 대신 `tests/rcwa/test_slot_order.py`가
에너지를 직접 단언합니다. 같은 관용구가 세 칸 등방성 빌더에서는 내내 올발랐으며, 이 점이 그것을
실수가 아니라 함정으로 만들었습니다.

이 문제는 `factorization.py` 안에서 이미 한 번 발견된 적이 있었습니다. `pn_mu_conv_matrices`는
`layer_modes_2d`로 가는 길에 두 그룹을 맞바꾸기 위해서만 존재했고, 그 docstring은 `mu_zz^-1`에
대해 똑같은 실패를 설명하고 있었습니다. 지역적인 래퍼로는 `solve_conv`에 닿을 수 없었으므로, 해결책은
**모든 곳에서 순서를 하나로** 만드는 것이었습니다 — 이제 모든 빌더가 `solve_conv`의 매개변수
순서로 반환하며, `pn_mu_conv_matrices`는 아무것도 재배열하지 않습니다.

`tests/rcwa/test_slot_order.py`는 모든 빌더에 대해 두 가지 방식으로 이를 고정합니다. 손실 없는 수동
층에서의 에너지, 그리고 2번 칸이 `inv(⟦eps⟧)`라는 구조적 항등식입니다(역으로 담기는 유일한 칸이므로
답을 몰라도 식별할 수 있으며 — 에너지 단언이 아무것도 말해 주지 못하는 손실 있는 구조에서도 여전히
구분해 냅니다). 두 생산자 중 하나를 옛 순서로 되돌리면 그 경우 중 여덟 개가 실패하고 세 칸 빌더는
통과한 채로 남으며, 이것이 바로 이 테스트가 노리는 구분입니다.

§2의 부호 규약은 전혀 바뀌지 않았고, 배포된 어떤 경로도 움직이지 않았습니다. 라이브러리 안의 모든
소비자는 이름으로 풀어 쓰므로, 순서 변경은 `solve`에 보이지 않습니다.

### 기준이 무엇이고, 무엇이 아닌가

위의 증거는 과대 해석하기 쉬우므로, 두 가지 한계를 분명히 밝혀 둘 가치가 있습니다.

**Berreman의 방법은 표준이지만, 여기 있는 그 50줄은 표준이 아닙니다.** 4x4 정식화
(Berreman 1972)는 층상 이방성 매질에 대한 기준 기법이며, 바로 이 경우를 위해 만들어졌습니다 — 그
논문의 초록은 6x6 출발점이 담으려는 것으로 패러데이 회전과 광학 활성을 직접 꼽습니다. 방법에 관해서는
즉흥적으로 만든 것이 전혀 없습니다.

지역적인 것은 *구현*입니다. `tests/rcwa/test_anisotropic_berreman.py`의 ~50줄은 그것이 판정하는
대상을 만든 같은 손으로 작성되었고, 이 솔버 자신의 이미 올바르다고 알려진 경우들로 검증되었습니다.
이것은 품질이 아니라 출처에 관한 진술입니다. `tests/README.md`의 기준 등급에서 이 구현은
**외부 솔버**가 아니라 **물리**에 속하는데, 두 구현이 공유하는 오해가 살아남을 수 있다는 좁은 이유
때문이지 — 기준이 약해서가 아닙니다.

**RETICOLO가 그 틈을 메웁니다** — 이 문서의 텐서들에 대해서이며, 이는 이 문서를 작성할 때 들렸던
것보다 좁은 범위입니다. Hugonin과 Lalanne의 코드는 V9부터 임의로 이방성인 다층 적층을 위한
도구 상자를 지니고 있었으며, V10은 텍스처를 전체 복소 3x3 유전율 텐서로 받고, 이를 보여 주기 위해
`exemple_V9_{0D,1D,2D,conique}_anisotrope.m`을 함께 배포합니다. 이 저장소는 이것을 가장 강한 기준으로
신뢰합니다.

그 뒤의 측정(2026-08-11): 그 신뢰는 어떤 입사 배치에서든 대각 텐서에 대해, 그리고 고전적 배치에서
비대각 쌍 **하나**에 대해 성립하며, 이는 이 문서의 모든 경우를 포함합니다. 그 범위를 넘으면
RETICOLO 자신의 `R + T`가 증명 가능하게 손실 없는 텐서에서 최대 1.2e-2까지 1에서 벗어납니다.
[`five-slot-limit.md`](five-slot-limit.md) §4와 `tests/references/README.md`를 보세요. 아래 내용은
바뀌지 않습니다. 여기의 경우들은 모두 쌍이 하나이고 `delta0 = 0`입니다. 같은 적층에서, 같은 규약
관문을 먼저 적용해 실행했습니다 — 등방성과 대칭 텐서에서 Berreman과 2.1e-15까지 일치하며, 규약을
맞추는 작업은 필요 없었습니다.

| 구성 | 배포된 그대로, RETICOLO 대비 | 쌍을 맞바꿈 | Berreman, RETICOLO 대비 |
|---|---|---|---|
| 실수 반대칭, 수직 | 5.3e-2 | **8.9e-16** | 4.4e-16 |
| 실수 반대칭, 35 deg | 5.5e-2 | **7.8e-16** | 1.0e-15 |
| 자이로트로픽, 수직 | 4.2e-2 | **7.8e-16** | 5.6e-16 |
| 자이로트로픽, 45 deg | 5.6e-2 | **1.0e-15** | 3.3e-16 |

따라서 다른 그룹이 다른 언어로 작성한 제3자의 코드가 맞바꾼 연산자와 같은 답에 도달하고, 배포된
연산자와는 다른 모든 곳에서 측정한 것과 같은 차이만큼 어긋납니다. 이것은 Berreman 구현도 독립적으로
뒷받침하므로, 소급해서 §5.1의 모든 수치를 강화합니다.

**S4도 작동하며, 작동하지 않는 것처럼 보였던 이유는 제 쪽에 있었습니다.** S4는 대칭 텐서에서 수치가
어긋난다는 이유로 한때 제쳐 두었습니다 — 실제로 어긋났지만, 원인은 각도 규약도 아니고 물리적인
무엇도 아니었습니다. S4는 이 저장소에 비해 **x와 y를 맞바꾼** 채로 유전율 텐서의 인덱스를 매깁니다.
교환 행렬로 켤레 변환한 `SWAP @ eps @ SWAP`는 수직과 비스듬한 입사 모두에서, 대칭 텐서에 대해
**5.6e-16**, 실수 반대칭 텐서에 대해 **6.7e-16 / 2.2e-16**으로 Berreman에 맞습니다. 각도 인자는
쓰인 그대로 `(polar,
azimuth)`이며, 0, 20, 45도에서 해석적인 Airy 판과 비교해 확인했습니다.

두 가지 한계가 있으며, 둘 다 S4를 쓰기 전에 알아 둘 가치가 있습니다. 이 빌드는 **복소 텐서를
거부하므로**, 엄밀한 의미의 자이로트로피는 다룰 수 없습니다. 실수 반대칭 텐서는 물리적 매질이
아니라 능동 매질이지만, 순서를 구분하는 데는 똑같이 유효합니다. 사용 가능한 솔버에 대한 별도의 조사는
S4가 **편광 분해와 이방성을 함께 쓰면 조용히 틀린 결과를 준다**고 기록합니다 — 그러므로 위의 측정들처럼
입사 편광별 전체 전력 플럭스를 읽고, 차수별로 분해한 s/p 진폭은 읽지 마세요.

S4가 RETICOLO가 할 수 없는 것으로 더해 주는 것은 **패턴이 있는** 경우입니다. 텐서 재료를 패턴
영역에 지정해 실행할 수 있습니다(49 차수에서 확인). 그것이 `anisotropic-materials.md` §3의 인수분해
작업에 필요할 기준이며, 오늘 이미 존재합니다.

**모든 경우는 균일 막입니다.** 그중 어느 것도 면내 구조가 없습니다. 구체적으로, 이 모든 것은
`truncation_order=(0, 0)` — 푸리에 차수 하나 — 에서 실행되며, 합성곱 행렬은 상수배한 단위 행렬로 손으로
채웁니다. 따라서 *패턴*을 그 행렬로 바꾸는 장치는 전혀 건드리지 않습니다. `dfs2d_*` 빌더도, Li의
규칙도, NVF도, 해석적 또는 경계 빌더도,
절단도 건드리지 않습니다.

따라서 검증된 것은 층 모드 연산자, s/p 회전, 경계 정합과 층 연결이며 — 바로 결함이 있는 곳이므로
이 발견은 유효합니다. 검증되지 않은 것은, 전혀, *패턴이 있는* 층의 이방성 거동입니다.

그 틈은 여기에 경우를 더한다고 메워지지 않습니다. 패턴이 있는 이방성 층에는 아직 존재하지 않는
인수분해가 필요하므로(`anisotropic-materials.md` §3) 시험할 것이 없고, 설령 있더라도 균일 층 기준은
거기에 닿을 수 없습니다. (그 인수분해는 2026-08-14부터 존재합니다.
[`patterned-anisotropic-factorization.md`](patterned-anisotropic-factorization.md)의 Popov–Nevière
인수분해이며, 거기서 fmmax와 비교해 판정했습니다. 텐서 Li는 2026-09-24에 합류했습니다.
[`tensor-li-factorization.md`](tensor-li-factorization.md).)

그렇지만 때가 되면 닿을 수 있습니다 — 다만 이 문서가 처음 주장한 경로로는 아닙니다.
RETICOLO는 패턴 층과 균일 층 사이에 선을 긋고, 자신의 V10 설명서 1쪽에 이를 밝힙니다.

> Diagonal anisotropy (`eps_xx != eps_yy != eps_zz`) can be incorporated in **structured grating
> layers** and gratings with **uniform layers** having **arbitrary anisotropy** (`eps_xy != 0` …)
> can also be handled

따라서 패턴 층은 대각 텐서만 받고 비대각 성분은 받지 않습니다. 전체 3x3은 층이 균일한 곳에서만
받아들여집니다. 여기에 두 가지 제약이 더 따르는데, 둘 다 예제에서 분명히 드러나지 않으며 그것을 중심으로
경우를 만들기 전에 알아 둘 가치가 있습니다.

* **기판과 superstrate는 이방성일 수 없습니다**(설명서, 1쪽). 여기의 골든 값은 양쪽이 진공이므로
  문제가 되지 않지만 — 이를테면 자기 광학 기판은 배제됩니다.
* `res3`의 흡수 손실 적분은 **비대각 이방성을 가진 균일 층에 대해서는 유효하지 않습니다**(설명서,
  13쪽). 효율은 영향을 받지 않으며, 그 손실 경로만 영향을 받습니다.

패턴이 있는 비대각 기준은 S4이며, S4는 패턴 영역의 텐서 재료를 직접 받습니다 — 실수 텐서만이지만,
그것으로 충분합니다. *복소*이기도 한 패턴 텐서에 대해서는 두 후보가 전체 복소 `eps` **와** `mu`
텐서를 지원합니다. `inkstone`과 `fmmax`입니다. 어느 것도 여기에 설치되어 있지 않습니다.

따라서 그 작업의 모든 단계에 기준은 존재하며, 존재하지 않는 것은 인수분해입니다. 어려운 부분은
비교할 대상을 찾는 것이 아니라 Popov–Nevière일 것이며 — 처음에는 틀린 이유로 도달했던 올바른
결론입니다.

## 참고 문헌

§5.1과 §8의 모든 수치는 이 둘 중 하나에 기대고 있습니다. 둘 다 기억에서 인용하지 않고 출판사 자료와
대조해 확인했습니다.

- D. W. Berreman, *Optics in Stratified and Anisotropic Media: 4×4-Matrix Formulation*,
  J. Opt. Soc. Am. **62**(4), 502 (1972).
  [doi:10.1364/JOSA.62.000502](https://doi.org/10.1364/JOSA.62.000502) —
  `tests/rcwa/test_anisotropic_berreman.py`가 구현하는 정식화입니다. 패러데이 회전과 광학 활성을
  표현할 수 있도록 고른 맥스웰 방정식의 6×6 표현에서 출발하며, 그래서 자이로트로픽 경우에 대한 우회책이
  아니라 자연스러운 기준입니다.
- J. P. Hugonin and P. Lalanne, *RETICOLO software for grating analysis*, Institut d'Optique,
  Orsay (2005); [arXiv:2101.00901](https://arxiv.org/abs/2101.00901) — 1D, conical, 2D 교차 격자를
  위한 RCWA 구현입니다. V9부터 임의로 이방성인 다층 적층을 위한 도구 상자를 지니며, 이것이 §8의 외부
  검사를 가능하게 했습니다. 이미 이 저장소에서 등방성 격자에 대한 가장 강한 기준입니다
  (`tests/references/golden_reticolo.npz`).

`anisotropic-materials.md`에서도, 패턴이 있는 이방성 층에 필요할 인수분해를 위해 다음을 인용합니다.
1차 정식화에 대해 Li (2003), 재배열에 대해 Popov and Nevière (2001), 이 저장소가 구현하는 NVF에 대해
Schuster et al. (2007).
