## 1. 스칼라 인수분해가 확장되지 않는 이유

`_nvf_assemble`의 입력은 `⟦eps⟧`와 `⟦1/eps⟧`가 전부입니다. 텐서에는 취할 `1/eps`가 없습니다 —
적어도 규칙이 요구하는 의미로는 없습니다. Li의 규칙은 불연속 인자 **하나**와 연속 인자 **하나**의
곱에 적용됩니다. 텐서에서는 연속인 양이 그런 곱 세 개의 합입니다.

```
  D_x = exx·E_x  +  exy·E_y  +  exz·E_z
```

그리고 항별 규칙은 없습니다. 스칼라 방법을 성분별로 적용하는 것은 올바른 답의 질 낮은 근사가
아니라, 다른 질문에 대한 답입니다.

## 2. 재배열

단위 법선이 `n`인 계면에서 접선 `E`와 법선 `D`는 연속이고, 법선 `E`와 접선 `D`는 불연속적으로
뜁니다. 점별 사영 연산자로 `N = n nᵀ`와 `T = I − N`을 쓰고, `D = eps E`에서 불연속인 `n·E`를
소거합니다. 다음과 같이 두면

```
  a = n·eps·n        p = eps n        q = epsᵀ n
```

소거로부터 `e_t = T E`에 대해 `(n·E) = [ (n·D) − q·e_t ] / a`를 얻고, 이를 다시 대입하면 다음과
같습니다.

```
  D = (eps − p qᵀ / a) e_t  +  (p / a) (n·D)
  E = (I   − n qᵀ / a) e_t  +  (n / a) (n·D)
```

이제 모든 우변은 **불연속 계수 하나와 연속인 양 하나의 곱**입니다 — Laurent 규칙이 수렴하는
경우입니다. 연속 벡터 `c = e_t + n (n·D)`로 모으면 다음과 같습니다.

```
  A = (eps − p qᵀ / a) T + (p / a) nᵀ        D = A c
  B = (I   − n qᵀ / a) T + (n / a) nᵀ        E = B c

  eps̃ = ⟦A⟧ ⟦B⟧⁻¹
```

행렬 역은 하나이고, 변환한 필드 사이의 행렬 곱은 없습니다. 이 마지막 부분이 설계의 전부이며,
§3은 그 이유를 다룹니다.

## 3. 동등해 보이지만 동등하지 않은 배열

더 깔끔해 보이는 경로가 있습니다. 연속 벡터와 불연속 벡터 사이의 점별 전달
`M = (T eps + N)(T + N eps)⁻¹`를 정의하고, `A = N + T M`과
`B = T + N M`임에 주목한 뒤, `⟦T⟧`, `⟦N⟧`, `⟦M⟧`을 세 개의 합성곱 행렬로 만들어 곱하는 것입니다.
점별 대수는 동일하며 — 1e-14까지 확인했습니다 — 그리고 틀렸습니다.

법선장은 내부로 확장한 **단위** 필드이므로(`normal_vector_field` — 이것이
`C_xx + C_yy = I`를 만듭니다) *그 자체가* 불연속입니다. 따라서 `⟦T⟧ @ ⟦M⟧`은 같은 곳에서 뛰는 두
인자에 Laurent를 적용한 것입니다. 바로 Li의 규칙이 금지하려고 존재하는 동시 불연속입니다. 사영
연산자 대수를 **점별로** 하고 변환을 한 번만 하면 이를 피할 수 있습니다.

이것이 절 하나를 할애할 가치가 있는 이유는 틀린 판이 보인 거동 때문입니다.

| 검사 | 틀린 배열 | 배포된 배열 |
|---|---|---|
| 손실 없는 텐서, `R + T = 1` | 성립 | 성립 |
| z축 회전 공변성 | 성립 | 성립 |
| fmmax와의 거리 | 그럴듯함 | 그럴듯함 |
| `eps̃`의 비에르미트성 | 4.4e-2, truncation_order에 따라 **정체** | 절단에만 의존 |
| **균일 층** | **0.5만큼 틀림** | 1e-15까지 정확 |

다섯 가지 중 세 가지는 유리판 하나에서 50% 틀리는 정식화에서도 통과합니다. 이를 잡아낸 것은 그
파일에서 가장 값싼 테스트이며 기준 솔버도 전혀 필요 없습니다. 계면이 없는 층에는 인수분해할 것이
없으므로, `eps̃`는 주어진 텐서 그대로 돌아와야 합니다. `eps = e I`에 대해 배포된 형태는 어떤
법선장에 대해서도 `⟦A⟧ = e ⟦B⟧`를 *항등적으로* 만족합니다 — 근사가 아니라 정확히 성립합니다.
`tests/rcwa/test_pn_factorization.py::test_a_uniform_layer_comes_back_as_the_tensor_it_was_given`.

## 4. 법선장이 사라지는 곳

`normal_vector_field`는 거리 변환의 골격 — 그래디언트가 사라지는 능선 — 에서 `(0, 0)`을
반환합니다. 재배열은 `a = n·eps·n`로 나누는데 거기서 이 값은 0이며, 처음 동작한 판은 그 몇 개의
픽셀 때문에 행렬 전체에 NaN을 만들었습니다.

해결책은 땜질이 아닙니다. `n = 0`이면 분자 `p`, `q`, `n nᵀ`가 모두 사라지고 `T = I`이므로,
`a = 1`을 대입하면 식이 스스로 `A = eps`와 `B = I`를 반환합니다 — direct 규칙이며, 이는
`_nvf_assemble`에서 0인 사영 연산자가 하는 일과 정확히 같습니다.

보호 조건은 **`a`가 사라지는 것이 아니라 필드가 사라지는 것**에 걸려 있으며, 이 구분은 핵심적입니다.
0인 법선은 기하입니다. 예상되고, 무해하며, 정확한 극한이 있습니다. *0이 아닌* 법선 아래에서
사라지는 `a`는 텐서 자체의 영방향이며 — 방법의 진짜 특이점입니다 — 거기서 값을 대입하면 진단
가능한 실패를 그럴듯한 숫자로 바꿔 버리게 됩니다. 그런 경우에는 대신 유한하지 않은 값으로
드러납니다.

## 5. 무엇으로 검사하는가

이 작업 이전에는 저장소의 어떤 것도 패턴이 있는 텐서를 판정할 수 없었습니다. 이 프로젝트를 위해
조사한 네 기준 솔버 중 RETICOLO는 이방성 층을 대각으로만, S4는 실수로만 받으며, inkstone은 전체
3×3을 받지만 z 행을 0으로 만든 텐서와 비트 단위로 같은 결과를 반환합니다 — 넘겨받은 것을 버리는
것입니다. **fmmax만이 패턴이 있는 복소 비대각 성분을 받아들이면서 실제로 그것을 사용한다는 것이
입증된 유일한 솔버**이며, 이것은 이 작업을 작성하기 전에 관문으로 확인했습니다. 패턴이 있는
`eps_xy`는 그 고유값을 8.9e-2만큼 움직이고, 자이로트로피에 패턴을 주면 균일한 경우와 8.2e-2만큼
달라집니다.

fmmax는 **동일성이 아니라 수렴으로** 판정합니다. 세 정식화가 관여합니다 — 이 정식화, fmmax의
`FFT`(순수 direct 규칙), fmmax의 `JONES_DIRECT`(다른 구성의 벡터 정식화) — 그리고 이들은 극한에서만
일치합니다. 그래서 골든 값은 fmmax의 답 *둘 다를* 고정하고, 허용 오차는 그 둘 사이의 퍼짐입니다.
어떤 주장도 기준 솔버 자신의 두 결과 사이 거리보다 더 정밀할 수 없습니다.

`truncation_order=14`, 진공 속 자이로트로픽 기둥에서:

| 경우 | fmmax FFT 대 JONES | 이 솔버, 더 가까운 쪽까지 |
|---|---|---|
| `n=1.15, g=0.10i` | 4.8e-6 | **3.0e-7** |
| `n=1.30, g=0.20i` | 3.0e-5 | **1.4e-7** |
| `n=1.60, g=0.30i` | 1.7e-4 | **2.0e-5** |

매번 그 폭 안에 있고, 그중 `JONES_DIRECT` 쪽에 있습니다 — 벡터 정식화라면 있어야 할 자리이며,
이것은 따로 단언합니다. 벡터 장치가 코드에는 있지만 답에는 없는 인수분해라면 `FFT` 쪽에 더
가까이 있을 것이며, 어떤 에너지 검사도 이를 볼 수 없습니다.

`tests/references/test_fmmax_patterned_golden.py`, 골든 값은 `gen_goldens_fmmax_patterned.py`로
생성합니다(`fwref` 환경 필요).

### 전치

**이 프로젝트는 층을 `A[y, x]`로 저장하고, fmmax의 배열 축 0은 첫 번째 격자 벡터, 여기서는 X를
따라갑니다.** 같은 물리적 층이 fmmax에게는 `A.T`입니다 — 어느 축이 x를 뜻하는지의 이름 바꾸기이지
거울상이 아니므로, 텐서 *성분*은 그대로입니다.

이것을 기록하는 이유는 잘못된 진단을 낳았기 때문입니다. 이것이 없으면 이 프로젝트의 두 인수분해 —
새 것*과* 그보다 먼저 배포된 등방성 NVF — 모두가 s/p 분리가 **뒤바뀐** 상태로 fmmax와 어긋났는데,
이는 비대각 부호 오류와 꼭 같아 보입니다. 결론을 낸 것은 배포된 경로를 대조군으로 실행한
것이었습니다. 오랫동안 검증된 경로가 같은 방식으로 실패한다면 그것은 새 경로의 버그가 아닙니다.
전치하자 세 대비 모두에서 fmmax가 두 인수분해 모두와, 자신의 정식화 퍼짐 이내로 맞았습니다.

같은 이유로 각 경우의 기둥은 일부러 **정사각형이 아닙니다**. 정사각형 기둥은 축 교환에 불변이어서
틀린 상태로도 통과했을 것입니다.

### 기준 솔버 없이 성립하는 것

- **`R + T = 1`** — 텐서가 모든 픽셀에서 에르미트이므로, 층은 어떻게 패턴을 주든 손실이 없습니다.
  truncation_order 4 / 8 / 12에서 잔차 1.7e-5 / 1.7e-6 / 5.8e-7이며, *추세*도 단언합니다. 초기의 한
  배열은 모든 차수에서 ~1e-2까지만 에너지를 보존했는데, 고정 허용 오차라면 그것을 통과로 판정했을
  것이기 때문입니다.
- 수직 입사에서 1e-12까지의 **z축 회전 공변성**. 비스듬한 입사에서는 래스터 회전을 `phi` 규약과
  맞춰야 하며, 배포된 NVF 경로도 거기서 같은 잔차를 보입니다 — 따라서 그 조합은 이 코드가 아니라
  시험 장치를 측정합니다.
- 겹치는 영역에서 **스칼라 NVF와의 일치**. truncation_order에 따라 수렴하는 방식은 아닙니다 — 측정해
  보면 그 차이는 1.3e-5 근처에 머물며 줄지 않는데, 이것은 괜찮습니다. 두 벡터 정식화는 어떤 유한
  절단에서도 다르며, 1.3e-5는 같은 구조, 같은 범위에서 fmmax 자신의 `FFT`와
  `JONES_DIRECT` 사이 차이 1.6e-4에서 4.3e-4(truncation_order 14에서 6)보다 한 자릿수 더 작습니다(2026-11-22에
  fmmax 1.7.1로 다시 측정했으며, 이 차수들 중 어디에서도 1.8e-4는 나오지 않습니다).
  강제되는 것은 *대비* 극한이며, 거기서 그 차이는 그것이 얹혀 있는 반사율보다 17x 빠르게 줄어듭니다.

## 6. 세 성분 전체 닫기

xz/yz/zx/zy 결합이 있으면 빌더는 A와 B의 아홉 성분을 모두 푸리에 변환하고 전체 연산자를
`conv(A) @ inv(conv(B))`로 닫습니다. 이때 zz 블록에는 횡방향 필드와의 결합이 담기므로
독립적으로 붙일 수 없습니다. 유전율과 투자율은 같은 구성을 쓰며 1차 솔버에 들어갑니다.
지원하는 기하, 독립적인 적층판/맥스웰 테스트와 수치 수렴 고려 사항은
[전체 텐서 패턴](../../guide/rcwa/full-tensor-patterns.md)을 보세요.

## 7. z 칸은 래스터를 계단으로 읽는다

`epz_i`는 계단에 대한 정확한 닫힌 형식인 `fourier2d_piecewise_constant`로 만듭니다 — 면내 블록
`A`와 `B`가 어쩔 수 없이 쓰는 `fourier2d_pointwise`가 아닙니다. 2026-08-17까지는 반대였으며, 이
전환을 여기에 기록하는 이유는 DFT를 그 자리에 넣은 논거가 버그를 근거로 삼고 있었고, 대체를
판정할 값싼 방법이 없기 때문입니다.

**옛 논거.** `eps_zz` 자체는 계단이므로 닫힌 형식은 그것에 대해 정확하며 언제나 당연한 선택이었습니다.
이를 기각한 근거는 일관성이었습니다. 닫힌 형식은 래스터를 연속 계단으로, DFT는 점 샘플로 읽는데,
`A`와 `B`는 닫힌 형식을 쓸 수 없고(eps와 샘플링한 법선장을 섞으므로), 한 층을 두 가지 방식으로
읽어 섞으면 참값이 가진 대칭 하나를 잃는 것처럼 보였습니다 — z축 회전 공변성이 1.9e-14에서
5.2e-8로 떨어졌습니다.

**그 논거가 더는 성립하지 않는 이유.** 그 차이는 기술 방식이 아니라 격자 원점 때문이었습니다.
샘플 변환은 픽셀 값을 왼쪽 가장자리에 두었고 닫힌 형식은 셀 중심에 두었습니다.
`da4762a`가 `_half_pixel_phase`를 추가해 닫힌 형식 쪽을 1.5e-14까지 맞췄습니다. 이제 두 쪽 모두
4분의 1 회전 대칭을 유지합니다.

**그리고 그 논거가 호소한 일관성은 애초에 작동하는 일관성이 아니었습니다.** `nz = 0`이면 사영
연산자는 블록 대각이므로 `A_zz = eps_zz`, `B_zz = 1`이고 z 칸은 `A`나 `B`와 곱해지지 않습니다 —
분리되어 있으므로 그들이 격자를 읽는 방식과 맞출 이유가 없습니다. 맞춰야 하는 것은 패키지입니다.
유전율 래스터는 각 픽셀을 *차지하는* 재료를 가리키므로, wavebit이 래스터를 읽는 곳이면 어디서나
계단입니다. `nvf_conv_matrices`도 같은 이유로 이 두 변환을 같은 방식으로 섞어, `ep_dir` / `ep_inv`에는
닫힌 형식을, 사영 연산자에는 샘플 변환을 씁니다. PN z 칸만이 그렇지 않은 유일한 곳이었습니다.

### 무엇으로는 판정할 수 없었는가

회전 공변성은 어느 쪽에서도 ~1e-14에 있으므로 아무것도 구분하지 못합니다. 에너지 보존은 애초에
불가능했습니다. 텐서가 모든 픽셀에서 에르미트이므로 층을 어떻게 인수분해하든 `R + T = 1`이
성립합니다 — 바로 그 점이 §5가 이 검사를 중시하는 이유이며, 동시에 둘 다 올바른 두 방식에 순위를
매길 수 없는 이유입니다. 외부 솔버도 순위를 매길 수 없습니다. 두 변환을 구분하는 것은 `sinc`
인자이며 이는 거친 격자 항이므로 —
`da4762a`에서와 똑같이 — 기준 솔버가 정밀해지는 곳에서는 신호가 사라집니다. **그리고 앙상블
중앙값으로도 안 됩니다.** 이 측정이 거의 빠질 뻔한 함정이 바로 이것입니다. truncation_order 6과
10에서 24개의 입사 조건에 대해 오차비의 중앙값은 0.98로, 겉보기에는 DFT가 유리합니다. 그 중앙값은
얕은 각도 영역이며, 거기서는 이 칸이 거의 기여하지 않습니다.

### 변환 자신의 정확한 극한과 비교하기

모델은 `da4762a`의 방식입니다. 경쟁 정식화가 아니라 정확한 계수와 비교합니다.
`fourier2d_integrated`가 직사각형의 실제 모서리 위에서 적분해 그 계수를 제공합니다. 모서리가 격자선인
직사각형에서는 래스터가 곧 층 **그 자체**이므로, 닫힌 형식에는 근사할 것이 없고 다른 쪽의 잔여는
오직 `sinc`에서 옵니다. 최대 상대 계수 오차,
truncation_order=6:

| N | 닫힌 형식 | DFT | DFT 차수 |
|---|---|---|---|
| 16 | 1.8e-16 | 3.0e-2 | |
| 32 | 1.8e-16 | 3.5e-3 | 3.08 |
| 64 | 1.8e-16 | 7.7e-4 | 2.19 |
| 128 | 1.8e-16 | 1.9e-4 | 2.04 |
| 256 | 1.8e-16 | 4.6e-5 | 2.01 |
| 512 | 1.8e-16 | 1.2e-5 | 2.00 |

닫힌 형식은 모든 N에서 정확하고 DFT는 `1/N**2`입니다 — 중점 규칙 자신의 차수이며, 반 픽셀 위상이 얻어
낸 것과 같은 차수입니다. 모서리를 격자에서 벗어나게 하면 픽셀화가 두 쪽 모두에 공통된 `O(1/N)` 항을 더합니다.
닫힌 형식은 거친 N에서 여전히 앞서며(N=16에서 2.5e-2 대 4.3e-2), 두 쪽은 N≈64부터 합쳐집니다.

### 풀이에서는 각도를 통해 답에 닿는다

`epz_i`는 `Kx epz_i Kx`와 그 짝들을 통해서만 들어오므로, 그 가중치는 입사각에 따라 커집니다. 측정은
모서리가 모든 N에서 격자선인 기둥에서 **고정된 truncation_order로 미세 격자 기준값과 비교하는** 래스터
스윕입니다 — 이때 층은 내내 문자 그대로 같은 함수이고 변환의 격자만 움직입니다. 기준값은 N=768이며,
거기서 두 쪽은 ≤5e-7까지 일치합니다 — 비교하는 가장 작은 오차보다 약 60x 아래 — 그래서 어느
쪽에도 유리하지 않습니다. 이를 N=1536으로 두 배로 늘려도 비는 셋째 자리에서만 움직입니다.

모든 차수에 대한 L2 오차, truncation_order=6, N=64, 자이로트로픽 기둥, 기판 `bot=2.1025` (`n = 1.45`):

| theta | 닫힌 형식 | DFT | DFT / 닫힌 형식 |
|---|---|---|---|
| 30 | 3.83e-5 | 3.58e-5 | 0.94 |
| 39 | 3.77e-5 | 3.87e-5 | 1.03 |
| 45 | 3.58e-5 | 4.85e-5 | 1.35 |
| 48 | 3.38e-5 | 5.79e-5 | 1.72 |
| 51 | 3.05e-5 | 7.31e-5 | 2.39 |
| 54 | 2.78e-5 | 1.03e-4 | **3.69** |
| 60 | 5.96e-5 | 9.58e-5 | 1.61 |
| 75 | 7.26e-5 | 8.79e-5 | 1.21 |

theta에 대해 매끄럽고 다른 설정에서도 재현되므로, 이것은 레일리 스파이크가 아니라 추세입니다.
wl=655 / psi=30에서는 교차점이 48° 근처이고 정점은 66°에서 1.94이며, truncation_order=10에서는 정점이
54°에서 2.84입니다. 닫힌 형식의 오차는 각도에 대해 훨씬 평탄하기도 합니다 — DFT 쪽의 오차가
입사각에 따라 커지는 것은 `Kx epz_i Kx`가 그것에 하는 일이 바로 그것이기 때문입니다.

38° 근처의 교차점 아래에서는 DFT가 실제로 최대 6.5%(30° 행) 앞섭니다. 이것이 위 중앙값의 정직한 절반이며,
그 이득은 절대값으로 2.5e-6이며, 닫힌 형식이 54°에서 얻는 7.5e-5와 비교하면 30분의 1입니다 — 그리고
7.5e-5 쪽이 바로 이 칸이 만들어진 목적의 영역입니다. (2026-11-22에 기록 당시의 `70b0993`과 `bbb04385`에서 다시
측정했으며, 위 표의 모든 행이 0.4% 이내로 재현됩니다. 앞서는 폭은 수직 입사에서 1%이고 30°에서 6.5%까지 커지며 38°에서
사라집니다.)

theta=54°, 같은 기둥에서의 래스터 수렴:

| N | 닫힌 형식 | DFT | DFT / 닫힌 형식 |
|---|---|---|---|
| 32 | 1.27e-4 | 4.40e-4 | 3.46 |
| 48 | 5.59e-5 | 1.91e-4 | 3.42 |
| 64 | 2.78e-5 | 1.03e-4 | 3.69 |
| 96 | 8.78e-6 | 4.03e-5 | 4.59 |
| 128 | 4.11e-6 | 1.98e-5 | 4.82 |
| 192 | 3.06e-6 | 6.57e-6 | 2.14 |
| 256 | 2.70e-6 | 2.73e-6 | 1.01 |

두 쪽은 같은 답으로 수렴합니다 — 이것은 처음부터 끝까지 거친 격자 항이며, 그래야 마땅합니다 —
그리고 닫힌 형식이 대략 래스터를 한 번 두 배로 늘린 만큼 더 빨리 도달합니다.

**곡선 경계에서는 어느 쪽도 극한이 아닙니다.** 원판에서 같은 스윕을 하면 두 쪽이 똑같이 지니는
형상 자체의 픽셀화가 지배합니다. 오차는 N에 대해 단조롭지 않고 비는 추세 없이 0.6과 1.6 사이를
오갑니다. 이것은 전환에 반하는 증거가 아니라, 곡선 층을 제한하는 것은 z 칸이 아니라는 진술입니다 —
제한하는 것은 계단 근사입니다
([`parametric-modeling.md`](../../guide/rcwa/parametric-modeling.md), 계단 근사가 사라진 경로).

`tests/rcwa/test_pn_factorization.py::test_the_z_slot_reads_the_raster_as_the_staircase_it_is`는
정확성 *그 자체인* 불변성으로 이 선택을 고정합니다. 래스터의 픽셀을 반복하면 같은 계단을 다르게
표기할 뿐이므로, 닫힌 형식은 움직일 수 없고 DFT는 움직입니다. 위의 각도 측정은 너무 느려서 그
파일에 둘 수 없습니다.

## 8. `mu`에도 쓰인다

E/H 쌍대성에 의해 그대로 쓰입니다. 재배열은 계면에서 어떤 양이 연속인지에 관한 것이며,
*법선 B와 함께한 접선 H*는 이름만 바꾸면 *법선 D와 함께한 접선 E*입니다. 래퍼와 투자율 쪽에만
있는 두 함정 — 뒤집힌 칸 순서, 그리고 두 텐서의 경계가 달라 법선장이 두 개 필요한 층 — 은
[`magnetic-materials.md`](magnetic-materials.md) §7을 보세요.

## 9. 사용하기

`to_conv_mat_raster_pn_eps(tensor_raster, half_width_u, half_width_v)`는 `(n_layers, Ny, Nx, 3, 3)`을 받아
적층의 다섯 칸을 반환합니다. 이 함수는 **유전율**을 받으며, 항상 그래 왔습니다 — `n ** 2`는
스칼라 연산이며, 텐서 필드의 제곱근은 추측해 볼 가치가 없습니다.
2026-08-20부터 이것은 더 이상 이 빌더만의 특별한 규칙이 아닙니다. 스칼라 입구도 유전율을 받으므로,
아래의 래스터와 그 옆의 텐서는 이제 랭크만 하나 다른 같은 양입니다.

공개 `structure`는 `(layers, Ny, Nx, 3, 3)` 모양의 텐서 래스터와
텐서 `Material` 값을 지닌 형상을 받습니다. 일반 입구가 필요한 칸을 만듭니다(코드 조각은 예전
인터페이스를 쓰며, 그 인터페이스는 2026-10-13부터 `wavebit.compat.legacy`였습니다. 공개 모듈은
텐서 래스터를 `rcwa.Layer(epsilon=...)`로 받습니다).

```python
import numpy as np
from wavebit.compat import legacy as wavebit

eps = np.where(mask, 2.56, 1.0).astype(complex)          # (Ny, Nx)
g = np.where(mask, 0.30j, 0.0).astype(complex)
t = np.zeros(eps.shape + (3, 3), dtype=complex)
t[..., 0, 0] = t[..., 1, 1] = t[..., 2, 2] = eps
t[..., 0, 1], t[..., 1, 0] = g, -g
mee = wavebit.rcwa(truncation_order=(truncation_order, truncation_order),
                   period=(p, p), wavelength=wl, thickness=[d], structure=t[None])
res = mee.solve()
conv = mee.eps_conv_matrices()                       # operators about the cell centre
relayed = mee.solve_conv(*conv)                      # the same solve; epz_i is third
```

`to_conv_mat_raster_pn_eps` 같은 비공개 빌더는 `mee._solve_conv(*conv)`용 모서리 기준 행렬을
만듭니다. 2026-09-28부터 공개 `solve_conv`는 중심 기준 입력을 읽습니다. 칸 순서 자체는 바뀌지
않았습니다. 2026-08-18부터 `epz_i`가 셋째 자리에 있습니다. 그 수정 이전에는 다섯 칸 빌더를 펼쳐
넘기면 뒤집힌 zz 행렬이 `epxy`에 들어가, 손실 없는 수동 기둥에 대해 `R + T = 1.61`을 반환할 수
있었습니다. `tests/rcwa/test_slot_order.py`는 비공개 빌더 경로를 수정된 순서로 고정해 둡니다.

이것을 틀리게 하는 남은 방법도 같은 식으로 조용합니다. 비대각 **칸은 부호를 뒤집은 값을 담으며**,
`to_conv_mat_raster_pn_eps`는 이를 이미 적용했습니다.
[`off-diagonal-slot-convention.md`](off-diagonal-slot-convention.md)를 보세요.
