# 배우기

이 강좌들은 물리 모델, 이산화, 솔버 출력, 수렴 검사를 서로 연결합니다. 순서대로 읽어도 되고, 지금 하려는 계산에 맞는 부분을 골라 읽어도 됩니다.

- [RCWA 기초](fundamentals/index.md): 20개 장과 자세한 부록 3개. 주기 산란부터 필드, 미분, 파수 벡터 가지 선택까지 다룹니다.
- [법선 벡터 인수분해(NVF)](nvf/index.md): 경계 연속성, 푸리에 곱, 투영 연산자 구성, 수렴을 다루는 15개 장.
- [FDTD 학습 과정](fdtd/index.md): 도메인, 소스, 모니터, 과도 오차, 솔버 간 비교.
- [실행 가능한 교육용 예제](examples.md)가 RCWA 강좌에 딸려 있습니다.

영어가 정본 문서 언어입니다. 언어 전환 메뉴는 전체 번역이 있는 경우 같은 페이지의 한국어판을 열고, 영어로 대체 표시되는 페이지는 따로 표시합니다. 원 출처와 과거 측정의 한계는 [학습 자료 반입 기록](../development/learning-provenance.md)에 있습니다.
