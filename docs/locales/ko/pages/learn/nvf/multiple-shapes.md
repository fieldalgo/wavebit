# 11. 여러 도형, 보조 솔버, 자주 생기는 오해

## 한 층에 여러 도형을 넣으면

`shapes` 목록에 도형을 더 넣을 수 있습니다. 서로 다른 재료가 만나거나 주기 셀을 가로지르는 경우에는 도형을 독립적인 섬으로만 보면 안 됩니다. 실제로 보이는 재료 경계와 주기 이미지를 함께 다뤄야 합니다. 겹치는 입력은 painting 규칙에 의해 실제 영역이 정해집니다. 지원 범위와 겹침의 세부 처리는 [parametric modeling 문서](../../guide/rcwa/parametric-modeling.md)를 확인하세요.

동일 재료 도형 둘 사이의 내부선은 물리적 유전율 불연속이 아닙니다. 다만 입력 도형을 쪼개는 방법이 방향장의 내부 연장에 영향을 주면 유한 차수의 계산값은 달라질 수 있습니다. “같은 물체이니 입력을 어떻게 나눠도 유한 차수 결과가 비트까지 같다”는 보장은 하지 않습니다. 중요한 문제라면 표현 방식도 검증 항목에 넣으세요.

## 보통 NVF를 쓸 때 FEM도 실행되나

```{figure} ../../figures/learn/nvf/12-map.svg
:alt: 일반 NVF와 명시적인 보조 셀은 서로 다른 구성 경로
:figclass: learning-figure

그림 11-1. 일반 NVF와 명시적인 보조 셀은 서로 다른 구성 경로
```

**이 교재의 예제 5개는 보조 FEM 셀을 호출하지 않습니다.** 일반 NVF는 경계의 방향 정보를 연장하고 투영 계수를 만들어 재료 행렬을 조립합니다. `factorization='nvf'`를 선택한다고 삼각형 보조 솔버가 자동으로 켜지지는 않습니다.

별도 고급 경로에는 `ConformingNVF`와 실험적인 pair transmission 셀 등이 있습니다. 추가적인 정전기·약형 문제로 장 기저 또는 재료 응답을 만들고, 구성한 행렬을 기존 RCWA 엔진에 전달합니다. 지원 구조, 재료 조건, 근사 공간과 검증 상태는 일반 NVF와 다릅니다. 여기서는 사용 흐름의 위치만 설명합니다. 고급 내용은 [ConformingNVF 안내](../../guide/rcwa/conforming-nvf.md)와 [개발 기록 교재](../../validation/rcwa/nvf-contact-followup.md)를 이어서 읽으세요.

## 오류나 낯선 결과를 읽는 법

| 상황 | 먼저 확인할 것 |
| --- | --- |
| raster에 shape_nvf_grid_size를 넣었더니 거부 | 입력 이미지의 해상도를 바꾸세요. shape_nvf_grid_size는 shape NVF용입니다. |
| shape에 raster_normal_method를 넣었더니 거부 | shape의 법선은 도형에서 구성합니다. 해당 옵션을 빼세요. |
| Li와 nvf_projector를 같이 넣었더니 거부 | NVF 투영을 만들지 않는 경로입니다. 전용 옵션을 빼세요. |
| 원/회전 도형에서 shape Li가 거부 | 지원되는 일반 shape NVF 경로를 사용하세요. |
| n=2를 입력했는데 예상과 다름 | material=2는 ε=2입니다. n=2라면 ε=4를 넣으세요. |
| R+T가 1인데 두 설정의 T가 다름 | 에너지 보존과 수렴은 다른 검사입니다. 차수와 공간 표현을 비교하세요. |
| circular로 바꿨는데 결과가 더 나쁨 | 보편적 정확도 순위가 아닙니다. 기준과 관심 물리량으로 비교하세요. |
| JIT에서 기하 관련 오류 또는 NaN | 먼저 구체적인 입력의 eager 계산을 확인하고, 기하를 밖에서 준비하세요. 입력 유효성과 조건화도 확인하세요. |
| 투과율은 안정적인데 기울기가 흔들림 | 값과 미분의 수렴은 다릅니다. 특히 shape의 shape_nvf_grid_size와 형상 변화를 함께 점검하세요. |
