# 04. 경계 법선 n → 보조벡터 J → 투영 행렬 P

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

**n은 경계의 방향, J는 그 정보를 영역 전체에 연장한 계산용 기준, P는 그 기준으로 성분을 뽑는 행렬입니다.** 전기장 E는 이 정보로 방정식을 구성한 다음 구합니다. 법선을 알아내려고 전기장을 먼저 계산하는 것이 아닙니다.

```text
도형·재료 정보 → 경계 법선 n → 영역 전체의 보조벡터 J
                                  ↓
                              투영 행렬 P
                                  ↓
                     Fourier 계수와 재료 행렬 구성
                                  ↓
                 입사광 조건과 함께 방정식 풀이 → 전기장 E
```

## n: 도형의 매끄러운 경계에서 정해지는 실제 법선

법선은 경계에 수직인 방향입니다. 이 교재의 xy 단면에서는 `n=(nx, ny)`처럼 숫자 두 개로 표현하며, 보통 `nx²+ny²=1`인 단위벡터로 씁니다. 중심이 원점인 원의 오른쪽 끝은 `n=(1,0)`, 위쪽 끝은 `n=(0,1)`, 오른쪽 위 45° 지점은 `n=(1/√2, 1/√2)`입니다. 모두 도형만 보고 알 수 있습니다.

**원의 중심에는 실제 경계 법선이 없습니다.** 경계가 아니기 때문입니다. 사각형의 꼭짓점처럼 경계 자체가 매끄럽지 않은 곳도 법선 하나를 정할 수 없습니다. 도형 내부에 방향을 지정할 수는 있지만, 그것은 실제 경계 법선과 구별해야 합니다.

## J: 경계의 법선 정보를 영역 전체로 연장한 보조벡터

NVF는 Normal Vector Field를 뜻합니다. RCWA의 Fourier 계산에는 경계의 몇 점만이 아니라 **한 주기 영역 전체에 정의된 분해 기준**이 필요합니다. 그래서 경계의 법선에 맞는 기준을 만들고, 도형 내부와 바깥 배경에도 계산용 벡터 J를 채웁니다. 이 교재에서는 실제 경계 법선을 n, 연장한 보조벡터를 J로 구별합니다. 구현이나 다른 자료에서는 연장된 장도 n이라고 부를 수 있으므로 기호보다 정의를 확인하세요.

| 기호 | 무엇인가 | 어디에서 어떻게 정하나 | 전기장 E가 필요한가 |
| --- | --- | --- | --- |
| `n` | 실제 경계의 단위 법선벡터 | 매끄러운 재료 경계의 기하가 정함 | 필요 없음 |
| `J` | 성분 분해 기준을 담은 보조벡터 | 경계 법선에 맞추고, 전체 영역으로 연장해 구성 | 필요 없음 |
| `P` | 그 기준을 적용하는 2×2 투영 행렬 | J의 성분으로 계산 | 필요 없음 |

```{figure} ../../figures/learn/nvf/04-field.svg
:alt: 경계의 n, 영역 전체의 J, 성분을 뽑는 P는 역할이 다르다
:figclass: learning-figure

그림 4-1. 경계의 n, 영역 전체의 J, 성분을 뽑는 P는 역할이 다르다
```

경계에서는 J가 n과 같은 투영을 만들도록 구성합니다. 실수 예에서는 `J=n`으로 둘 수 있고, 복소 표현에서는 n에 공통 복소 위상이 곱해져도 같은 투영이 됩니다. **내부의 J는 실제 법선일 필요가 없습니다.** 주기성, 여러 경계의 조합과 매끄러운 연결을 고려해 구성하는 계산용 정보입니다.

## P: J로 하는 성분 분해를 하나로 묶은 행렬

J는 벡터이고 P는 행렬입니다. 0이 아닌 J에서 다음처럼 만듭니다. `H`는 복소켤레를 취한 뒤 세로·가로를 바꾸는 켤레전치입니다. 실수에서는 보통의 전치와 같습니다.

```text
P = J Jᴴ / (Jᴴ J)

J의 길이를 1로 맞췄다면:
J = (a, b)ᵀ,  |a|² + |b|² = 1

P = [ |a|²    a b*  ]     *는 복소켤레
    [ b a*    |b|²  ]
```

길이를 1로 맞춘 J를 사용해 성분을 뽑는 계산은 두 단계입니다. 먼저 `c = JᴴE`로 해당 성분의 크기를 구합니다. c는 스칼라이며 복소수일 수 있습니다. 다음으로 `Jc`를 계산해 그 성분을 벡터로 되돌립니다. 단위 J를 쓸 때 이 두 단계를 묶으면 `J(JᴴE) = (JJᴴ)E = PE`입니다. **P는 별도의 방향을 새로 정하는 것이 아니라, J로 하는 계산을 미리 묶어 놓은 것입니다.**

아래는 가로 방향의 분해를 보여 주는 손계산입니다. E의 예시값은 P가 무엇을 하는지 확인하기 위해 넣었으며, 법선을 구할 때 사용한 값이 아닙니다.

```text
J = (1, 0)ᵀ  →  P = [ 1  0 ]
                     [ 0  0 ]

예시 E = (3, 2)ᵀ  →  PE = (3, 0)ᵀ
```

```{figure} ../../figures/learn/nvf/05-projector.svg
:alt: J로 P를 만들고, P를 적용하면 선택한 성분이 남는다
:figclass: learning-figure

그림 4-2. J로 P를 만들고, P를 적용하면 선택한 성분이 남는다
```

P는 E 없이 미리 만들 수 있습니다. Wavebit는 위치별 `Pxx, Pxy, Pyx, Pyy`를 Fourier 계수로 바꾸고, ε와 1/ε의 계수와 결합해 RCWA의 재료 행렬을 구성합니다. E는 그 행렬이 들어간 방정식을 풀어 얻습니다. **이미 구한 E를 사후에 나누기만 하는 방법이 아닙니다.** 5장에서 이 조립식을 봅니다.

## 접선 쪽이 I−P인 이유

I는 벡터를 그대로 두는 항등행렬입니다. 전체에서 선택한 성분을 빼면 나머지 성분이므로 `(I−P)E = E−PE`입니다. 매끄러운 경계에서는 PE가 법선 성분이고 나머지가 xy 평면의 접선 성분입니다.

```text
E = PE + (I−P)E
(3, 2)ᵀ = (3, 0)ᵀ + (0, 2)ᵀ
             법선        접선     ← 세로 경계의 예
```

복소 J에도 이 분해는 성립합니다. 다만 경계에서 떨어진 내부에서는 두 부분을 실제 법선·접선이라고 해석하기보다, **경계의 분해를 내부까지 연장한 계산용 두 성분**으로 읽어야 합니다. 0이 아닌 J의 정규화된 투영은 `P²=P`, `Pᴴ=P`, `trace(P)=1`을 만족합니다. 실제 코드의 영벡터·퇴화 지점 처리는 이 식의 적용 조건과 별도로 필요합니다.

실수 법선에서는 `P=nnᵀ`이며, `P(n)=P(−n)`입니다. 부호가 반대여도 같은 분해를 한다는 뜻입니다. 그러나 반대 벡터를 먼저 더하면 0이 될 수 있으므로, 이 성질만으로 여러 벡터를 더할 때의 상쇄 문제가 해결되는 것은 아닙니다.

## linear와 circular: 내부의 분해 기준을 구성하는 두 방식

실수 재료의 기본 예에서 **linear는 실수 직선 방향을 연장해 투영을 만듭니다.** 경계 법선에 맞춘 J가 내부에서도 실수 방향을 나타내는 형태입니다. Wavebit의 복소 재료 shape 경로에서는 linear에도 복소 성분과 Hermitian 투영을 사용할 수 있으므로, API 이름을 단순히 “실수 배열 / 복소 배열”로 해석해서는 안 됩니다.

**Circular는 복소 보조벡터를 사용하는 별도의 구성입니다.** 경계에서는 실제 법선과 같은 투영을 만들고, 내부에서는 두 성분 사이의 상대적인 크기와 위상까지 사용해 분해 기준을 이어 갑니다. 모든 점에서 순수한 원형 기저를 쓰는 것도, 원 모양 도형에만 쓰는 것도 아닙니다.

## 원의 중심에서 왜 차이가 생기나

원의 법선을 중심 쪽으로 그대로 연장하는 실수 예를 생각해 봅시다. 오른쪽에서 접근하면 가로 방향, 위에서 접근하면 세로 방향이 남습니다. 중심 한 점에 임의의 벡터를 지정해도 **주변에서 접근하는 방향마다 투영의 극한이 다르다는 문제**는 없어지지 않습니다. 반대쪽인 오른쪽·왼쪽은 같은 투영을 만들므로, 이 예에서는 오른쪽·위쪽을 비교합니다.

```{figure} ../../figures/learn/nvf/04b-center.svg
:alt: 원 중심의 실제 법선은 없지만, 복소 보조벡터로 투영을 매끄럽게 연결할 수 있다
:figclass: learning-figure

그림 4-3. 원 중심의 실제 법선은 없지만, 복소 보조벡터로 투영을 매끄럽게 연결할 수 있다
```

복소수까지 허용하면 중심에서 `J=(1,i)/√2`를 사용하는 연장이 가능합니다. 이 J는 고정된 실수 화살표 하나가 아니지만, 두 성분의 값과 그로부터 계산하는 P는 확정됩니다.

```text
중심의 한 가지 선택:
J = (1, i)ᵀ / √2

P = ½ [ 1  −i ]
      [ i   1 ]
```

**“중심에서 하나로 이어진다”는 것은 같은 실수 화살표가 아니라 같은 P로 이어진다는 뜻입니다.** 위 P는 단순히 `I/2`가 아닙니다. 대각선 밖의 ±i/2 성분이 있어야 이 복소 분해를 나타낼 수 있습니다. i는 보조 기저의 x·y 성분 사이에 90° 위상 관계를 담지만, 실제 입사광이 회전한다는 뜻은 아닙니다.

그림은 가능한 연장을 보여 주는 교육용 모델입니다. 반지름 1인 원판에서 `v=(x,y)ᵀ`, `r²=x²+y²`, `M=vvᵀ+(1−r²)I`, `J=M(1,i)ᵀ`로 둡니다. 경계에서 `M=nnᵀ`이므로 P는 실제 법선 투영이 되고, 중심에서 `M=I`이므로 위의 복소 투영이 됩니다. 이는 Wavebit가 계산한 실제 필드나 주기 셀 전체의 구현식을 그대로 그린 것이 아닙니다.

## Wavebit에서 어디에 쓰이며, 무엇과 독립적인가

이 투영 구성은 **raster NVF와 shape NVF 모두**에서 사용됩니다. raster는 픽셀 재료 패턴에서 방향장을 추정하고, shape는 도형의 경계 기하에서 구성합니다. 이어서 P의 Fourier 성분을 재료 행렬에 반영하는 역할은 같습니다. Li 경로에서는 이 NVF 투영장을 구성하지 않습니다.

세부 구현은 두 입력에서 다릅니다. raster circular는 방향과 수직 방향을 상대 위상 i로 조합하며 장의 크기 정보에 따라 혼합합니다. shape circular는 경계 조각의 법선 다이애드 `nnᵀ`를 양의 가중치로 결합한 행렬에서 J에 해당하는 복소 조합을 만들고 투영을 구성합니다. J는 설명을 위한 공통 기호이며, 코드가 모든 경로에서 J라는 배열을 반드시 따로 저장한다는 뜻은 아닙니다.

**`nvf_projector='linear'`와 `'circular'`는 입사광 편광 설정이 아닙니다.** 입사광은 `psi`, `chi`, `polarization` 등의 별도 설정으로 지정합니다. 같은 선편광 입사광을 유지한 채 NVF 투영 방식만 비교할 수 있습니다. circular가 언제나 더 정확하다는 뜻도 아니며, 유한 Fourier 차수에서 원하는 물리량의 수렴을 비교해야 합니다.
