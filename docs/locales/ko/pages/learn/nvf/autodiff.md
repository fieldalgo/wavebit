Wavebit의 장점 중 하나는 선택한 유한 계산의 미분을 얻을 수 있다는 점입니다. 먼저 재료값 ε 하나만 바꾸고 도형 배치는 고정한 예제로 연습합니다. 형상 접촉·겹침의 변화까지 한꺼번에 다루지 않아도 미분의 흐름을 이해할 수 있습니다.

JAX 환경이 없다면 Wavebit 소스 폴더에서 문서화된 선택 의존성을 설치한 뒤 예제를 실행합니다. 이 교재를 만들 때는 기존 환경을 사용했고 새 라이브러리를 추가하지 않았습니다.

```bash
# Wavebit 소스 폴더에서 필요한 경우에만
python -m pip install '.[jax]'

# 같은 폴더에서
python examples/rcwa/learning/nvf/04_jax_gradient.py
```

`rcwa.prepare()`는 구체적인 구조로 이산 기하 선택을 기록합니다. JIT 함수 안의 `prepared.run(updated_problem)`은 새 재료값의 연속 계산과 JAX 미분을 유지합니다. “기하를 준비했다”는 말이 모든 입력의 미분을 끊는다는 뜻은 아닙니다.

이 예제는 **같은 도형 배치에서 재료값만** 바꾸므로 준비한 기하를 재사용합니다. 도형 개수, 겹침 관계, 주기 이미지 요구 등이 달라지면 같은 기록을 무조건 재사용해서는 안 됩니다. 이 예제는 기하를 바꾸지 않습니다. 일반 형상을 JIT에서 바꾸려면 명시적 host topology 정책을 선택하고 결과의 validity를 확인하세요. 새로운 기하 관계는 구체적인 입력으로 다시 준비하고 확인해야 합니다.

## 실제 미분과 차분 비교

| 항목 | 실제 실행값 |
| --- | --- |
| JIT에서 T_p | 0.996179995709902 |
| 새 eager 계산의 T_p | 0.996179995709905 |
| 자동미분 dT/dε | 0.002181443388964 |
| 중심차분, h=0.001 | 0.002181443461702 |
| 중심차분, h=0.0005 | 0.002181443408689 |
| 마지막 차분과 자동미분의 절대 차이 | 1.97×10⁻¹¹ |

차분에서는 고정 기하 기록을 재사용하지 않고, ε+h와 ε−h의 solver를 새로 만듭니다. h를 절반으로 했을 때도 미분값이 일치하는지 확인했습니다. h가 무조건 작을수록 좋은 것은 아닙니다. 너무 작으면 두 비슷한 값의 뺄셈에 반올림 오차가 커집니다.

이 결과는 이 구조와 유한 설정에서 재료 미분의 구현이 차분과 일치함을 보여 줍니다. 더 높은 Fourier 차수에서도 같은 물리 기울기로 수렴했음을 증명하지는 않습니다. 예를 들어 ε=n²인 손실 없는 실수 재료에서 n을 최적화한다면 `dT/dn = 2n·dT/dε`이며, 지금 출력한 값과 미분 대상이 다릅니다.
