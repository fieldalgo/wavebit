## 실제 문제에 적용하는 순서

1. 관심 물리량과 허용 오차를 먼저 정합니다. 예를 들어 투과율 절대 차이와 기울기 상대 차이를 서로 다른 기준으로 둘 수 있습니다. 특정 숫자가 모든 문제의 공통 기준은 아닙니다.
2. shape에서는 Fourier 차수를 고정하고 shape_nvf_grid_size를 늘립니다. raster에서는 원본 기하를 더 정밀한 픽셀로 다시 표현해 비교합니다. 이때 Fourier 계수 방식과 법선 설정은 고정합니다.
3. 충분히 안정된 공간 표현을 고정하고 Fourier 차수를 여러 단계 높입니다. x와 y의 변화 규모가 다르면 Nx와 Ny를 따로 늘려 어느 방향이 부족한지도 확인합니다.
4. 최종적으로 두 해상도를 함께 더 높여 결과가 유지되는지 확인합니다. 최적화에 사용할 경우 값뿐 아니라 해당 미분값도 비교합니다.
5. 가능한 문제에서는 해석해, 다른 독립 풀이 또는 충분히 검증한 기준과 비교합니다. 에너지 보존과 대칭성도 함께 확인하되, 각각이 검증하는 범위를 구분합니다.

조밀한 재료 행렬의 크기는 M×M이며, 전자기 고유치 문제는 이보다 큰 블록을 사용합니다. 두 방향의 차수를 함께 늘리면 M이 빠르게 커지고, 조밀 행렬의 메모리와 분해 시간도 크게 증가합니다. `shape_nvf_grid_size`는 주로 방향장 샘플링·적분 비용을 늘립니다. 둘의 비용 원인이 다르므로 한 번에 모두 최대값으로 올리기보다, 부족한 축을 파악하는 편이 합리적입니다.

흡수가 있는 경우에는 무조건 R+T=1을 기대하면 안 됩니다. 입출력 매질과 정규화가 적절한 수동 구조에서 `1−R−T`는 흡수와 연결됩니다. 손실 없는 예제의 에너지 검사 공식을 모든 손실 문제에 그대로 적용하지 마세요.
