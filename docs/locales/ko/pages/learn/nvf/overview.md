# 01. RCWA 안에서 NVF는 무슨 일을 하나

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

RCWA는 주기 구조의 빛 산란을 계산하는 방법입니다. 한 층의 xy 단면에 나타나는 재료와 장을 Fourier 성분으로 표현하고, z 방향으로 전파하는 모드를 구한 뒤, 층 사이의 경계조건을 연결합니다. 최종적으로 회절차수별 반사율과 투과율 등을 얻습니다.

```{figure} ../../figures/learn/nvf/01-rcwa.svg
:alt: 반복되는 xy 셀과 z 방향 층 구조
:figclass: learning-figure

그림 1-1. 반복되는 xy 셀과 z 방향 층 구조
```

푸리에 차수는 정수 쌍 `(m,n)`으로 표시합니다. 기본 역격자 벡터를 `b₁`, `b₂`라 쓰면 각 차수의 파수 벡터는 `m b₁ + n b₂`입니다. 이는 [기초 2장](../fundamentals/rcwa.md)·[6장](../fundamentals/lattice.md)과 같은 표기입니다. 셀 크기가 `(Lx, Ly)`인 직사각 셀에서는 `b₁=(2π/Lx, 0)`, `b₂=(0, 2π/Ly)`이므로 `m b₁ + n b₂ = 2π(m/Lx, n/Ly)`가 됩니다. 전기장의 횡방향 성분에는 입사광의 평행 파수도 더해집니다. 실제 계산에서는 무한히 많은 `(m,n)` 가운데 일부만 남깁니다.

```text
E(x,y,z) ≈ Σ E_mn(z) exp[i(k_parallel + m b₁ + n b₂) · (x,y)]
           m = −Nx … Nx,  n = −Ny … Ny

유지하는 공간 모드 수 M = (2Nx + 1)(2Ny + 1)
```

재료 경계에서 ε와 전기장 성분이 동시에 불연속이면, Fourier 급수를 유한하게 자른 뒤 단순히 곱하는 방식이 경계조건을 잘 표현하지 못할 수 있습니다. NVF는 **재료 경계의 법선 방향을 이용해, 성분마다 알맞은 Fourier 곱 규칙을 적용하도록 돕습니다.** RCWA 전체를 대체하는 별도 광학 솔버가 아니라, RCWA에 들어가는 재료 연산자를 구성하는 방법입니다.

NVF는 Wavebit가 처음 발명한 개념이 아닙니다. 불연속 함수의 Fourier 곱을 다루는 기반은 [Li의 1996년 논문](https://doi.org/10.1364/JOSAA.13.001870)에, crossed grating의 RCWA에 법선 벡터장을 적용하는 방법은 [Schuster 등의 2007년 논문](https://doi.org/10.1364/JOSAA.24.002880)에 나옵니다. 이 책은 그 배경 위에서 **현재 Wavebit가 실제로 선택한 유한 행렬 조립과 API**를 설명합니다. 아래의 모든 구현 세부가 두 논문과 동일하다는 뜻은 아닙니다.
