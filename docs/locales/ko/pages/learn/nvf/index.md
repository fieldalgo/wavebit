# NVF 배우기: Wavebit의 원리, 구현, 사용법

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

경계에서 달라지는 전기장 성분을 이해하고, 그 원리가 Wavebit의 재료 행렬과 실행 코드로 이어지는 과정을 배우는 교재입니다.

**기준: Wavebit 0.1.0 개발 작업본.** 비자성 재료와 스칼라 상대 유전율을 중심으로 설명합니다. 텐서 재료와 고급 보조 셀의 범위는 영문 사용 안내를 함께 확인하세요.


**이 책의 목표는 세 가지입니다.** NVF가 필요한 이유를 설명할 수 있고, Wavebit에서 법선장이 재료 행렬로 바뀌는 과정을 읽을 수 있으며, 자신의 구조에 NVF를 적용한 뒤 결과의 정확도를 확인할 수 있게 하는 것입니다.

앞서 만든 [개발 기록 교재](../../validation/rcwa/nvf-contact-followup.md)는 어떤 문제를 고쳤고 무엇을 검증했는지를 다룹니다. 이 책은 독립적으로 읽을 수 있는 원리·사용 교재입니다. 먼저 1–4장으로 원리를 익히고, 7장의 예제를 실행한 뒤 5–6장으로 돌아와 구현을 읽어도 좋습니다.

기본 과정에는 원리 그림과 개념 조작 예제, Python 실행 예제 5개가 있습니다. 개념도와 브라우저 조작 예제는 RCWA 계산 결과가 아니며, 실제 결과는 출처가 표시된 표와 그림에서 구분합니다.

**금속 사례는 13–15장을 순서대로 읽으세요.** 원본 그림에서 이상 징후를 찾고, 역 규칙의 작은 분모를 이해한 뒤, 특이값 하한 보정의 효과와 한계를 평가합니다. 이 세 장은 저장된 실험 결과를 설명하며 새 계산을 실행하지 않습니다.
