# 06. 정사각형 바깥으로: 격자와 두 좌표계

:::{note}
이 페이지의 본문과 코드는 현재 `rcwa` API를 씁니다. 그림에는 이전 생성자의 이름(`bot`, `structure`,
원의 지름 `lx`)이 남아 있을 수 있습니다. 현재 표기는 [기본 약속](conventions.md)을 참고하세요.
:::

**래스터는 격자 칸에 재료를 붙이고, 도형은 실제 공간에 모양을 정합니다.** 아래에서는 두 변의 길이를 모두 600 nm로 유지하고, 두 격자 벡터 사이의 각도 `α`만 90°에서 60°로 바꿉니다. 여기서 바꾸는 것은 두 변 사이의 각도입니다. 구조 전체를 통째로 회전시키는 경우와 구별합니다.

`period=(600., 600.)`은 직교 셀을 쓰는 방법입니다. 사선 셀은 두 기본 벡터를 갖는 `Lattice`로 표현합니다. `period`와 `lattice`는 한 셀에 대한 두 표현이므로 동시에 넘기지 않습니다.

```python
import numpy as np
from wavebit import Lattice

A90 = Lattice.rectangular(600., 600.)
A60 = Lattice.oblique(600., 600., np.deg2rad(60.))
X, Y = A60.meshgrid_xy((64, 96))
# X와 Y: 60° 셀 안에 있는 각 픽셀 중심의 실제 x, y 좌표, 단위 nm
```

## 응용 예 · 원기둥을 삼각 배열로 반복할 때

**사선 격자는 원기둥을 삼각 배열로 반복하는 구조를 작은 셀 하나로 표현할 때 유용합니다.** 이런 원기둥 배열은 광결정의 대표적인 예입니다. [MPB 공식 학습 문서](https://mpb.readthedocs.io/en/latest/Python_Data_Analysis_Tutorial/#triangular-lattice-of-rods)에서도 같은 종류의 배열을 다룹니다. 아래 그림은 Wavebit의 좌표 표현에 맞춰 새로 그린 기하학 도식입니다.

삼각 배열에서는 한 원기둥에 가장 가까운 이웃이 **여섯 개**이고, 그 중심 사이 거리는 모두 `a`입니다. 오른쪽으로 `a`만큼 이동하는 `a₁`과 오른쪽 위 60° 방향으로 `a`만큼 이동하는 `a₂`를 반복 이동 벡터로 고르면 이 배치를 그대로 표현할 수 있습니다.

```{figure} ../../figures/learn/learn/06d-triangular-cell.svg
:alt: 같은 삼각 배열을 왼쪽은 원기둥 1개의 60도 사선 셀, 오른쪽은 원기둥 2개의 직사각형 셀로 표현한다. 사선 셀 면적은 절반이며 가장 가까운 이웃 여섯 개의 중심 거리는 모두 a이다.
:figclass: learning-figure

그림 6-1. 같은 삼각 배열을 왼쪽은 원기둥 1개의 60도 사선 셀, 오른쪽은 원기둥 2개의 직사각형 셀로 표현한다. 사선 셀 면적은 절반이며 가장 가까운 이웃 여섯 개의 중심 거리는 모두 a이다.
```

두 그림의 원기둥 배치는 같습니다. 왼쪽은 **원기둥 1개가 들어 있는 60° 마름모 셀**, 오른쪽은 **원기둥 2개가 들어 있는 직사각형 셀**을 선택했습니다. 오른쪽은 최소 반복 셀 두 개를 묶은 셀, 즉 초셀(supercell)입니다. 사선 격자를 쓰는 이점은 이 예의 반복 구조를 가장 작은 단위로 직접 지정할 수 있다는 데 있습니다.

| 같은 삼각 배열을 표현하는 방법 | 60° 사선 셀 | 직사각형 셀 |
| --- | --- | --- |
| 반복 벡터 | `a₁=(a,0)`, `a₂=(a/2, √3a/2)` | `(a,0)`, `(0,√3a)` |
| 한 셀 안 원기둥 수 | 1개 | 2개 |
| 셀 면적 | `√3a²/2` | `√3a²` |

왼쪽 그림의 반복 셀과 원기둥 단면은 다음처럼 입력합니다. 각도는 라디안이며, 원의 반지름은 실제 xy 길이로 지정합니다.

```python
import numpy as np
from wavebit import Lattice, Material, rcwa

a = 600.  # 가장 가까운 중심 사이 거리, nm
lattice = Lattice.oblique(a, a, np.deg2rad(60.))
layer = rcwa.Layer(
    thickness=180.,
    background=Material(epsilon=1.),
    regions=(rcwa.Region(
        geometry=rcwa.Circle(radius=120.),   # 반지름 120 nm (지름 240 nm)
        material=Material(epsilon=4.)),),    # 상대 유전율 4
)
stack = rcwa.Stack(lattice=lattice, layers=(layer,))   # rcwa.Problem(stack=...)에 사용
```

`Lattice.hexagonal(a, np.deg2rad(60.))`로도 같은 셀을 만들 수 있습니다. `Lattice.hexagonal(a)`의 기본 각도는 120°이므로 위 그림과 같은 두 벡터를 원하면 60°를 명시합니다. 60°와 120° 기저는 같은 삼각 격자를 생성하지만, 같은 차수 번호로 잘라 낸 Fourier 파수 집합까지 같지는 않습니다.

## 그림 A · 같은 칸의 위치가 실제로 어떻게 움직일까

`u`, `v`는 셀 안에서의 상대적인 위치입니다. 0에서 1까지를 한 셀로 읽으면 `(u,v)=(0.5,0.5)`가 셀 중심입니다. 중심을 실제 좌표 `(x,y)=(0,0)`으로 맞추기 위해 각각에서 `1/2`를 뺍니다.

```text
r = (u − 1/2) a₁ + (v − 1/2) a₂

예: (u, v) = (0.75, 0.75)
    → 셀 중심에서 a₁ 방향으로 1/4, a₂ 방향으로 1/4 이동
    → r = ¼a₁ + ¼a₂
```

```{figure} ../../figures/learn/learn/06-lattice.svg
:alt: 같은 격자 좌표 P=(0.75,0.75)를 고정해도, 90°에서 60°로 바꾸면 실제 위치는 (150,150)에서 (225,129.9) nm로 이동한다. 파랑·초록 화살표는 각각 ¼a₁, ¼a₂이다.
:figclass: learning-figure

그림 6-2. 같은 격자 좌표 P=(0.75,0.75)를 고정해도, 90°에서 60°로 바꾸면 실제 위치는 (150,150)에서 (225,129.9) nm로 이동한다. 파랑·초록 화살표는 각각 ¼a₁, ¼a₂이다.
```

왼쪽에서는 `a₂`가 위로 향하고, 오른쪽에서는 오른쪽 위로 기울어 있습니다. 그래서 같은 `¼a₂`를 더해도 도착점이 달라집니다. **같은 배열 인덱스를 유지한다는 것은 같은 실제 xy 위치를 유지한다는 뜻이 아닙니다.**

## 그림 B · 같은 배열을 유지한 원과, 지름을 유지한 원

위쪽 파란 무늬는 원을 24×24 래스터 칸으로 근사한 것입니다. 두 그림에서 **재료가 칠해진 배열 원소는 완전히 같습니다.** 그런데 칸 자체가 정사각형에서 평행사변형으로 변하므로 실제 공간의 무늬도 함께 찌그러집니다. 매끄러운 원을 이 변환으로 옮기는 이상적인 경우에는 타원이 되며, 그림에서는 그 계단 근사가 보입니다.

아래쪽 초록 원은 셀 중심에 놓은 `rcwa.Circle(radius=120.)`입니다. 지름 240 nm라는 조건은 실제 xy 길이에 대한 조건이므로 셀을 기울여도 그대로 원입니다.

```

**아래쪽도 전체 구조가 그대로인 것은 아닙니다.** 중앙 원의 중심은 `(0,0)`으로 고정하지만, 다른 셀에 반복되는 원의 위치는 격자를 따라 달라집니다. 중앙에서 `a₂`만큼 이동한 이웃 원은 90° 격자에서 `(0,600)` nm, 60° 격자에서 약 `(300,519.6)` nm에 있습니다. 중심 사이 거리는 600 nm로 같고 방향이 달라집니다. 그래서 원 하나의 크기를 고정해도 광학 응답은 달라질 수 있습니다.

| 90° → 60°에서 무엇이 변하나 | 같은 래스터 배열을 유지 | 원 도형의 중심·지름을 유지 |
| --- | --- | --- |
| 셀과 이웃 무늬의 반복 배치 | 변함 | 변함 |
| 셀 내부 물체의 실제 모양 | 칸과 함께 변형됨 | 원으로 유지됨 |
| 한 셀 안 물체의 실제 단면적 | 처음의 약 86.6% | 원의 면적 그대로 |
| 물체가 셀에서 차지하는 면적 비율 | 그대로 | 처음의 약 1.155배 |

위 비율은 광학 계산값이 아니라 기하학으로 바로 구한 값입니다. 두 변의 길이를 유지하면 셀 면적은 `600²·sin α`입니다. 고정 래스터는 색칠한 칸의 비율이 같고, 고정 원 도형은 원 자체의 면적이 같습니다. 그림의 원은 셀 경계에 닿지 않으므로 잘림이나 이웃과의 겹침을 고려할 필요가 없는 예입니다.

## ‘격자 각도 미분’이 서로 다른 질문인 이유

각도를 아주 조금 바꾸고 투과율의 변화 `dT/dα`를 묻는다고 생각해 봅시다. **어느 그림의 규칙으로 다음 구조를 만드는지**가 미분의 뜻을 정합니다.

| 고정한 것 | 실제로 묻는 질문 |
| --- | --- |
| 래스터 배열의 각 원소 | 칸과 물체를 함께 변형하면 T가 얼마나 변하는가? |
| 원 도형의 실제 중심·지름 | 원의 크기는 유지하고 반복 배치를 바꾸면 T가 얼마나 변하는가? |

둘은 서로 다른 물리적 변화이므로 기울기도 달라도 됩니다. 원의 크기를 유지한 채 격자 각도를 최적화하려면, 이 예처럼 원을 실제 길이로 지정하는 도형 경로가 질문을 직접 표현합니다.

래스터로도 각 각도에 맞는 실제 `X, Y`를 다시 구해 원을 다시 그릴 수 있습니다. 다만 이것은 **같은 배열을 유지하는 작업과 다릅니다.** 또한 `X²+Y²<r²` 같은 이진 조건으로 픽셀을 갑자기 뒤집는 재생성을, 곧바로 매끄러운 형상 미분이라고 생각해서는 안 됩니다. 관련 미분의 범위와 비교는 [사선 격자 문서](../../theory/rcwa/oblique-lattice.md)를 참고합니다.

## 그림 C · 푸리에 성분에는 왜 두 개의 번호를 붙일까?

앞에서는 도형이 격자를 따라 어디에 반복되는지 살펴봤습니다. 이제 그 **주기적인 분포를 계산에 어떻게 표현하는지**로 넘어갑니다. 2장에서 본 것처럼, RCWA는 복잡한 분포를 단순한 물결 모양의 성분들을 더해 표현합니다. 이 푸리에 성분들을 구별하려고 붙이는 번호가 **차수**입니다.

**1. 먼저 한 방향에서 0차·1차·2차가 어디서 나오는지 봅시다.** 길이 600 nm인 한 셀 안에서, 물결이 공간적으로 몇 번 진동하는지 생각하면 됩니다. 여기서 세는 것은 시간에 따른 진동이 아니라, 위치를 옮기며 보았을 때의 진동입니다.

| 한 셀 안에서 기본 성분이 변하는 모습 | 붙이는 번호 |
| --- | --- |
| 위치에 따라 변하지 않는 상수 | 0차 |
| 600 nm를 가는 동안 한 번 진동 | 1차 |
| 600 nm를 가는 동안 두 번 진동 | 2차 |

한 셀만큼 옮겨도 같은 주기적 성분으로 이어져야 하므로, 한 셀에 들어가는 진동 횟수는 정수입니다. 이것이 0·1·2처럼 번호를 붙이는 이유입니다. 음수 차수는 위상, 즉 진동의 진행 단계가 반대 방향으로 변하는 성분을 나타냅니다. **번호가 성분의 크기를 뜻하지는 않습니다.** 각 성분을 얼마나 더할지는 별도의 계수로 나타냅니다.

**2. 두 방향으로 반복되면 번호도 두 개가 필요합니다.** 첫째 반복 벡터 `a₁`을 따라 한 셀을 갈 때의 번호를 `m`, 둘째 반복 벡터 `a₂`를 따라갈 때의 번호를 `n`이라 쓰고, 둘을 묶어 `(m,n)`으로 표시합니다.

| 성분의 번호 `(m,n)` | `a₁`을 따라 한 셀 이동 | `a₂`를 따라 한 셀 이동 |
| --- | --- | --- |
| `(0,0)` | 변하지 않음 | 변하지 않음 |
| `(1,0)` | 한 번 진동 | 변하지 않음 |
| `(0,1)` | 변하지 않음 | 한 번 진동 |
| `(2,0)` | 두 번 진동 | 변하지 않음 |
| `(1,1)` | 한 번 진동 | 한 번 진동 |

**여기서 설명할 예로 고른 것이 표의 `(1,0)` 성분입니다.** 첫 번째 `1`은 `a₁`을 따라 한 번 진동한다는 뜻이고, 두 번째 `0`은 `a₂`를 따라서는 변하지 않는다는 뜻입니다. `0`이라고 해서 성분 자체가 없는 것은 아닙니다. `(1,0)`은 이렇게 성분을 구별하는 번호이며, 점의 실제 좌표 `(x,y)`가 아닙니다.

여기까지는 주기적인 부분의 푸리에 성분을 보고 있습니다. 실제 회절파에는 입사파의 위상 변화도 더해지며, 아래 C2에서 연결합니다.

**3. 이 예의 번호를 실제 xy 방향과 연결해 봅시다.** `(1,0)` 성분은 `a₂`를 따라가는 동안 어느 지점에서도 위상이 변하지 않습니다. 따라서 같은 위상을 가진 점들을 선으로 이으면 `a₂`와 나란합니다. 그림의 선 하나를 따라가면 위상이 같고, 선들을 가로지르면 위상이 달라집니다.

이 성분의 위상이 가장 빠르게 증가하는 방향과 그 변화율을 나타내는 화살표를 파수 벡터 `b₁`이라고 합니다. `b₁`은 같은 위상의 선을 수직으로 가로지르므로 `a₂`와 수직입니다.

```

왼쪽에서는 같은 위상 선이 세로이므로 `b₁`이 오른쪽을 향합니다. 오른쪽에서는 선이 오른쪽 위 60°로 기울어 있으므로, 수직인 `b₁`은 오른쪽 아래 −30°를 향합니다. **`a₁`이 오른쪽을 향하더라도, `b₁`까지 오른쪽을 향하는 것은 아닙니다.** `b₁`과 `b₂`를 역격자 벡터라고 부릅니다. 반복 배치에 대응하는 공간 주파수의 기본 단위입니다.

**먼저 용어: 횡파수란 무엇일까요?**

이 문서에서 **횡파수는 파수 벡터의 x·y 성분을 묶은 것**을 뜻합니다. 정확한 이름은 **횡방향 파수 벡터**입니다. 여기서 ‘횡방향’은 층을 쌓는 z축에 수직인 방향, 즉 **층 표면과 나란한 xy 방향**입니다.

**전체 파수 벡터:** k = (k<sub>x</sub>, k<sub>y</sub>, k<sub>z</sub>)

**횡방향 파수 벡터:** k<sub>∥</sub> = (k<sub>x</sub>, k<sub>y</sub>)

파수는 공간에서 이동할 때 파동의 위상이 얼마나 빠르게 변하는지를 나타냅니다. 같은 시간과 같은 높이 z에서, `kₓ`는 x 방향으로 이동할 때의 위상 변화율이고, `kᵧ`는 y 방향으로 이동할 때의 위상 변화율입니다. `∥` 표시는 층 표면과 평행한 성분이라는 뜻입니다. 여기서 `k∥`는 두 성분을 가진 벡터이며, 그 크기 하나만을 뜻하지는 않습니다.

균일한 등방성 매질에서 입사하는 평면파를 예로 들어 봅시다.

| 입사 모습 | 입사파의 횡방향 파수 | 같은 높이의 표면에서 보면 |
| --- | --- | --- |
| 층에 수직으로 입사 | `kₓ=0`, `kᵧ=0` | x·y로 이동해도 위상이 같음 |
| xz 평면 안에서 비스듬히 입사 | `kₓ≠0`, `kᵧ=0` | x로 이동하면 위상이 달라짐 |

수직 입사에서 횡파수가 0이어도 빛은 z 방향으로 진행합니다. 표면을 따라서는 위상이 변하지 않는다는 뜻입니다.

아래 그림의 **Δ는 변화량이라는 뜻**입니다. `Δk∥=(Δkₓ, Δkᵧ)`는 회절 차수에 따라 입사파의 x·y 파수 성분에 더하는 값입니다.

**4. 같은 번호를 회절파를 구별할 때도 씁니다.** `(1,0)` 성분에 대응하는 파수 벡터가 `b₁`이고, `(0,1)` 성분에 대응하는 것이 `b₂`입니다. 일반적인 `(m,n)` 성분은 `m b₁ + n b₂`에 대응합니다. 실제 회절파의 횡파수는 여기에 입사파의 횡파수를 더한 값입니다.

| 차수 `(m,n)` | 입사파의 횡파수에 더하는 값 `Δk∥` |
| --- | --- |
| `(0,0)` | `0` |
| `(1,0)` | `b₁` |
| `(0,1)` | `b₂` |
| `(1,1)` | `b₁ + b₂` |

**먼저 2π/L의 뜻을 살펴봅시다.**

격자 한 변의 길이를 `L`이라고 합시다. 그 변을 따라 길이 `L`만큼 이동하는 동안 한 번 진동하는 성분을 보면, 위상은 한 바퀴, 즉 `2π` 라디안만큼 변합니다. 따라서 **단위 길이당 위상 변화는 2π/L**입니다.

```text
한 번 진동할 때의 위상 변화 = 2π
그동안 이동하는 거리       = L
단위 길이당 위상 변화      = 2π/L

L = 600 nm이면:
2π/L = 2π/(600 nm) ≈ 0.010472 nm⁻¹
```

즉, `2π/L`은 **길이 L을 따라 이동하며 위상이 한 바퀴 변하는 기준값**입니다. 여기서 `L`은 구조의 반복 길이입니다. 위상을 라디안으로 세며, 라디안은 무차원이므로 길이를 nm로 쓰면 단위는 `nm⁻¹`입니다.

앞의 그림처럼 `a₁`이 +x 방향이고 `a₂`가 60° 기울어진 경우, `(1,0)` 성분의 역격자 벡터를 이 값으로 직접 쓰면 다음과 같습니다. `b₁`은 `a₂`에 수직인 −30° 방향이므로 y 성분은 x 성분의 `−1/√3`배입니다.

```text
b₁ = (2π/L, −2π/(√3 L))
```

**이제 반복되는 2π/L을 짧게 쓰기 위해 g라는 이름을 붙입니다.** 아래 두 식은 같은 벡터를 나타냅니다.

```text
g = 2π/L

b₁ = (2π/L, −2π/(√3 L))
   = (g,    −g/√3)
```

아래 C2 그림은 이렇게 줄인 표기를 사용합니다. `g`는 하나의 숫자이고, `b₁`은 방향과 크기를 가진 벡터입니다. 이 사선 격자에서 `g`는 `b₁`의 x 성분이며, 벡터의 길이 전체를 뜻하지는 않습니다.

```{figure} ../../figures/learn/learn/06c2-order-wavevectors.svg
:alt: 오른쪽 파수 차이 좌표에서 (1,0)차는 b1을 한 번 더한다. 60도 셀의 b1은 x 성분이 양수 g, y 성분이 음수 마이너스 g 나누기 루트 3이다. 실제 횡파수에는 입사파의 횡파수를 더한다.
:figclass: learning-figure

그림 6-5. 오른쪽 파수 차이 좌표에서 (1,0)차는 b1을 한 번 더한다. 60도 셀의 b1은 x 성분이 양수 g, y 성분이 음수 마이너스 g 나누기 루트 3이다. 실제 횡파수에는 입사파의 횡파수를 더한다.
```

위 C2 그림에서 `(1,0)`은 x 성분이 `+g`, y 성분이 `−g/√3`인 파수 차이를 뜻합니다. `(1,0)`을 단순히 “실제 x 방향의 1차”라고 읽으면 이 y 성분을 놓칩니다.

앞의 C1은 **실제 xy 위치에 같은 위상 선을 그린 그림**이고, C2는 **횡파수 차이를 표시한 그림**입니다. C2의 화살표를 그대로 실제 빛의 출사 방향으로 읽지는 않습니다. 실제 회절파에는 입사파의 횡파수를 더합니다.

```text
차수에 따라 더하는 값:  Δk∥ = m b₁ + n b₂
실제 회절파의 횡파수:  k∥(m,n) = k∥(입사) + Δk∥
```

여기에 해당 매질에서 전파 가능한 차수인지까지 확인해야 출사 방향을 해석할 수 있습니다. 코드에서는 `result.order(1,0)`처럼 차수 번호로 결과를 꺼냅니다. `orders_u`는 `m`, `orders_v`는 `n`에 해당합니다. 앞에서 셀 안 위치를 나타낸 `u, v`와 달리, `m, n`은 정수 차수 번호입니다.

수식으로 확인하면 `b₁·a₁=2π`, `b₁·a₂=0`입니다. 두 번째 식이 바로 위 그림의 수직 관계이고, 첫 번째 식은 `a₁`만큼 갈 때 한 주기가 변한다는 뜻입니다. `b₂`는 반대로 `a₁` 방향에서 위상이 변하지 않고 `a₂`를 따라 한 주기가 변하는 성분에 대응합니다.

**두 변의 길이가 다르면 g는 어떻게 정할까요?**

위 그림의 `g=(2π/600) nm⁻¹`은 두 변이 모두 600 nm인 예에서 수식을 짧게 쓰려고 정한 공통 상수입니다. 두 변의 길이가 `L₁`, `L₂`로 다르면, 각 변에 대해 `g₁=2π/L₁`, `g₂=2π/L₂`를 따로 두면 됩니다. 실제 역격자 벡터는 이 값에 **두 변 사이의 각도까지 반영**해서 구합니다.

이 장의 그림처럼 `a₁`은 +x 방향, `a₂`는 +x에서 반시계 방향으로 `α`만큼 기울었다고 합시다. 그러면 다음과 같습니다.

```text
격자 벡터:     a₁ = (L₁, 0)
               a₂ = (L₂ cos α, L₂ sin α)

기본 스케일:   g₁ = 2π/L₁,  g₂ = 2π/L₂

역격자 벡터:   b₁ = (g₁, −g₁ cos α / sin α)
               b₂ = (0, g₂ / sin α)
```

예를 들어 **두 변이 600 nm와 800 nm이고 사잇각이 60°**이면:

```text
g₁ = (2π/600) nm⁻¹ ≈ 0.010472 nm⁻¹
g₂ = (2π/800) nm⁻¹ ≈ 0.007854 nm⁻¹

b₁ = (g₁, −g₁/√3) ≈ (0.010472, −0.006046) nm⁻¹
b₂ = (0, 2g₂/√3)   ≈ (0,         0.009069) nm⁻¹
```

`g₁`, `g₂`는 위 식을 쓰기 위한 기본 스케일입니다. 사선 격자에서는 역격자 벡터의 길이 자체와 다릅니다. `0°<α<180°`에서 벡터의 길이는 각각 `g₁/sin α`, `g₂/sin α`입니다. 직교 격자처럼 `α=90°`이면 `b₁=(g₁,0)`, `b₂=(0,g₂)`로 단순해집니다.
