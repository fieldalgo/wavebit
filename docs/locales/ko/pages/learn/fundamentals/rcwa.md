# 02. RCWA: 복잡한 빛을 여러 파동으로 나눠서 푼다

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

RCWA는 Rigorous Coupled-Wave Analysis의 약자입니다. 여기서 ‘나눈다’는 것은 공간을 작은 시간 계산 격자로 잘게 자른다는 뜻이 아닙니다. 한 층 안의 횡방향 분포를 **여러 공간 주파수의 파동을 더한 형태**로 표현합니다. 주기적인 재료가 이 파동들을 서로 결합시킵니다.

```text
E(x, y, z) ≈ Σ E_mn(z) · exp[i (k_parallel + m b₁ + n b₂) · (x, y)]
                         ↑ 각 Fourier 차수의 공간적 진동
```

`b₁`, `b₂`는 격자의 역격자 벡터입니다. 직교 셀에서는 x 성분 간격이 `2π/Px`, y 성분 간격이 `2π/Py`입니다. `m`, `n`이 차수 번호이고, 각 파동의 계수 `E_mn(z)`를 구하는 것이 계산의 핵심입니다. 모든 파동을 무한히 남길 수 없어 일부 차수에서 자릅니다.

```{figure} ../../figures/learn/learn/02-rcwa.svg
:alt: 주기 셀과 Fourier 파동, 각 층의 모드, 층 연결이 맡는 역할
:figclass: learning-figure

그림 2-1. 주기 셀과 Fourier 파동, 각 층의 모드, 층 연결이 맡는 역할
```

한 층은 z 방향으로 같은 단면을 갖습니다. 솔버는 그 층에서 가능한 전파·감쇠 모드와 z 방향 변화를 계산한 뒤 층 사이의 경계조건을 맞춥니다. 옆면이 기울어져 z에 따라 단면이 달라지는 구조는 여러 얇은 층으로 근사하고, 층 분할에 따른 변화도 확인해야 합니다.

**회절 차수와 층의 고유모드는 같지 않습니다.** 바깥의 균일한 매질에서는 차수마다 진행 방향을 말할 수 있습니다. 패턴 층 안의 고유모드는 여러 Fourier 성분이 결합된 상태입니다. ‘25개 차수를 남긴다’는 말을 ‘기둥 안에 서로 독립인 광선 25개가 있다’로 해석하면 안 됩니다.

## 구조와 재료에서 RCWA 계산까지

이 과정을 Wavebit의 계산 순서로 연결하면 다음과 같습니다. **구조와 재료를 계산 행렬로 구성하고, 각 층의 고유모드를 구한 뒤, 층 사이의 경계조건을 맞춰 반사·투과와 전자기장을 계산합니다.** 그림의 Li와 NVF는 첫 단계에서 재료와 장의 곱을 행렬로 구성하는 두 방식이며, `factorization`으로 선택합니다.

```{figure} ../../figures/learn/learn/02-factorization-flow.svg
:alt: 구조 형상을 Li 또는 NVF로 처리하고 재료값은 두 경로에 모두 전달하여 재료 컨볼루션 행렬을 만든 뒤 공통 RCWA 계산으로 합류하는 흐름
:name: factorization-flow
:figclass: learning-figure

그림 2-2. 구조와 재료에서 RCWA 계산까지. 파장·입사 조건과 균일층의 계산 생략 등 세부 분기는 생략한 개념도입니다.
```

실선은 계산 흐름이고, 점선은 **재료값 ε·μ의 전달**입니다. Li와 NVF 모두 재료값을 사용합니다. NVF 쪽에서는 경계의 방향으로 법선장과 투영행렬을 만든 뒤, 재료값과 함께 컨볼루션 행렬을 구성합니다. 재료 경계는 서로 다른 재료가 만나는 위치를 뜻합니다.

그림의 **재료 컨볼루션 행렬**은 남긴 Fourier 차수 사이의 관계를 나타내는 계산 행렬입니다. 그림의 `conv_mat 묶음`은 성분별로 구성한 컨볼루션 행렬들을 뜻합니다. 한 위치의 재료 성질을 나타내는 3×3 유전율·투자율 텐서와는 크기와 역할이 다릅니다.

차수와 행렬 구성 방식의 사용 조건은 [10장](fourier-orders.md)에서, NVF의 법선장과 투영행렬은 [11장](nvf.md)에서 자세히 설명합니다.
