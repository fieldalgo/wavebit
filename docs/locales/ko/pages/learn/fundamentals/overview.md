# 01. Wavebit는 어떤 질문에 답할까

:::{note}

`psi`/`chi` 편광 각도나 순수 1D `tetm` 경로처럼 현재 API에 아직 없는 기능을 설명하는 몇 대목은
‘이전 인터페이스’ 상자 안에 있습니다(2026-10-15에 `wavebit.compat`와 함께 퇴역). 일부 그림에는
이전 이름이 남아 있으며, 그런 그림이 있는 장에서 현재 이름을 알려 줍니다. [현재 시작 안내](../../getting-started/index.md)와
[API 이행 안내](../../migration/index.md)를 함께 참고하세요. 과거 측정 파일과 원본 출처는 그대로 둡니다.
:::

“주기적으로 반복되는 나노구조에 빛을 비추면, 빛이 어디로 얼마나 나갈까?” 이것이 현재 Wavebit의 중심 질문입니다. 파장, 재료, 모양, 층 두께, 입사 방향과 편광을 정하면 반사와 투과의 방향별 세기, 복소 진폭, 구조 안의 전자기장을 계산합니다. JAX나 PyTorch를 사용하면 설계 변수를 조금 바꿀 때 결과가 얼마나 변하는지도 구할 수 있습니다.

```{figure} ../../figures/learn/learn/01-journey.svg
그림 1-1. 입력한 장면이 계산과 결과를 거쳐 설계 변경으로 돌아오는 전체 흐름
```

예를 들어 “유리 위에 실리콘 기둥을 반복 배치하고, 900 nm 빛의 0차 투과를 높이고 싶다”면 구조와 빛을 먼저 정의합니다. 한 번 계산한 뒤 `result.order(0, 0).T`를 읽습니다. 기둥 지름이나 높이를 바꾸는 것은 설계의 문제이고, Fourier 차수를 늘리는 것은 같은 설계를 더 정확히 계산하는 문제입니다. 이 두 작업을 구별해야 최적화가 계산 오차를 이용하는 일을 줄일 수 있습니다.

## 현재 범위와 FDTD의 자리

이 교재에서 다루는 솔버는 **RCWA**입니다. 시간의 진동을 복소수로 표현하고 지정한 파장에서 문제를 풉니다. 횡방향으로 주기적인 층 구조에 적합합니다. FDTD는 시간에 따라 전자기장을 격자 위에서 진전시키는 별도의 계산 방식입니다. 현재 저장소는 공개 `wavebit.fdtd` 모듈의 `fdtd.Problem`, `fdtd.prepare`, `fdtd.run`을 제공합니다. 사용법은 [현재 FDTD 가이드](../../guide/fdtd/general-fdtd.md)를 참고하세요. 이전 주기 구조·일반 장면 팩터리의 `wavebit.compat.legacy` 경로는 퇴역했으며, [주기 구조용 설명서](../../guide/fdtd/time-domain.md)와 [일반 장면 설명서](../../migration/general-fdtd-v1.md)에서 호환 범위를 구분합니다. 이 교재는 원래 RCWA 학습 흐름과 당시 측정 기록을 유지합니다.

| 질문 | 현재 접근 |
| --- | --- |
| 주기 격자·메타표면·다층 박막의 반사/투과 | RCWA로 표현 가능한 층 구조를 만들기 |
| 구조 안의 국소 전기장 | `answers='field'`와 장 재구성 |
| 재료나 형상 변수의 민감도 | JAX 또는 PyTorch 자동미분, 해당 경로의 지원 범위 확인 |
| 유한한 단일 물체의 산란 | 반복 경계의 영향을 검토한 큰 주기 셀 등이 필요; 무한 주기 해와 구별 |
| 통합 FDTD 사용 | 주기 구조 및 일반 공간 영역 가이드에서 현재 사용법과 지원 범위 확인 |
