# 05. 구조를 만드는 두 언어: 래스터와 도형

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

래스터는 ‘각 칸을 어떤 재료로 채우는가’를 배열로 말합니다. 도형 방식은 ‘어디에 어떤 크기의 물체를 놓는가’를 매개변수로 말합니다. 둘 다 같은 종류의 층별 Maxwell 문제를 설명합니다. `structure`의 **자료형**이 경로를 선택하므로 모드 선택 스위치를 따로 붙이지 않습니다.

```{figure} ../../figures/learn/learn/05-geometry.svg
:alt: 두 가지 입력 방식만 비교: 왼쪽은 래스터 배열, 오른쪽은 도형 매개변수
:figclass: learning-figure

그림 5-1. 두 가지 입력 방식만 비교: 왼쪽은 래스터 배열, 오른쪽은 도형 매개변수
```

| 방식 | 입력 | 잘 맞는 설계 변수 |
| --- | --- | --- |
| 래스터 | `(층 수, 행 수, 열 수)` ndarray | 픽셀별 유전율, 재료 분포 |
| 도형 | 층별 `background`와 `shapes` 목록 | 중심 위치, 폭, 높이, 각도 |

래스터에서 서로 다른 층은 같은 배열의 앞쪽 축으로 쌓습니다. 도형에서는 `rectangle`, `circle`, `ellipse`를 사용합니다. `cx`, `cy`는 셀 중심 기준의 절대 길이이며, `lx`, `ly`도 절대 길이입니다. **원의 `lx`는 지름**입니다. 사각형과 타원은 두 축의 전체 크기를 지정합니다. 회전 `angle`은 라디안입니다.

## 도형 방식의 추가 규칙: 한 층에 여러 도형을 놓으면

```{figure} ../../figures/learn/learn/05b-painting.svg
:alt: 도형 목록의 순서에 따른 겹침 처리: 원 다음에 놓은 사각형의 재료가 겹친 곳을 덮는다
:figclass: learning-figure

그림 5-2. 도형 목록의 순서에 따른 겹침 처리: 원 다음에 놓은 사각형의 재료가 겹친 곳을 덮는다
```

`shapes`에 순서대로 넣습니다. **나중 도형의 재료가 앞 도형을 덮습니다.** 겹친 영역의 유전율을 더하는 것이 아닙니다. 배경 재료로 만든 도형을 마지막에 놓아 구멍을 표현하는 식으로 이해할 수 있습니다. 실제로 받아들이는 형상·교차·접촉 조건은 현재 경로의 제약을 따릅니다.

겹침이 있는 층에서는 경계를 해석해 서로 겹치지 않는 영역으로 정리합니다. 곡선이 포함된 painting 경로는 다각형 경계 근사가 개입할 수 있습니다. 따라서 ‘도형 입력’이라는 말이 모든 단계에서 곡선을 무한 정밀도로 다룬다는 뜻은 아닙니다. 처음 입력한 장면은 `wavebit.plot_structure(...)`나 `wavebit.slice_structure(...)`로도 확인할 수 있습니다. 세부 인자는 [API 참조](../../reference/api.md)를 따릅니다.
