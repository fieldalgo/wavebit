# Wavebit 전체를 이해하는 책

:::{note}
이 교재의 실행 예제는 원래 수치 기록을 재현할 수 있도록 `wavebit.compat.legacy` 인터페이스를 명시적으로 사용합니다. 새 작업은 [현재 시작 안내](../../getting-started/index.md)와 [API 이행 안내](../../migration/index.md)를 참고하세요. 기존 측정값은 이번 문서 이행에서 다시 계산하지 않았습니다.
:::

**구조를 그리는 순간부터, 빛의 응답을 계산하고 설계를 바꾸는 순간까지.** 이 책은 Wavebit의 기능을 하나씩 나열하기보다 하나의 계산이 어떤 과정을 거치는지 따라갑니다. NVF를 이미 공부했다면, 이제 그 방법이 전체 솔버의 어디에 들어가는지 볼 수 있습니다.

2026년 9월 21일 · Wavebit 0.1.0 / develop `a1d23fc` 기반의 **API 이름 변경과 분산 재료 개선이 반영된 로컬 작업본**을 설명합니다. 아래 예제는 이 작업본으로 실행했습니다. 당시 작업본에는 FDTD가 아직 통합되지 않았으므로, 이 책의 측정 기록과 실행 예제는 RCWA를 다룹니다. 이 역사적 기록은 공개 릴리스나 현재 전체 회귀검사 완료를 선언하지 않습니다.

현재 저장소는 공개 `wavebit.fdtd` 모듈의 `fdtd.Problem`, `fdtd.prepare`, `fdtd.run`을 제공합니다. 사용법은 [현재 FDTD 가이드](../../guide/fdtd/general-fdtd.md)를 참고하세요. 이전 주기 구조·일반 장면 팩터리는 `wavebit.compat.legacy` 아래에 남아 있으며, [주기 구조용 설명서](../../guide/fdtd/time-domain.md)와 [일반 장면 설명서](../../migration/general-fdtd-v1.md)에서 호환 범위를 구분합니다.

## 어떻게 읽으면 좋을까

| 목적 | 읽는 순서 |
| --- | --- |
| 전체가 무엇인지 알고 싶다 | 1–3장 → 4장의 첫 계산 → 12장의 결과 |
| 효율과 흡수의 의미를 알고 싶다 | 8장의 입사 조건 → 12–13장의 결과와 전력 |
| 두꺼운 기판의 뒷면 반사와 측정 평균을 이해하고 싶다 | 15장의 층 연결 → 부록 C(두꺼운 기판) |
| 내 구조를 계산하고 싶다 | 4–8장 → 10–14장 → 19장의 정확도 확인 |
| 여러 입사파나 양면 입사를 계산하고 싶다 | 8장의 기본 입력 → 9장의 여러 입사파 → 14장의 필드 |
| 역설계와 최적화를 하고 싶다 | 16–18장, 특히 17장의 미분과 제약 |
| 내부 코드를 공부하고 싶다 | 2·10·11·15장 → 20장의 코드 지도 |
| 복소 각도·이득 매질이나 다른 솔버와의 차이가 궁금하다 | 8장의 복소 횡파수 → 부록 A(무손실 매질) → 부록 B(흡수·이득 매질) |

**20장과 부록 셋 · 그림과 개념 조작 · 실행 가능한 Python 예제 10개.** 그림에 ‘개념도’라고 쓰인 것은 설명용입니다. 수치 결과를 그린 그림에는 연결된 실행 파일을 표시했습니다. 코드는 문서에서 읽거나 실행 파일로 내려받을 수 있습니다. 그림을 누르면 크게 볼 수 있습니다.
