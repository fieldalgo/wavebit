# 스펙트럼 피팅의 법선장 격자 수렴 검사

최적화 성공은 **선택한 이산 모델**에 대한 맞춤이 끝났다는 뜻입니다.
`shape_nvf_grid_size`를 바꿔도 추정 치수가 유지된다는 뜻은 아닙니다.
유한한 Jacobian, 같은 격자에서의 AD/유한차분 일치, 작은 잡음 공분산만으로도
격자 수렴을 판단할 수 없습니다.

기본값 `max(1024, 4*half_width+1)`은 시작 해상도이며 값·미분·추정 치수의
허용오차를 보장하지 않습니다. 필요한 물리량의 허용오차를 정하고 격자를
세분화해 확인합니다. 이 검사에서는 Fourier 차수를 고정하고, 이후 차수와
곡선 근사에 대한 수렴을 별도로 확인합니다.

## 자동 격자 세분화와 재맞춤

소스 체크아웃의
[`spectral_fit_grid.py`](https://github.com/fieldalgo/wavebit/blob/main/examples/rcwa/spectral_fit_grid.py)는
응용 함수 `fit_grid_ladder`를 제공합니다. 설치되는 피팅 API나 `rcwa.run`의
새 옵션이 아니라, 사용자 모델에 맞춰 가져다 쓰는 예제 코드입니다.

```shell
python examples/rcwa/spectral_fit_grid.py
```

격자 크기를 받아 `model(parameters) -> (spectrum, Jacobian)` 함수를 반환하는
factory를 전달합니다. 스펙트럼은 `(m,)`, Jacobian은 `(m, n)`의 실수 유한
배열이어야 합니다. 모델 함수 안에서 실행 유효성과 기하 재준비를 처리합니다.
최적화·격자 반복은 호스트에서 실행하며 개별 값/Jacobian 계산은 컴파일해도 됩니다.

| 인수 | 의미 |
| --- | --- |
| `initial`, `data` | 초기 매개변수와 고정 관측 스펙트럼. |
| `grids` | 엄격히 증가하는 양의 정수 격자 크기, 최소 세 개. |
| `noise_sigma` | 관측별 알려진 독립 잡음 표준편차. 스칼라 또는 벡터. |
| `parameter_tolerance` | 각 매개변수의 물리 단위로 정한 최대 허용 이동. |
| `spectrum_tolerance` | 각 관측량의 최대 허용 모델 변화. |
| `max_nfev` | 격자별 최적화 평가 횟수 한도. |
| `on_stage` | 완료된 각 단계를 받아 진행 기록을 남기는 선택 콜백. |

각 격자에서 이전 추정값을 시작점으로 같은 데이터를 다시 맞춥니다.
추정 매개변수의 이동과 **더 촘촘한 격자의 추정값이라는 동일한 점**에서
계산한 두 격자의 스펙트럼 차이를 따로 검사합니다. 각자 피팅한 잔차만 비교하면
치수 이동이 모델 오차를 숨길 수 있습니다. 두 번 연속 세분화에서 모든 성분이
허용오차 안에 들어야 통과합니다. 거친 격자의 최적화 실패는 다음 격자에서
재시도하며 통과 횟수에 넣지 않습니다. 무효 계산은 오류, 순위 부족은 미수렴입니다.
최적화가 마지막으로 채택한 값·Jacobian을 보존하므로, 끝의 시도점이 거절돼도
이미 평가한 최종점의 계산을 보고서 작성 때문에 반복하지 않습니다.

반환된 `GridFit`의 `parameters`, `stages`, `converged`, `reason`을 확인합니다.
단계별로 최적화 성공 여부, 잡음만의 표준편차, 잡음으로 가중한 잔차 노름,
두 종류의 최대 변화/허용오차 비율을 기록합니다. 비율 1이 한계입니다.
격자 목록을 소진하면 `converged=False`이며 예제는 오류로 종료합니다.
마지막 최적화 성공을 격자 수렴으로 대신하지 말고, 기록을 남겨 다음 격자를 검사합니다.

연속 두 번의 통과는 우연히 한 쌍만 비슷해지는 상황을 거르지만, 남은 오차의
상한·전역 최적점·물리 정확도를 증명하지는 않습니다. 변화가 불규칙하면 추가
해상도를 확인합니다. 잡음 표준편차는 가중 Jacobian의 특이값 분해로 계산하며,
국소적으로 식별 가능한 최소제곱 모델을 가정합니다. 이산화 편향이나 모델 불일치는
포함하지 않습니다. 가중 잔차도 따로 확인해야 합니다. 격자 수렴은 관측값과
모델이 잡음 범위 안에서 일치한다는 뜻이 아닙니다.

## 새 문제에서 확인할 것

실행 전에 물리 단위 허용오차를 정합니다. 예를 들어 두께 변화 0.02 nm와
반사율 변화 `1e-5`는 서로 다른 요구입니다. 반사율 차이가 작아도 식별이 약한
치수는 크게 움직일 수 있습니다. 선택한 격자에서 여러 간격의 유한차분으로 AD를
확인하고, 격자 안정성 요구보다 엄격한 최적화 정밀도를 사용하며 실패도 보존합니다.
그 다음 Fourier 차수·다각형 근사·실험 모델을 검사합니다.

[측정 예제와 네 매개변수 연구](../../validation/rcwa/fitting-grid-convergence.md)는
치수 이동·잡음 불확도·격자 차이를 구분합니다. 작은 예제는 중앙차분, 큰 연구는
JAX 전방 자동미분을 사용합니다. 두 합성 표적 모두 독립 Maxwell 기준은 아닙니다.
