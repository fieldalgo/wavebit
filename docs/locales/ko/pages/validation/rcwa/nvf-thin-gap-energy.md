# 사라지는 틈을 위한 conforming 순방향 정식화

`studies/rcwa/nvf_thin_gap_energy/nvf_thin_gap_energy.py`는 중심에 놓인 직사각형 접촉 대조 실험에서
빠져 있던 법선장 기여를 분해합니다. 실제 주기 Galerkin 셀 문제와 기존의 에너지 Gram 닫힘을
계산합니다. 그 결과 얻는 접촉 미분은 JAX JIT에서 독립적인 p, s 비교 관문을 통과합니다. 이것은
**축에 정렬된 직사각형 하나에 대한 선택형(opt-in) 연구**이며, 제품용 NVF 방법이나 임의의 기본
도형 분할과 기울어진 접촉에 대한 해법이 아닙니다.

이어진 [분할 틈 확장](nvf-partitioned-gap-energy.md)은 이제 이 접촉 필드를 같은 재료 분할 불변성,
살아 있는 내부 재료/이음매 미분, 평행 이동한 수평 직사각형 타일링과 결합합니다. 이 셀 공간을 그대로
쓰며, 일반 기하에 대한 수용 작업은 열린 채로 남겨 둡니다. 그다음의
[조화 좌표 연구](nvf-harmonic-coordinates.md)는 x 기저와 아핀 리프트를 바꾸어, 고정된 메시에서 닫힌
실제 계면의 움직임을 분해합니다. 접촉 필드는 유지하지만 양의 틈에서 이음매 오차가 여전히 있습니다.

이전의 푸리에 보정기 구현과 그 엄격한 s 예상 실패(expected-failure) 테스트는 바뀌지 않았습니다. 그
고정된 매끄러운 공간은 여전히 얇은 층 항을 놓치며, 이 실험은 다른 conforming 셀 공간을 씁니다.

## 측도가 사라지는 영역에서 필드 유지하기

주기를 1로 정규화하고 `g = gap / 700`라고 씁니다. 재료 몸체의 높이는 `1-g`이고, 유전율은 x에만
의존합니다. 주기적 틈의 유전율은 1이며 위/아래 경계에 걸쳐 있습니다. 몸체 좌표
`t = y/(1-g)`에서 다음 퍼텐셜을 씁니다.

```
chi_body(x,t) = v(x,t) - g*t*a(x),       -1/2 <= t <= 1/2
chi_gap(x,s)  = v(x,-1/2) + g*s*a(x),   -1/2 <= s <= 1/2
```

여기서 v는 몸체 위의 주기적 텐서곱 Q1 함수이고, a는 x에 대한 연속 구간별 선형 함수입니다. 두
퍼텐셜은 두 계면 모두에서 일치합니다. 모든 양수 g에서 이것은 보통의 conforming 주기 H1 공간이며,
틈을 가로지르는 퍼텐셜 도약은 `g*a`입니다. 틈 안의 법선 그래디언트는 a이고, g가 사라져도 유한하게
남습니다. 따라서 전기 에너지에는 1차 항 `g * integral(a^2)`가 들어 있습니다. 예전의 유한 푸리에
공간을 정확한 접촉에서 미분할 때는 이 항이 없었습니다.

M과 K가 가중 1차원 질량 행렬과 강성 행렬을 나타낸다고 합시다. 보강(enrichment) 강성은 다음과
같습니다.

```
A_aa = g*M_bg + g^2*(M_eps/(1-g) + (1-g)*K_eps/12) + g^3*K_bg/12
A_va = g*C
```

선형 계를 계산하기 전에 보강 **시험 방정식**을 대수적으로 g로 나눕니다. 구현한 계는 다음과
같습니다.

```
[ A_vv    g*C       ] [ v ] = [ b_v   ]
[ C.T     A_aa/g    ] [ a ]   [ b_a/g ]
```

표시한 몫은 모두 구현 안에서 해석적으로 전개합니다. 수치적인 0으로 나누기도, 작은 틈 차단값도,
멈춘 기하 그래디언트도, 미리 정한 광학 미분도 없습니다. 보통의 퍼텐셜 자유도 하나가 게이지를
고정합니다. 틈 구적법은 폭이 0일 때도 필드를 유지하며, 그 적분 가중치는 연속적으로 사라지면서 미분에
기여합니다.

균일한 법선 강제 아래 정확한 접촉에서 두 번째 방정식은 `M_bg*a = load(eps-1)`가 됩니다. 따라서 x
메시가 재료 계단을 분해할수록 틈 필드 `1+a`는 호스트/틈 유전율 비에 다가갑니다. 대비 인자는 변분
풀이에서 나옵니다. 투과율에 맞춰 피팅한 것이 아닙니다.

셀 강성, 질량, 하중 적분은 재료 구간 위에서 해석적으로 조립합니다. Gauss 구적법은 B, `B.T*epsilon*B`,
epsilon을 푸리에 계수로 투영하는 데에만 씁니다. 가로 닫힘은 여전히
`inv(C(B)).H @ C(B.T*epsilon*B) @ inv(C(B))`이며, 세로 인수분해와 공유 Maxwell 산란 계산 도구는
바뀌지 않습니다. 이 모델은 카르테시안 Li 함수를 하나도 호출하지 않습니다.

## 측정과 수치 대조 실험

기존의 주기 700 nm, 폭 350 nm, epsilon 12.25 대조 실험에서 바깥 차수 7일 때 닫힌 투과율은
p = 0.626061531897, s = 0.878242289574입니다. conforming 닫힘은 서로 다른 푸리에 좌표 원점을
고려하면 두 독립 카르테시안 구성 행렬을 모두 복원합니다.

독립적인 양의 틈 할선 기울기를 0으로 외삽하면 대략 `dT_p/dgap = 0.001891546`와
`dT_s/dgap = -0.000778575`를 얻습니다(단위는 nm의 역수). conforming 연구의 정확한 접촉 JAX 미분은
다음과 같습니다.

| x 계면 세분화 비율 | p 미분 | s 미분 |
| --- | ---: | ---: |
| 1e-4 | 0.001891546100 | -0.000777803964 |
| 1e-5 | 0.001891546100 | -0.000778495983 |
| 1e-6 | 0.001891546100 | -0.000778566984 |

마지막 s 오차는 약 **0.001%** 로, 예전 유한 푸리에 접촉 미분의 약 92%와 비교됩니다. 이것은 유한
차수, 단일 픽스처 비교이며, 임의의 광학 구성에 대한 오차 상한이 아닙니다.

x 노드는 재료 계면 근처에서 비균일하게 촘촘해집니다. 몸체의 y 노드도 틈 근처에서 세분화가
필요합니다. 균일한 몸체 구간이 여덟 개뿐이면 정확한 끝점 미분은 개선되지만, 양의 틈 할선 기울기가
그 값에 느리게 다가갑니다. 비균일 y 노드를 더하면 이 해상도 문제가 해결됩니다. x 비율 1e-6에서
기록된 실행은 몸체 구간 16개와 스칼라 미지수 611개를 씁니다. 틈 1e-4 nm와 1e-5 nm에서 s JAX 미분은
각각 -0.000776638606과 -0.000778356234로, 끝점 값에 다가갑니다. 이 유한 틈 미분이 모든 양의 틈에서
독립 Li 모델과 같다고 주장하지는 않습니다.

평균 정적 법선 에너지 미분에는 별도의 해석적 검사가 있습니다:
`-epsilon*(epsilon-1)*(width/period)/period`. 같은 x 세분화에서 그 절대 오차는 1.96e-6에서
2.00e-7, 2.01e-8로 줄어듭니다. 이 검사는 광학 고유값 풀이에 기대지 않고 법선장 메커니즘을
검증합니다.

테스트는 또한 배율을 조정한 정식화를, 양의 틈에서 독립적으로 조립한 배율 조정 없는 주기 절점 Q1
풀이와 비교합니다. 투영한 계수 필드 여덟 개 모두에서 일치합니다. 틈, 재료, 폭에 대한 JIT 미분은
대비가 0일 때의 살아 있는 재료 미분까지 포함해 NumPy 유한 차분과 일치합니다. 양의 틈 미분 사다리는
정확한 접촉 JIT 미분에 다가갑니다. 두 편광 모두 무손실 전력을 보존합니다.

가장 작은 x 요소는 조건수 비용을 키웁니다. 기록된 가장 고운 배율 조정 선형 잔차는 약 1.3e-10입니다.
연구는 유한하지 않은 잔차나 1e-8을 넘는 잔차를 거부합니다. 이 문턱값은 광학 오차의 추정값이
아닙니다. 새로운 차수와 기하에서는 푸리에 구적법을 따로 검사해야 합니다. 처음의 8점 구적법 대조
실험은 불충분해서 받아들이지 않았고, 테스트는 정확도 기준을 완화하지 않고 12점과 16점을 비교합니다.
기록된 차수 7/비율 1e-6 설정에서 투영한 모든 계수는 틈 0과 1e-4 nm 모두에서 12점에서 16점으로 갈 때
최대 1.40e-13만큼 바뀝니다.

## 아직 열려 있는 범위

이 모델은 고정된 conforming 위상 위에서 폭, 틈을 통한 높이, 유전율이 살아 있는 양의 실수 스칼라
직사각형을 지원합니다. 기본 도형 칠하기/분할 어댑터, 기울어지거나 굽은 계면, 자성/손실 재료, 제품
백엔드 통합은 없습니다. 따라서 앞서의 재료로 정의한 푸리에 모델의 분할 불변성을 이 새 메시 모델의
것으로 볼 수 없습니다. 계면 적합성(conformity)과 유한 차수 표현 불변성을 결합하는 일은 여전히
필요합니다. 기울어진 경우의 광학 수렴과 독립 3D 기준의 불확도도 바뀌지 않았습니다. 별개인 제품용
고유값 그래디언트 정칙화 한계는 앞서의 테스트에 계속 기록되어 있습니다.

```bash
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m studies.rcwa.nvf_thin_gap_energy.nvf_thin_gap_energy --rows 8 16 --edge-fraction 0.00001 --gaps 0 0.00001 --autodiff
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m pytest -q tests/rcwa/test_nvf_thin_gap_energy.py
```

실행 파일은 NumPy만으로도 동작하며, `--autodiff`를 주면 JAX x64를 씁니다. 더 거친 몸체 대조 실험을
재현하려면 `--uniform-y`를 쓰세요. 기록된 출력은
`studies/rcwa/nvf_thin_gap_energy/records/nvf_thin_gap_energy.log`에 있습니다.
