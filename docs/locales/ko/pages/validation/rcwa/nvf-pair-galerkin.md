# 실수 구속 그래디언트로 얻는 유한 접촉 응답

작성: 2026-09-14.

대상:
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair_galerkin.py`
- `src/wavebit/rcwa/_engine/conforming/triangle_moments.py`
- `tests/rcwa/test_nvf_pair_galerkin.py`
- `studies/rcwa/nvf_pair_galerkin/nvf_pair_galerkin.py`
- `studies/rcwa/nvf_pair_galerkin/records/nvf_pair_galerkin.log`
- `studies/rcwa/nvf_pair_galerkin/records/nvf_pair_galerkin_quadratic.log`

새로 만든 명시적 NumPy 유한 계열은 유지하는 가로 푸리에 열마다 서로 다른 퍼텐셜 보정을 풉니다.
실수 시험 공간과 원래의 복소 재료 방정식 덕분에 상반성, 수동성, 재료에 대한 정칙(holomorphic)
의존성을 함께 보존합니다. 해석적인 틈/재료 방향 미분은 정확한 접촉과 임의로 작은 양의 틈을
포함합니다. 독립적인 원래 절점 방정식과 Laurent 방정식이 이 유한 계산을 검증합니다. 측정한 금속
광학은 여전히 퍼텐셜 공간에 따라 크게 바뀝니다. 따라서 이것은 인정된 기본 NVF 대체물도, 완결된
광학 수렴 결과도 아닙니다.

## 유지 필드는 구속 조건입니다

Phi를 유지하는 정규 직교 가로 평면파, L을 실수 주기 절점 퍼텐셜의 그래디언트, Q를 그 유지 푸리에
사영이라고 합시다. 상수 퍼텐셜 게이지는 제거합니다. 다음과 같이 씁니다.

```text
Z = L - Phi Q,
E = Phi c + Z a = Phi x + L a,
x + Q a = c.
```

Z의 유지 푸리에 사영은 0입니다. 따라서 보정자는 Maxwell 솔버에 넘기는 물리 전기장 좌표 c를 바꿀
수 없습니다. 푸리에 상자가 두 부호를 모두 포함하고 절점 기하가 실수이므로, 시험 공간은 복소 켤레에
대해 닫혀 있습니다. 이 공간은 재료가 아니라 기하에 의존합니다.
앞선 쌍 에너지 모델의 상수 입사 보정자 두 개와 달리, a는 유지하는 가로 전기장마다 별도의 열을
가집니다.

원래의 물리 적분은 다음과 같습니다.

```text
A = integral Phi.H epsilon Phi,
R = integral Phi.H epsilon L,
S = integral L.T epsilon Phi,
K = integral L.T epsilon L.
```

모든 적분은 셀 면적으로 나눕니다. S나 K에서 복소 epsilon을 켤레로 바꾸는 일은 없습니다. 흡수
재료에서는 S가 R.H가 아닙니다. 실수 L과 푸리에 반전 J에 대해 S = R[J,:].T입니다. 유지 구속
조건과 함께 정상성(stationarity)을 적용하면 다음을 얻습니다.

```text
x + Q a = c,
d = A x + R a,
K a + S x - Q.H d = 0.
```

그 결과 d = H c가 구성 응답입니다. 틈이 양수일 때 이것은 사영이 0인 그래디언트 기저 Z에서의
Schur 보수이기도 합니다. 독립적인 양의 틈 오라클은 그 Schur 형식을 쓰고 물리 에너지를 따로
적분합니다. 구현은 x와 d를 대수적으로 소거하고, 모든 유지 우변에 대해 사영된 퍼텐셜 계 하나를
풉니다.

```text
B = R - A Q,
D = K - S Q - Q.H B,
a = solve(D, -(S - Q.H A)),
H = A + B a.
```

원래 약형식 퍼텐셜의 개수가 유지 필드/플럭스 미지수의 개수보다 많으면, 구현은 원래 약형식
퍼텐셜을 먼저 소거하기도 합니다. `U = solve(K, Q.H)` 와 `V = solve(K, S)` 로 두면 같은 방정식은
다음이 됩니다.

```text
[ I-Q V,   Q U ] [x] = [I],
[-A+R V, I-R U ] [H]   [0]
a = U H - V x.
```

접촉에서는 이 식들의 Q.H가 아래에서 정의하는, 해석적으로 스케일한 시험 모멘트를 뜻합니다. 두
소거 모두 원래 방정식을 미분하며, 어느 쪽도 계수(rank)를 자르거나 시험 공간을 바꾸거나 재료를
조정하지 않습니다. 어느 쪽을 고를지는 행렬 크기에만 달려 있습니다. 메타데이터는 `elimination` 과
선택한 행렬의 `solve_condition` 을 기록합니다. 예전 `projected_condition` 필드는 퍼텐셜 소거만
설명했습니다. 독립 테스트가 두 형식을 비교하고, 각각에 대해 원래 절점 방정식을 다시 조립합니다.

접촉 버전은 아래에서 설명하는, 물리 열과 나눈 시험 행의 서로 다른 스케일링을 유지합니다. 사영된
행렬의 크기는 유지 푸리에 모드 수의 네 배가 아니라 퍼텐셜 미지수의 개수입니다. 예를 들어 세분
3에는 열린 퍼텐셜이 575개 있고, 차수 (8,8)에는 모드가 289개 있습니다.
독립적인 접촉 오라클은 x, d와 원래 접촉 퍼텐셜을 별도의 축약하지 않은 계에 유지합니다.

## 이 구성이 보장하는 것

정상 필드에서 `c.H H c = integral E.H epsilon E` 입니다. 따라서 수동 물리 재료는 음이 아닌 소산을
줍니다. 공통으로 회전한 재료 반평면은 양수인 회전 저장 에너지를 줍니다. 유지 사영이 c이므로,
Parseval 정리도 다음 스칼라 하한을 줍니다.

```text
HermitianPart(exp(-i alpha) H) >= min_j Re(exp(-i alpha) epsilon_j) I,
DissipativePart(H) >= min_j Im(epsilon_j) I.
```

이것은 정확한 유한 구성의 성질이지, 부동소수점 조립에 대한 구간 산술 증명서가 아닙니다. 구현은
물리 저장/소산, 상반성, 유지 좌표와 원래 잔차를 확인합니다.
테스트는 스칼라 저장 하한과, 중첩된 퍼텐셜 세분에서 무손실 에너지가 단조 감소하는지도 확인합니다.
이 중 어느 것도 광학 오차 상한이 아닙니다.

실수 시험 공간은 Lorentz 상반성 `H = J H.T J` 를 바로 줍니다. 전치 응답과의 평균은 취하지
않습니다. 이 점에서 두 재료 의존 필드 사상의 에너지를 평균하는 명시적
[켤레 쌍 프레임 에너지](nvf-paired-frame.md)와 다릅니다.

A, R, S, K는 물리 스칼라 재료에 대해 선형이고, Q와 시험 공간은 재료와 무관합니다. 따라서 특이하지
않은 영역에서 H는 그 재료들에 대해 정칙입니다. i만큼 회전한 방향 미분은 원래 미분의 i배를
줍니다. 재료 켤레, 절댓값 대비, 기준 유전율, 맞춘 손실이나 멈춘 미분은 방정식에 들어가지
않습니다.
허용 위상은 재료 섹터만 보증합니다.

균일한 재료는 정확히 `H = epsilon I` 를 줍니다. 처음으로 패턴이 생기는 재료 변화는 그 변화의 직접
푸리에 변환입니다. 이것은 모든 재료를 같은 상수만큼 바꾸는 것보다 강한 대조입니다. 일반적인
패턴의 유한 차수 값이 카르테시안 Li 인수분해와 같을 필요는 없습니다.

## 정확한 접촉과 방향 미분

기존의 정수 주기 붕괴 그래프를 다시 씁니다. s를 틈을 `sqrt(det(basis))` 로 나눈 값, C를 접촉
퍼텐셜을 주입하는 연산자, Zc를 그 독립적인 열림 차이를 담는 연산자라고 합시다. 물리 절점 퍼텐셜은
`C u + s Zc v` 입니다. 차이 시험 행을 해석적으로 s로 나눈 뒤의 약형식 행렬은 다음과 같습니다.

```text
Kbar = [[Kcc, s Kcz],
        [Kcz.T, Kzz]].
```

물리 푸리에 열에는 같은 s가 붙지만, 나눈 시험 행에는 붙지 않습니다. 이 행렬은 무손실 재료에서도
에르미트일 필요가 없으며, 행 스케일링을 반드시 지켜야 합니다. 0에서는 접촉 방정식과 차이
방정식이 유한한 오른쪽 열림 응답을 유지합니다. 틈의 수치적 역수, 작은 틈 차단, 고유값 자르기나
재료에 의존하는 계수 결정은 쓰지 않습니다.

위상이 z_i인 삼각형에서 평균 평면파는 지수 분할 차분인
`2 exp[z_0,z_1,z_2]` 입니다. 움직이는 위상은 미분에서 자기 노드를 덧붙입니다. 이 방법은 물리
삼각형의 면적이 0인 경우를 포함해 기준 심플렉스 평균을 직접 계산합니다. 부호가 있는 면적을 곱하면
지시 함수 변환이 되며, 그래디언트-면적 상쇄는 곱하기 전에 해석적으로 처리합니다. 계산한 작은 푸리에
적분에서 물리 면적을 나누어 내는 일은 없습니다. 기존의 합류 분할 차분 구현이 반복되는 위상과 가까운
위상을 처리합니다. 더 큰 푸리에 차분 격자는 최대 16개 삼각형 묶음으로 한 번 적분하며, 유지 모드
평균은 거기서 모읍니다. 저장된 평균은 여전히 삼각형 수와 푸리에 계수 수의 곱에 비례합니다. 솔버
전체가 상수 메모리라는 주장은 없습니다.

모든 풀이와 그 미분을 원래 방정식에 대해 확인합니다.
코드는 게이지 행과 붕괴된 띠의 반력을 포함해 사영하지 않은 모든 절점 방정식도 다시 조립합니다.
잔차 기준은 `1e-10` 으로 유지됩니다.
결함 보정 두 단계는 감쇠나 추가 손실 없이 같은 방정식을 풉니다. 유효하지 않은 재료, 기하, 유한하지
않은 출력, 원래/물리 점검 실패는 예외를 냅니다. 실패한 응답을 대칭 사영으로 고치는 일은 없습니다.

## 독립적인 유한 검증

`test_nvf_pair_galerkin.py` 의 테스트 48개는 다음을 다룹니다.

- 실수 유전체, 흡수 유전체와 금속의 접촉 값과 양의 틈 값. 서로 독립적인 Duffy 적분 차수 16과 24
  두 가지를 씁니다.
- 연속된 원래 Laurent 방정식에서 얻은 접촉 미분. 기하 계수와 Laurent 강성은 유리수 물리
  Vandermonde 행렬로 구성하며, 후보의 다시 스케일한 블록과 삼각형 모멘트는 쓰지 않습니다. 값
  허용 오차는 `3e-10` 이고, 미분 허용 오차는 정규화 길이를 곱한 뒤 `3e-9` 입니다.
- 고정된 방향 차트 네 개 모두, 부호가 있거나 기울어진 격자 기저, 서로 다른 푸리에 차수, 접촉
  세분 0부터 3까지.
- 균일한 값, 처음으로 패턴이 생기는 정확한 재료 변화, 복소 선형 재료 JVP, 동시에 바꾸는
  틈/재료 방향과 물리 단위 스케일링.
- 두 창에서의 4차 재료 할선, 양의 틈 중앙 할선, 2차 접촉 Taylor 나머지와 틈 `1e-9` 극한.
- 중첩 무손실 에너지, 스칼라 강압성 하한, 독립적인 붕괴 삼각형 평균/미분, 실패 주입과 유효하지
  않은 재실행 거부.

공유 위상 구조와 유리수 기하 보조 함수는 이미 독립적으로 인정받은 것입니다. 새 오라클은 원래 절점
구속 조건과 연속된 Laurent 방정식을 풀며, 후보의 조립이나 닫힘을 호출하지 않습니다. 삼각형 평균
보조 함수를 추가한 뒤에도 기존 2차 셀 테스트 61개가 통과합니다. 이 테스트들은 유한 구성 계열을
검증할 뿐, 연속체 Maxwell 해나 모든 기하 미분을 검증하지는 않습니다.

## 광학 측정과 결정

바꾸지 않은 쌍 시험 구성은 주기 700, 맞닿은 300 정사각형 직사각형 두 개, 배경 1, 두께 300,
파장 900, 위/아래 유전율 1/2.25, theta 0.2, phi 0을 씁니다. 퍼텐셜 메시는 유지 푸리에 상자와
독립적으로 세분합니다. Li는 같은 재료 칠하기를 독립적으로 적분하지만, 그 유한 차수 값을 수렴한
기준으로 가정하지는 않습니다.

로그에는 두 편광, 반사, 틈 `0, .0005, .001, .002,
1e-9`, 한쪽 기울기 창 두 개, 원래 잔차와 소스 해시가 기록되어 있습니다.
재료 `12.25 | -10+i` 에서 닫힌 투과 총량은 다음과 같습니다.

| 퍼텐셜 세분 | p, 차수 4 | p, 차수 8 | s, 차수 4 | s, 차수 8 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 0.318112424 | 0.319220974 | 0.618596377 | 0.442763611 |
| 1 | 0.378351202 | 0.377955281 | 0.617416836 | 0.408439897 |
| 2 | 0.296914881 | 0.406190556 | 0.632438079 | 0.429152015 |
| 3 | 0.417043536 | 0.433015544 | 0.461736741 | 0.418364180 |

Li는 차수 4/8에서 p `0.483946395 / 0.480976241`, s
`0.480212354 / 0.402781608` 을 줍니다. 차수 8/세분 3에서
새 p/s 값 `0.433015544 / 0.418364180` 은 앞선 보정자 두 개짜리 P1 에너지 값
`0.618325309 / 0.518567397` 보다 이 유한 차수 비교에 더 가깝습니다. 그 앞선 값은
[세분 연구](nvf-pair-refinement.md)에 기록되어 있습니다. 한 설정에서의 이 개선은 일반적인 수렴
결과가 아닙니다. 차수 4의 p 값은 Li 비교에 비해 오히려 덜 정확해지고, 새 단계열도 여전히 단조롭지
않습니다.

차수 8/세분 3에서 새 p/s 접촉 기울기는 길이 단위당 약
`-0.0166665 / +0.0104858` 이고, Li는
`-0.00323219 / +0.0115477` 을 줍니다. 이 설정에서는 이제 두 부호가 모두 일치하지만, 앞선 보정자
두 개짜리 P1 기울기는 부호가 반대였습니다. 그래도 p의 큰 차이 때문에 접촉 정확도 주장은
기각됩니다. 두 기울기 창이 일치한다는 것은 각 유한 계산의 미분이 분해되었다는 것만 확인합니다.

같은 유전체 재료 `4 | 4` 에서 차수 8/세분 3의 새 p/s 총량은
`0.997722367 / 0.987966005` 이고, Li는 `0.997682393 / 0.988163075` 입니다.
이 차이는 앞선 보정자 두 개짜리 P1 예보다 작지만, 이것 역시 유한 차수 비교일 뿐입니다. 기록된
단계열 전체에서 무손실 전력 균형과 원래 방정식 점검을 통과합니다.

이 결과는 실수, 상반, 수동이며 재료에 대해 정칙인 유한 접촉 구현으로 보관합니다. 일반적인 금속
광학 수렴을 해결하거나, 연속체 접촉 그래디언트 상한을 주거나, 기본 NVF 경로를 바꾸지는 않습니다.
더 나아가려면 퍼텐셜 공간과 푸리에 절단을 함께 분해해야 합니다. 유한 재료 보장과 상반성 보장만으로는
어느 쪽의 광학 극한도 확립되지 않습니다.



## 2차 퍼텐셜과 국소 조립

2차는 각 아핀 삼각형에 절점 퍼텐셜 여섯 개를 씁니다. 그 그래디언트는 선형이며, 기준 꼭짓점 세
개에서 지정됩니다. 따라서 물리 약형식 적분에는 2차 다항식이 들어갑니다. 푸리에 하중은 정확한
평균 `mean(lambda_i exp(-i G.r))` 을 쓰며, 이는 꼭짓점 i를 반복한 지수 분할 차분의 두 배로
계산합니다. 반복한 위상을 미분하면 그것을 두 번 셉니다. 이 기준 평균은 삼각형이 붕괴해도 유한하게
남습니다.
그 합은 상수 평면파 평균을 주며, 면적으로 나누는 계산은 하지 않습니다.

접촉 C/sZ 스케일링은 바뀌지 않았습니다. 가로 다항식 소멸은 물리 기하를 평가하기 전에 정수 위상
구조에서 보증합니다.
독립적인 2차 오라클은 6절점 Vandermonde, 유리수 기하 여인수, 수치 Duffy 적분, 연속된 원래
Laurent 방정식을 씁니다. 세분 3은 기존의 절대 3e-10 값 점검과 3e-9 정규화 미분 점검을 유지합니다.
처음에 오라클의 여인수를 반올림된 역 Jacobian에서 계산했을 때는 미분 기준을 넘었습니다. 유리수
여인수가 어느 허용 오차도 바꾸지 않고 그 기준값 반올림 오차를 해결합니다.

이제 조립은 각 삼각형을 실제로 닿는 최대 세 개 또는 여섯 개의 퍼텐셜로 제한한 뒤 그 블록을
흩뿌립니다. 더 이상 삼각형마다 전역 절점 폭의 그래디언트나 조밀한 전역 폭 국소 곱을 만들지
않습니다.
전역 약형식 풀이는 여전히 조밀합니다. 이것은 국소 조립 저장 공간에 대한 상한이며, 솔버 전체가
희소하다거나 상수 메모리라는 주장이 아닙니다.

기울어지고 오프셋된 금속 대조 사례의 2차/세분 3, 차수
(1,0)에서 퍼텐셜 소거의 조건수는 약 6.74e7이고, 유지 소거는 8.65e3입니다. 이것은 지정한 그 유한
계에 대한 관찰이며, 보편적인 조건수 보장이 아닙니다. 어느 소거에도 원래 절점 잔차와 같은 독립 미분
기준이 적용됩니다.

### 2차 광학 단계열

2차 로그는 위의 선형 연구와 같은 시험 구성, 물리 전력 점검과 접촉 창을 쓰고, 차수 12를
추가합니다. 요청한 48개 행 모두 유한 잔차, 상반성과 물리 기준을 통과했습니다. 금속의 닫힌 투과는
다음과 같습니다.

| 세분 | p, n=4 | p, n=8 | p, n=12 | s, n=4 | s, n=8 | s, n=12 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 0.378686023 | 0.361990161 | 0.414288503 | 0.631855974 | 0.496658999 | 0.433634811 |
| 1 | 0.428119068 | 0.457057276 | 0.429199030 | 0.446176516 | 0.415485036 | 0.387158657 |
| 2 | 0.454192751 | 0.466272060 | 0.442039501 | 0.398871799 | 0.391349471 | 0.395952814 |
| 3 | 0.467236471 | 0.467848935 | 0.461417724 | 0.417392569 | 0.375747030 | 0.392565033 |

n=12에서 Li는 p 0.489085870, s 0.407928008을 줍니다. 이 데이터로는 기하 단계열도 푸리에 단계열도
안정되지 않았습니다. n=8의 p 접촉 기울기도 세분 2에서 -0.0216597이던 것이 세분 3에서
+0.0057894로 바뀌는 반면, Li는 -0.00323219를 줍니다. 따라서 더 큰 공간은 정확한 유한 대수적
성질을 갖추었는데도 금속 접촉 미분을 인정받지 못합니다.

별도의 [주기 직사각형 연구](nvf-periodic-galerkin.md)는 같은 방정식을 원래의 닫히는 틈 사례에
적용합니다. 그 사례의 p 편광 미분을 크게 개선하지만 s 편광 트레이스 오차는 남습니다.
어느 연구도 일반 NVF 디스패치를 바꾸지 않습니다.


## 명시적 사용법

```python
import numpy as np
from wavebit.rcwa._engine.conforming.cartesian_pair_opening import CartesianPairOpeningPlan
from wavebit.rcwa._engine.conforming.cartesian_pair_galerkin import CartesianPairGalerkinGapCell

geometry = dict(basis=np.diag([700., 700.]), widths=(300., 300.), height=300.)
plan = CartesianPairOpeningPlan.from_geometry(**geometry, refinement=1)
cell = CartesianPairGalerkinGapCell(plan, order=(2, 1), degree=2, coercivity_angle=1.53)
slots, gap_derivative, metadata = cell.closure(
    gap=0., epsilon=(12.25, -10.+1j), **geometry)

# Derivative along simultaneous changes of the two materials.
slots, material_derivative, metadata = cell.closure(
    gap=7., epsilon=(12.25, -10.+1j), gap_tangent=0.,
    epsilon_tangent=(.2, .3j), **geometry)
```

슬롯은 층 축을 포함하며, 음의 가로 교차 블록을 포함해 기존의 다섯 슬롯 순서를 유지합니다. 기본
JVP 방향은 호출자 길이 단위로 1만큼 틈을 엽니다. `background_tangent` 의 기본값은 0입니다.
미분할 때 다른 기하 매개변수는 고정됩니다. 이 모듈은 NumPy 전용이며, JAX 추적이나 자동 공개 NVF
디스패치는 제공하지 않습니다. 계획 수립과 기하 허용 판정은 기존 카르테시안 쌍 계열을 따르며, 엄격한
포함 조건과 세분 0부터 3까지를 씁니다.

`degree=1` 은 여전히 기본값이며 삼각형마다 선형 퍼텐셜 노드 세 개를 씁니다. `degree=2` 는 2차
퍼텐셜 노드 여섯 개와 선형 그래디언트를 씁니다.
둘 다 기하 세분 0부터 3까지를 허용합니다. 세분 3의 2차는 열린 자유 퍼텐셜 2,303개와 접촉 자유
퍼텐셜 1,791개를 가지며, 그 모서리 노드는 다음 이진 세분 그래프를 씁니다. 이것이 별도 P1 계획의
세분 계약이나, 앞선 보정자 두 개짜리 2차 셀의 지원 범위를 넓히지는 않습니다.

의존성, 외부 솔버, 복사한 소스나 기준 데이터는 추가하지 않았습니다. 구현은 기존 NumPy 의존성과
저장소의 삼각형 및 주기 위상 구조 코드를 씁니다. 체크아웃에서 다음으로 재현합니다.
