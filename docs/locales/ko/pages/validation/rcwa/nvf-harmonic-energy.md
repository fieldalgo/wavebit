# 재료로 정의한 에너지 인수분해 연구

`studies/rcwa/nvf_harmonic_energy/nvf_harmonic_energy.py`는 표현 문제와 수렴 문제를 위한, 아직
받아들여지지 않은 새로운 연구 후보입니다. 이 후보는 제품 NVF 분배에 설치되지 **않았습니다**.
직사각형에 대해 직교 좌표 Li를 선택하지도 않습니다.

**확장된 접촉 검사는 이제 s 편광에서 실패합니다.** 그 미분은 약 12.25배 너무 작고, 내부 차수를
늘려도 개선되지 않습니다. 앞서의 0.54% 불일치는 p 편광에만 해당합니다. 새로운 정합 2D 셀 도구는
보조 필드의 불확실성을 크게 줄이지만, 그 움직이는 접촉 극한을 풀지는 못합니다.
[셀과 편광 후속 연구](nvf-cell-corrector.md)를 참고하세요.

이후의 [정합 얇은 틈 연구](nvf-thin-gap-energy.md)는 빠져 있던 법선장 에너지를 유지하며, 직사각형
대조군에서 두 접촉 편광 관문을 모두 통과합니다. 이 연구는 살아 있는 JIT 미분을 가진 다른 셀 공간을
사용합니다. 아래의 푸리에 후보와 그 예상된 실패는 바뀌지 않습니다. 새 연구는 임의의 기본 도형 분할
불변성을 아직 확립하지 않았습니다.

다음 [재료 불연속 확장](nvf-partitioned-gap-energy.md)은 수평 직사각형 타일링에 대해, 살아 있는 내부
대비를 포함해 정합 접촉 필드와 분할 불변성을 결합합니다. 임의의 형상은 아직 열린 문제입니다.

## 구성

기본 도형의 인위적인 이음매를 유지하는 대신, 정확한 재료 푸리에 급수로 두 정전기 셀 문제를
결정합니다:

```
div(epsilon (e_j + grad chi_j)) = 0
B_j = e_j + grad chi_j
```

상수 퍼텐셜은 고정하고, 나머지 스칼라 푸리에 모드는 라플라시안 전처리기를 쓴 켤레 기울기법으로
풉니다. 정확한 직사각형 계수와 0으로 채운 합성곱이 이 연산자를 이룹니다. 따라서 픽셀보다 작은 틈은
픽셀 임계값 없이 재료 계수를 바꿉니다.

횡방향 전기 에너지는 Gram 행렬을 사용해 유지된 물리 푸리에 좌표로 표현합니다:

```
Q = C(B)
G = C(B.H epsilon B)
epsilon_effective = inv(Q).H G inv(Q)
```

양의 실수 epsilon에 대해 G는 에르미트 양정치 행렬입니다. 이렇게 하면 구성 관계 닫힘(closure)에서 무손실
에르미트성이 보존됩니다. 종방향 자리는 역 직접 재료 행렬로 남습니다. 그다음 연구는 Wavebit의 층
고유값 풀이를 호출하고 일반적인 균질 외부 모드와 맞춥니다. 이것은 제안된 구성 관계 닫힘이며,
두 정전기 보정자가 모든 유한 절단에서 최선의 동적 Maxwell 기저를 준다는 증명이 아닙니다.

정확한 재료 적분과 삼각함수 Galerkin 셀 문제를 관련 지어 사용하는 방법은
[Vondrejc, 2014](https://arxiv.org/abs/1412.2033)에 설명되어 있습니다. 그
논문의 스칼라 균질화 한계는 이 새로운 닫힘의 광학 투과에 대한 한계가 **아닙니다**. 외부 솔버
구현은 복사하지 않았습니다.

실제 절단은 두 가지입니다: 바깥 Maxwell 차수 n과 내부 보정자 차수
H. FFT 평가 격자는 `4*(H+n)`을 넘기 전까지만 세 번째 매개변수입니다. 그 임계값을 넘으면, 유지된
Gram 적분은 선택한 삼각함수 보정자와 정확한 조각별 재료에 대해 정확합니다. H를 늘리면 근사가
바뀌지만, 이미 충분한 평가 격자를 늘리면 바뀌지 않습니다. 양수 잘라 내기나 법선장 스무딩은
적용하지 않습니다.

이것이 제품 백엔드 계약이나 Torch 구현을 확립하지는 않습니다.
대역 제한 보정자는 정확한 점별 경계면 불연속도 강제하지 않습니다.
도입하기 전에 내부 수렴, 접촉 극한, 동적 수렴, 칠한 형상, 손실/자성 매질, 제품 백엔드 계약을 해결해야
합니다.

시제품도 테스트했습니다. 에너지는 보존했지만 n=6에서 H를 31에서 63으로 바꾸었을 때 T가 0.847516652에서
0.825436908로 바뀌었습니다. 그 접촉 기울기는 테스트한 범위에서 Li 비교값에 가까워지지 않았습니다. 그
완전 기저 변형도 채택하지 않았으며, 유지된 연구는 위의 에너지 구성 관계 닫힘입니다.

## 유한 후보의 암시적 미분

`studies/rcwa/nvf_harmonic_energy_jax/nvf_harmonic_energy_jax.py`는 세 이산화 크기를 고정한 채
직사각형 치수, 각도, 위치, 실수 유전율을 살아 있게 유지합니다.
셀 해는
[`jax.lax.custom_linear_solve`](https://docs.jax.dev/en/latest/_autosummary/jax.lax.custom_linear_solve.html)를
사용해 암시적으로 미분합니다.
각 순방향 풀이와 전치 풀이는 실제 잔차를 검사합니다. 실패하면 JIT 아래에서 NaN이 나오고, 측정
명령은 유한하지 않은 데이터를 거부합니다. 복소 에르미트 연산자는 전치 대칭으로 선언하지
**않습니다**. 재료 계수가 복소수인 평행 이동한 직사각형에서는 이것이 중요합니다. 산란은 NumPy와 JAX에
같은 연구 루틴을 사용하고, Wavebit의 기존 고유 모드 미분을 사용합니다. 셀 반복 이력은 미분하지
않습니다.

재료 FFT는 이제 셀 문제마다 한 번 계산해 모든 행렬-벡터 곱에서 재사용합니다. 이것은 비용을 바꿀 뿐
이산화를 바꾸지는 않습니다. 원래의 균일 슬래브, 분할, 정확한 곱, 실패한 풀이 검사는 여전히
통과합니다.

바깥 차수 7에서 JAX가 주는 정확한 접촉 미분은 다음과 같습니다:

| 내부 H | gap=0에서의 JAX T | gap=0에서의 JAX dT/dgap | 독립적인 NumPy 양의 할선 기울기, 간격 1e-4 |
| --- | ---: | ---: | ---: |
| 31 | 0.612500546747 | 0.001969613266 | 0.001969620802 |
| 63 | 0.619488391427 | 0.001931692175 | 0.001931700341 |
| 127 | 0.622779529439 | 0.001911989676 | 0.001911997762 |
| 255 | 0.624419298425 | 0.001901820104 | 0.001901829385 |

이 행들에서 NumPy/JAX T의 차이는 최대 1.10e-13입니다. H=255에서 미분은 독립적인 Li 접촉 도구의 약
0.00189156과 0.54% 다릅니다. 이는 **남아 있는 이산화 오차**이며, JAX 미분 오차도 아니고 받아들여진
접촉 허용 오차도 아닙니다. Gap=0은 문서화된 겹치지 않는 형상의 오른쪽 미분이며, 음의 틈은 테스트로
사용하지 않습니다.

angle=0.31, epsilon=6.25인 평행 이동한 440x270 직사각형은 n=2/H=7에서
T=0.988388160136과 `(lx, ly, angle, epsilon)`에 대한 다음 미분을 줍니다:
`(0.000217965944, 0.000317737805, -0.032707833248, 0.008461345282)`.
각 값은 두 간격 크기에서 독립적인 NumPy 중앙 차분과 일치합니다.
다른 테스트들은 인위적인 같은 재료 이음매를 옮겨도 값과 그 물리 매개변수 미분이 바뀌지 않는지,
그리고 대비가 0일 때도 유전율 미분이 살아 있는지를 검사합니다. 별도의 실패 테스트는 순방향 풀이는
수렴하고 수반 풀이는 수렴하지 않는 경우를 다루며, 유한하지 않은 그래디언트를 요구합니다. 원래의
JAX 테스트 6개와 후보 테스트 4개가 통과했습니다. 확장된 스위트는 이제 s 접촉 물리와, 기존 고유값
정규화에서 오는 훨씬 작은 s 그래디언트 편향에 대해 엄격한 예상된 실패를 기록합니다. native 비축퇴
고유값 대조군은 바뀌지 않은 그래디언트 테스트를 통과합니다.

이 검사들은 고정된 이산화에서의 1차 역방향 미분을 다룹니다. 고차 미분, 제품의 고정된 형상, 손실
매질, 아직 수렴하지 않은 Maxwell 극한의 올바른 미분은 주장하지 않습니다. 원래의 제품 분할/병합 진단은
여전히 해결되지 않았습니다.

## 역수 재료 플럭스 변형: 거부된 접촉 미분

전기 변위를 표현하면 내부 절단 오차가 줄어드는지 보려고 쌍대 시도를 검사했습니다. 이 시도는 같은 두
보정자를 `rho=1/epsilon`에서 풀고, 그 회전 없는(curl-free) 필드를 90도 돌려 발산 없는 플럭스 기저 F를
얻은 다음, 다음을 사용합니다

```
Q = C(rho F)
G = C(rho F.H F)
epsilon_effective = inv(Q).H G inv(Q)
```

상수 열 회전과 정규화는 이 합동 변환에서 상쇄됩니다. 종방향 자리는 여전히 원래의 직접 epsilon 행렬을
사용합니다. 같은 충분 격자 기준과 함께 정확한 푸리에 곱 적분을 사용합니다.

이 변형은 이미 H=15에서 닫힌 막대 n=7 값 0.626061531897을 주며, 독립적인 Li 도구와 일치합니다.
그러나 H=15/31/63/127에서의 양의 1e-6 틈 기울기는 0.0140110158 / 0.0140109736 / 0.0140110495 /
0.0140110449로, 독립적으로 검사한 0.00189156의 약 7.4배입니다. 따라서 정확한 닫힌 값이 그 접촉
미분을 올바르게 만들지는 않습니다. 공명 n=10 T도 0.712083547 / 0.802017271 /
0.838896268 / 0.848265979로 크게 움직입니다. 이 시도는 거부되었습니다. 후보나 제품 분배에 설치하지
않았으며, 어떤 기준값도 제공하지 않습니다.

## 고차 모드 정전기 응축: 탐색 전용

별도의 시도는 유지된 Maxwell 상자 밖의 그래디언트 모드에 대해 전기 에너지를 최소화합니다. D를 고차
모드 그래디언트, C를 정확한 재료 행렬이라 하면, 유지된 횡방향 행렬은 Schur 보수
`C_low - C_low,high D inv(D.H C_high D) D.H C_high,low`입니다. 고차 스칼라 모드는 라플라시안으로
전처리하고, 저차 스칼라 모드는 유지된 전기 좌표를 바꾸도록 허용하는 대신 제외합니다. 유지된 각 전기
열마다 자체 셀 풀이가 필요하므로, 이 방법은 보정자 두 개보다 훨씬 비쌉니다.

H=7/15/31에서 n=3 닫힌 막대 T 값은 0.602171643 / 0.635706685 /
0.652768616으로, 독립적인 n=3 값 0.669377786과 비교됩니다. 기울어진 n=6 T는
0.934219637 / 0.898950973 / 0.878052788입니다. 이 기울어진 실행들에서 실제 셀 잔차는 1e-12 미만이고
에너지 오차는 2e-13 미만입니다. 이 몇 개의 내부 차수로는 수렴하거나 더 빠른 대안이 확립되지
않습니다. 이 시도는 후보나 제품 분배에 설치하지 않았으며, 광학 오차 한계에 대한 주장도 없습니다.

## 재현

NVF 작업 트리에서, 기존 Wavebit 환경으로 실행합니다:

```bash
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python studies/rcwa/nvf_harmonic_energy/nvf_harmonic_energy.py --inners 31 63 127 --orders 6 10 14 --gates
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m studies.rcwa.nvf_harmonic_energy_jax.nvf_harmonic_energy_jax --inners 31 63 127 255
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m pytest -q tests/rcwa/test_nvf_harmonic_energy.py tests/rcwa/test_nvf_harmonic_energy_jax.py
```

도구 테스트는 후보 행렬과 산란을 정확한 균일 슬래브, 분할 재료 변환과 투과, 충분한 적분 격자에 대한
불변성, 앨리어싱 격자의 거부, 실패한 보정자 풀이의 거부와 비교해 검사합니다. 이 테스트들이 해결되지
않은 수렴 결과를 통과하는 물리 관문으로 바꾸지는 않습니다. 선택한 패키지 출력은
[`studies/rcwa/nvf_harmonic_energy/records/nvf_harmonic_energy.log`](../../../studies/rcwa/nvf_harmonic_energy/records/nvf_harmonic_energy.log)에
남겨 두었습니다.
위의 H=15/31/63 행은 로컬 시제품에서 나왔고, H=127/255 행은 패키지된 연구를 사용합니다. 후자는 더
작지만 충분한 평가 격자와 Wavebit의 층 고유값 풀이를 사용합니다. 순방향 값은 시제품과 약 1e-12까지
일치하며, 1e-6 할선 기울기는 남은 솔버 반올림 오차를 증폭합니다.
더 새로운 암시적 미분 측정과 독립적인 NumPy 할선 기울기는
[`nvf_harmonic_energy_jax.log`](../../../studies/rcwa/nvf_harmonic_energy_jax/records/nvf_harmonic_energy_jax.log)에
있습니다.
