# 접촉을 지나는 정확한 유한 쌍 계열

작성: 2026-09-10

대상:
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair_gap.py`
- `tests/rcwa/test_nvf_cartesian_pair_gap.py`
- `studies/rcwa/nvf_cartesian_pair/records/nvf_cartesian_pair_gap.log`

`CartesianPairGapCell`은 하나의 불변 차트 위에서 물리 틈이 0이거나 양수인 유한 수평 쌍을
평가합니다. 이 클래스의 NumPy 구현은 약형식 방정식, 필드, 그리고 그들의 틈 미분을 평가하기 전에
얇은 삼각형의 극점을 해석적으로 제거합니다. 따로 검증된
[접촉 열림 응답](nvf-cartesian-pair-opening.md)이 계속 끝점 기준으로 남습니다. 일반 쌍 빌더와
접촉을 보존하는 그 JAX 탄젠트는 바뀌지 않았습니다. 사용법과 허용 조건은
[설명서](../../guide/rcwa/cartesian-pair-gap.md)에 있습니다.

## 정확한 재척도 좌표

이 물리 계열은 폭, 공통 높이, 격자, 재료, 셀 전체 오프셋을 고정합니다. 틈 g를 늘리면 왼쪽/오른쪽
직사각형이 `(-g/2, 0)` / `(g/2, 0)`만큼 움직이고, 셀 경계는 고정됩니다. 모든 길이를
L = √det(A)로 정규화하고 s = g/L로 둡니다. 정확한 붕괴(collapse) 그래프로부터 접촉 퍼텐셜을 그
반복 노드에 주입하는 C와, 그 차이를 펼치는 Z를 얻습니다. 물리 퍼텐셜은 다음과 같습니다.

```text
w = L * (C u + s Z v).
```

정규화된 각 삼각형에 대해 `N(s) = N0 + s N1`, `d(s) = d0 + s d1`로 두고, 원래 국소 방정식을
`K = epsilon/(2*d) * N N^T`, `F = -epsilon*N/2`로 둡니다.
`X = N^T C`, `Y = N^T Z`로 쓰면, 정칙 삼각형은 다음을 기여합니다.

```text
H00 = epsilon/(2*d) * X^T X
H01 = epsilon/(2*d) * X^T Y
H11 = epsilon*s/(2*d) * Y^T Y
fC = -epsilon*X^T/2,  fZ = -epsilon*Y^T/2.
```

얇은 삼각형에서는 정확한 이진(dyadic) 붕괴 항등식으로부터 `d0=0`과 `N0^T C=0`이 구조적으로
성립합니다. `a=N1^T C`로 두면 그 유한 기여는 다음과 같습니다.

```text
H00 = epsilon*s/(2*d1) * a^T a
H01 = epsilon/(2*d1) * a^T Y
H11 = epsilon/(2*d1) * Y^T Y
fC = -epsilon*s*a^T/2,  fZ = -epsilon*Y^T/2.
```

이 국소 항들을 조립하면 다음을 얻습니다.

```text
M = [[H00, s*H01], [H01^T, H11]]
M x = f,  x = [u; v]
M x' = f' - M' x.
```

이것은 양의 틈에서 유한 좌표를 정확히 바꾼 것이지, 잘라 낸 끝점 급수가 아닙니다. 0에서는 접촉
극한 방정식과 차이 극한 방정식, 그리고 그 미분을 줍니다. 응답을 정의하는 데 유한 틈 외삽은 쓰지
않습니다. 모든 행렬 미분과 필드 미분은 해석적으로 평가합니다.

전체 M은 의도적으로 비대칭이며, 그 원래의 에르미트 부분은 강압성(coercivity) 검사가 아닙니다.
양의 s에서 `diag(I,s*I) M`은 열이 `[C,s*Z]`인 물리적 합동 변환입니다. 구현은 H00과 H11의 실수
에너지 부분을 따로 보호하고 M의 조건수를 보고합니다. 차트가 포함되고 양수라고 해서 균일한 조건수
반지름이 보장되지는 않습니다.

## 필드, 가중치, 원래 방정식

정규화된 국소 필드는 다음과 같습니다.

```text
B_regular = I + (X u + s Y v)/d
B_thin = I + (a u + Y v)/d1.
```

얇은 필드도, 재척도한 풀이도 틈으로 나누지 않습니다. 그 해석적 미분은 변하는 국소 기하와 암묵적
해 응답을 포함합니다. C/Z 투영 전에 게이지 행을 포함한 원래 주기 약형식 플럭스 전체도 조립합니다.
각 국소 기여는 `epsilon*N*B/2`이고, 그 미분은 `N1*B + N*B'`를 포함합니다. 이 잔차들은 판독만을
위해 발산하는 행렬을 만들지 않고 원래 방정식을 검사합니다.

기존 다각형 윤곽 변환이 접촉에서 반복되는 점을 포함해 삼각형 가중치를 평가합니다. 그 해석적
이동 윤곽 미분은 면적과 공간 위상의 움직임을 유지합니다. 접촉에서는 바깥 부채꼴 삼각형을 포함한
모든 얇은 삼각형이 기여합니다. 독립적인 Duffy 모멘트와 검증된 끝점 가중 모서리 식이 절댓값과
정규화된 미분을 검사합니다. 아주 작은 개별 얇은 가중치에 대해서는 균일한 상대 정확도를 주장하지
않습니다.

아홉 개의 계수 필드는 에너지에 `epsilon * B.conj().T @ B`를 사용하며, 두 켤레 미분 항을 모두
유지합니다. 선택한 닫힘과 그 미분은 역행렬을 구하기 전에 요청한 정확한 푸리에 차이를 사용합니다.
최종 미분은 L로 나누어 **호출자 길이 단위당** 값으로 돌려줍니다.

## 범위를 정한 독립 검증

고정된 30점 연구는 끝점 연구와 같은 열 개의 선언된 차트/세분화 사례를 `s=0, 1/64, 1/16`에서
사용합니다. 주 물리 픽스처는 기저 `[[700,315],[0,490]]`, 폭 `(140,193)`, 높이 210, 오프셋
`(49,-21)`, 유전율 `(4+.8j,9+.3j)`, 배경 `1+.1j`를 가집니다. 이것을 부호 있는 열 기저 네 개
모두로, 세분화 0/1에서 표현합니다. 두 번째 픽스처는 기저 `[[640,-160],[70,560]]`, 폭
`(160,110)`, 높이 190, 오프셋 `(31,-19)`, 유전율 `(2.4+.17j,5.8+.46j)`, 배경 `1.2+.08j`를
가지며, 차트 1이 두 세분화 모두에서 허용됩니다. 열 개의 사례가 열 개의 서로 다른 물리 기하는
아닙니다. 사례들은 8개 또는 35개의 자유 재척도 퍼텐셜을 가집니다.

양의 틈에서 독립 기준은 정확한 유리수 물리 3×3 노드 방데르몽드 행렬, 원래의 완전한 약형식 계,
그리고 그 해석적 미분을 구성합니다. 움직이는 단체 위의 Duffy q16/q24 적분이 계수 기준을 제공합니다.
0에서는 독립적인 원래 로랑 끝점 방정식을 사용합니다. 별도의 미분된 닫힘 풀이가 정수 레이블을
명시적으로 선택합니다. 네이티브 양의 틈 셀 값은 추가 검사입니다.

미리 정한 절댓값 및 구적 보호 기준은 `3e-10`입니다. 미분 비교는 단위당 출력에 L을 곱하고
`3e-9`를 요구합니다. 원래, 투영된, 미분된 약형식 잔차와 역행렬 항등식은 `1e-10`을 요구합니다.
소스를 고정한 뒤에 허용 오차, 사례, 구적을 바꾸지 않았습니다.

잘못된/불변 호출 아홉 개가 모두 통과합니다. 차수 `(1,2)` / `(2,1)`은 정확한 부호 있는 기저 레이블
순열을 따르고, `(0,0)`, `(1,0)`, `(0,1)`은 더 작은 선택 닫힘을 검사합니다. .01로 공통 척도를
바꾸면 물리 틈도 함께 바뀌어 돌려주는 미분이 1/.01배가 됩니다.
테일러 사다리는 이미 정의된 미분을 확인할 뿐이며, 연속체 수렴 속도나 오차 상한이 아닙니다.

M의 측정 조건수는 49.4730–489.018 범위입니다. H00/H11 실수 에너지 고유값의 최솟값은
.203997/.136961이고, 닫힘 저장량/부호 있는 소산의 최솟값은 1.00298/.0800624입니다. 이것들은
유한 사례에서 측정한 성질입니다. 원래의 재척도 전 조건수는 남겨 두지 않았으므로, 수치적 개선
비율은 추론하지 않습니다.

원래 감사(audit)는 2.97389 s가 걸렸고, 부모 프로세스 경과 시간은 3.29534 s였습니다. 별도의 저장
배열 감사는 .08486 s가 걸렸으며 주 체크포인트 30개와 대조 체크포인트 22개 전부, 소스/실행/완료 고정값,
그리고 정확히 다시 계산한 비교들을 확인했습니다. 솔버를 다시 실행하지는 않았습니다. 원래 오라클
닫힘 배열과 전체 부하 정규화 값은 저장하지 않았습니다. 그 원래 비교/잔차는 소스/해시로 확인했고,
저장된 행렬 잔차, 조건수, 직접 닫힘 항등식은 독립적으로 다시 계산했습니다. RSS는 측정하지
않았습니다.

저장소 반영은 클래스 이름 변경 하나, 상대 import 세 개, 모듈 머리말 외에는 수치 추상 구문을 그대로
보존합니다. 새 전용 테스트 묶음은 비공개 배열 없이 독립 기준을 다시 계산하며 3.14 s에 79개 테스트를
통과합니다. tests, studies, JAX, PyTorch import를 막은 상태에서 새로 복사한 패키지로 실행한 가이드
예제도 통과합니다. 완전한 정밀도의 측정값과 소스 고정값은
[결과 로그](https://github.com/fieldalgo/wavebit/blob/main/studies/rcwa/nvf_cartesian_pair/records/nvf_cartesian_pair_gap.log)에
있습니다.
이 유한 계열은 연속체, 임의 대비, 패턴이 있는 광학 정확도를 입증하지 않으며, 일반 접촉 기하
JVP에 대한 보장을 새로 도입하지도 않습니다.

별도의 [NumPy/JAX x64 값 평가기](nvf-cartesian-pair-gap-autodiff.md)가 이제 같은 고정 계열에서
물리 틈에 대한 일반 자동 미분을 검증합니다. 이 해석적 NumPy 기준은 바뀌지 않았고, 일반 접촉
어댑터 탄젠트는 기존 범위를 유지합니다.
