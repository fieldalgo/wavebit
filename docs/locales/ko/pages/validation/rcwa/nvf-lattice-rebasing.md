# 동등한 격자 기저 위의 conforming NVF

작성: 2026-09-09

대상:
- `src/wavebit/rcwa/_engine/conforming/__init__.py`
- `tests/rcwa/test_conforming_lattice_rebasing.py`

`ConformingNVF`는 비직교 기저 벡터라도 그것이 직교 점 격자를 나타낸다면 받아들입니다.
이로써 물리 직사각형이나 보정기 방정식을 바꾸지 않고 표현상의 제약 하나가 없어집니다.
진짜로 비직교인 점 격자는 여전히 직사각형 셀 빌더의 범위 밖입니다.
[설명서](../../guide/rcwa/conforming-nvf.md)에 입력과 재실행(replay) 계약이 있습니다.

예를 들어 다음과 같습니다.

```text
A = [[700, 2100], [0, 430]]
T = [[1, -3], [0, 1]]
C = A T = diag(700, 430)
```

A와 C는 정확히 같은 주기 평행 이동들을 생성합니다. A를 벡터 노름과 같은 변 길이를 가진 직교
셀로 취급하면 그 격자가 바뀝니다. 반대로 형상 좌표에 연속적인 전단을 적용하면 직사각형이
평행사변형으로 바뀝니다. 두 연산 모두 이번 확장에 포함되지 않습니다.

## 고정된 정수 축약과 살아 있는 기하

계획 단계에서는 기존 격자 모듈의 Gauss/Lagrange 축약으로 정수 유니모듈러 행렬 T를 얻습니다.
그다음 직사각형 어댑터와 같은 직교성 검사와 양의 주기 검사를 적용합니다. 이미 직교인 기저는
항등 축약을 그대로 씁니다. 축약한 뒤에도 비직교로 남는 기저는 거부합니다.

이제 불변 계획은 층 순서와 각 층의 타일링 축에 더해 T도 저장합니다. 재실행은 살아 있는 격자에서
`C = A T`를 만듭니다. 추적된(traced) 격자를 반올림하거나 축약하거나 다시 계획하지 않습니다.
계획은 T가 정수로 이루어져 있고 행렬식이 1인지 검증합니다. 주기, 공통 회전, 위치, 치수와 서로
독립인 재료 손실은 살아 있는 값으로 남습니다. 미분은 C가 직교로 유지되는 계열 안에서 정의됩니다.
이와 무관한 연속 전단은 그 계열을 벗어나므로, 즉시 실행(eager)에서는 예외를 일으키고 추적
중에는 NaN을 냅니다.

직사각형 길이는 물리 길이 그대로이며, 각도는 실험실 좌표계에서 잽니다. 직사각형의 변은 A가
아니라 C에 맞춰 정렬됩니다. 기존의 층별 `(c1,c2)`와 `(c2,-c1)` 사이 선택, 재료 프로필, 접촉
연속(contact continuation)과 종횡비 계량은 수정 없이 적용됩니다.

## 호출자가 정한 형상 원점 보존하기

형상 중심은 입력한 격자 벡터 합의 절반에서 잰 오프셋입니다. 따라서 입력 중심 d는 다음 절대
중심을 나타냅니다.

```text
x_center = A [1,1]^T / 2 + d
```

구성 셀에서 이에 대응하는 오프셋은 `d_C = d + (A-C)[1,1]^T/2`입니다. 어댑터는 직교 좌표 변환
전에 이 이동을 적용한 뒤, 일반적인 셀 꼭짓점 기준 푸리에 위상을 씁니다. 그래서 두 기본
평행사변형의 중심이 반 주기만큼 달라도 형상의 절대 위치가 보존됩니다.

이 이동은 사용자가 의도한 기하 변경과는 다릅니다. 사용자가 A를 바꾸고 d를 그대로 두면, 일반
형상 API에서와 마찬가지로 형상은 새로 입력한 셀 중심에 붙어 있습니다. A를 Anew로 바꾸면서
절대 위치를 고정하려면 사용자 오프셋을 `(A-Anew)[1,1]^T/2`만큼 바꾸세요.

## 정확한 유한 푸리에 집합 보존하기

원래 정수 차수 k에 대해, 같은 물리 역격자 벡터는 다음과 같습니다.

```text
q = 2 pi A^(-T) k = 2 pi C^(-T) k_C
k_C = T^T k
```

원래의 직사각형 차수 창은 보통 C 좌표에서 직사각형이 아닌 집합이 됩니다. 어댑터는 변환한 차수들
사이의 모든 차이를 덮을 만큼 푸리에 계수를 투영하지만, 유지하는 모드의 개수와 순서는 원래와
정확히 같게 둡니다. 두 번째 축약 축을 쓰는 층에서는 추가 사상이 `(m,n) -> (n,-m)`입니다.

선택은 `E = Q^(-H) G Q^(-1)`와 `Z^(-1)`보다 먼저 Q, G, Z에서 일어납니다. 이미 닫힌 더 큰
직사각형 행렬에서 성분을 뽑아내는 것은 다른 유한 구성이 됩니다. 행렬 역산과 부분집합 선택은
일반적으로 교환되지 않기 때문입니다.

투영 셀은 필요한 푸리에 포락 차수별로 캐시합니다. 이것은 계수 모드 개수를 바꿀 뿐, 보정기
메시나 그 미지수 개수를 바꾸지 않습니다. 큰 정수 전단은 투영 비용을 키울 수 있습니다. 결과를
쓰는 엔진은 항상 원래의 A와 절단 차수를 받으므로, 파동 벡터와 출력 차수 레이블은 원래 의미를
유지합니다.

## 독립 대조와 남은 범위

대조에는 원래 물리 형상 기술을 쓴 해석적 푸리에 적분과, 두 층 방향 모두에서 독립적인 역규칙
접촉 텐서가 포함됩니다. 별도의 양의 틈 기준은 직교 셀에서 물리 역격자 벡터로 대응하는 차수를
찾고, 닫힘 전에 Q/G/Z를 선택합니다. 같은 물리 모드를 유지하는 특수한 차수 집합들도 격자 표기가
달라져도 완전한 엔진 결과를 재현합니다. 수평, 균일, 수직 방향이 섞인 흡수성 접촉 적층은 NumPy,
JAX, Torch 엔진에서 검사합니다.

열다섯 개의 기하, 저장 재료, 손실, 주기 매개변수를 두 가지 유한 차분 간격과 비교합니다. 접촉
열림 미분은 같은 물리 모드의 동등한 표현들 사이에서 비교합니다. 잘못된 축약, 바뀐 고정 축약과
진짜 비직교 격자는 즉시 실행과 추적 재실행 모두에서 검사합니다.

명령과 측정은
`studies/rcwa/nvf_lattice_rebasing/records/nvf_lattice_rebasing_validation.log`에 있습니다. 재기저화
(rebasing) 사례 52개, 기존 공개 구성·재료 사례 203개, 문서 사례 35개가 통과해 서로 다른 검사
290개가 통과했습니다. 설명서 예제 세 개 모두와 lint, 엄격한 문서 빌드도 통과했습니다. 이것은 기하
표현과 유한 모드 통합에 대한 자격 검증이며, 광학 수렴 인증이 아닙니다. 셀, 수동성, 접촉, 광학
허용 오차는 하나도 바꾸지 않았습니다. 일반 비직교 보정기, 곡면 기하, 양이 아닌 실수 유전율과
자동 투영기 선택은 별도의 작업으로 남아 있습니다.
