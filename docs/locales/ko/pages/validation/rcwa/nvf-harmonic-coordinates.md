# 고정된 틈 메시 안에서 움직이는 재료 불연속

`studies/rcwa/nvf_harmonic_coordinates/nvf_harmonic_coordinates.py`는 고정된 각 x 요소 안에서 움직이는
재료 필드 불연속을 다룹니다. 닫힌 혼합 막대는 이제 재료 경계면이 요소를 가로지르는 경우에도 정확한
정적 에너지, 이음매/재료/폭 미분, 독립적인 직교 좌표 구성 행렬과 일치합니다. 앞선 연구의 평행 이동한
분할 검사와 p/s 접촉 검사도 계속 통과합니다.

이것은 직사각형 외곽 안의 수평 재료 분할을 위한, 선택적으로 켜는 연구 모델입니다. 양의 틈에서는 실제
이음매가 메시 절점을 지날 때 여전히 작은 한쪽 광학 미분 불일치가 남습니다. 그 불일치, 일반 형상, 기울어진
광학 수렴, 제품 통합은 아직 열린 문제입니다. 제품 NVF 분배나 고유값 미분은 바꾸지 않았습니다.

이후의 [적분형 연속 플럭스 모델](nvf-continuous-flux.md)은
인위적인 메시 절점을 가로질러 물체 변위를 연속으로 만들어 이제 그 양의 틈 이음매 관문을 통과합니다.
아래의 국소 모델 실패와 측정은 대조군으로 남겨 둡니다. 일반 광학 수렴은 아직 열린 문제입니다.

## 재료 조화 좌표와 아핀 들어올림

고정된 x 요소 `[x_i, x_i+h_i]`에서 다음을 정의합니다

```
rho(x) = 1/epsilon(x)
R_i    = integral_element rho(x) dx
s_i(x) = integral_{x_i}^x rho(u) du / R_i
s_i'(x) = rho(x) / R_i
```

일반적인 선형 절점 좌표를 `s_i`로 바꿉니다. 퍼텐셜은 연속으로 유지되지만, 그 미분은 요소 안의 각
재료 불연속을 따라갑니다. 메시는 재료 조각의 개수나 동일성이 아니라 외곽과 명시적인 해상도 설정에
따라 정해집니다. 앞선 틈 연구에서처럼 양의 실수 유전율이 필요합니다.

주기 보정자 기저만 바꾸는 것으로는 부족합니다. 물리적 아핀 퍼텐셜 x는 일반적으로 조화 요소 공간
밖에 있습니다. 따라서 x 열에도 준주기 아핀 들어올림을 사용합니다:

```
ell(x) = x_i + h_i*s_i(x)
L(x)   = ell'(x) = h_i*s_i'(x)
phi_x  = ell(x) + chi_x(x,y)
phi_y  = y      + chi_y(x,y)
```

들어올림은 연속이고, 정규화된 주기 동안 1만큼 증가하며,
`ell-x`는 주기적입니다. 따라서 전체 필드 B의 평균은 여전히 I입니다.
물체/틈 퍼텐셜 구성과 틈 시험 방정식의 해석적 나눗셈은
[정합 틈 연구](nvf-thin-gap-energy.md)에서 물려받습니다.

들어올림은 순방향 변분 강제항과 사영 에너지를 바꿉니다. 특히 x 강제항은 물체와 틈 모두에서 `L`을
각 절점 미분과 짝짓습니다. xx 에너지에는 가중된 `L^2` 항과
`L*grad(chi)` 교차항이 들어갑니다. 예전의 단위 아핀 강제항을 그대로 둔 채 보정자만 바꾸면 잘못된
정적 에너지가 나왔습니다. 구현된 모델은 이 모든 항을 함께 바꿉니다. 광학 그래디언트 배수는 없습니다.

## 정확한 적분과 분할 상쇄

각 재료 조각 안에서 `s_i`는 물리적 국소 좌표에 대해 아핀입니다.
따라서 다항식 차수 2까지의 기존 정확한 푸리에 모멘트로 가중된 기저 곱, 미분 곱, 들어올림 항을
적분할 수 있습니다. 필요한 묶음은 다음과 같습니다

```
integral w * s_i**k * Fourier_wave dx,       k = 0, 1, 2
integral w * s_i' * Fourier_wave dx
integral w * (s_i')**2 * Fourier_wave dx
integral w * L * Fourier_wave dx
integral w * L**2 * Fourier_wave dx
integral w * L*s_i' * Fourier_wave dx
```

여기서 w는 물체 유전율 또는 단위 틈 유전율입니다. 조각 변화는 좌표를 정의하는 역수 재료 모멘트를
포함해, 접미 구간 위의 부호 있는 다항식 계수 도약으로 적분합니다. 같은 재료끼리의 이음매는 그 계수들을
하나도 바꾸지 않으므로, 동일성 판정 없이도 그 기여가 상쇄됩니다. 그 두 재료 값에 대한 독립적인 미분은
살아 있습니다. 균일하지 않은 프로파일 안의 분할을 포함해, 테스트한 중복 분할들은 직접 NumPy 배열에서
비트 단위로 동일하게 유지됩니다.

공유 띠 사영은 이제 미분 묶음과 들어올림 묶음을 받아들입니다. 기본 경로는 원래의 선형 좌표 모델을
대조군으로 보존합니다. 작은 요소에서의 안정성을 위해, 새 조립은 산술 묶음 순서가 동일한 기준선과의
차이를 더합니다. 따라서 분할되지 않은 요소의 보정은 정확히 0이 되어, 원래의 질량 행렬과 강성 행렬에서
불필요한 상쇄를 피합니다. 에너지 사영은 여전히 곱하기 전에 국소 퍼텐셜 차이를 사용합니다.

독립적인 48점 조각별 Gauss 적분이 들어올림 항을 포함한 모든 묶음을 절대 허용 오차 2e-12, 상대 허용
오차 1e-13으로 검사합니다.

## 닫힌 혼합 막대 검사

이 픽스처는 주기 700 nm, 외곽 폭 350 nm, 재료 값 4와 9,
내부 이음매 x=s를 가집니다. 주기 틈이 닫혀 있을 때 정확한 정적 법선 에너지와 이음매 미분은 다음과
같습니다

```
Uxx = 1 / (0.5 + (175+s)/700/4 + (175-s)/700/9)
dUxx/ds = -Uxx**2 * (1/4 - 1/9) / 700
```

이음매 0에서 예전 고정 P1 모델의 왼쪽/오른쪽 할선 기울기는
-0.001281263686과 -0.000253089616으로, 정확한 값 -0.000569451310과 비교됩니다.
조화 좌표 모델의 결과는 다음과 같습니다:

| 이음매, nm | 계산된 정적 에너지 | JIT 이음매 미분 | 정확한 미분 |
| ---: | ---: | ---: | ---: |
| 0 | 1.6941176470588233 | -0.0005694513099357396 | -0.0005694513099357390 |
| 31 | 1.6766467065868258 | -0.0005577667021246928 | -0.0005577667021246925 |

독립적인 해석적 테스트는 이음매 -31과, 두 재료 및 외곽 폭에 대한 미분도 다룹니다. 에너지에는 절대
허용 오차 2e-12, 미분에는 2e-11을 사용합니다. 예전의 엄격한 정적 이음매 실패 테스트는
두 모델에 대해 매개변수화되어 있습니다. 예전 모델에서는 여전히 예상된 실패이고, 새 모델에서는
허용 오차를 바꾸지 않고 통과합니다.

바깥 차수 3에서 이음매 0, 31과 재료 `[4,9,6.25]`를 가진 두 이음매 프로파일 `[-73,19]`에 대한 닫힌
구성 행렬은 푸리에 원점 위상을 고려했을 때 독립적인 직교 좌표 역규칙 행렬과 2e-10 이내로 일치합니다.
바깥 차수 2에서 닫힌 p/s 투과와 이음매/재료 미분은 상대 허용 오차 3e-6, 절대 허용 오차
2e-9로 독립적인 직교 좌표 할선 기울기 검사를 통과합니다. 직교 좌표 Li는 테스트 도구일 뿐이며, 새
모델은 이를 결코 호출하지 않습니다. 이 비교들은 명시된 각 바깥 차수에서 테스트한 닫힌 적층판(laminate)
거동을 확립할 뿐, 일반 광학 수렴을 확립하지는 않습니다.

## 남아 있는 양의 틈 메시 절점 민감도

양의 틈에서는 보조 필드가 x와 y로 변합니다. 국소 조화 좌표는 요소 안의 재료 불연속을 다루지만, 유한
정합 Galerkin 필드는 성긴 요소 경계를 가로지르는 플럭스 연속성을 약하게만 강제합니다. 그런 경계를
지나는 재료 이음매는 여전히 왼쪽과 오른쪽 광학 미분 사이의 작은 불일치를 드러낼 수 있습니다.

틈 17 nm, 이음매 0, 재료 4/9, 바깥 차수 2, s 편광,
`rows=4`, `edge_fraction=1e-4`, 이음매 간격 1e-4 nm에서:

| x 세분 수 | T | 왼쪽 이음매 할선 기울기, /nm | 오른쪽 이음매 할선 기울기, /nm | 절대 차이 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0.952153068848 | -0.001382052641 | -0.001383810998 | 1.75836e-6 |
| 2 | 0.951742849497 | -0.001388636899 | -0.001390193894 | 1.55700e-6 |
| 4 | 0.951611423083 | -0.001390800389 | -0.001391687297 | 8.86907e-7 |

x 세분 4에서 기본 물체 행을 4에서 8로 늘려도 차이는 약 8.86273e-7로 남습니다. 이음매 간격을 줄여도
기본 메시 불일치는 사라지지 않습니다. 세분화하면 줄어들지만, 테스트한 메시들은 1e-7 미분 연속성
관문을 충족하지 못합니다. 그 관문은 새로운 엄격한 예상된 실패이며, 별도의 통과 테스트가 측정한 세분화
추세를 기록합니다. 차수 3 CLI 로그도 독립적으로 같은 문제를 드러내며, 차이는 약 1.72e-6입니다.

양의 틈에서 단위 평균 필드, 무손실 전력 보존, 에르미트성, 작은 실제 셀 잔차는 모두 통과합니다. 그중
어느 것도 남은 형상 미분을 보증하거나 수렴한 광학 값을 확립하지 않습니다. 특히 메시 절점에서의 JAX
미분은 서로 다른 한쪽 할선 기울기 사이에 놓입니다. 그 미분이 존재한다고 해서 그 유한 모델이 그 점에서
미분 가능해지는 것은 아닙니다. 이후의
[적분형 플럭스 기저](nvf-continuous-flux.md)는 앞선 관문을 유지하면서 순방향 모델에서 이 테스트한
불일치를 해결합니다.

## 재현과 검증

NumPy, SciPy, JAX가 설치된 상태에서 저장소 루트에서 실행합니다:

```bash
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m studies.rcwa.nvf_harmonic_coordinates.nvf_harmonic_coordinates
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m studies.rcwa.nvf_harmonic_coordinates.nvf_harmonic_coordinates --static
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m studies.rcwa.nvf_harmonic_coordinates.nvf_harmonic_coordinates --order 2 --gaps 17 --seams 0 --subdivisions 4
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest -q tests/rcwa/test_nvf_harmonic_coordinates.py tests/rcwa/test_nvf_partitioned_gap_energy.py tests/rcwa/test_nvf_thin_gap_energy.py tests/rcwa/test_nvf_cell_bounds.py tests/rcwa/test_nvf_cell_corrector.py tests/rcwa/test_nvf_harmonic_energy.py tests/rcwa/test_nvf_harmonic_energy_jax.py tests/rcwa/test_resonant_nvf_probe.py tests/rcwa/test_contact_jones_probe.py::test_equal_material_split_is_equivalent_to_one_rectangle
```

`HarmonicCoordinateGapModel`은 앞선 모델의 스칼라 프로파일,
평행 이동한 형상 목록 API, 정의역 보호 검사를 물려받습니다. CLI는 JAX x64를 켜고
NumPy/JAX 값, 이음매 할선 기울기, 살아 있는 틈/이음매/재료 미분을 기록합니다.
기본 광학 실행과 정적 실행은
`studies/rcwa/nvf_harmonic_coordinates/records/nvf_harmonic_coordinates.log`에 기록되어 있습니다.

2026-09-08의 초기 검증: 위의 전체 선택에서 **94 passed, 5 skipped, 5 xfailed**,
새 전용 테스트 모듈에서 **11 passed, 1 xfailed**. 건너뛴 항목은
선택적인 NGSolve 대조군입니다. 엄격한 예상된 실패 다섯 개는 제품의 분할/병합 의존성, 예전의
유한 푸리에 s 접촉 미분, 별도의 정규화된 고유 그래디언트 편향, 예전 고정 P1 정적 이음매 오차,
새로운 양의 틈 이음매 불일치입니다. 기존 허용 오차는 하나도 완화하지 않았습니다.
