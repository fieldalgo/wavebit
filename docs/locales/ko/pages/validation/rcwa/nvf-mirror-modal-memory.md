# 거울 모드 전파의 임시 저장 공간 상한

이 NumPy 연구 변경은 같은 유한 NVF 에너지 닫힘, 푸리에 차수, 모드 근과 두 계면 정합 방정식을 그대로
유지합니다. 조밀한 임시 행렬을 없애 바깥 세분화(outer refinement) 용량을 늘립니다. 어떤 모드도, 작지만 0이
아닌 어떤 전파 인자도 버리지 않으며, 물리적 수용 문턱값은 하나도 바뀌지 않습니다.

## Maxwell 조립

`sector_operator`는 최종 Fortran 순서 LR 행렬을 사분면 단위로 채웁니다. 조밀한 `np.block` 조립과 그 뒤에
따르는 Fortran 복사는 필요 없습니다. 희소한 ky 교환은 조밀한 기하 행렬이 아니라 인덱스로 지정한 항목만
기여합니다. 이 변경 전에 쓰던, 상쇄(cancellation)가 없는 LR 식은 그대로 유지합니다.

`sector_magnetic_modes`는 R W의 구성 부분을 자기 성분 순열과 부호까지 포함해 최종 출력에 직접 계산합니다.
대각 항과 희소 ky 항은 모드 열 128개 단위의 패널로 더합니다. 조밀한 R 인자는 한 번도 할당하지 않습니다.
원래 모드 비율로 나누는 연산은 제자리에서 합니다. 고유값 풀이는 여전히 유지한 모든 모드를 찾으며, 그
세제곱 비용은 바뀌지 않습니다.

## 계면 정합

W와 V가 전기 모드와 자기 모드를 담고, D가 대각 감쇠 행렬, Yt/Yb가 외부 어드미턴스라고 합시다. 아래쪽
풀이는 그대로

```
O = (V + Yb W)^-1 V D
Rround = D (2 O - D)
```

입니다. 아래쪽 풀이의 두 피연산자는 모두 최종 Fortran 저장 형식으로 만듭니다. 희소한 외부 곱은 128열
패널을 씁니다. 입구 방정식계는

```
Afront = Yt^-1 V (I - Rround) + W (I + Rround)
Afront f = 2 Ein
```

입니다. Rround를 저장하는 대신 자기 행 패널이 `V (I + D^2) - 2 (V D) O`를 만듭니다. 희소한 Yt 역행렬은
열 패널 단위로 적용합니다. 그다음 전기 행 패널이 `W (I - D^2) + 2 (W D) O`를 Afront에 직접 더합니다.
이렇게 하면 저장해 두던 왕복 행렬과 별도의 Efront 행렬이 없어집니다. 최종 필드에는 벡터만 필요합니다.

```
b = O f
Etransmitted = 2 W b
Ereflected = W [f + D (2 b - D f)] - Ein
```

W, V, O의 모든 열이 참여합니다. 특히 이 항등식들은 약하게 투과하는 소멸 모드나 그 계면 결합을 근사하지
않습니다. 큰 차수에서의 비용은 여전히 조밀한 고유값 풀이와 LU 풀이가 제한합니다.

## 검증

새 테스트 파일은 두 패리티 섹터 모두에 대해 직접 LR 저장과 R W 작용을 명시적 Maxwell 인자와 비교합니다.
빈 성분 공간, 서로 다른 x/y 차수, 에르미트가 아닌 복소 테스트 행렬, 패널 크기를 넘는 차원을 포함합니다.
입력 배열은 보존되어야 합니다.

별도의 검사는 두 계면에서 결합된 순방향/역방향 방정식을 2H×2H 방정식계로 풉니다. 패턴이 있는 층의 두께
0, 300, 2400 nm에서 두 편광 모두 패널 정합과 일치합니다. 전파하는 모든 모드의 라벨을 뒤집어도 유한 층의
전력은 보존됩니다.

처음 제안한 V W^-1 벤치마크는 적합하지 않았습니다. 고유값 풀이의 아주 작은 반올림 오차가 거의 허수인 모드
근의 선택된 부호를 뒤집을 수 있기 때문입니다. 그러면 슬랩 전체의 산란이 바뀌지 않아도 V W^-1은 바뀝니다.
구현은 기존 근 선택을 유지하며, 최종 T/R과 직접 Maxwell 방정식을 수용 통제로 씁니다. 기각한 진단은
`studies/rcwa/nvf_mirror_modal_memory/records/nvf_mirror_modes_memory.log`에 기록했습니다.

이것은 여전히 손실 없는, y 거울 대칭 직사각형 연구 경로입니다. 일반 기하, 제품 통합, 광학 오차 상한이나
스치듯 입사에 가까운 군집 처리는 구현하지 않습니다.

## 측정한 전파 메모리

새 프로세스들은 저장해 둔 같은 cap-96 국소 기저 계수, 바깥 차수 32, p 편광을 썼습니다. 각 측정은 닫힘,
모든 모드 풀이, 두 계면과 최종 전력을 포함합니다.

| 구현 | 최대 프로세스 RSS | 경과 시간 | p T |
| --- | ---: | ---: | ---: |
| 이전의 조밀한 모드/중간 블록 | 2,122,334,208 bytes | 89.456 s | 0.9066971830116604 |
| 직접 모드 저장과 계면 패널 | 1,429,438,464 bytes | 65.169 s | 0.9066971830119874 |

최대 프로세스 RSS는 32.65% 줄어듭니다. T 차이는 3.27e-13, R 차이는 5.58e-14입니다. 두 구현 모두 원래의
1e-9 전력 균형 관문을 유지하며, 패널 결과의 잔차는 2.50e-13입니다. 이 측정은 앞선 닫힘 전용 메모리 표와
달리, 지정한 단일 섹터 계산 전체에 대한 것입니다. 더 큰 모든 차수의 최대값을 예측하지는 않습니다.

시간은 방법마다 한 번 관측한 값이며, 측정마다 1초 미만의 작은 테스트들이 함께 돌았습니다. NumPy/SciPy는
Apple Accelerate를 씁니다. OPENBLAS_NUM_THREADS와 OMP_NUM_THREADS를 설정해도 실제 스레드 수가 정해지지는
않습니다. 이것은 통제된 처리량 주장이나 보편적인 속도 주장이 아닙니다.
원시 기록: `studies/rcwa/nvf_mirror_modal_memory/records/nvf_mirror_propagation_memory.log`.

## 선택적 방향 검사

`mirror_powers(..., polarizations=('p',))`와 CLI `--polarizations p`로 비용이 큰 섹터 하나만 명시적으로
요청할 수 있습니다. 기본값은 여전히 두 섹터 모두입니다. 결과에는 계산하지 않은 편광 키가 빠지며, 계산한
모든 섹터는 여전히 바뀌지 않은 전력 균형 보호 검사를 통과해야 합니다. 비어 있거나, 반복되거나, 잘못된
선택은 거부합니다. 단일 편광 출력을 p/s를 합친 수렴 검사처럼 제시해서는 안 됩니다.

모드, 계면, 섹터 선택 변경 뒤의 최종 관련 검증: **76 passed in 82.41 s**. 다섯 파일은
`test_nvf_energy_closure.py`, `test_nvf_mirror_convergence.py`,
`test_nvf_mirror_cartesian.py`, `test_nvf_mirror_doubling.py`,
`test_nvf_mirror_modes.py`이며, 마지막 파일이 테스트 17개를 기여합니다.
이 묶음에는 기존의 독립적인 전체 푸리에, 카르테시안 구간, Airy, 접촉, JAX/배가 검사가 포함됩니다. 로그:
`studies/rcwa/nvf_mirror_modal_memory/records/nvf_mirror_modes_validation.log`.

변경 전의 정확한 모드/정합 비교 스크립트는 `nvf_mirror_modal_memory` 연구의 기록에
`nvf_mirror_propagation_check.py.txt`로 남겨 두었으며, 지금은 저장소 밖에 보관되어 있습니다. `.py` 파일로
복사하면, 지정한 cap-96 투영을 생성한 뒤 인자 `original 32 p` 또는 `panels 32 p`로 실행됩니다. 벤치마크
런타임과 소스 해시는 그 로그 옆의 매니페스트(`nvf_modal_memory_manifest.json`, 결과 디렉터리가 커밋하지 않는
기계 판독용 파일)에 기록했습니다. 이 매니페스트는 커밋된 릴리스를 뜻하지 않고, 커밋되지 않은 변경이 있는
작업 트리(dirty worktree)의 구현을 기록합니다.
