# 카르테시안 쌍의 유한한 오른쪽 열림 극한

작성: 2026-09-10

대상:
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair_opening.py`
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair.py`
- `tests/rcwa/test_nvf_cartesian_pair_opening.py`
- `studies/rcwa/nvf_cartesian_pair/records/nvf_cartesian_pair_opening.log`

별도의 실험적 `CartesianPairOpeningCell`은 물리적 틈이 열릴 때 유한한 두 직사각형 셀의 접촉 값과 해석적인
오른쪽 미분을 계산합니다. NumPy 구현은 세분화 0과 1에서 허용된 순환 차트를 지원합니다. 독립적인 원래 노드
방정식과 움직이는 삼각형 적분이 아홉 개의 계수 필드와 선택한 에너지 닫힘을 모두 검증합니다. 이것으로
확립되는 것은 한정된 유한 응답이며, 연속체나 광학적 정확도가 아닙니다. 일반 `CartesianRectanglePairNVF`의
접촉 재생과 접촉을 보존하는 JAX 접선은 기존 계약을 그대로 유지합니다. 명시적 인터페이스는
[설명서](../../guide/rcwa/cartesian-pair-opening.md)에 있습니다.
2026-09-13부터 쌍 계획은 세분화 2와 3도 허용합니다. 아래 측정은 0과 1에서 한 것이며, 더 세밀한 공간은
[세분화 기록](nvf-pair-refinement.md)에서 검사합니다.

## 물리적 틈과 정확한 붕괴

수평으로 놓인 두 직사각형은 고정된 폭, 하나의 공유 높이, 재료, 기저, 셀 전체 오프셋을 유지합니다. 틈 g를
늘리면 왼쪽 직사각형은 `(-g/2, 0)`만큼, 오른쪽 직사각형은 `(g/2, 0)`만큼 움직입니다. g = 0에서 전체 높이에
걸친 공통 변은 정확합니다. 바깥 경계는 고정되어 있습니다. 어떤 카르테시안 변도 전단되지 않으며 격자 축소도
하지 않습니다.

기존 [쌍 삼각분할](nvf-cartesian-pair.md)은 바뀌지 않는 위상 구조만 제공합니다. 분모가 `2**refinement`인
정수 보간 분자가 붕괴하는 노드를 정확하게 식별합니다. 살아남는, 방향과 재료 태그를 가진 삼각형은 접촉
메시와 같아야 합니다. 얇은 삼각형은 작은 면적 허용 오차가 아니라 이 노드 동일성으로 식별합니다. 접촉 재생은
여전히 엄격한 포함 관계와 유한하고 양의 면적을 가진 정규 삼각형을 요구하며, 각 얇은 삼각형은 양의 오른쪽
열림 면적 기울기를 가져야 합니다.

| 세분화 | 열린 자유 퍼텐셜 | 접촉 자유 퍼텐셜 | 붕괴하는 차이 | 얇은 삼각형 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 8 | 6 | 2 | 4 |
| 1 | 35 | 27 | 8 | 16 |

고정된 게이지는 보존됩니다. C는 접촉 퍼텐셜을 붕괴 그룹의 모든 구성원에 주입하고, Z는 나머지 차이를
생성합니다. 각 얇은 삼각형은 반복된 접촉 끝점의 원래 퍼텐셜 두 개를 연결합니다. 이 정확한 그래프는 모든
붕괴 그룹을 연결하되 그 밖의 것은 연결하지 않으므로, 기하에 의존하는 수치적 계수(rank) 절단 없이 극점 핵과
차이의 계수를 줍니다.

## 극한 이전의 약형 연산자

삼각형 하나에 대해, 틈에 대해 아핀인 Jacobian을 J(g), 부호 있는 행렬식을 d(g), 기준 노드 그래디언트를 R로
씁니다. `N = R adj(J)`로 두면 국소 강성과 소스는 다음과 같습니다.

```text
K(g) = epsilon/(2*d(g)) * N(g) N(g)^T
F(g) = -epsilon/2 * N(g)
```

수평 꼭짓점 속도만 나타나므로 d와 N은 모두 g에 대해 아핀입니다. 정규 삼각형은 양의 d(0)를 가지며, 얇은
삼각형은 d(0) = 0이고 d'(0) > 0입니다. 이 원래 식들을 전개하면 다음을 얻습니다.

```text
K(g) = K_minus1/g + K0 + g*K1 + O(g^2)
F(g) = F0 + g*F1
```

스칼라 복소 재료 약형 행렬은 대칭이지만 일반적으로 에르미트는 아닙니다. 얇은 삼각형에서 국소
`N(0).T @ C`는 구조적으로 0이 됩니다. 구현은 그 항등식을 검사하고 합산 전에 국소 항을 투영하여, 조립된 극점
성분의 상쇄를 피합니다. 또한 원래의 완전한 Laurent 연산자와 잔차를 유지합니다.

A = CᵀK₀C, D = ZᵀK₋₁Z로 두면 필요한 유한 계수는 다음을 만족합니다.

```text
A u0 = C^T F0
D v0 = Z^T (F0 - K0 C u0)
A u1 = C^T (F1 - K1 C u0 - K0 Z v0)
```

따라서 열린 퍼텐셜은 `C u0 + g (C u1 + Z v0) + O(g²)`입니다. 추가 차이 계수 하나로 g 차수 잔차 전체를
검사합니다. 실수부가 양인 유전율은 강압적(coercive)인 접촉 블록과 차이 블록을 주며, 측정한 에르미트 부분의
최솟값과 조건수를 보고합니다. 투영한 접촉 계는 게이지 행을 포함하여 원래의 접촉 노드 조립과 독립적으로
비교합니다.

## 사라지는 면적도 미분에 기여합니다

정규 삼각형의 미분에는 필드, 면적, 푸리에 위상의 움직임이 들어 있습니다. 얇은 삼각형은 접촉 가중치가 0이지만
극한 필드는 유한합니다. 반복된 끝점 a와 다른 끝점 b에 대해, 정규화한 푸리에 가중치의 오른쪽 미분은
다음과 같습니다.

```text
W'(0) = d'(0)/det(A_cell) * exp(-i k·a) * phi2(-i k·(b-a))
phi2(z) = (exp(z)-1-z)/z^2,  phi2(0) = 1/2
```

가중된 변 위상이 중요합니다. 무게중심 위상이나 균일한 변 평균은 이 붕괴 삼각형 적분이 아닙니다. 바깥
부채꼴 삼각형을 포함한 모든 얇은 삼각형이 기여합니다. 에너지 미분은 `epsilon * B.conj().T @ B`의 두 켤레
필드 항을 모두 유지합니다. 정확히 요청한 푸리에 차이는 닫힘 역행렬 계산 전에 선택하며, 미분은 역행렬 곱의
법칙을 따릅니다. 저장 에너지, 부호 있는 소산, 역방정식 잔차는 계속 보호됩니다.

## 독립적인 적격성 검사

테스트 오라클은 이산 위상 구조만 공유합니다. 정확한 유리수 입력으로 물리 꼭짓점을 만들고, 원래의 3×3 노드
Vandermonde 행렬에서 Laurent 계수를 유도하며, 움직이는 기준 삼각형을 Duffy 구적법으로 적분합니다. 왼쪽과
오른쪽 닫힘 풀이 방정식은 따로 미분합니다. 양의 틈 표본은 이미 구성된 미분을 검사할 뿐, 외삽으로 미분을
정의하지 않습니다.

선언한 열 가지 사례는 주 기저 `[[700,315],[0,490]]`, 폭 `(140,193)`, 높이 210, 오프셋 `(49,-21)`을 두
세분화와 부호 있는 열 표현 네 가지 모두에서 사용합니다. 독립적인 두 번째 고정 사례는 기저
`[[640,-160],[70,560]]`, 폭 `(160,110)`, 높이 190, 오프셋 `(31,-19)`와 다른 손실 재료를 두 세분화에서
사용합니다. 둘 다 순환 차트 1을 허용합니다. 차수 `(1,2)`와 `(2,1)`은 정확한 기저 라벨 순열을 따릅니다.
추가 대조군은 `(0,0)`, `(1,0)`, `(0,1)`을 사용합니다.

미분은 호출자의 길이 단위당 값으로 반환합니다. 비교할 때에만 무차원 섭동 g/L에 해당하도록 L = √det(A)를
곱합니다. α = .01로 공통 스케일링하면 값은 바뀌지 않고 반환되는 미분은 1/α만큼 바뀝니다. 고정 구적/값
가드는 `3e-10`, 정규화 미분 가드는 `3e-9`이며, 원래 약형/역방정식 잔차는 `1e-10` 미만이어야 합니다.

| 고정한 열 가지 사례 측정 | 가장 큰 불일치 |
| --- | ---: |
| q16/q24 계수 값 | 9.240e-13 |
| q16/q24 정규화 미분 | 4.370e-12 |
| 독립 오라클 대비 계수 값 | 3.580e-15 |
| 오라클 대비 정규화 계수 미분 | 7.470e-15 |
| 오라클 대비 정규화 닫힘 미분 | 3.372e-14 |
| 원래의 완전한 Laurent 잔차 | 1.056e-14 |
| native 양의 틈 약형 잔차 | 1.075e-13 |
| 역방정식 잔차 | 8.069e-16 |

부호 있는 기저 비교 여섯 개, 공통 단위 대조군 네 개, 0차 집합 세 개, 유효하지 않은/불변 대조군 14개가 모두
통과합니다. 측정한 최소 저장 에너지와 부호 있는 소산은 1.00298과 .0800624입니다. 이는 시험한 유한 사례의
성질이며 일반적인 대비 정리가 아닙니다. 네 점짜리 양의 틈 사다리도 모든 성분과 닫힘 슬롯에 대해 미리 선언한
나머지 검사를 통과하지만, 수렴 차수나 오차 상한을 주장하지는 않습니다.

고정한 NumPy 감사는 16 GiB Apple M4 호스트, Python 3.12.9, NumPy 2.5.1, BLAS 스레드 하나에서 1.08183 s
걸렸습니다. 저장소로 승격하면서 클래스 이름 변경, 상대 import, 모듈 문구, 서식을 바꾼 뒤에도 추상 구문은
보존됩니다. 전용 저장소 테스트 모음은 37개 테스트를 1.25 s에 통과합니다.
소스를 고정한 측정은
[결과 로그](https://github.com/fieldalgo/wavebit/blob/main/studies/rcwa/nvf_cartesian_pair/records/nvf_cartesian_pair_opening.log)에
보관되어 있으며, 독립 테스트를 실행하는 데 비공개 원시 배열은 필요하지 않습니다.

이 유한 응답은 임의의 방향, 서로 다른 높이, 수직 이동, 겹치는 쌍, 이득 재료나 텐서 재료를 허용하지 않습니다.
허용된 모든 대비나 기하에 대한 정확도를 증명하지 않고, 광학적 종료 규칙을 확립하지 않으며, 고정 접촉 JAX
접선을 영역을 가로지르는 형상 미분으로 바꾸지도 않습니다.

별도의 [정확한 유한 틈 계열](nvf-cartesian-pair-gap.md)은 해석적으로 다시 스케일한 좌표를 써서 허용된 양의
틈까지 평가를 확장합니다. 이 끝점 구현은 바뀌지 않고 남아, 독립적으로 적격성이 확인된 기준을 제공합니다.
