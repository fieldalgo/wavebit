# 사각이 아닌 보조 셀 안의 두 물리 직사각형

작성: 2026-09-10

대상:
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair.py`
- `studies/rcwa/nvf_cartesian_pair/nvf_cartesian_pair.py`
- `tests/rcwa/test_nvf_cartesian_pair.py`
- `tests/rcwa/test_nvf_cartesian_rectangle_pair_api.py`
- `studies/rcwa/nvf_cartesian_pair/records/nvf_cartesian_pair.log`

실험적 `CartesianPairCell`은 사각이 아닌 주기 셀 안에 수평으로 놓인 높이가 같은 물리 직사각형 두 개에 대해
유한 P1 필드, 에너지, 재료 계수를 제공합니다. 양의 틈과, 전체 높이에 걸친 정확한 공유 변은 각각 고정된
conforming 메시를 가집니다. 독립적인 약형 방정식, 삼각형 적분, NumPy/JAX 미분이 이 유한 모델들을 검증합니다.
틈이 열리는 경우는 별도의
[NumPy 유한 오른쪽 열림 응답](nvf-cartesian-pair-opening.md)이 다루며, 이 셀의 고정 접촉 JAX 접선을 바꾸지
않습니다. 더 일반적인 쌍과 광학적 수렴은 여전히 검증되지 않았습니다. 명시적 실험 기능인
[`CartesianRectanglePairNVF`](../../guide/rcwa/cartesian-rectangle-pair-nvf.md)가 일반 직사각형 사전과 필수
계획을 통해 이 제한된 모델을 노출합니다.
다른 공개 기하 어댑터는 현재 범위를 유지합니다.

## 물리 기하와 고정된 차트

A의 열은 물리 격자 벡터입니다. 서로 독립인 양의 폭을 가진 두 직사각형은 하나의 양의 높이를 공유하며, 음이
아닌 틈을 두고 왼쪽에서 오른쪽으로 놓입니다. 두 직사각형의 경계 직사각형은
`A @ (.5, .5) + offset`을 중심으로 합니다. 오프셋은 적분 셀 전체를 평행 이동하여, 유한 모델의 평행 이동
공변성을 보존합니다. A를 바꾸면 카르테시안 직사각형 변을 전단하지 않고 중심과 주기 경계가 움직입니다.

`CartesianPairPlan.from_geometry`는 바깥 평행사변형과 경계 직사각형 사이의 네 가지 순환 대응 중 하나를
고릅니다. 양의 폭을 가진 각 안쪽 띠는 삼각형 두 개를 가집니다. 인접한 바깥 삼각형 위의 부채꼴(fan)이 모든
재료 끝점을 포함하므로, 계면에 매달린 노드(hanging node)가 없습니다. 세분화는 공유하는 변 중점을 써서 각
삼각형을 넷으로 나눕니다. 정확한 2진 가중치가 실제 기하와 무관하게 주기 노드 동일성을 정합니다.

| 상태 | 세분화 | 삼각형 | 꼭짓점 | 자유 퍼텐셜 미지수 | 축당 주기 점 쌍 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 전체 높이 접촉 | 0 | 14 | 10 | 6 | 2 |
| 전체 높이 접촉 | 1 | 56 | 33 | 27 | 3 |
| 양의 틈 | 0 | 18 | 12 | 8 | 2 |
| 양의 틈 | 1 | 72 | 41 | 35 | 3 |

불변 계획은 접촉 상태, 순환 선택, 세분화만 저장합니다. 계획 수립에는 구체적인 기하가 필요하며, JIT 안에서는
거부합니다. 재실행은 선택한 위상 구조를 고정합니다. 기하는 실수이고 유한해야 하며, 격자 행렬식이 양의 유한값이고,
분수 여유 `1e-10`으로 엄격하게 포함되어야 하며, 삼각형 넓이가 양의 유한값이어야 합니다. 복소 기하는 실수 값으로
변환하기 전에 거부합니다. 포함 검사가 삼각형 보호 검사를 대신하지는 않습니다.

제한된 영역은 서로 다른 높이, 수직 오프셋, 변 일부나 모서리에서의 접촉, 겹치는 직사각형, 임의의 회전, 주기
바깥 경계와의 접촉을 제외합니다. 예비 기하 스캔은 지정한 기울기/종횡비/틈 경우 135개를 받아들였으며, 그중
45개가 접촉입니다. 이것은 일반적인 적용 범위 결과가 아닙니다. 순환 선택 두 가지를 강제하면 포함 조건을 만족하는
주 고정 예제에서도 실패하므로, 명시적인 양의 차트가 필요함을 보여 줍니다.

## 유한 계수와 닫힘

거시적 카르테시안 방향마다, 주기 P1 퍼텐셜은 물리 유전율 가중치를 가진 원래 약형 방정식을 풉니다. 퍼텐셜 값
하나가 상수 게이지를 고정합니다. 대각 균형화는 선형 풀이의 좌표를 바꾸며, 잔차는 원래의 전체 약형 방정식에서
계산하고 `1e-10`을 넘어서는 안 됩니다.

물리 필드는 B = I + grad(u)와 G = epsilon BᴴB입니다. 정확한 다각형 변환이 조각별 상수인 아홉 필드를 기존 순서
`Bxx, Bxy, Byx, Byy, Gxx, Gxy, Gyy, epsilon, Gyx`로 투영합니다. 푸리에 위상은 물리 역격자 벡터와 원래 셀
원점을 씁니다. 호출자는 스칼라 푸리에 반폭이나 `(x, y)` 쌍을 제공하며, 요청한 정확한 차이는 에너지 닫힘의
역행렬 계산 전에 선택합니다. 격자 축소나 추가 재료, 위상, 회전 인자는 도입하지 않습니다.

`CartesianPairCell(plan, order=1)`은 `coefficients`와 `conv_matrices`를 노출합니다.
둘 다 배열과 함께 유한 셀 메타데이터를 반환합니다. 기하 길이는 호출자의 물리 단위를 공유합니다.
`epsilon`은 두 포함물의 물리 스칼라 유전율을 담고, `background`는 물리 스칼라이며, 각각 유한하고 실수부가
양수, 허수부가 음이 아니어야 합니다. NumPy와 JAX는 x64를 요구합니다. 잘못된 즉시 실행(eager) 입력은 오류를
일으키고, 잘못된 추적(traced) 갱신은 모든 계수나 슬롯을 오염시킵니다. 닫힘에는 양의 저장, `-1e-9`보다 큰
소산 고유값, `1e-9`보다 작은 무손실 에르미트 불일치가 필요하며, 부호 있는 결과를 잘라내지(clamp) 않습니다.
이 검사들은 유한 닫힘을 거부할 수 있지만, 임의 대비에서의 신뢰성을 확립하지는 않습니다.

## 독립 검증

주 고정 예제는 나노미터를 씁니다. A = 700 [[1, .45], [0, .7]], 폭 (140, 193), 높이 210, 오프셋 (49, -21),
틈 17 또는 0입니다. 유전율은 (4 + .8i, 9 + .3i)이고 배경은 1 + .1i입니다. 세분화 0과 1로 작은 셀 네 개가
나옵니다. 별도의 제어는 다른 순환 차트를 고르는 기울기 -1.1과, 0이 아니고 서로 다른 푸리에 차수 `(1, 2)`와
`(2, 1)`을 씁니다.

오라클은 선언한 기하만 공유합니다. 움직이는 꼭짓점을 따로 구성하고, 원래 노드 K와 F를 누적하며,
K du = dF - dK u를 미분합니다. 움직이는 삼각형 Duffy 구적법은 물리 그래디언트, 넓이, 역격자 벡터, 푸리에
위상, 재료 가중치의 미분을 포함합니다. 제품 조립, 균형화, 다각형 변환, 닫힘을 호출하지 않습니다. 닫힘 미분은
명시적 역행렬을 독립적으로 미분합니다.

떨어진 쌍에서는 무차원 좌표 16개가 모두 살아 있습니다. 격자 항목 네 개, 폭 두 개, 높이, 틈, 오프셋 항목 두 개,
재료의 실수부/허수부 항목 여섯 개입니다. 접촉 제어는 `dgap = 0`을 유지하므로 좌표 15개가 남습니다.
혼합 방향, 셀 전체 평행 이동 방향, 공통 스케일 방향을 더하면 여섯 경우의 합계는 111이 됩니다. 계수 JVP와
닫힘 JVP 모두 무차원 방향마다 같은 `3e-9` 절대 보호 한계를 씁니다. 값 보호 한계와 기준 구적 보호 한계는
`3e-10`입니다. 원래의 네 경우는 간격 `2e-4`와 `1e-4`에서의 5점 유한 차분 제어 74개도 유지합니다.

| 예비 유한 제어 | 측정한 최대 불일치 | 보호 한계 |
| --- | ---: | ---: |
| 주 셀 네 개, q16/q24 값 또는 미분 | 2.603e-14 | 3e-10 |
| 주 계수 대 독립 노드/Duffy 값 | 2.887e-15 | 3e-10 |
| 주 해석적 미분 대 5점 간격 2e-4 | 1.677e-10 | 3e-9 |
| 주 해석적 미분 대 5점 간격 1e-4 | 2.174e-11 | 3e-9 |
| 다른 차트, 틈/세분화 1/차수 (1, 2), q16/q24 | 4.146e-14 | 3e-10 |
| 다른 차트, 접촉/세분화 0/차수 (2, 1), q24/q32 | 8.755e-14 | 3e-10 |

마지막 경우는 처음에 **q16/q24에서 실패했습니다**. 푸리에 라벨 (m, n) = (4, 2)에서 재료 계수의 높이 미분이
`3.2018768211880356e-10`만큼 달라 `3e-10`을 넘었습니다. 원래의 실패와 원시 배열 해시는 결과 기록에 남아
있습니다. 기준 구적만 q24/q32로 올리자, 같은 접촉 메시, 재료, 푸리에 집합에서 불일치가
`8.754374308731933e-14`로 줄었습니다. 반복한 q24 배열은 정확히 동일합니다.
이로써 그 유한 경우의 기준 적분 문제가 해결됩니다. 이것은 q16 통과도, 유한 공간 세분화도, 완화한 허용 오차도
아닙니다.

0 차수/서로 다른 차수의 손실, 무손실, 균질 닫힘 제어 48개가 슬롯 차원, 물리 재료 계수, 균질한 경우의 B = I,
등방 슬롯, 저장, 소산을 검증합니다. 패턴이 있는 무손실 소산은 반올림 오차로 `-4.737e-16`까지만 내려가며,
에르미트 불일치는 `4.653e-16`보다 작습니다.
테스트는 독립 기준값을 소스에서 다시 계산하므로 비공개 결과 배열이 필요 없습니다. 선택 사항인 백엔드를 쓸 수
없으면 JAX 테스트는 건너뜁니다.

통합 테스트 묶음은 16 GiB의 Apple M4 호스트, NumPy 2.5.1, JAX 0.11.0에서 12.47 s 동안 테스트 25개를
통과했습니다. JAX 임포트를 막은 별도의 새 프로세스는 설치를 바꾸지 않은 채 5.25 s 동안 테스트 17개를 통과하고
JAX 테스트 8개를 건너뛰었습니다. 전체 묶음의 표본 최대 RSS는 662,110,208 바이트였고, 자식 프로세스 자원 최고
수위는 665,124,864 바이트였습니다.
두 실행 동안 소스와 테스트 해시는 바뀌지 않았습니다. 이 운영 측정은 이 작은 제어들을 설명할 뿐, 실용적인 광학
풀이의 비용이나 정확도를 설명하지 않습니다.

## 공개 물리 입력 검증

패키지된 커널은 이전의 모든 셀 보조 함수, 계획기, 수치 방법의 추상 구문을 정확히 보존합니다. 바뀌는 것은 모듈
문구, 내보내기, 상대 임포트뿐입니다. 연구 모듈은 그 구현을 다시 내보내며, 25개 테스트의 소스는 바뀌지
않았습니다. 공개 빌더는 구조적 허용 검사를 추가하고, 물리 폭과 중심을 기존 유한 셀에 직접 대응시킵니다.
배경 정규화, 격자 축소, 추가 푸리에 위상이나 회전은 하지 않습니다. 계획 수립은 구체적인 중심을 한 번 정렬하며,
재실행 동안 원래 입력 인덱스와 재료 동일성을 보존합니다.

공개 테스트는 두 입력 순서, 일반적인 `l`/`lx`/`ly` 우선순위, Material 래퍼, 균일/패턴 적층, 평행 이동, 공통
스케일, 0/서로 다른 푸리에 차수, 엄격한 제약, 잘못된 추적 입력을 다룹니다.
원래의 노드/Duffy 오라클은 같은 여섯 유한 경우에 걸친 공개 native 매개변수 방향 111개에 대해 명시적 닫힘 변분을
독립적으로 제공합니다. native 좌표는 물리 격자 항목, 폭 두 개, 공유 높이 하나, 수평 중심 두 개, 공유 수직 중심
하나, 재료 성분 여섯 개입니다. 그 접선은 원래의 무차원 계열로부터 해석적으로 대응시킵니다. 접촉 방향은 공유
변을 보존하며, 높이 하나만, y 하나만 바꾸거나 틈을 여는 임의의 접선은 그 계열 밖입니다.
경우별 이전 구적 선택과 `3e-10` 값/기준 보호 한계, `3e-9` 미분 보호 한계는 바뀌지 않습니다.

API 고정 예제는 물리 십진 치수와 중심을 직접 지정합니다.
처음 테스트는 대신 무차원 부동소수점 값으로 접촉 중심을 만들었고, 아주 작은 음의 틈이 생겨 허용 검사가 이를
올바르게 거부했습니다. 계산된 접촉 틈은 `-2.842170943040401e-14` nm였습니다. 그 실패한 고정 예제 기록은
보존되어 있습니다. 최종 물리 평가점(primal)은 명시적으로 지정하며, 어댑터는 스냅을 하지 않고, 표현 가능한 0이
아닌 접촉 열림을 따로 거부합니다. 이 테스트 고정 예제 수정은 유한 모델도, 어떤 허용 오차도 바꾸지 않습니다.
대응시킨 native 기하는 표현 반올림 오차 때문에 무차원 오라클 좌표와 최대 `1.137e-13` nm만큼 다르며, 값 비교와
미분 비교는 명시적으로 기록한 그 평가점에서 원래 보호 한계를 통과합니다.

기존 제어 25개와 새 제어 29개가 함께 통과했습니다: **테스트 54개, 15.89 s**.
JAX 임포트를 막은 새 프로세스는 5.54 s 동안 38개를 통과하고 16개를 건너뛰었습니다.
패키지 전용 수치 스모크 테스트는 연구 모듈이나 JAX 모듈을 임포트하지 않습니다. 결합 실행의 표본 RSS는
759,201,792 바이트였고, 별도의 자원 최고 수위는 759,513,088 바이트였으며, 소스 해시는 고정되어 있었습니다.
`(0, 0)`, `(1, 0)`, `(0, 1)`에서의 작은 `solve_conv` 제어 세 개는 독립적인 균일 Airy 전력과 일치하며, 패턴이
있는 무손실 슬롯 배치/에너지를 검사합니다. 패턴 에너지 검사와 수동 예제는 통합 제어이지, 독립적인 광학 기준이
아닙니다.
기존의 단일 셀, 단일 직사각형, ConformingNVF, AffineProfileNVF 제어 156개도 56.83 s 동안 통과합니다. 안내서의
예제를 그대로 실행하면 연구 모듈이나 JAX 모듈을 임포트하지 않으며, 유한 p/s 투과는
0.9901311633000325와 0.9366247460109753입니다. 이 값들은 실행을 기록할 뿐, 광학적 수렴을 기록하지 않습니다.

## 접촉과 정확도의 한계

정확한 접촉 차트는 두 계면 끝점을 합치고 폭이 0인 삼각형을 없앱니다. 틈을 열면 자유도와 퇴화하는 삼각형이
추가됩니다. 접촉 차트의 일반적인 미분으로는 그 응답을 복원할 수 없으며, 극한 약형 정식화가 여전히 필요합니다.
따라서 접촉에서 열림으로, 열림에서 접촉으로의 재실행은 오류를 일으키거나 추적된 NaN을 만듭니다. 차트 안에서의
접촉 폭, 높이, 재료, 격자, 오프셋은 여전히 미분 가능합니다.

같은 재료의 접촉은 더 큰 직사각형 하나와 같은 해석적 재료 변환을 가집니다. 그 유한 B/G가
[단일 직사각형 셀](nvf-cartesian-cell.md)과 같을 필요는 없습니다. 쌍 메시는 다른 퍼텐셜 공간을 담기 때문입니다.
그 유한 공간들 사이의 동등성은 강제하지 않습니다. 이 테스트들은 명시한 유한 방정식과 미분을 검증할 뿐, 연속체
오차 상한, 패턴이 있는 광학 검증, 기존 광학 수렴 기준의 변경을 제공하지 않습니다.
