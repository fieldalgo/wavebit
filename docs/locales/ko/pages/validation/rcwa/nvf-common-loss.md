# 공통 수동 손실비를 가진 conforming NVF

작성: 2026-09-09

대상:
- `src/wavebit/rcwa/_engine/conforming/__init__.py`
- `src/wavebit/rcwa/_engine/conforming/partitioned_gap.py`
- `tests/rcwa/test_conforming_common_loss.py`
- `tests/rcwa/test_conforming_nvf.py`

이 페이지에서 측정한 구현은 리비전 `6b0a60b`(`a85ae18` 로 반영)의 공통 인자 확장입니다. 이후의
[복소 재료 확장](nvf-complex-material.md)은 공통 손실비 제한을 없앱니다. 아래 유도는 그 일반 구성에 대한
정확한 대조군으로 남아 있습니다.

그 리비전에서 `ConformingNVF` 는 패턴이 있는 층의 모든 재료가 같은
`eta = Im(epsilon)/Re(epsilon)` 을 공유할 때, 실수부가 양수인 수동 복소 유전율을 받아들입니다. 여기에는
직사각형 바깥과 직사각형 사이의 배경이 모두 포함됩니다. 층마다 다른 비율을 쓸 수 있습니다. 균일한 층은 실수부가
양수인 수동 유전율을 서로 독립적으로 가질 수 있습니다. [설명서](../../guide/rcwa/conforming-nvf.md)에 현재 입력
계약과, 포함체 손실을 독립적으로 바꾸는 JAX 예제가 있습니다.

## 셀 방정식과 에너지 닫힘의 인수분해

패턴이 있는 한 층 전체의 재료를 다음과 같이 씁니다.

```text
epsilon(x) = alpha * epsilon_storage(x)
alpha = 1 + i*eta, eta >= 0
epsilon_storage(x) = Re(epsilon(x)) > 0
```

alpha는 0이 아닌 상수이므로, 법선 변위의 연속 조건을 포함하여 `div(epsilon grad(phi))=0` 에서 소거됩니다.
따라서 보정자(corrector)는 기존의 실수 저장 재료 보정자와 같습니다. 같은 종횡비 계량, 틈 보강, 재료 경사,
평행 이동과 층 축 사상이 그대로 적용됩니다. 이 경우를 위해 복소 기저나 다른 인수분해로 바꾸지 않습니다.

투영된 필드 Q, 에너지 G, 종방향 재료 Z에 대해 다음이 성립합니다.

```text
Q = Q_storage
G = alpha * G_storage
Z = alpha * Z_storage
E = Q^(-H) G Q^(-1) = alpha * E_storage
Z^(-1) = Z_storage^(-1) / alpha
```

따라서 `epx`, `epy`, `epxy`, `epyx` 에는 alpha를 곱하고 `epz_i` 는 alpha로 나눕니다. 어댑터는 물리 저장
행렬을 닫은 뒤 이 인자들을 적용합니다. 손실이 있는 물리 행렬은 에르미트일 필요가 없으므로, 1e-9 에르미트
보호 검사는 여전히 저장 횡방향 행렬을 검사합니다. 그다음 스케일한 슬롯이 유한한지 확인합니다.

에르미트 양의 저장 E에 대해 소산 부분은 `(E_lossy-E_lossy.H)/(2i) = eta*E_storage` 이며, 이는 양의
준정부호입니다. 독립 테스트는 이 행렬 성질과 실제 엔진의 흡수를 함께 검사합니다. 역 종방향 슬롯을 잘못된
방향으로 스케일하면 재료 대조군과 접촉 대조군을 위반하게 됩니다.

## 살아 있는 매개변수와 거부 규칙

어댑터는 실수부 비율 `Re(epsilon_i)/Re(background)` 로 상대 셀 재료를 구성합니다. 이렇게 하면 복소 나눗셈에서
공통 인자를 소거할 때 생기는 가짜 셀 미분을 피할 수 있습니다. 손실비 비교는 살아 있는 값으로 남으며,
`128*machine_epsilon*(1+abs(eta_background))` 이내의 반올림 차이만 받아들입니다. 이득, 유한하지 않은 값,
양수가 아닌 실수부, 서로 다른 패턴 층 비율은 거부합니다.

좌표, 실수 재료 값과 공통 비율은 하나의 고정된 기하 계획 아래에서 바뀔 수 있습니다. 미분은 eta=0에서의 한쪽
손실 미분을 포함하여 그 구속을 따라 지원합니다. 한 재료의 손실을 독립적으로 바꾸면서 다른 재료를 고정하면 지원하는
재료 계열을 벗어납니다. 추적된 입력이 잘못되면 유효해 보이는 실수 재료 결과 대신 NaN 행렬이 나옵니다.

밑바탕의 다항식 몸체 셀은 여전히 양의 실수 재료 보정자입니다. 그 프로파일 검증기는 이제 실수 평균 행렬을 조립하기
전에 허수부가 0인지 명시적으로 확인합니다. 인수분해하지 않은 손실로 직접 호출하면 즉시 실행(eager)에서는 예외를
일으키고 추적 중에는 NaN 계수를 만듭니다. 일반 복소 보정자에는 일관된 복소 시험·검정 함수와 에너지 투영이
필요합니다. 허수 평균 행렬을 버리는 것으로는 그 확장을 제공할 수 없습니다.

## 독립 대조군과 범위

추가한 테스트는 다음을 다룹니다.

- 손실 없는 경계와 1.3까지의 손실비를 포함하여, 두 층 축 모두에서의 공통 인자 스케일링과 양의 준정부호 소산.
- 유지 차수가 서로 다르고 0차 축이 있는 경우의 독립적인 해석적 재료 적분.
- NumPy, JAX, Torch 엔진에서 해석적 접촉 행렬과 비교한, 수평·균일·수직 흡수층이 섞인 적층.
- 세 백엔드 모두에서 두 입사 편광에 대해 독립적인 Airy 공식과 비교한 흡수 균일 슬래브.
- 두 가지 유한 차분 간격과 비교한 13개의 살아 있는 기하, 저장 재료, 주기, 자세, 손실 매개변수와, 별도의 정확한
  손실 미분.
- 한쪽 방향의 내부 틈, 수직 접촉, 손실 없는 경계 미분, 재료 래퍼, 잘못된 즉시 실행/추적된 입력.

명령과 결과는 `studies/rcwa/nvf_common_loss/records/nvf_common_loss_validation.log` 에 있습니다. 새 공통 손실
사례 30개를 포함해 서로 다른 사례 346개가 통과했고, 고정 P1 움직이는 계면 대조군에서 과거부터 예상된 실패가
1개 있었습니다. 설명서 예제와 엄격한 문서 빌드도 통과했습니다. 이 결과는 유한 구성과 통합을 검증하는 것이며, 광학
수렴을 증명하지는 않습니다.

손실 없는 배경 안의 손실 포함체, 또는 한 패턴 층 안에서 손실비가 다른 두 재료는 이 공통 인자 확장의 범위 밖이었고,
이후의 복소 재료 구성에서 지원합니다. 곡면 계면, 전단된 셀, 양수가 아닌 실수 유전율과 자동 투영자 선택도 여전히
별도 작업으로 남아 있습니다. 공통 인자 사례가 일반 손실 보정자 개발을 완성하는 것은 아닙니다.
