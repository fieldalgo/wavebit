# 유한 쌍 틈을 통한 자동 미분

작성: 2026-09-10

대상:
- `src/wavebit/rcwa/_engine/conforming/cartesian_pair_gap_autodiff.py`
- `tests/rcwa/test_nvf_cartesian_pair_gap_autodiff.py`

별도의 실험적 `CartesianPairGapEvaluator`는 NumPy 또는 JAX x64를 써서, 정확하게 다시 스케일한
유한 틈 계열을 통해 계수와 선택한 에너지 닫힘을 계산합니다. 이 값 함수를 보통의 방식으로
미분하면 물리적 틈 응답을 얻습니다. 사용자 정의 미분, 멈춘 유효 그래디언트, 맞춘 미분, 유한
틈 외삽은 추가하지 않습니다. 독립적으로 인정된 [NumPy 해석 계열](nvf-cartesian-pair-gap.md)과
[끝점 응답](nvf-cartesian-pair-opening.md)은 바뀌지 않습니다. 사용법은
[설명서](../../guide/rcwa/cartesian-pair-gap-autodiff.md)에 있습니다.

## 유한 방정식과 접촉의 의미

같은 불변 붕괴 위상 구조가 세분화 0 또는 1(2026-09-13부터는 0부터 3까지.
[세분화 기록](nvf-pair-refinement.md)을 보세요)에서 C와 Z를 제공합니다.
물리 길이를 L = √det(A)로 정규화하고, s = g/L로 두고, 물리 퍼텐셜
`w = L*(C*u + s*Z*v)`를 씁니다. 해석적으로 제거한 얇은 극점은 다음을 줍니다.

```text
M(s) x(s) = f(s),  x = [u; v]
M = [[H00, s*H01], [H01^T, H11]].
```

국소 방정식과 필드 표현식은 [정확한 유한 계열](nvf-cartesian-pair-gap.md)의 것과 같습니다.
그 얇은 필드도, 그 풀이도 틈으로 나누지 않습니다. 정확하게 모은 반복 끝점과 고정된 이진 분할
그래프가 어느 삼각형이 붕괴하는지 정합니다. 부동소수점으로 작은 면적이 위상 구조를 고르는
일은 없습니다. 기존 다각형 윤곽 변환은 반복 꼭짓점에서 유한하며, 붕괴하는 모든 삼각형에서
공간 위상을 유지합니다.

구현은 값만 계산합니다. JAX가 유한 행렬 풀이, 움직이는 필드와 다각형 연산, 에너지 켤레, 선택한
닫힘을 미분합니다. 암묵 관계 `M*x' = f' - M'*x`와 원래의 전체 약형식 플럭스 미분은 독립적으로
검사합니다. g=0에서 양의 접선은 물리적인 오른쪽 미분의 의미를 가집니다. 음의 접선 선형성은
형식적 확장만 시험하며, 음의 틈 원시값을 허용하지 않습니다.

잘못된 추적 입력은 최종 출력을 전부 NaN인 계수/닫힘으로 내기 전에 안전한 기하와 유한한 대체
블록을 씁니다. 이 마스크는 유효한 산술을 살아 있는 채로 둡니다. JAX x64가 필요하며, 계획은
추적 밖에서 구체적인 값으로 유지됩니다. 의도적으로 대칭이 아닌 M은 원래 Hermitian 부분의 최소
고유값으로 시험하지 않습니다. 접촉/차이 대각 블록, 원래의 약형식 잔차, 닫힘 저장/손실과 역행렬
항등식에는 별도의 보호 장치가 있습니다.

## 고정된 독립 인정

미리 선언한 관측 80개는 물리 고정 장치 두 개, 기존의 부호 있는 열 표현 네 가지, 세분화 0/1,
틈 `s=0, 1/64, 1/16`을 씁니다. 주 관측 30개, 공통 단위 12개, 0/비동일 차수 6개, 균일 30개, 명시적
무손실 점 2개입니다. 유한 약형식 공간에는 자유 퍼텐셜이 8개 또는 35개 있습니다. 무손실 점은
주 좌표판 0, 세분화 0 고정 장치의 0과 `s=1/64`이며, 재료의 허수부를 정확히 0으로 둡니다.

기준은 양의 틈에서는 원래의 유리 절점 Vandermonde 계를, 접촉에서는 원래의 Laurent 끝점 계를
독립적으로 조립합니다. 움직이는 심플렉스 Duffy q16/q24 적분으로 계수와 해석적 물리 틈 미분을
검사합니다. 독립적으로 미분한 닫힘 풀이는 역행렬을 구하기 전에 정확한 정수 푸리에 라벨을
고릅니다. 기존 NumPy 해석 계열은 추가 기준이며, 유일한 기대 결과가 아닙니다.

고정된 값/구적 보호 한계는 `3e-10`이며, L을 곱한 q16/q24 미분 차이도 포함합니다. L을 곱한 실제
틈 JVP/기준 차이는 `3e-9`를 요구합니다. 투영, 원래, 미분, 역행렬 잔차는 `1e-10`을 요구합니다.
저장은 양수로 남아야 하고, 부호 있는 소산은 `-1e-9`보다 커야 하며, 무손실 재료에는 명시적인
Hermitian/무손실 대조군이 있습니다. 수치 동결 뒤에 경우, 구적 수준, 허용 오차를 바꾸지
않았습니다.

| 동결한 임시 측정 | 최대 차이 |
| --- | ---: |
| 계수 값 대 독립 q24 | 4.458e-15 |
| 닫힘 값 대 독립 기준 | 6.695e-15 |
| L × 계수 틈 JVP 대 독립 기준 | 1.191e-13 |
| L × 닫힘 틈 JVP 대 독립 기준 | 3.072e-14 |
| q16/q24 값 / 정규화 미분 | 1.219e-12 / 5.399e-12 |
| 투영 / 원래 비투영 원시 잔차 | 6.840e-16 / 9.013e-16 |
| 미분한 투영 / 비투영 잔차 | 2.398e-14 / 2.575e-14 |
| 닫힘 곱 항등식 네 개 전부 | 1.906e-15 |
| 부호 있는 기저 정규화 미분 | 2.845e-14 |
| 공통 단위 정규화 미분 | 2.472e-14 |
| 스칼라 역방향 미분 대 독립 투영 | 1.336e-13 |
| 역방향 대 실제 순방향 JVP 투영 | 2.642e-14 |

부호 있는 기저 비교 18개는 모두 계수 라벨과 두 닫힘 축을 대응시킵니다. 단위 대조군 12개는 모든
물리 길이와 틈을 .01배로 스케일합니다. 값은 불변으로 남고 단위당 미분은 100배가 됩니다. 끝점
0/음의 접선 비교 8개는 선형성 차이가 0입니다. 스칼라 역방향 검사 4개는 독립적으로 선언한 복소
시드를 씁니다. 즉시 실행 JVP 30개는 컴파일한 결과와 일치합니다. 컴파일한 좌표판 하나가 실제로
서로 다른 물리 고정 장치 두 개를 모두 재실행하며, 임의의 기하/재료 그래디언트가 아니라 살아
있는 입력값과 틈 미분을 검사합니다.

바깥쪽 붕괴 부채꼴 삼각형을 포함해 모든 삼각형 가중치와 그 미분이 독립 기준과 일치합니다.
균일 미분은 반올림 오차 안에서 사라집니다. 두 무손실 닫힘의 Hermitian 오차는 최대
5.579e-16이고, 정규화 미분의 Hermitian 오차는 최대 3.553e-15입니다. 80개 경우 전체에서 M의
측정 조건수는 23.8044–489.018 범위입니다. 최소 닫힘 저장은 약 1이고 최소 부호 있는 소산은
-5.506e-16이며, 잘라 내지 않고 무손실 반올림 오차로 남겨 두었습니다.

## 출처, 감사와 한계

원래의 두 단계는 모두 exit 0으로 끝났고 17개 소스 고정값은 바뀌지 않았습니다. NumPy 기준의
부모/감사 경과 시간은 5.349595/5.116957 s였고, 관측한 프로세스 최대치는 90,079,232 바이트였습니다.
JAX의 부모/감사 시간은 19.583773/19.008142 s였고 최대치는 1,989,066,752 바이트였습니다. 독점
180 s 부모가 각 자식을 회수했습니다. 8 GiB 보호 장치는 체크포인트/네이티브 반환 뒤의 누적
프로세스 최대치를 관측합니다. 연속적인 RSS 표본기도, 엄격한 할당 상한도 아닙니다.

별도의 저장 배열 감사는 NPZ 해시 182개를 검증했습니다. 기준 80개, 관측 80개, 접선 8개, 역방향
4개, 잘못된 입력 대조군 10개입니다. 이 감사는 솔버, 평가기, 기준 구현, JAX를 가져오지 않고 모든
계수/닫힘 차이, 선택한 닫힘 곱 항등식, 저장한 투영 행렬과 원래의 플럭스/하중 잔차, 변환/단위
비교, 잘못된 입력의 전부 NaN 원시값을 다시 계산했습니다. 덧붙인 v2는 정확한 선언과 보고만 된
잔차에 대한 유한 보호 장치를 검증하며, 통과한 v1은 그대로 보존합니다.

저장한 끝점 정규 필드 미분 마스크는 남기지 않았으므로, 그 선택한 지표는 아주 작은 면적에서
추론한 것이 아니라 소스/보고로 검증한 것입니다. 모든 끝점 가중치와 미분은 독립적으로 비교합니다.
원래의 기준 약형식 행렬/하중은 임시 단계에서 저장하지 않았습니다. 보고한 잔차는 보호되고
고정되어 있지만, 저장 배열 감사가 다시 조립하지는 않습니다. 저장소 시험은 독립 방정식을 다시
계산하며 구조 마스크를 직접 압니다.

전용 저장소 묶음은 **231개 시험을 22.54 s에** 통과하며, 독립 기준을 패키지 소스에서 다시
계산합니다. JAX를 막은 새 프로세스는 NumPy/정적 시험 96개를 통과하고 선택적 JAX 시험 135개를
5.24 s에 건너뜁니다. 정확한 가이드 예제도 저장소 밖으로 복사한 패키지에서 tests, studies, 시험
도우미와 PyTorch import를 막은 채 통과합니다. 그 프로세스 최대치는 425,345,024 바이트입니다. 전체
묶음의 관측 최대치는 1,899,331,584 바이트이고, JAX 없는 프로세스는 최대 108,707,840 바이트입니다.

소스는 기계적으로 승격했습니다. import 네 개가 상대 import가 되고 서식이 바뀌었을 뿐, 나머지
수치 추상 구문은 정확히 같습니다. 완전 정밀도의 동결 측정, 소스 고정값, 원래의 보호 장치만 있던
초안 이력과 저장소 검증은 결과 로그 `nvf_cartesian_pair_gap_autodiff.log`에 남아 있으며, 이 로그는
저장소 밖에 보관되어 있습니다. 로그는 `studies/rcwa/nvf_cartesian_pair/` 연구에 속합니다. 로그의
엄격한 JSON에서 의도적인 잘못된 입력 NaN 값은 명시적인 `{"invalid_float": "NaN"}` 인코딩을
쓰며, 유효한 출력은 여전히 유한 보호 장치를 받습니다. 외부 소스/체크포인트 경로는 기록한 내용
해시를 바꾸지 않고 정리했습니다.

이것은 별도의 고정 좌표판, 유한 공간 틈 미분 인정입니다. 임의의 기하/재료 그래디언트, 혼합 또는
고차 미분, 균일한 조건수 반경, 연속체 오차, 패턴이 있는 광학 수렴을 인정하지 않습니다. 보통의
접촉 보존 어댑터 재실행/JVP 계약은 바뀌지 않습니다.
