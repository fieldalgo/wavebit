# 늘린 좌표의 계산을 유한요소 필드와 견줌 — 측정

[`Numerics(wall_resolution=G)`](../../guide/rcwa/wall-resolution.md)를 무엇과 견주었고, 무엇이 나왔고, 어디를 확인하지 않았는지 적습니다. 이 옵션은 실험적입니다. 늘린 계산을 같은 차수에서 견줄 독립 구현이 없으므로, 여기의 모든 것은 유한요소 필드와의 비교(방법이 얼마나 정확한지)이거나 구성이 만족해야 하는 성질입니다.

## 방법, 한 문단으로

축마다 좌표 `u`를 쓰고 `x = F(u)`입니다. `F`는 이웃한 두 벽 사이에서 직선에 사인 한 주기를 더한 것입니다(Granet의 adaptive spatial resolution을 Vallius와 Honkanen의 꼴로 쓴 것, Opt. Express 10, 24 (2002)). `F'`는 모든 벽에서 옵션의 값 `G`와 같고, 벽은 `u`에서 같은 간격으로 놓입니다. `(u, v, z)`에서 맥스웰 방정식은 `eps~ = eps diag(g/f, f/g, f g)`와 같은 꼴의 `mu~`로 형태를 유지하므로(`f = F'`, `g`는 다른 축의 기울기), 층마다 지금과 같은 고유값 문제를 기울기로 가중한 푸리에 적분으로 풉니다. 스택 전체를 이 좌표에서 풉니다. 반공간도 층처럼 모드를 구하고, 진행하는 차수만 늘린 기저로 적은 정확한 평면파로 바꿉니다.

## 일곱 층의 근접장

400 nm 정사각 셀 안, 공기 중의 두께 150 nm 층 하나에 900 nm를 수직으로, `E`를 x 방향으로 입사시켰습니다. `factorization='li'`입니다. 각 값은 층 가운데 높이 평면의 2304개 표본(벽 위의 표본 포함)에서 `E`의 면내 벡터 오차의 RMS를 기준 해의 평면 RMS로 나눈 것이며, 차수 8 / 12 / 16의 순서입니다. 기준 해는 3D 유한요소 필드입니다(gyptis 1.2.0, 이차 에지 요소).

| 층 | 늘리지 않음 | `wall_resolution=0.02` | `R`: 늘린 계산 (기준 해) |
| --- | --- | --- | --- |
| 금속 블록 200 nm, `eps` -20+1.5j | 32.1 / 25.8 / 22.5% | 4.0 / 0.63 / 0.52% | 0.35555 / 0.35553 / 0.35547 (0.35615) |
| 그 금속 막에 뚫린 정사각 구멍 200 nm | 36.8 / 30.9 / 29.0% | 6.5 / 3.3 / 1.8% | 0.89270 / 0.89331 / 0.89344 (0.89281) |
| 유전체 정사각형 200 nm, `eps` 12.25 | 14.8 / 11.5 / 9.1% | 0.71 / 0.41 / 0.39% | 0.03650 / 0.03650 / 0.03650 (0.03662) |
| 금속 직사각형 250 × 150 nm | 37.9 / 36.4 / 26.5% | 4.5 / 3.6 / 3.4% | 0.63826 / 0.63888 / 0.63885 (0.64043) |
| 금속 블록, `eps` -100+5j | 85.3 / 34.7 / 27.4% | 5.0 / 3.3 / 0.70% | 0.28785 / 0.28750 / 0.28783 (0.28827) |
| 금속 블록, `eps` -5+1j | 21.8 / 17.0 / 13.4% | 2.8 / 1.4 / 1.0% | 0.37259 / 0.37308 / 0.37361 (0.37454) |
| 유전체 직사각형 250 × 150 nm | 16.0 / 12.0 / 9.8% | 1.7 / 1.6 / 1.6% | 0.07651 / 0.07651 / 0.07651 (0.07671) |

- **앞의 네 기준 해는 저장되어 있습니다**(`tests/references/golden_gyptis_rectangles_field.npz`와 그 기록). 차수 8의 행은 테스트이고, 차수 12의 행은 느린 묶음에 있습니다. 그 넷의 늘리지 않은 차수 16 값은 같은 계산의 시험 구현으로 쟀습니다. 뒤의 세 기준 해는 이 저장소에 저장되어 있지 않고, 이를 읽는 테스트도 없습니다.
- **기준 해의 정확도.** 블록과 구멍은 한 단계 거친 메시가 저장된 것에서 평면 RMS의 0.37%, 0.20% 떨어져 있습니다. 나머지 다섯은 메시 단계가 하나입니다. 늘린 계산이 더 좋아지지 않는 곳(금속 직사각형 3.4%, 유전체 직사각형 1.6%, 유전체 정사각형 0.4%)에서 그 `R`은 다섯 자리까지 자리 잡았고 기준 해의 값에서 0.2~0.3% 떨어져 있으며, 남은 오차는 도형 바깥의 벽 옆에 있습니다. 그 바닥은 메시 한 단계인 그 기준 해들의 정확도로 봅니다. 더 촘촘한 메시로 확인하지는 않았습니다.
- **구멍**이 일곱 가운데 가장 느립니다. 차수 8에서 6.5%, 차수 16에서 1.8%입니다.
- **늘리지 않은 계산의 `R`**은 금속 블록에서 세 차수에 0.3505, 0.3506, 0.3512입니다. 늘린 계산은 차수 8부터 기준 해의 0.2% 이내입니다.

### 구현 전에 적어 둔 기준

제품 코드가 있기 전에, 시험 구현의 값에 두 배쯤 여유를 두고 정한 것입니다. 차수 12에서, 늘리지 않은 평면 오차에 대한 비율입니다.

| 기준 | 한계 | 측정값 |
| --- | --- | --- |
| 금속 블록, 필드 | 0.06 | 0.024 |
| 금속 블록, 기준 해 대비 `R` | 0.3% | 0.17% |
| 유전체 정사각형, 필드 | 0.1 | 0.036 |
| 유전체 정사각형, `R`(차수 8부터) | 0.5% | 0.33% |
| 금속 직사각형, 필드 | 0.25 | 0.10 |
| 구멍, 필드 | 0.2 | 0.11 |

차수 16에서 블록은 0.023, 직사각형은 0.13입니다. 적어 둔 대로 충족되지 않은 기준이 하나 있습니다. 세 백엔드가 1e-10까지 일치해야 했는데, `R`과 `T`는 그렇지만(가장 나쁜 경우 3e-11) 350 nm에서 금속 층의 필드는 백엔드 사이에 4e-10 다릅니다.

## 구성이 만족해야 하는 것

각각 `tests/rcwa/test_wall_resolution.py`의 테스트입니다.

- **늘리지 않는 극한.** 주기의 절반 폭인 블록은 벽이 이미 고르게 놓여 있어서, `wall_resolution=1.0`이면 좌표가 셀의 원래 좌표입니다. 그때 `R`, `T`, 정반사 진폭, 필드의 여섯 성분 모두가 늘리지 않은 계산과 1e-12까지 일치합니다. 유리 위의 네 층(둘은 균일)에 양쪽에서 비스듬히 입사시킨 경우이고, 반공간과 균일한 층이 평면파 대신 고유값 문제를 거쳤는데도 그렇습니다.
- **구조 옮기기.** 사각형을 셀 안에서 (37.5, -25) nm 옮겨도 `R`과 `T`가 1e-11까지 같고, 옮긴 표본에서의 필드도 같습니다. 늘린 셀에서 벽의 자리는 벽의 순서에만 달려 있습니다.
- **에너지.** 손실 없는 블록에서 차수 8일 때 `R + T = 1`이 1e-4까지 맞습니다. 수직과 비스듬한 입사, 진행하는 차수가 넷과 다섯인 경우입니다.
- **백엔드.** NumPy, JAX, PyTorch의 즉시 실행이 `R`과 `T`에서 3e-11, 필드에서는 필드 크기의 4e-10까지 일치합니다.

## 비스듬한 입사, 진행하는 차수 여럿

여기에는 유한요소 기준 해가 없습니다. 위의 모델은 한 파장의 수직 입사용입니다. 볼 수 있는 것은 늘린 계산이 자리 잡는지, 그리고 늘리지 않은 계산이 차수를 올리며 그쪽으로 움직이는지입니다. 다시 200 nm 블록(또는 구멍)이고, 차수 8 / 12 / 16의 `R`이며 늘리지 않은 계산은 차수 20도 적었습니다.

| 경우 | 진행하는 차수 | `wall_resolution=0.02` | 늘리지 않음 |
| --- | --- | --- | --- |
| 유전체, 900 nm, theta 20°, phi 30°, p | 1 | 0.02594 / 0.02594 / 0.02594 | 0.02615 / 0.02605 / 0.02601 / 0.02599 |
| 같은 입사, s | 1 | 0.05394 / 0.05393 / 0.05393 | 0.05418 / 0.05406 / 0.05402 / 0.05399 |
| 유전체, 350 nm, 수직 | 5 | 0.24577 / 0.24502 / 0.24497 | 0.23188 / 0.23990 / 0.24262 / 0.24372 |
| 유전체, 350 nm, theta 20°, p | 4 | 0.12974 / 0.16194 / 0.16203 | 0.13188 / 0.15125 / 0.15719 / 0.15948 |
| 유전체, 405 nm, 수직 | 1 | 0.02123 / 0.31136 / 0.31217 | 0.14721 / 0.27412 / 0.30218 / 0.31042 |
| 유전체, 395 nm, 수직 | 5 | 0.63451 / 0.64034 / 0.64034 | 0.61329 / 0.63145 / 0.63660 / 0.63850 |
| 금속, 900 nm, theta 20°, phi 30°, p | 1 | 0.32910 / 0.32900 / 0.32902 | 0.32154 / 0.32339 / 0.32445 / 0.32565 |
| 금속, 350 nm, 수직 | 5 | 0.36196 / 0.36280 / 0.36279 | 0.34676 / 0.35414 / 0.35748 / 0.35884 |
| 구멍, 900 nm, theta 20°, p | 1 | 0.88329 / 0.88395 / 0.88409 | 0.87830 / 0.87979 / 0.87982 / 0.87956 |

- 손실 없는 경우들에서 `R + T = 1`은 차수 8에서 2e-6, 차수 12부터 1e-9까지 맞습니다.
- 블록의 여덟 경우에서 늘린 계산이 차수 12와 16 사이에 움직이는 양(Rayleigh 파장 옆에서 가장 커서 8e-4, 그 밖에서는 9e-5 이하)은 늘리지 않은 계산이 16과 20 사이에 움직이는 양보다 작고, 늘리지 않은 계산은 그 값으로 단조롭게 다가갑니다.
- 구멍에서 늘린 계산은 차수 12와 16 사이에 1.4e-4 움직입니다. 늘리지 않은 계산은 차수 20까지 자리 잡지 못하고 거기서 되돌아갑니다.
- **이것은 정확도의 증거가 아닙니다.** 반공간을 늘린 좌표에서 풀고 진행하는 차수마다 그 평면파로 바꾸는 방식이, 비스듬한 입사나 진행하는 차수가 여럿일 때 깨지지 않는다는 것을 보여 줄 뿐입니다.

### Rayleigh 파장 옆

셀의 주기가 400 nm이므로 405 nm는 Rayleigh 파장 바로 위, 395 nm는 바로 아래입니다.

- 395 nm에서는 진행하는 차수가 다섯이고, 늘린 계산이 차수 8부터 자리 잡습니다.
- **405 nm에서는 차수 8에서 크게 틀리고**(`R` 0.021, 자리 잡은 값은 0.312) 차수 12부터 자리 잡습니다. 늘리지 않은 계산도 거기서는 느립니다. 시험 구현에서 컷오프를 막 지난 차수까지 평면파로 바꿔 보았지만 달라지지 않았습니다. 낮은 차수에 부족한 것은 더 나은 반공간이 아니고, 그 파장에서 층 자체가 느리게 수렴합니다.

## 반공간을 늘린 좌표에서 푸는 이유

다른 방법은 반공간을 늘리지 않고 그 평면파 전부를, 감쇠하는 것까지, 층의 기저로 옮기는 것입니다. 시험 구현이 먼저 그렇게 했습니다. 그러면 좌표가 빠르게 진행하는 곳에서 높은 차수가 유지한 고조파보다 빠르게 진동하고, 그것들을 옮기는 행렬이 특이에 가까워집니다. 기울기 0.02에서 그 조건수는 차수 8, 12, 16에 1e4, 5e6, 2e9였습니다.

- 유전체 층에서는 어느 쪽이든 답이 네 자리까지 같았습니다. 2e9에서도 그랬습니다.
- 금속 층에서는 반사율은 맞는데 필드가 차수와 함께 무너졌습니다. 금속 직사각형은 차수 8, 12, 16에서 5.7%, 17%, 27%였고 위의 계산은 4.5%, 3.6%, 3.4%입니다. `eps` -100+5j인 블록은 차수 16에서 143% 틀렸습니다.

반공간을 같은 좌표에서 풀면 진행하는 차수의 평면파만 있으면 됩니다. 조건이 좋은 열 몇 개이고, 그 행렬의 역은 어디에도 필요 없습니다.

## 이 함수와 이 배치를 쓰는 이유

- **벽마다 혹을 두는 것은 덜 들었습니다.** 벽 주위의 정해진 띠 안에서만 좌표를 늦추는 함수를 먼저 쟀고, 벽에서의 기울기를 0.02까지 낮췄습니다. 금속 직사각형에서 세 차수에 19%, 14%, 4.2%였고 사인 함수는 4.5%, 3.6%, 3.4%입니다. 그 함수에서는 낮은 차수에서 유전체 층의 `R`도 나빠졌습니다(차수 8에서 3.5% 차이, 여기서는 0.26%). 벽에서의 기울기보다 함수의 꼴이 더 중요합니다.
- **벽 사이를 같은 간격으로.** 조각마다 `u`에서의 폭을 `x`에서의 폭과 같게 두면 금속 직사각형이 차수 8과 12에서 6.7%, 6.3%였고, 두 벽이 37.5 nm 떨어진 균일 슬래브에서는 필드가 자기 크기보다 더 틀렸습니다. 같은 간격에서는 같은 슬래브의 필드가 1.5%까지 균일했습니다.
- **기울기.** 기울기 0.1은 금속 직사각형에서 8.6 / 4.6 / 4.1%, 유전체 정사각형에서 0.93 / 0.75 / 0.51%로, 늘리지 않은 계산과 0.02 사이입니다.

이 세 비교는 시험 구현으로 했습니다. 제품 코드는 열세 경우에서 그 구현의 `R`과 `T`를 다섯 자리까지 재현합니다.

## 측정하지 않은 것

- 비스듬한 입사, 진행하는 차수 여럿, 기판, 패턴 층 여럿에 대한 기준 해.
- 한 축에 벽이 둘보다 많은 층을 기준 해와 견준 것. 고르지 않게 놓인 벽 넷을 지나는 균일 슬래브는 `R`이 1e-5까지 맞습니다.
- 일곱 기준 해 가운데 다섯의 둘째 메시 단계.
- 단정밀도. `jax.jit`, `jax.vmap`, 미분은 거절합니다.
- 예외점 처리와의 상호작용. 문헌은 센 늘림이 차수를 올리면 물러나는 가짜 층 모드를 더한다고 보고하는데, 여기서는 찾아보지 않았습니다.
