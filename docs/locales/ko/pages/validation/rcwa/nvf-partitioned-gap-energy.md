# 한 모델 안의 분할 불변성과 얇은 틈 필드

`studies/rcwa/nvf_partitioned_gap_energy/nvf_partitioned_gap_energy.py`는 conforming 틈 연구를
수평 재료 분할과 평행 이동한 직사각형 형상 목록으로 확장합니다. 이제
같은 유한 모델이 같은 재료 분할 점검과
p/s 접촉 미분 점검을 모두 통과합니다. 이로써 서로 다른 두
측정 도구 사이에 있던 공백이 메워집니다. 푸리에 모델은 분할 불변성을 가졌지만
s 접촉 미분이 틀렸고, 초기 conforming 모델은 접촉 필드를 가졌지만
분할 표현이 없었습니다.

이것은 여전히 연구용 구현입니다. x 방향으로 분할한 직사각형 외곽(envelope)과
y 방향의 주기적 틈을 지원합니다. 기울어진/곡선 경계,
일반적인 칠하기, 제품 NVF 통합은 아직 열린 과제입니다.

이후의 [재료 조화 좌표 연구](nvf-harmonic-coordinates.md)는
이 분할/접촉 관문을 유지하면서 닫힌 혼합 막대의 필드 도약과 정적 이음매 미분을
해결합니다. 다만 양의 틈에서 그보다 작은 메시 노드 민감도 불일치가
남아 있습니다. 아래의 고정 P1 오차는 이 원래 모델에 대해 계속 기록하고
시험합니다.

## 고정된 공간 위의 재료 도약

셀 메시는 외곽과 명시적인 해상도 설정에 따라 정해집니다.
재료 조각의 개수나 서로 같은지 여부에는 의존하지 않습니다. 순서가 정해진
이음매 s와 재료 값 e가 있을 때, 재료 함수는 다음과 같이 표현합니다.

```
epsilon(x) = 1 + (e[0]-1) I[envelope]
               + sum_j (e[j]-e[j-1]) I[s[j-1], envelope_right]
```

외곽 다음의 각 항은 오른쪽 끝 구간(suffix)을 채웁니다. 이것은 서로 다른 재료를 포함한
조각별 상수 재료에 대한 망원(telescoping) 항등식입니다. 같은 재료 사이의 인공 이음매는
가중치가 정확히 0입니다. 따라서 그 이음매의 움직임은 행렬과 물리 매개변수 미분에
0을 기여합니다. 재료가 같을 때도 독립적인 재료 미분은 살아 있습니다.
재료 값 하나만 바뀌면 `e[j]-e[j-1]`의 미분은
0이 아닙니다.

같음을 판정하는 조건문, 조건부 기하 병합, 재료 매개변수 제거는
없습니다. 같은 항등식은 그 외에는 균일하지 않은 재료 분포 안에 끼워 넣은
중복 이음매도 상쇄합니다. 시험한 직접적인 NumPy 표기들에서 사영한
계수 배열 여덟 개가 모두 비트 단위로 같습니다.

실제 보정 공간과 해석적으로 척도를 맞춘 틈 방정식은
[conforming 틈 연구](nvf-thin-gap-energy.md)에서 유도한 것입니다. 작은
공유 헬퍼 리팩터링으로 그 풀이와 에너지 닫힘을 재사용합니다.
제품의 인수분해 루틴은 바꾸지 않았습니다.

## 분할한 재료의 정확한 적분

각 고정 P1 요소에서 다음 모멘트를 써서 재료를 국소 다항식
기저와 푸리에 파동에 대해 적분합니다.

```
integral r^k exp(-2*pi*i*m*x) dx,    k = 0, 1, 2.
```

이 모멘트들이 셀의 질량/강성/하중 기여와,
B, `B.T*epsilon*B`, epsilon의 푸리에 사영을 제공합니다. Sinc 함수와 그 1·2계
미분이 닫힌 형태를 줍니다. 0 근처에서는 수렴하는 Taylor 급수로
상쇄를 피합니다. 길이가 0인 교차 구간도 공식에 남아 있으며, 정확한 접촉에서의
살아 있는 미분도 포함합니다. 새 모델은 유전율 래스터나 푸리에 사영
구적법을 쓰지 않습니다.

수치 안정성을 위해 사영 에너지는 국소
퍼텐셜 차이로 계산합니다. 첫 구현은 퍼텐셜에 조립한
강성 행렬을 곱했는데, 아주 작은 계면 요소에서 상쇄 때문에 사영 계수의
약 1e-11을 잃었습니다. 곱하기 전에 국소 차이를 먼저 만들면,
측정한 대조 실험에서 독립적인 conforming 구적법과의 불일치가
약 2e-14로 줄어듭니다. 정확한 구간 모멘트는 또한
0에 가까운 주파수, 음의 주파수, 폭이 0인 구간을 포함해 독립적인 80점 Gauss 적분과 일치합니다.

## 형상, 미분, 측정

기존 스칼라 인터페이스는 계속 쓸 수 있습니다.

```python
model = PartitionedGapEnergyModel(order=7, rows=8, edge_fraction=1e-6)
profile = dict(seams=[31.], values=[12.25, 12.25])
result = model.transmission(gap=0., epsilon=profile, width=350.)
```

형상 어댑터는 `lx`, `ly`, `epsilon`과
선택 항목 `cx`, `cy`, `angle`을 가진 연구용 딕셔너리를 받습니다. 이 형상들은
높이/y 중심이 같고 각도가 0인, 순서가 정해진 수평 타일링을 이루어야 합니다. 어댑터는 그
기하를 확인하고, 공통 외곽과 재료 이음매를 추출하며, 전체 평행 이동에 대한
정확한 푸리에 위상을 적용합니다. 틈을 채우거나, 관련 없는 형상을 합치거나,
일반적인 칠하기 연산을 제공하지는 않습니다. 추적 중의 잘못된 갱신은
유한하지 않은 데이터를 만들고, 잘못된 일반 호출은 오류를 냅니다.

```python
shapes = [dict(lx=300., ly=300., epsilon=4., cx=-150.),
          dict(lx=300., ly=300., epsilon=4., cx=150.)]
result = model.shape_transmission(shapes)
```

테스트는 이 600x300 표기를 직사각형 하나와 비교합니다. 움직이는
인공 이음매, 평행 이동, 두 편광, 높이 700에서의 정확한 주기적 접촉을
포함합니다. 값 차이는 원래의 1e-10 분할 기준을 통과하고,
물리 그래디언트 차이는 2e-10을 통과합니다. 형상을 주기
셀 경계 너머로 옮겨도 전력은 변하지 않습니다. 재료가 같을 때,
대비가 0일 때, 재료가 다를 때의 독립적인 재료 미분은 NumPy
유한 차분과 일치하며, 실제 대비를 나타내는 이음매의 움직임도 마찬가지입니다.

바깥 차수 7, 폭 350, epsilon 12.25, x 모서리 비율 1e-6에서
평행 이동한 형상 어댑터는 병합/분할 결과가 같습니다.

| 편광 | 닫힌 T | dT/dgap |
| --- | ---: | ---: |
| p | 0.626061531896588 | 0.001891546100056 |
| s | 0.878242289574451 | -0.000778566984054 |

두 실행 모두에서 인공 이음매 미분은 0입니다. 평행 이동 미분은
기록한 가장 세밀한 이 경우에서 4e-11 미만입니다. s 접촉 불일치는 독립 기준 대비
여전히 약 0.001%입니다. 두 접촉 관문은
더 저렴한 x 비율 1e-5에서도, 앞선 연구가 쓴 것과 같은 1e-7 절대 기준으로
통과합니다. 카르테시안 Li는 독립적인 시험
도구일 뿐이며, 새 모델이나 그 형상 어댑터가 호출하지 않습니다.

## 표현 불변성이 셀 오차를 없애지는 않습니다

서로 다른 재료 사이의 이음매는 고정된 메시 요소를 가로지를 수 있습니다. 그
재료의 적분은 정확하지만, 유한 셀 공간은 그 필드
도약을 분해하지 못할 수 있습니다. 이음매가 메시 노드에 있는 닫힌 혼합 막대는 독립적인
역규칙 행렬을 재현합니다. 노드에서 벗어난 이음매는 측정 가능한 근사 오차를 남깁니다.

폭 350, 이음매 x=31, 재료 4/9에서 정확한 정적 법선 에너지는
1.676646706586826입니다. 원래의 각 x 구간을 재료
분할과 무관하게 세분화하면 다음과 같습니다.

| x 세분 수 | 계산한 법선 에너지 | 정확값 대비 초과분 |
| --- | ---: | ---: |
| 1 | 1.684405196727 | 0.007758490140 |
| 2 | 1.681276361636 | 0.004629655049 |
| 4 | 1.678794667052 | 0.002147960465 |

이 중첩 세분화를 재현하려면 `x_subdivisions`를 쓰세요. 분할 동등성은
모든 해상도에서 보존됩니다. 이 표는 정적 셀 수렴
점검이며, 광학 투과 오차 한계나 혼합 재료 정확도가 수렴했다는
주장이 아닙니다. 일반적인 계면 정합성, 일반적인 기본 도형
분할, 기울어진 경우의 광학 수렴, 독립 3D 기준의
불확도는 제품에 채택하기 전에 아직 작업이 필요합니다.

독립적인 움직이는 계면 점검은 더 강한 남은 한계를 드러냅니다.
실제 이음매가 처음에 x=0 메시 노드에 있는 같은 4/9 막대에서, 이음매 위치에 대한
정확한 정적 미분은 -0.000569451310입니다. 간격 1e-4에서 계산한
왼쪽/오른쪽 할선 기울기는 -0.001281263686과 -0.000253089616입니다.
닫힌 에너지는 정확하지만, 재료 도약을 고정된 P1 요소 안에서 움직여도
필드 도약이 함께 움직이지 않습니다. 따라서 메시 노드에서 떨어진 곳에서 이 모델의 AD가 자기 자신의
할선과 일치한다는 사실로는 물리적 이음매 정확도를 확립할 수 없습니다.
이 결과는 새로운 엄격한 예상 실패(expected-failure) 관문으로 기록합니다. 같은 재료 이음매가
상쇄된다는 증명된 결과에는 영향을 주지 않습니다.

후속 [조화 좌표 정식화](nvf-harmonic-coordinates.md)는
요소 전체 적분으로 정규화한 `1/epsilon`의 누적 적분을 씁니다.
메시를 바꾸거나 재료가 같을 때 분기하지 않고 움직이는 필드 도약을 함께 옮깁니다.
구현은 아핀 리프트, 변분 강제항, 순방향 에너지도 바꿉니다. 독립적인 닫힌 정적
관문과 광학 관문은 이제 통과하지만, 양의 틈에서의 미분 불일치는 남아 있습니다.

## 재현과 검증

```bash
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m studies.rcwa.nvf_partitioned_gap_energy.nvf_partitioned_gap_energy --order 7 --edge-fraction 0.000001 --shape-gates
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m studies.rcwa.nvf_partitioned_gap_energy.nvf_partitioned_gap_energy --order 3 --width 600 --epsilon 4 --gap 400 --shape-gates
PYTHONPATH=$PWD OPENBLAS_NUM_THREADS=1 python -m pytest -q tests/rcwa/test_nvf_partitioned_gap_energy.py tests/rcwa/test_nvf_thin_gap_energy.py
```

기록한 비교는 `studies/rcwa/nvf_partitioned_gap_energy/records/nvf_partitioned_gap_energy.log`에 있습니다.
CLI는 JAX x64를 쓰며, Python 모델은 NumPy만으로도 실행됩니다.

2026-09-08의 초기 검증: **새 테스트 19개가 통과**하며, 새로 드러난 실제 이음매
물리 실패는 엄격한 예상 실패로 남겨 두었습니다. 관련 테스트를 합친
선택은 **66개 통과, 5개 건너뜀, 4개 xfail**입니다. 선택 의존성인 NGSolve의 건너뜀과
과거의 엄격한 예상 실패 세 개는 그대로 유지합니다. 이 셋은 원래의
제품 분할 실패, 유한 푸리에 s 접촉 실패, 별개의 작은
정규화 고유값 그래디언트 실패입니다. 대상 Ruff와 `git diff --check`는 통과합니다.
물리 허용 오차는 하나도 완화하지 않았습니다.
