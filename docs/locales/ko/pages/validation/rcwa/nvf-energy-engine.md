`wavebit.ConformingNVF`는 보통의 형상 층 사전(dictionary)으로부터 conforming 직사각형 셀을 만들고
기존 `solve_conv()` 파이프라인에 넘깁니다. 셀 커널은 이제 라이브러리 안에 있으며, 연구 클래스는
그것을 재사용하고 고정 구성 광학 판독만 `studies/`에 남겨 둡니다. 공유 닫힘은
`ConvMatrices.from_energy()`입니다. 2026-10-13부터 두 이름은 최상위 `wavebit` 네임스페이스가 아니라
`wavebit.compat.legacy`에서 내보냅니다.

이렇게 하면 어댑터에서 다섯 칸 배치를 재구성하거나, zz 행렬의 역행렬을 구하거나, 비대각 부호를
추측할 필요가 없어집니다. 이를 사용하는 솔버가 파장, 입사, 두께, 바깥 매질, 층 산란을 맡습니다.
앞서 하드코딩했던 연구용 전파기가 더 이상 셀의 구성 행렬을 쓰는 유일한 방법이 아닙니다.

## 닫힘과 미분 계약

Q = C(B), G = C(B.H epsilon B), Z = C(epsilon_zz)가 주어지면 빌더는 다음을 만듭니다.

```text
E = Q^(-H) G Q^(-1)
ConvMatrices(E_xx, E_yy, Z^(-1), -E_xy, -E_yx).
```

합동 변환의 양쪽 모두 선형 풀이를 씁니다. 빌더는 단일 층과 적층을 받아들이고, 입력 배열과 그 자동
미분 그래프를 보존하며, G를 대칭화하거나 정칙화하지 않습니다. 따라서 복소 손실이 닫힘을 거쳐도
살아남습니다. 모든 행렬은 같은 유지 푸리에 차수 집합과 카르테시안 좌표계를 기술해야 합니다. 빌더는
차원을 검사할 뿐, 그 물리적 대응을 검사하지는 않습니다. 유한한 입력과 출력의 검사는 정확도 추정과
별개입니다. 조건이 나쁘지만 유한한 풀이는 정확하다고 보증하지 않습니다.

실수 유전체 셀은 절대 1e-9의 Hermitian 결함 보호를 유지합니다. 닫힘 통합 자체는 셀 구성이나 접촉
방정식을 바꾸지 않았습니다. 이후의 단계형 격자 변경은 아래에서 설명합니다. 특화된 고차 거울 경로는
기존의 메모리를 아끼는 LU 구현을 유지합니다.

새 테스트는 NumPy, JAX, PyTorch에서, 두 복소 정밀도 모두에서, 층 축이 있을 때와 없을 때 모두,
복소 비직교 기저 변환 아래에서 미리 정한 비Hermitian 구성 텐서를 복원합니다. JAX JIT와 Torch
autograd는 또한 미분이 상쇄되어야 하지만 재료 미분은 0이 아니어야 하는 기저 변환도 검사합니다.
이것들이 닫힘 미분의 자격을 확인합니다. 기존 제품 전파기는 자신의 미분 동작을 유지하며, 이 통합은
그것을 고유벡터 없는 연구용 전파기로 대체하지 않습니다.

## 처음부터 끝까지의 대조 실험

실제 Wavebit 엔진을 서로 다른 파장과 두께에서 독립적인 무손실 및 흡수 균일 판 공식과 비교합니다.
conforming 혼합 재료 틈에서는 두 입사 편광 모두 세 백엔드에서 별도의 산란 배가 계산 도구와 절대
2e-10 기준으로 일치합니다. conforming 층 하나를 똑같은 인접 층 두 개로 나누어도, 다른 파장과
기판에서 반환된 모든 차수 효율이 2e-11 이내로 보존됩니다. 이것은 유한 모델 통합 대조 실험이며,
광학 수렴을 주장하는 것이 아닙니다.

원래의 닫힘 통합 기록에서는 빌더/통합 검사 29개와 접촉, 다항식 몸체, 국소 플럭스, 자세, 칸 순서
검사 62개가 통과합니다. 문서 계약 검사 28개도 통과합니다. 이는 서로 다른 검사 119개이며, 저장소
전체 테스트 묶음을 실행한 것이 아닙니다. 기록된 명령 요약은
`studies/rcwa/nvf_energy_engine/records/nvf_energy_engine_validation.log`에 있습니다.

## 형상 구성과 푸리에 원점

공개 생성자는 각 층에서 어느 격자 축을 따라서든 겹치지 않는 직사각형 열, 균일 층, 양의 스칼라 배경,
서로 독립인 직교 주기, 평행 이동, 공통 격자/형상 회전, 직사각형 유지 차수 집합을 받아들입니다. 공유
셀 풀이에 앞서 물리 길이와 재료 비를 정규화합니다. 그다음 필드와 그 에너지에 평행 이동과 카르테시안
텐서 회전을 적용하고, 요청한 푸리에 차 지표를 고른 뒤, 투영한 행렬을 닫습니다. 이미 닫힌 정사각
행렬을 잘라 내면 다른 유한 모델이 되므로 그렇게 하지 않습니다.

독립적인 해석적 재료 적분이 통합 중에 반 셀 위상 불일치를 드러냈습니다. 셀 커널은 중심에 둔 푸리에
원점을 쓰는데, 보통의 형상 API는 중심 오프셋을 `(a1+a2)/2`에서 재면서 그 푸리에 계수는 셀 모서리를
씁니다. 어댑터는 이 이동을 **모든** 계수 필드에 적용합니다. 이전의 불일치는 홀수 차수의 부호를
바꾸었지만 단일 층 총 전력은 보존했으므로, 전력 보존만으로는 찾을 수 없었을 것입니다. 이제 재료
합성곱 검사는 물리 배율, 배경 대비, 큰 평행 이동, 회전, 같지 않은 유지 차수를 다룹니다. 독립적인
회전 카르테시안 역규칙 대조 실험이 전체 높이 접촉에서 모든 칸을 검사합니다.

추가 공개 API 대조 실험은 강체 회전과 평행 이동 아래 두 입사 편광과 반환된 모든 회절 전력, 적층
전체의 물리 배율, NumPy, JAX, Torch 순방향 풀이, 같은 재료 세분, 살아 있는 JIT 기하·재료·배경·주기·
자세 미분, 한쪽 접촉 미분, 그리고 잘못된 즉시(eager)/추적(traced) 재실행을 다룹니다. 패키지만 쓰는
하위 프로세스 스모크 테스트는 `studies` 패키지 없이 패턴이 있는 셀을 구성합니다. 명령과 결과는
`studies/rcwa/nvf_energy_engine/records/nvf_conforming_shapes_validation.log`에 기록되어 있습니다.

처음의 형상 통합 검증은 통과한 공개 API 검사 48개, 통과한 공유 커널 및 엔진 회귀 검사 204개, 통과한
문서 계약 검사 29개를 기록했습니다. 기존의 엄격한 예상 실패 하나는 예전 고정 P1 모델의 움직이는
계면 한계를 기록합니다. 공개 빌더가 쓰는 다항식 몸체 모델은 그 대조 실험을 통과합니다. 수동 예제
두 개, 엄격한 Sphinx 빌드, lint, diff 공백 검사도 통과합니다.

접촉 미분 테스트는 유한 차분 간격을 훑습니다. 700단위 구성에서 1e-4 간격은 접촉 근처의 짧은 길이
척도를 분해하지 못합니다. 1e-6과 1e-7의 두 창은 같은 절대 기준 3e-6으로 JAX 미분과 일치합니다.
이것은 유한 셀의 미분 대조 실험이며, 광학 수렴 문턱값이 아닙니다.

## 재현과 남은 범위

[공개 설명서](../../guide/rcwa/conforming-nvf.md)에는 독립 실행 풀이와 JAX 예제, 해상도 기본값, 재료
의미, 명시적인 거부 규칙이 있습니다. NumPy와 JAX x64가 셀을 구성하며, NumPy로 내보낸 결과는 Torch
엔진으로 옮길 수 있습니다. 더 낮은 수준의 에너지 닫힘 자체는 세 배열 프레임워크와 복소 재료 데이터를
모두 받아들이고, 직사각형 생성자는 모든 재료와 배경에 대해 서로 독립인 손실비를 가진, 실수부가 양인
수동 재료를 지원합니다.

[직사각 셀 확장](nvf-rectangular-cells.md)은 살아 있는 물리 종횡비 계량을 제공하며, 에너지 정상성,
구적법, 주기 미분에 대한 별도의 대조 실험이 있습니다. 또한 높이를 정규화할 때 반올림 오차로 작동할
수 있던 그래디언트 0 접촉 고정(clamp)을 없앱니다.

[층 축 확장](nvf-layer-axes.md)은 같은 적층 안에서 첫째 축과 둘째 축 타일링을 허용합니다. 닫힘 전에
모든 층을 솔버의 원래 카르테시안 좌표계와 유지 차수 배치로 되돌립니다. 계획(plan)은 순서와 축을 모두
고정하며, 1/4 회전으로 동등한 직사각형 표기는 기하와 다섯 행렬을 모두 보존합니다.

[분리된 직사각형 확장](nvf-separated-rectangles.md)은 형상 사이에 살아 있는 배경 구간을 끼워 넣습니다.
폭이 0인 구간과 그 열림 미분을 유지하며, 부호 있는 로그 도약 단계화(grading)를 써서 일치하는 경계가
합쳐지거나 상쇄되게 합니다. 이는 단계형 셀이 쓰는 유한 근사를 바꿉니다. 과거의 측정은 원래 밀도를
유지합니다.

[공통 손실 확장](nvf-common-loss.md)은 패턴이 있는 각 층의 셀 방정식에서 공유된 수동 복소 스칼라를
인수로 뽑아냅니다. 실수 저장 셀 구성은 보존하고, 그 인자를 역 세로 칸을 포함한 에너지 닫힘에
적용합니다. 균일 층은 서로 독립인 수동 유전율을 가질 수 있습니다. 바탕이 되는 실수 셀은 인수로
뽑지 않은 허수 재료 값을 명시적으로 거부합니다.

[복소 재료 확장](nvf-complex-material.md)은 복소 보정기, 켤레 시험 필드, 서로 독립인 교차 에너지 항을
써서 공통 비율 제약을 없앱니다. 원래의 실수 커널은 그 연구를 재현할 수 있도록 계속 제공합니다.

임의의 형상, 격자에 정렬되지 않은 물체 모서리, 전단된 보정기 셀, 보통 솔버의 `nvf_projector` 설정을
통한 자동 선택, 사용 사례 전반에 걸친 정확도 자격 확인은 별도의 작업으로 남아 있습니다. 기존의 원형
형상 투영기는 계속 제공합니다. 이 통합은 잠정적인 1e-5 연구 증분을 제품 정확도 요구 사항으로 만들지
않습니다.

```bash
PYTHONPATH=$PWD python -m pytest -q tests/rcwa/test_nvf_energy_builder.py tests/rcwa/test_nvf_thin_gap_energy.py tests/rcwa/test_nvf_polynomial_body.py tests/rcwa/test_nvf_local_flux.py tests/rcwa/test_nvf_posed_gap.py tests/rcwa/test_slot_order.py
PYTHONPATH=$PWD python -m pytest -q tests/rcwa/test_conforming_nvf.py
```

[격자 기저 재설정 확장](nvf-lattice-rebasing.md)은 같은 직교 점 격자를 기술하는 비스듬한 기저 벡터를
받아들입니다. 물리 직사각형, 주어진 셀 중심 규약, 정확한 원래 푸리에 집합을 보존합니다. 진짜로
직교하지 않는 점 격자에는 여전히 다른 셀 구성이 필요합니다.
