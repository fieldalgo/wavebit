## 판정

일반적인 수동, 등방성, 비자성 매질에서 **입사 쪽은 무손실이고 출사 쪽만 흡수하는** 경우는 물리적으로
잘 정의됩니다. 이 단일 계면 검사에서 Wavebit의 반사율과 계면 투과 전력은 Fresnel 및 Poynting 계산과
일치했습니다. 여기서 투과 전력은 기판으로 **들어가는** 전력을 뜻하며, 흡수하는 기판을 무한히 지나고도
남는 전력이 아닙니다.

**흡수하는 입사 매질**도 기준 평면과 입사파를 정하면 전력을 정의할 수 있습니다. 그러나 Wavebit의
현재 `R`/`T`는 그 정의대로 구현되어 있지 않습니다. 일부 진폭 검사가 통과한다는 것은 전력을 올바르게
계산하는 것과 별개의 문제입니다.

`docs/reference/common/conventions.md`의 "정의에 따라 달라지므로 계산 경로 사이의 차이를 허용한다"는
문장은 이 결함을 정당화하지 않습니다. 같은 입력과 같은 기준 평면이라면 모든 계산 경로가 같은 물리량을
돌려주어야 합니다.

## 논문이 다루는 범위

Moharam et al., *Formulation for stable and efficient implementation of the rigorous
coupled-wave analysis of binary gratings*, JOSA A 12, 1068–1076 (1995). PDF로 읽었으며, 수식이 실린
쪽은 이미지로 확인했습니다.

- p.1069 식 (7)과 p.1072 식 (52)는 실수 크기를 비교해 출사 회절파의 전파하는 가지와 소멸하는 가지를
  나눕니다. 그 분류는 복소 굴절률에 그대로 옮겨 가지 않습니다.
- p.1072 식 (45)의 TM 투과 효율은 분자의 실수부를 입사 쪽 정규화 인자와 따로 둡니다. 여기에 복소 입사
  굴절률을 대입하는 것은 그 자체로 유도가 아닙니다.
- 격자 재료 안의 흡수를 다루는 것과 흡수하는 입사 매질에서 전력을 정의하는 것은 서로 다른 범위입니다.
- "모든 반공간의 굴절률은 물리적으로 실수여야 한다"는 보편적인 주장은 논문에서 나오지 않습니다. 이는
  주어진 수식이 적용되는 조건을 읽어 낸 것이지, 두 바깥 굴절률이 실수여야 한다고 말하는 문장을 인용한
  것이 아닙니다.

NIST SCATMECH는 비교해 볼 만한 실제 RCWA 구현입니다. 위쪽 입사에 대해 반사만 계산하는 모드에서는
흡수하는 기판을 허용하고, 다른 모드에서는 흡수하지 않는 기판을 요구합니다. 관측값별로 지원 경계를 긋는
예입니다.
[NIST RCW_Model](https://pages.nist.gov/SCATMECH/docs/rcwmodel.htm)

## 독립 기준

단일 평면 계면에서, 계면까지 외삽한 입사파만의 전력을 기준으로 삼았습니다. `q = kz/k0`,
`β = k_parallel/k0`라고 하면 다음과 같습니다.

```text
q_j² = ε_j μ_j − β²
TE: use the E amplitude, Y_j = q_j / μ_j
TM: use the H amplitude, Z_j = q_j / ε_j
```

`Y`와 `Z` 가운데 편광에 해당하는 쪽을 `a`라고 쓰면, 경계 조건에서 다음을 얻습니다.

```text
r = (a₁ − a₂) / (a₁ + a₂)
t = 2 a₁ / (a₁ + a₂)
R = |r|²
T = |t|² Re(a₂) / Re(a₁)
```

여기서 TM `t`는 H 진폭비입니다. Wavebit의 공개 E 진폭과 비교하려고 `(n₁/μ₁)/(n₂/μ₂)`를 곱했습니다.
이 검사에서는 세 조건 아래에서 이 공식을 썼습니다. 실수 가로 파수 벡터, 등방성 매질, 0이 아닌 입사
전력입니다.

흡수하는 입사 매질에서는 입사파와 반사파가 간섭하므로, 계면에서 실제로 들어가는 순 전력이 일반적으로
`1−R`와 다릅니다. 같은 진폭 변수로 쓰면 다음과 같습니다.

```text
P_enter / P_inc = Re[(1+r)* a₁ (1−r)] / Re(a₁)
```

여기서 `(1+r)*`의 별표는 복소 켤레입니다. 단일 계면에서는 이것이 위의 `T`와 같습니다. 그래서
흡수 입사 문제에서 `R+T≠1`만으로는 오류의 증거로 보지 않았습니다.
[Byrnes, §4.3–4.4 and Appendix B](https://arxiv.org/html/1603.02720v5)

## 재현

NumPy complex128, 파장 500 nm, 0차 회절 차수만 사용했습니다. 단일 계면은 두께 0의 균일 층으로
표현했습니다. TE/TM, 1D/2D, ETM/SMM을 비교했습니다. 각도의 단위는 라디안입니다.

| 경우 | 독립 계산 | Wavebit |
|---|---|---|
| 공기 → ε=4+0.6i, μ=1, θ=0.45, TE | R=0.139374746, T=0.860625254 | 일치 |
| 같은 계면, TM | R=0.090828202, T=0.909171798 | 일치 |
| 공기 → n=0.18+3i, μ=1, θ=0.45, TM | R=0.922979811, T=0.077020189 | 일치 |
| n=1.5+0.3i → 공기, μ=1, 수직 입사, TE | R=0.053627760, T=0.984227129 | R 일치, T=0.946372240 |
| 같은 계면, 2D TM | R=0.053627760, T=0.984227129 | R=0.049502548, T=0.946372240 |
| 양쪽이 같은 흡수 매질, 두께 0, TM | R=0, T=1 | 1D T=1, 2D T=0.923076923 |

두께 0 표현이 원인일 가능성을 배제하려고, 반사하는 계면이 없는 균일 흡수 매질 안에서 75 nm 떨어진 두
평면 사이의 전력도 확인했습니다. `ε=2.16+0.9i`, `μ=1`, 즉 `n=1.5+0.3i`, 수직 입사에서

```text
T = exp(−4π Im(n) d / λ) = 0.568083605878
```

1D TE/TM과 2D TE는 일치했습니다. 2D TM은 `0.524384866964`를 주어 약 7.69% 낮았습니다. 같은 결함이
위쪽 입사와 아래쪽 입사에서, 그리고 2차 경로와 1차 경로에서 재현되었습니다. 이 경우에는 반사파가
없으므로, 간섭을 정규화하는 방식의 차이로는 설명할 수 없습니다.

최소 재현:

```python
import numpy as np
from wavebit.compat import legacy as wavebit

common = dict(
    backend='numpy',
    top=2.16 + 0.9j,
    bot=2.16 + 0.9j,
    structure=np.full((1, 2, 2), 2.16 + 0.9j),
    thickness=[75.], wavelength=500., period=[1000., 1000.],
    truncation_order=0, theta=0., phi=0.,
)
for psi in (np.pi / 2, 0.):
    result = wavebit.rcwa(psi=psi, **common).solve()
    print(result.T.sum())
# TE: 0.5680836058777344
# TM: 0.5243848669640628
```

2026-10-13부터 이 솔버 인터페이스는 위와 같이 가져오는 `wavebit.compat.legacy`입니다. 수정 뒤에
실행하면 두 줄 모두 TE 값을 출력합니다.

이 조사에서 확인한 것:

- 단일 계면 설정 11개 × 편광 2개 × 경로 2개 × 알고리즘 2개 = 호출 88번. 그 가운데 음의 굴절률 사례는
  아래에서 따로 설명합니다.
- 균일 흡수 매질 안의 두 기준 평면: 입사 쪽, 정식화(2차 또는 1차), TE/TM의 조합 8가지.
- 기존 흡수 매질 테스트에서 273 passed, 70 deselected. 선택한 것: 기판 반사, 기판으로 들어가는 전력의
  보존, 반사/투과 진폭, 그리고 흡수 입사에서 경로 차이를 고정하는 테스트.
- 이 조사는 일반 패턴의 모든 회절 차수나 모든 백엔드를 보증하지 않습니다.

기존 테스트가 왜 통과했는지도 확인했습니다. 당시의
`test_absorbing_superstrate_efficiency_is_convention_bound`는 올바른 전력 대신 1D와 2D 사이의 TM 차이
인자를 주어진 그대로 검사했습니다. 1단계에서 이 테스트는
`tests/rcwa/test_lossy_media.py::test_absorbing_incident_reflectance_matches_airy`로 바뀌었습니다. 이
테스트는 수직 입사와 실수 가로 파수 벡터 `n_top·sinθ = 0.5`에서, ETM과 SMM 모두에 대해, 1D와 2D TM
반사율이 Airy `|r_p|²`와 `1e-12` 이내로 일치하는지, 두 경로의 `r_p` 진폭이 `1e-12` 이내로 일치하는지
검사합니다.

## 구현 안의 원인

1. `src/wavebit/rcwa/_engine/solve_1d.py::sp_efficiencies`는 `Re(a_out / a_inc)` 꼴을 씁니다. 입사 인자가
   복소수이면 이는 전력비에 필요한 `Re(a_out) / Re(a_inc)`와 다릅니다. 순수 1D 경로와 `scattering.py`도
   같은 꼴입니다.
2. 결합된 s/p 경로는 복소 입사 매질에서도 두 편광에 복소 정규화 인자 하나를 똑같이 적용합니다. 실제 입사
   전력은 E/H 진폭과 편광별 어드미턴스로 계산해야 합니다. 복소 입사각에서는 s/p 가중치도 확인해야
   합니다.
3. `check_physical`(2026-10-03 제거)은 입사 굴절률이 복소수이면 전력 검사를 건너뛰었습니다. 위에서
   재현한 일반적인 흡수 입사 사례는 아무 경고 없이 값을 돌려주었습니다.
4. `engine.py::_incident_kxy`에서 복소 굴절률에 실수 입사각을 곱하면 가로 파수 벡터도 복소수가 됩니다.
   이는 세기가 표면을 따라서도 변하는 입사파입니다. 실수 가로 파수 벡터를 가정하는 차수별 전력 합산을
   여기에 그대로 확장할 수는 없습니다. 가로 파수 벡터가 실수가 되도록 고른 복소 입사각으로 단일 계면을
   계산해도 전력 오차가 재현되었으므로, 이 결함은 복소 가로 파수 벡터만으로 생기는 것이 아닙니다.

## 자성 반공간에서 발견한 가지 선택 문제

`engine.py::_half_space_index`의 "수동 ε, μ에 대해 εμ는 복소 상반 평면에 있다"는 주장은 일반적으로
성립하지 않습니다.

```text
ε = μ = −1 + 0.1i
ε μ = 0.99 − 0.2i
principal sqrt(ε μ) = +1 − 0.1i
index of the passive outgoing wave = −1 + 0.1i
```

출사파는 구조에서 멀어질수록 감쇠하고 그 방향으로 에너지를 날라야 합니다. 이 예에서 물리 어드미턴스
`n/μ=1`은 공기와 같으므로, 수직 입사에서 R=0이고 계면 T=1입니다. 현재 구현은 반대쪽 가지를 고르며,
단일 계면 풀이가 `Singular matrix`를 일으킵니다.

정확한 임피던스 정합이 원인인지도 확인했습니다. 출사 매질을 `ε=−2+0.1i`, `μ=−1+0.1i`로 바꾸면 독립
계산은 `R=0.029282057`, `T=0.970717943`를 줍니다. 현재 결과는 `R=34.150606141`, `T=−33.150606141`이며
비물리적 결과 경고가 함께 나옵니다. 실수부가 양인 기판 `ε=4+0.2i`, `μ=1.5+0.1i`는 통과했습니다.

2026-10-04부터 자성 반공간은 부호 있는 굴절률 `sqrt(ε)*sqrt(μ)`를 쓰며, 위의 두 예 모두 독립 값으로
풀립니다(`R=0`, `T=1`; `R=0.029282057`, `T=0.970717943`).
[`negative-index-media.md`](../../theory/rcwa/negative-index-media.md)를 보세요.

## 지원 범위와 수정 방향

- 일반적인 무손실 입사 매질 아래에서 수동 흡수 기판을 유지할 근거는 있습니다. `T`의 기준 평면은 구조와
  기판 사이의 계면이라고 밝혀야 합니다.
- 흡수하는 입사 매질에서는 현재 `R`/`T`를 검증된 효율로 내놓아서는 안 됩니다. 실제 입사 면은
  `incidence_side`에 따라 달라지므로 `top`만 검사하는 것으로도 충분하지 않습니다.
- 이를 지원하려면 정규화를 기준 평면의 Poynting 전력으로 통일하고, `power_entering`을 층 흡수와
  분리해야 합니다. 기존 진폭이 맞는 사례를 보존하면서 독립 전력 기준과 비교해 테스트해야 합니다.
- 실수 가로 파수 벡터의 입사와 복소 가로 파수 벡터의 입사를 분리하고, 후자의 차수별 전력과 모드 가지는
  따로 정의해야 합니다.
- 자성 바깥 매질의 가지 선택은 `sqrt(ε μ)`의 주값만으로 보장되지 않습니다.
- 이방성 `top`/`bot`은 현재 입력 단계에서 거부합니다. 이를 구현하려면 바깥 매질 고유 모드, 입사 모드,
  전력 정규화를 함께 설계해야 하며, 스칼라 검사 하나를 지우는 일로 끝나지 않습니다. 이 조사는 그런
  구현을 검증하지 않았습니다.

외부 솔버 코드나 새 의존성은 들여오지 않았습니다.

## fmmax와 RETICOLO 직접 실행

같은 날 후속 요청에 따라, 기존 외부 검증 환경에서 fmmax 1.7.1과 RETICOLO V10을 직접 실행했습니다.

### 물리 문제 정의

유한한 위치의 소스에서 계면까지 진행하는 빛은 흡수하는 입사 매질에서도 물리적으로 가능합니다. 그러나
입사파만 보아도 전파 거리 `L`에 따라 `exp(−αL)`로 전력을 잃습니다. 소스 전력을 유한하게 두고 `L→∞`로
보내면 계면에 도달하는 입사 전력은 0으로 갑니다. 따라서 무손실 바깥 매질에서처럼 무한원에서의 일정한
입사 진폭을 기준으로 쓸 수 없습니다.

이 실험은 **계면까지 외삽한 입사파만의 전력**으로 정규화했습니다. 반사파와 합친 순 전력은 경계 조건과
에너지 흐름을 확인하려고 따로 계산했습니다. 복소 입사 매질을 일반적으로 지원하려면 이 기준 평면, 파수
벡터, 정규화 정의가 API에서 명시적이어야 합니다.
[Byrnes, Appendix B](https://arxiv.org/html/1603.02720v5)

### 기존 진폭을 다시 계산하는 것만으로 이미 고쳐지는 것

실수 가로 파수 벡터, 등방성 바깥 매질, 균일 층으로 된 기준 구조 여덟 개를 확인했습니다. 무손실 대조
실험, 흡수하는 출사 매질, 흡수하는 입사 매질, 흡수 매질 하나 안에서의 75 nm 전파, 흡수 입사 매질 아래의
유한 막, 그리고 실수부가 양인 복소 ε·μ를 가진 입사 매질입니다. 위/아래 입사, TE/TM/혼합 편광,
1D·conical·2D·1차, 그리고 지원하는 ETM/SMM 조합을 합쳐 **304** 번 풀었습니다. 1차 경로는 현재 지원하는
유일한 ETM만 포함했습니다.

- 공개 복소 반사/투과 진폭의 독립 경계 조건/Airy 계산 대비 최대 오차: `8.25e-16` 미만.
- 그 진폭으로 다시 계산한 R/T의 독립 계산 대비 최대 오차: `1.00e-15` 미만.
- 무손실 입사 대조 실험에서는 기존 R/T도 일치했습니다.
- 이는 반사/투과 진폭을 검증합니다. 전체 내부 필드, 일반 패턴의 수렴, 모든 백엔드와 미분을 검증했다는
  뜻은 아닙니다.

| 경우, 2D TM | 현재 반환값 | 기존 진폭으로 전력 재계산 | 독립 계산 |
|---|---:|---:|---:|
| n=1.5+0.3i → 공기, 수직 입사: R | 0.049502548 | 0.053627760 | 0.053627760 |
| 같은 계면: T | 0.946372240 | 0.984227129 | 0.984227129 |
| 같은 흡수 매질 안에서 75 nm 전파: T | 0.524384867 | 0.568083606 | 0.568083606 |

마지막 사례에는 반사파가 없습니다. 따라서 이 오류는 간섭 항이 빠진 것이 아니라 **이미 올바른 진폭의
전력 변환/정규화** 문제입니다.

공개 s/p 진폭을 그대로 쓰면, `q=kz/k0`인 한 차수의 전력 가중치는 공통 단위 인자를 빼고 다음과
같습니다.

```text
w_s = Re(q / μ)
w_p = |n / μ|² Re(q / ε)
P_inc ∝ w_s,inc |a_s|² + w_p,inc |a_p|²
```

따라서 각 출사 차수의 `w_s |r_s|² + w_p |r_p|²` 또는 `w_s |t_s|² + w_p |t_p|²`를 **같은 실제 입사
전력**으로 나누기만 하면 됩니다. 이 공식의 p 진폭은 Wavebit의 현재 공개 진폭 정의를 따릅니다. 내부 TM
H 진폭을 직접 쓰면 가중치는 `Re(q/ε)`입니다. 모든 `real(a / denom)`을 `real(a) / real(denom)`로 바꾸는
것만으로는 s/p 및 혼합 편광 정규화가 해결되지 않습니다.

이와 별도로, 두 회절 차수가 한꺼번에 입사하는 균일 흡수 매질을 8번 확인했습니다. 기본 차수 수직 입사,
`(0,0)` 진폭 1과 `(1,0)` 진폭 `0.5i`, 주기 1000 nm, 파장 500 nm, 전파 거리 75 nm입니다. 이론적 TM
투과율은 `0.564563926081`입니다. 현재 1D는 `0.564589751100`을, conical/2D/1차는 `0.565551868830`을
돌려줍니다. 기존 진폭의 차수별 전력을 다시 계산하자 모든 경로가 이론값과 `1e-15` 이내로 맞았습니다.
`_incident_flux`의 단순한 `Σ|a_m|² Re(q_m)`도 마찬가지로 편광과 매질에 맞는 실제 전력 가중치가 되어야
합니다.

### 입사 설정 자체를 바꿔야 하는 것

`engine.py::_incident_kxy`는 `n_inc sin(theta)`를 씁니다. 흡수하는 입사 매질에서 실수 각도는 일반적으로
가로 파수 벡터를 복소수로 만듭니다. `n=1.5+0.3i`, `theta=0.4`, `phi=0`에서 지금 실제로 반환되는 값은
다음과 같습니다.

```text
kx/k0 = 0.584127513463 + 0.116825502693 i
```

파장 500 nm에서 x를 따라 1000 nm 움직이면 입사파의 `|E|²`에 약 `0.053069913`이 곱해집니다. 이는 세기가
표면을 가로질러서도 변하는 물리적 입사파이며, 허수부를 그냥 버리면 다른 문제를 풀게 됩니다.

실수 가로 파수 벡터를 지정할 수 있는 입사 입력이 수정의 첫 범위로 알맞습니다. 위의 304번 풀이 검사는
`theta=arcsin(beta/n_inc)`로 그 조건을 만들었습니다. 복소 가로 파수 벡터를 표준 효율로 지원하려면 단위
셀 위의 전력 적분, 그리고 기준 평면과 가로 방향 에너지 흐름을 따로 정의해야 합니다. 공통 Bloch 인자가
감쇠하므로 서로 다른 푸리에 차수 사이의 전력 교차 항도 셀 적분에서 일반적으로 사라지지 않습니다. 따라서
실수 가로 파수 벡터에 대한 차수별 대각 가중치를 재사용해서는 안 됩니다.

### 효율 재계산으로 고쳐지지 않는 것으로 확인된 반례

자성 바깥 매질의 가지 선택 문제도 재현되었습니다.

- `ε=μ=-1+0.1i`: 현재 n은 `1-0.1i`이고 수동 출사파의 n은 `-1+0.1i`입니다. 현재 솔버는
  `Singular matrix`를 일으킵니다. 올바른 계면은 임피던스 정합되어 R=0, T=1입니다.
- `ε=-2+0.1i`, `μ=-1+0.1i`: 현재 R=`34.150606141`, T=`-33.150606141`. 올바른 값은
  R=`0.029282057`, T=`0.970717943`입니다.

여기서는 반사/투과 진폭을 만드는 경계 조건 자체가 이미 틀렸으므로, 결과를 다시 정규화해서는 고칠 수
없습니다. `_half_space_index`와 `boundary_kz`가 ε·μ와 실제 전력 방향을 함께 고려하도록 바꿔야 합니다.
실수 가로 파수 벡터의 수동 반공간에서는 규칙이 바깥으로 감쇠하는 파동을 골라야 하고, 감쇠 없는 전파하는
파동에서는 위상 진행의 부호가 아니라 전력 방향으로 골라야 합니다. 이 규칙을 복소 가로 파수 벡터나 이득
매질로 무조건 확장하지는 않습니다.

### 필요한 변경, 순서대로

1. **기준 평면과 반환량:** 위쪽 입사에서는 구조의 위쪽 면에서, 아래쪽 입사에서는 아래쪽 면에서 입사파만의
   전력을 분모로 삼습니다. R/T는 파동별 전력비로 유지하고, 입사파와 반사파를 합친 필드가 구조로 보내는 순
   전력 `power_entering`을 따로 계산합니다. 한쪽 입사의 실수 가로 파수 벡터에서 유한 구조의 흡수는
   `power_entering - T`이며, 흡수 입사에서는 `1-R-T`로 대신하지 않습니다. 여기서 `power_entering`도
   입사 전력으로 정규화합니다.
2. **공유 전력 계산:** 순수 1D 효율 공식, `sp_efficiencies`, 대응하는 SMM 공식, 다중 차수
   `_incident_flux`를 하나의 E/H 전력 정의로 통일합니다. 실수 가로 파수 벡터에서는 모드 진폭에서 바로
   계산할 수 있으며, 이를 위해 필드를 전체 공간 격자에 다시 그릴 필요가 없습니다. 이미 올바르다고 밝혀진
   진폭, NVF/푸리에 행렬, 내부 층 연결은 보존할 근거가 있습니다.
3. **흡수 입사 입력:** 실수 가로 파수 벡터를 지정하는 입력을 정의하고 복소 가로 파수 벡터 계산과
   구분합니다. `polarization`은 현재 전기 진폭 쌍의 유클리드 노름을 정규화하므로, 단위 실제 전력으로
   정규화한다고 설명해서는 안 됩니다. API는 현재 입사 진폭 정의를 유지하고 별도의 실제 전력 분모를 계산할지,
   전력으로 정규화한 모드 입력을 추가할지 명시적으로 정해야 합니다.
4. **자성 바깥 매질:** n과 kz의 가지, 그리고 입사 모드의 전력 방향 검사를 고칩니다. `_incident_flux`가
   `Re(kz)>0`만으로 전력 방향을 판단하는 것도 함께 고칩니다.
5. **검사와 설명 교체:** `check_physical`이 복소 입사에서 모든 검사를 건너뛰는 것을 고치고, 순 전력과
   유한 층 흡수의 수지를 검사합니다. `R+T>1`만으로 흡수 입사를 오류로 판단하지 않습니다. 경로 차이를
   정답으로 고정하는 기존 테스트와 문서는 같은 물리량에 대한 일치 검사로 바꿉니다.

구현 뒤에는 일반 패턴의 여러 회절 차수, 전체 s/p 응답, 위/아래 입사, 복소 μ, NumPy/JAX/PyTorch와 미분을
검증해야 합니다. 이 검사는 수정 범위를 정했을 뿐, 솔버 수정이나 그 전체 범위의 검증을 완료하지
않았습니다.

### 1. 효율 변환을 하나의 전력 계산으로 합치기

효율 계산은 한 함수에 있지 않습니다. 실제 호출 관계는 다음과 같습니다.

```text
ETM, pure 1D ────────────────────── the efficiency formula inside solve_1d()
ETM, conical / 2D / first-order ─── final_matching() → sp_efficiencies()
SMM, pure 1D ────────────────────── the efficiency formula inside smm_1d()
SMM, conical / 2D ───────────────── _smm_sp() → sp_efficiencies()
```

| 위치 | 현재 문제 | 필요한 변경 |
|---|---|---|
| `src/wavebit/rcwa/_engine/solve_1d.py:474–486`, `solve_1d` | 반사와 투과 모두 복소 비를 먼저 만든 뒤 실수부를 취함 | 실제 입사 전력을 먼저 계산하고 각 출사파의 실제 전력을 그것으로 나눔 |
| `src/wavebit/rcwa/_engine/solve_1d.py:653–684`, `_incident_flux` | 여러 입사 차수의 가중치가 `Re(kz)`뿐이며 편광, ε, μ를 받지 않음 | 각 입사 차수의 실제 s/p 진폭과 ε·μ를 받아 전력을 합산 |
| `src/wavebit/rcwa/_engine/solve_1d.py:838–875`, `final_matching` | 지정 편광 결과와 순수 s/p 결과가 분모 하나를 공유 | `incident`, `s_inc`, `p_inc` 각각의 입사 진폭으로 분모를 계산 |
| `src/wavebit/rcwa/_engine/solve_1d.py:886–905`, `sp_efficiencies` | `Re(admittance / complex_denom)`를 씀 | 실제 입사 편광의 전력을 분모로 삼아 `Re(admittance) / real_incident_power`를 계산 |
| `src/wavebit/rcwa/_engine/scattering.py:525–549`, `smm_1d` | 순수 1D 효율 공식이 따로 중복되어 있음 | ETM과 같은 공유 전력 계산을 호출 |
| `src/wavebit/rcwa/_engine/scattering.py:700–747`, `_smm_sp` | 입사 열 세 개를 만들지만 효율 분모는 하나만 씀 | 실제 `c_inc`의 열마다 전력을 계산하고 출력 열을 열별로 나눔 |

`sp_efficiencies`의 p 입력은 공개 `r_p`가 아니라 위상을 곱한 **H 진폭**입니다. `q=kz/k0`와 내부 계면
진폭 `c_s`, `c_p`로 쓰면, 실수 가로 파수 벡터의 등방성 반공간에서 분리된 한 방향 파동 하나의 전력은 공통
단위 인자를 빼고 다음과 같습니다.

```text
P_order = |c_s|² Re(q/μ) + |c_p|² Re(q/ε)
P_inc   = sum(P_order for incident orders)
R_order = P_reflected_order / P_inc
T_order = P_transmitted_order / P_inc
```

이를 공개 p 진폭에 적용하려면 앞 절의 `|n/μ|²` 변환이 필요합니다. 순수 1D TM은 입사 H 진폭을 1로 두는
반면 결합 경로는 입사 E 계수를 H로 바꾸므로, 각 경로는 **실제로 쓴 입사 진폭**을 공유 함수에 넘겨야
합니다. (순수 TM 풀이의 전력 계산에는 지금도 해당합니다. 2026-09-27부터는 그 풀이가 재구성에 넘기는 필드
상태를 결합 경로와 마찬가지로 단위 입사 E로 배율 조정합니다.) 경로마다 다른 복소 분모를 넘기는 오늘의
인터페이스를 유지한 채 공식만 바꾸면 같은 문제가 남습니다.

공유 함수를 둘 곳으로는 별도의 내부 모듈(예: `src/wavebit/observations/power.py`)이 알맞습니다. 그 입력은
매질, 차수별 파수 벡터, 그리고 실제 입사·반사·투과 진폭입니다. 전력 계산에는 전체 공간 필드의 재구성도,
두 번째 고유값 문제도 필요하지 않습니다. NumPy/JAX/PyTorch는 같은 공식을 쓰며, 값을 읽을 수 있을 때 입사
전력의 유한성과 양수 여부를 검사합니다.

이것은 TM만의 수정이 아닙니다. 앞서의 기준 사례 `n_inc=1.5+0.3i → air` 수직 입사에서 **TE 투과율도
현재 0.946372239748이며 올바른 값은 0.984227129338입니다**. 이 조건에서 TM은 반사율까지 틀리고, 위의 균일
매질 전파 예에서도 오류가 드러나므로 TM을 대표 사례로 삼았습니다.

### 2. 함께 반환하는 순수 편광 결과의 입사 열 고치기

별개의 오류도 확인했습니다. 다중 차수 입사에서 `final_matching`의 일반 입사 열은 `Kz_top @ delta`를
쓰지만(`solve_1d.py:802–807`), 순수 s/p 결과의 열은 언제나 `kz_inc * delta`를 씁니다(`:817–823`). 즉
중심 차수의 파수 벡터를 모든 입사 차수에 적용합니다. **분모를 고쳐도 이 진폭 오류는 그대로 남습니다.**

- 설정: 전부 한 재료, 두 입사 차수 `(0,0): 1`, `(1,0): 0.5i`, 파장 500 nm, 주기 1000 nm, 두께 75 nm.
  반사가 없어야 합니다.
- 무손실 ε=2.25와 흡수 ε=(1.5+0.3i)², TE/TM, conical/2D/1차, 그리고 지원하는 ETM/SMM: 모두 20번 검사.
- 무손실 ETM에서 `incident`의 R은 약 `1e-31`인 반면, 같은 순수 편광을 뜻하는 `s_inc`/`p_inc`의 R은
  `0.0001754677013`입니다. 복소 진폭은 최대 약 `0.0151650`만큼 다릅니다.
- 흡수 ETM에서도 같은 불일치가 생깁니다. SMM 비교 8개에서는 진폭 차이가 0입니다.

수정은 `incident`와 순수 s/p 열을 같은 입사 열 생성기로 만드는 것입니다. 모든 열에 차수별 파수 벡터와
같은 `delta`를 적용한 뒤, 각 열의 실제 입사 전력을 따로 계산합니다. `tests/rcwa/test_excitation.py`의 현재
다중 입사 비교는 대부분 `incident`만 검사하므로, `s_inc`/`p_inc`가 같은 편광을 직접 지정한 `incident`와
일치하는지 확인하는 회귀 검사가 필요합니다.

앞 절의 304번 풀이 진폭 일치는 단일 입사의 `incident`에 대한 것이고, 8번 풀이 다중 입사 전력 검사도
`incident`에 대한 것입니다. 이 발견은 그 검사들이 살펴보지 않은 결과 열의 오류입니다. 손실이 없어도 생기며,
흡수 입사의 효율 오류와 혼동해서는 안 됩니다.

### 4. 비스듬한 입사 입력과 파수 벡터 가지를 따로 고치기

**실수 가로 파수 벡터 입력**의 중심은 `engine.py:1727`, `_incident_kxy`입니다. 각도에서 변환하는 입력과

역수인지, k0로 정규화한 값인지), 각도와 함께 주었을 때의 검사, 수직 입사에서 s/p 기준 방향을 정하는

새 입력은 다음까지 전달되어야 합니다.

- `domain.py:632`, `Incidence`와 `as_kwargs`.
- `spec.py:874`, `_incidence_from_dict`, `:972`, `_incidence_to_dict`와 spec 키.
- `engine.py` 생성자, `_incident_kxy`, 1D 선택과 입사 검증, 그리고 `:2883`, `_reconstruction_scene`의

  y 성분이 있는 입사가 순수 1D TE/TM으로 보내지지 않는지 확인하는 검사.

이것은 흡수하는 **수직 입사만** 고치는 데 필요한 선행 조건이 아닙니다. 수직 입사 효율 회귀를 먼저 고치고
비스듬한 입사 지원을 나중에 더할 수 있습니다. 복소 가로 파수 벡터에 대한 일반적인 셀 적분 지원은 이
실수 가로 파수 벡터 전력 공식과 별개의 작업입니다.

**자성 매질의 파수 벡터 가지**는 `engine.py:177`, `_half_space_index`와 `conventions.py:195`,
`boundary_kz`에서 함께 고칩니다. `boundary_kz`의 매개변수 이름은 현재 `eps`이지만, 모든 솔버 호출 지점은
실제로 `n**2=εμ`를 넘깁니다. ε와 μ를 구별할 수 없는 인터페이스부터 정리해야 합니다. 투자율을 고려하는
전력 방향 검사가 필요하며, 실수 가로 파수 벡터의 수동 문제에서는 감쇠하는 가지와 무손실 극한의 전력
방향을 일관되게 골라야 합니다.

호출 지점은 `solve_1d.py`의 두 솔버, `solve_2d.py`, `solve_2d_first_order.py`, 그리고 `scattering.py`의 두
계산 경로입니다. `_incident_flux`의 `Re(kz)>0` 검사도 바뀌어야 합니다. `refractive_index_from_eps` 같은
일반 변환 함수의 의미를 무조건 바꾸거나, 내부 유한 층에 대한 `mode_q`에 같은 규칙을 대입하는 것은 수정
범위 밖입니다. 반공간의 경계 조건과 내부 유한 층의 모드 표현은 구분해 두어야 합니다.

## 1단계: 분리된 파동의 전력과 효율

2026-09-22, 위의 조사에 이어 **효율 변환과 입사 전력 분모**를 고쳤습니다. 앞 절들의 조사 결과와 수정
명세는 수정 이전의 상태를 기록합니다.

다음 계산을 `src/wavebit/observations/power.py`에 모았습니다.

```python
wave_power = real(amplitude * conj(amplitude)) * real(admittance)
efficiency = wave_power / incident_power
```

여기서 어드미턴스는 내부 전기장 진폭에 대해서는 `kz/mu`, 내부 자기장 진폭에 대해서는 `kz/epsilon`입니다.
입사 전력은 실제 입사 차수들의 전력을 합합니다. 공개 전기 p 계수를 내부 자기 진폭으로 바꾸는 `n/mu`
인자도 포함합니다. 복소 비를 먼저 만들고 나중에 실수부를 취하는 일은 없습니다.

- 순수 1D ETM/SMM, conical/2D ETM/SMM, 1차 ETM이 같은 전력 정의를 씁니다.
- 지정 편광 결과와 순수 s/p 결과의 분모를 따로 계산합니다.
- 함께 반환하는 순수 s/p 결과의 입사 열도 각 차수의 파수 벡터를 씁니다. 단일 입사 진폭 계산과 내부
  NVF/푸리에 행렬은 바꾸지 않았습니다.
- 출사 쪽 epsilon을 공유 효율 함수까지 넘기므로, 굴절률을 다시 제곱한 값이 아니라 주어진 epsilon을
  씁니다.
- 흡수 입사에서 경로별 효율 차이를 정답으로 고정하던 테스트를 Airy 반사율과의 일치 검사로 바꾸었습니다.

편광 결과의 동일성, 반환 단계 전반의 일치, 그리고 흡수 입사 재료에 대해 미분한 JAX/JIT와 PyTorch 결과를

## 2단계: 경계의 순 전력과 구조 전체의 흡수

`result.power_entering`은 스칼라입니다. 입사파와 반사파를 함께 써서 계산한 경계의 순 전력을 입사파만의
전력으로 나눈 값입니다. 위쪽 입사든 아래쪽 입사든, 전력이 구조로 들어갈 때 양수입니다.
`result.absorption`은 다음과 같습니다.

```python
result.absorption == result.power_entering - result.T.sum()
```

이는 유한 두께 층 전체를 합친 흡수입니다. `top`과 `bot` 반공간의 흡수는 빠집니다. 입사 매질이
무손실이면 `power_entering = 1 - R.sum()`입니다. 입사 매질이 무손실이라는 것만으로 구조의 흡수가 0이
되지는 않습니다. 유한 층도 무손실이어야 합니다.

공유 `net_power` 함수는 경계 필드를 먼저 합칩니다.

```python
primary = incident + reflected
partner = admittance * (incident - reflected)
net = real(primary * conj(partner))
```

주 진폭은 TE에서는 E, TM에서는 H입니다. Poynting 벡터의 두 인자를 맞바꿔도 실수부는 그대로이므로 함수
하나로 둘 다 처리합니다. 간섭 항이 살아남으려면 곱셈 내내 복소 어드미턴스를 유지해야 합니다. 그 항은
분리된 파동의 `R`, `T`에 섞지 않습니다. 이 구분은
[Byrnes, §4.3–4.4 and Appendix B](https://arxiv.org/html/1603.02720v5#A2)와 대조해 확인했습니다. 자성
매질에서는 같은 E/H 경계 관계가 실제 ε와 μ를 씁니다. 외부 구현 코드를 복사하지 않았고 의존성도 더하지
않았습니다.

범위와 반환 계약:

- 순수 1D ETM/SMM, conical ETM/SMM, 2D ETM/SMM, 1차 ETM에 연결했습니다.
- `incident`, `s_inc`, `p_inc` 각각의 입사 전력과 간섭을 씁니다.
- 두 스칼라는 `answers='efficiency'`에서도 제공합니다. 이 단계는 풀이 직후의 경계 진폭을 쓰며, 결과에
  값을 담으려고 더 높은 답 수준으로 올라가거나 내부 필드를 재구성하지 않습니다.
- 저수준 효율 반환은 `(R, T, power_entering)`이며, 공개 `Result`의 모양은 바뀌지 않았습니다. 해당 저수준
  호출 테스트와 벤치마크를 갱신했습니다.
- `power_entering`은 `ResultSub`의 JAX pytree에 속하고, `absorption`은 그것으로 계산하는 속성입니다. 미분
  경로는 끊기지 않습니다.
- `UnphysicalResultWarning`은 순 전력을 쓸 수 있을 때 `T.sum() > power_entering`를 검사합니다. 흡수
  입사에서 `R+T>1`이라는 이유만으로는 경고하지 않습니다. 이 검사는 수동 구조를 가정하므로 이득 재료는
  따로 해석해야 합니다.
- 이 단계에서는 복소 가로 파수 벡터에 대한 일반 셀 적분을 구현하지 않았습니다. 그 경우 두 새 스칼라는
  틀린 흡수 대신 `NaN`입니다. 실수 가로 파수 벡터 테스트는 부동소수점 반올림 오차만 허용합니다.

| 입사 → 유한 층 → 출사 매질 | R | T | power_entering | absorption |

| n=1.5+0.3i → 두께 0 → 공기 | 0.053627760252366 | 0.984227129337540 | 0.984227129337539 | ≈ 0 |
| ε=2.25 → ε=4+0.8i → 공기 | 0.139756850733125 | 0.578016970599071 | 0.860243149266875 | 0.282226178667804 |

결과: 관련 테스트 파일 16개에서 **1,638 passed, 48 skipped**. 그 실행이 시작된 뒤에 더한 세 층 분할 검사

## 3단계: 손실 있는 입사 반공간의 위상 입사각

> **2026-10-04에 확장했습니다.** 이 단계는 실수 각도를 위상 진행 방향으로 정의했습니다. 이 방향은 굴절률이
> 양인 모든 매질에서 빛이 진행하는 방향이며, 그 모든 매질에서 바뀌지 않습니다. 당시 여기에는 없던 음의
> 굴절률 입사 쪽 매질에서는 위상이 전력과 반대로 진행하며, 그곳에서도 `theta`는 빛의 방향을 가리킵니다:
> `k_par = s*N*sin(theta)`, `s = sign(Re(sqrt(eps)*sqrt(mu)))`이며 그런 매질에서는 `-1`입니다. 현재의
> 서술은 `docs/reference/common/conventions.md`("Real-angle incidence")와
> `docs/theory/rcwa/negative-index-media.md`를 읽으세요. 아래 기록은 당시 그대로의 단계입니다.

실수 `theta`, `phi`는 **선택한 입사 반공간 안에서 위상이 진행하는 방향**으로 정의합니다. 입사파의 세기는
구조 표면을 따라 균일하므로 가로 파수 벡터는 실수입니다. 입사 면 위에 가상의 공기 층이나 유한 흡수 층을
더하지 않으며, 재료의 허수부를 버리는 근사도 하지 않습니다. 기존 `theta`, `phi` 입력이 이 파동을
지정하며, 별도의 직접 가로 파수 벡터 입력 키는 더하지 않았습니다.

`epsilon_r*mu_r = a+i*b`, `N=|Re(k)|/k0`로 두고 안쪽 법선 성분을 `q/k0 = N*cos(theta)+i*alpha`로 쓰면,
다음 두 식이 함께 성립해야 합니다.

```text
N² - alpha² = a
2 N cos(theta) alpha = b

N² = (a + sqrt(a² + b²/cos²(theta))) / 2
kx/k0 = N sin(theta) cos(phi)
ky/k0 = N sin(theta) sin(phi)
```

무손실 양의 굴절률 매질에서는 `b=0, a>0`이므로 익숙한 `kx/k0=n*sin(theta)*cos(phi)`로 정확히
환원됩니다. 일반적인 손실 매질에서는 위상 진행 방향과 Poynting 벡터의 방향이 다를 수 있으므로, `theta`를
전력 흐름의 각도로 읽지 않습니다. 위상 벡터와 감쇠 벡터에 대한 Maxwell 관계는
[Mishchenko et al.의 비균질 평면파, 식 (11)–(15)](https://pmc.ncbi.nlm.nih.gov/articles/PMC7580800/)와
대조해 확인했습니다. 표면에서 입사 세기가 균일하다고 가정하는 범위는
[Byrnes §2](https://arxiv.org/html/1603.02720v5#S2)와 같습니다. 구현은 위의 관계를 직접 유도해 작성했으며,
외부 코드를 복사하지 않았고 의존성도 더하지 않았습니다.

`conventions.incident_phase_index`는 음의 `a`에서 상쇄를 피하려고 작은 근을 유리화한 꼴로 계산합니다.
`engine._incident_kxy`가 이를 호출하므로 NumPy, JAX, PyTorch, 두 정식화의 모든 ETM/SMM 경로, 필드 재구성이
같은 입사 파수 벡터를 씁니다. `incidence_side='bottom'`이면 `bot`의 실제 ε·μ를 쓰며, 분산 재료에서 파장이
바뀌면 계산된 재료를 통해 반영됩니다.

복소 입사각 기능은 유지합니다. `theta`나 `phi`의 허수부가 0이 아니면 기존의 형식적인 `n*sin(theta)`
매개변수화를 씁니다. 이것은 실수 위상각 모델을 복소 평면으로 해석적으로 연속한 것이 아닙니다. 실수 위상각을
통해 미분하려면 실수 설계 변수가 필요합니다. 일반 복소 가로 파수 벡터에 대한 셀 적분 전력은 여전히 범위
밖입니다.

손실 있는 위상 입사에서 `abs(theta)>=pi/2`이면 균일한 표면 입사와 유한한 파수 벡터가 동시에 성립할 수
없으므로, 구체값 입력은 오류를 일으킵니다. 값을 읽을 수 없는 JAX JIT 안에서는 틀린 유한 결과 대신 NaN을
돌려줍니다. 무손실 입사각과 복소 입사각에 대한 기존의 스치듯 입사 처리, 그리고 음의 ε·μ에서의 별개의 가지
선택 문제는 남아 있습니다.

ε=4+3i, μ=1, λ=1,000 nm, θ=30°, φ=0 예에서는 `kx=0.006771390373184058 nm⁻¹`, `ky=0`입니다. 무손실 유한 층
ε=2.25와 같은 출사 반공간으로 s 입사를 풀면 다음을 얻습니다.

| R | T | power_entering | absorption |
|---:|---:|---:|---:|
| 0.1452272767102451 | 1.0131886090510112 | 1.0131886090510107 | ≈ 0 |

흡수 입사에서 T가 1을 넘어도, 입사–반사 간섭을 포함한 순 전력이 나가는 전력과 일치하므로 유한 구조는
아무것도 흡수하지 않습니다.

검증에는 미리 정한 위상 벡터와 감쇠 벡터로 만든 재료, 분산 관계의 독립적인 이분법 역산, Fresnel/Airy
진폭, E/H 경계 전력, 층 안의 열 흡수 적분, 표면을 따른 필드의 위상과 법선을 따른 감쇠, JAX JIT/vmap,
PyTorch 미분을 씁니다. 손실 있는 입사각을 예전 꼴로 계산하던 기준 검사는 같은 입사파를 비교하도록 독립
역산으로 바꾸었습니다. 실수 입사각의 허수 방향으로는 미분하지 않으며, 무손실 점에서 재료 손실에 대한 1차와
2차 미분의 연속성도 검사합니다.

## 직접 가로 파수 벡터 입력 (2026-09-23)

`wavebit.rcwa(kx=..., ky=...)`는 고정된 xyz 좌표계의 실수 가로 파수 벡터를 직접 받습니다. 길이를 nm로
쓰면 입력은 nm⁻¹ 단위이며, 내부에서 `wavelength/(2*pi)`를 곱해 기존 솔버의 무차원 파수 벡터로 넘깁니다.
회절 차수의 역격자 성분은 그 뒤에 더합니다. `theta`·`phi`와 직접 파수 벡터는 함께 쓸 수 없으며, 방향을
생략하면 수직 입사입니다. 한 성분만 주면 다른 성분은 0이 됩니다. 직접 지정한 물리 가로 파수 벡터는 재료나
파장이 바뀌어도 유지됩니다. 법선 파수 벡터와 전력은 실제 입사 반공간의 ε·μ로 계산합니다.

공개 입력, `Incidence`, `JobSpec` 직렬화와 스윕, JAX pytree, NumPy/JAX/PyTorch, 파수 벡터에 대한 자동
미분, 필드 재구성이 모두 같은 조건을 전달합니다. 복소수, 유한하지 않은 값, 배열 입력은 거부합니다. JIT
중에 읽을 수 없는 잘못된 값은 NaN으로 전달합니다. 직접 지정한 입사파는 다중 차수 입사와 같은 양의 입사
전력 검사를 거치므로, 입사 전력을 나르지 않는 소멸파에는 효율이 붙지 않습니다. 복소 가로 파수 벡터에 대한
일반 셀 적분은 더하지 않았습니다.

- `tests/rcwa/test_direct_wavevector.py`: 검사 141개. 패턴이 있는 구조에서 각도 입력과 직접 파수 벡터
  입력이 반사, 투과, 필드에서 일치하는지, 자성과 손실이 있는 독립 Fresnel 경계 계산, 일곱 가지 계산 경로,
  위/아래 입사, 독립 열 흡수 적분의 파수 벡터 미분, 다중 차수 입사 전력, 사각이 아닌 격자, 분산 매질의
