# 입사파 보조 격자를 포함한 자동 종료

공개 `fdtd.DecayStop` 정책은 CPU 구체값 `PlaneWave`와 축 방향 `TFSF`를 지원합니다.
각 입사파 보조 격자의 E/H, CPML 이력, 지원하는 재료 기억을 읽고, 층상 TFSF의
균일 구동 격자도 포함합니다. 모든 그룹은 자체 최대값을 유지합니다.
Yee 갱신식·광원 파형·진폭 기준·고정 길이 실행기는 변경하지 않습니다.

`tests/fdtd/test_source_decay.py`는 공개 API를 검사하며, 별도 구현으로 실제
커널 배열을 열거하고 종료 판정을 재계산합니다. 이 독립 재생은 제품의 그룹
선택기나 종료 판정기를 호출하지 않습니다. 매 단계와 첫 적격 창, 각 최대값을
확인합니다.

등록한 사례는 균일 격자 0.05 µm, 중심 파장 1 µm, 주파수 표준편차
`0.05*c/(1 µm)`, cutoff 0.001, 진폭 기준 0.02, 창 길이 `1 µm/c`를 사용합니다.
상한은 1,800단계입니다. 층상 TFSF에는 z=-0.4부터 0 µm까지 유전율 2.25인
막이 있습니다. 고정 격자의 시간 검증이며 공간 수렴 측정이 아닙니다.
막에서는 기존의 거친 격자 경고가 발생합니다.

PML 사례에서 모든 광원·백엔드가 상한 전에 종료할 것이라는 최초 예상은
충족되지 않았습니다. NumPy 균일 사례는 1,750단계에서 멈췄지만, JAX 균일 사례와
층상 TFSF는 상한에 도달할 수 있었습니다. NumPy 층상 사례의 상한만 3,600으로
늘려도 작은 잔류 그룹이 남았습니다. 이 관찰은 각 기억을 상대 진폭으로 판단하는
정책의 한계로 보존하며, 그룹 삭제나 허용오차 완화의 근거로 쓰지 않습니다.
반올림 수준의 그룹에서는 백엔드별 종료 단계가 다를 수 있습니다. 상한 종료도
해당 고정 길이 실행과 일치해야 합니다.

별도 사례에서는 기존 `fdtd.ConductiveAbsorber(cells=12)`를 명시적으로 선택하고 동일한 기준·창·
상한으로 세 CPU 백엔드 모두 조기 종료하도록 검증합니다. PML과 반사가 같다는
뜻은 아닙니다. 두 경계 선택 모두 최종 장, 점 이력, 입사 E/H 이력, 원시 푸리에
장을 실제 실행 단계 수까지의 일반 실행과 비교합니다. 기존 허용치는 기준 크기에
float64 epsilon의 128배를 곱한 값이며, SI 푸리에 장의 크기 기준은 `1 µm/c`입니다.

추가 판정 실험은 다른 상태를 조용하게 둔 채 보조·구동 격자의 E/H 또는 CPML
배열 하나, 보조 격자의 분극·이전 분극·증분 배열 하나를 유지합니다. 각 배열은
독립적으로 종료를 막아야 합니다. 누적 참조 이력은 제외합니다. 알 수 없는 항,
중복 기억 이름, 잘못된 중첩 상태는 거절해야 하며, 지연 가우시안 조건과 JAX·
PyTorch 미분 거절도 유지합니다.

## 고정 격자의 시간 비교

macOS arm64, Python 3.12.9, NumPy 2.5.1에서 같은 장면·경계의 5,400단계
고정 실행과 비교했습니다. 시간 꼬리는 남은 점 장의 최대 진폭을 해당 이력의
최대값으로 나눈 값입니다. 푸리에 차이는 각 파장 자체의 최대 장 크기를 기준으로
계산하며, 표는 0.9·1.0·1.1 µm 중 최댓값입니다. 사전 등록한 한도는 둘 다 0.02입니다.

| 광원 | 패딩 | 실제 단계 / 이유 | 상대 시간 꼬리 | 최대 상대 푸리에 차이 |
|---|---|---|---|---|
| PlaneWave | PML | 1750 / decay | 0.0001790 | 0.0002392 |
| 균일 TFSF | PML | 1750 / decay | 0.0001790 | 0.0002392 |
| 층상 TFSF | PML | 1800 / cap | 0.0001142 | 0.0001426 |
| PlaneWave | Absorber | 1750 / decay | 0.0001083 | 0.0001454 |
| 균일 TFSF | Absorber | 1750 / decay | 0.0001083 | 0.0001454 |
| 층상 TFSF | Absorber | 1750 / decay | 0.0005175 | 0.0004225 |

이 수치는 해당 사례와 유한 시간 구간에만 해당하며, 진폭 기준을 일반적인
스펙트럼 오차 한도로 바꾸지 않습니다. 백엔드별 동일 구간 비교에는 CPU의
JAX 0.11.0·PyTorch 2.14.1도 사용합니다. 다른 운영체제·GPU의 근거는 아닙니다.

개발 환경에서 다음 명령으로 회귀 검증을 재현할 수 있습니다.

```bash
python tools/run_verification.py --profile full --slow exclude --workers 0 \
  --path tests/fdtd/test_source_decay.py \
  --path tests/fdtd/test_fd_decay_stop.py \
  --path tests/fdtd/test_physical_stopping_absorber.py
```

자동 종료는 진폭 기반 경험적 조건이며, 전자기 에너지·스펙트럼 오차·미래 반사·
수렴을 보증하지 않습니다. GPU·미분 지원의 근거도 아닙니다. 충분히 긴 고정
실행과 비교해 실제 관측량의 시간 오차를 평가하세요.
