요약: `pulse_notches`는 장면의 가우시안 소스에 유한 표본 스펙트럼 영점을 한 개 또는 두 개
넣습니다. 이것은 독립적으로 알려진 재료 모드를 억제하면서, 기준 실행으로 보정한 광학 결과와
그래디언트를 보존합니다. 회절 차단점 근처에서는 되돌아오는 성분 일부와 누적된 TM 시간 오차를
줄이지만, 두 편광의 전체 복소 진폭 오차를 안정적으로 함께 줄이지는 못합니다.
기본 소스는 바뀌지 않았습니다. 이것은 소스 제어 수단이지 수렴 문제의 해결책이 아닙니다.

## 구성과 검증

[가이드](../../guide/fdtd/time-domain.md#suppressing-selected-source-frequencies)는 단위, 필수
주파수 보호 장치, 표본 스펙트럼 진단을 정의합니다.
양의 주파수 fn에 놓인 영점(notch)은 계수 `exp(-2*pi*i*fn*dt)`를 가진 인과적 지연 차분을
적용합니다. 완전한 유한 합성곱은 푸리에 스펙트럼에 `1-exp(2*pi*i*(f-fn)*dt)`를 곱하며, 이 인자는
fn에서 0이 됩니다. 영점 하나마다 그 합성곱을 위해 실행 시간의 마지막 표본 하나를 확보합니다. 최종
소스는 표본 최고 진폭이 1이며, 네 가지 기저/기준 실행이 모두 이 소스를 공유합니다.
구현은 독립적이며, 외부 필터링이나 솔버 소스를 참고하거나 가져오지 않았습니다.

테스트는 유한 합성곱 정리, 주파수 부호, 한 개/두 개/중복 영점, 물리 단위 배율, 입력 거부와
소스 정밀도를 검사합니다. 균일하고 감쇠가 없는 Lorentz 진동자는 독립적으로 알려진 이산 주파수를
가집니다. 그 주파수에 영점을 두면 최종 E 노름과 분극 노름이 필터하지 않은 펄스에 비해 1e8배보다
더 많이 줄어듭니다. 비스듬한 입사의 유전체 슬래브 진폭은 세분화할수록 독립적인 TE/TM Airy 해로
2차 수렴합니다. 아래쪽 입사, 정적 비균일화, 방향별 추출, DFT 부분 표본화, 결맞는 시간 기록과
epsilon, mu, 극점 세기에 대한 미분은 NumPy, JAX, Torch에서 일치합니다.

새로운 Meep 1.34.0 CPU 검사는 문서화된
[CustomSource와 시뮬레이션 API](https://meep.readthedocs.io/en/latest/Python_User_Interface/#customsource)만
씁니다. 균일 재료는 epsilon=2, omega0=3, gamma=0, strength=2이고, Courant=0.4, 해상도 10(dt=0.04)을
씁니다. 가우시안은 폭 5, 최고점 시간 25이며, 반송파는 이산 재료 주파수 0.503628254518과 같습니다.
유한 지지 구간은 0부터 50까지이고, 지연 차분은 50.04까지 이어집니다. 각 소스의 표본 최고 진폭은
1이며, 소스가 끝난 뒤 시간 단위 10만큼 Ey를 기록합니다.

| 공개 API Meep 대조 | 측정 결과 |
| --- | ---: |
| 필터하지 않은 경우 후반 Ey 크기 최댓값 | 0.222001179 |
| 필터한 경우 후반 Ey 크기 최댓값 | 3.08e-12 |
| 필터함/필터하지 않음 후반 기록 노름 비 | 1.30e-11 |
| 필터하지 않은 경우 맞춘 주파수 | 0.503628254518 |
| 필터하지 않은 경우 맞춘 진폭 감쇠 | 1e-9까지 0과 일치 |

Native E 기록은 같은 반 단계 전류 표본과 정수 필드 시각을 씁니다.
복소값은 세 CPU 백엔드 모두에서 고정된 Meep 트레이스와 절대 허용 오차 1e-10 안에서 일치합니다.
이것은 균일 ADE와 소스 타이밍을 검사할 뿐, 임의의 열린 계의 Q를 검증하거나 격자 실행을 더 짧게
끝낼 수 있음을 보장하지 않습니다.
일반 테스트는 보관된 출력을 읽으며 Meep을 가져오지 않습니다.

## 인터페이스가 영점 두 개에서 멈추는 이유

차분을 거듭하면 유한한 가우시안의 양 끝점과 산술 오차가 모두 증폭됩니다. 소스만 쓰는 대조는 아래의
차단점 근처 펄스를 써서, 반송파에서 0.2보다 멀리 떨어진 곳의 가장 큰 FFT 진폭을 전체에서 가장 큰
FFT 진폭으로 나눈 값을 잽니다. 이것은 표본 스펙트럼 진단이며, 모든 연속 주파수에서의 상한이
아닙니다.

| 해상도 | 영점 하나 | 같은 영점 두 개 | 같은 영점 세 개, 지원하지 않는 대조 |
| --- | ---: | ---: | ---: |
| 40 | 4.93e-10 | 2.63e-6 | 0.01128 |
| 80 | 7.55e-10 | 5.75e-6 | 0.05124 |

해상도 80에서 영점 세 개짜리 펄스의 가장 큰 표본은 t=300 근처의 가우시안 중심이 아니라
t=0.00577 근처의 시작 가장자리로 옮겨 갑니다. 그래서 공개 인터페이스는 영점을 세 개 이상
거부합니다. 이중 영점조차 대역 밖 여기를 늘리므로, 본질적으로 단일 영점보다 낫지 않습니다.
지원하지 않는 대조 중 어느 것도 솔버 기본값을 바꾸지 않습니다.

## 레일리 근처 비교

기하와 기준은 [링다운](fdtd-ringdown.md)과 [CPML 세기](fdtd-pml-strength.md) 사례와 같습니다.
이진 epsilon 2.25/1, 두께 0.2, 주기 0.8, 파장 0.95808/0.96192이며, 가로 방향 파동 벡터는 중심 파장
0.96에서 sin(theta)=0.2에 해당하는 값으로 고정합니다. 두 입사 열을 모두 계산합니다. 모든 행은 펄스
폭 60, 물리 PML 길이 0.6, 목표 1e-40, 층 정렬, 패딩 배율 1, 각 계면에서 0.2 떨어진 방향별 추출을
씁니다. 명목 물리 차단점은 1.041666666667입니다. 단일/이중 Yee 영점은 각 격자에서 독립적으로 계산한
이산 차단점을 따릅니다.
RCWA 기준은 차수 32를 유지하고 물리 차수 -1/0을 비교합니다.

아래 오차는 요청한 두 파장과 그 두 차수 전체에 걸친 복소 r/t 절대 차이의 최댓값입니다. 여기에는
공간, 경계, 유한 시간 기여가 모두 들어 있으므로, 숫자가 작다고 해서 각 기여가 줄었다는 증거가
되지는 않습니다. 나열한 필드/상태 감쇠 검사는 모두 거짓으로 남아 있습니다.

| 해상도 | 주기 수 | 소스 | TE 오차 | TM 오차 |
| --- | ---: | --- | ---: | ---: |
| 40 | 800 | 가우시안, 이전 대조 | 0.025048 | 0.048183 |
| 40 | 800 | Yee 차단점 영점 하나 | 0.032591 | 0.051804 |
| 40 | 800 | Yee 차단점 이중 영점 | 0.028908 | 0.051259 |
| 40 | 800 | 물리 차단점 영점 하나 | 0.028720 | 0.050206 |
| 40 | 1600 | 가우시안, 이전 대조 | 0.022332 | 0.051702 |
| 40 | 1600 | Yee 차단점 영점 하나 | 0.024928 | 0.051516 |
| 40 | 1600 | Yee 차단점 이중 영점 | 0.024983 | 0.051266 |
| 80 | 800 | 가우시안, 이전 대조 | 0.015474 | 0.010338 |
| 80 | 800 | Yee 차단점 영점 하나 | 0.013935 | 0.011963 |
| 80 | 800 | Yee 차단점 이중 영점 | 0.014372 | 0.011892 |

해상도 40, 주기 800에서 Yee 차단점 영점 하나는 투과 쪽에서 들어오는 차수 -1 진폭의 최댓값을
TE/TM 0.009470/0.003621에서 0.003984/0.001382로 줄입니다. 이중 영점은 0.002295/0.001056을 줍니다.
이것은 유한 필드 스펙트럼에서 겉보기로 들어오는 성분이며, 독립적인 PML 반사 계수가 아닙니다.
표에서 보듯이, 이 성분이 줄었다고 전체 산란 오차가 그만큼 줄어드는 것은 아닙니다.

주기 1600의 단일 영점 실행을 그 앞쪽 절반 전체(갱신 66511회, 시간 단위 약 768)와 비교하면 TE/TM
최대 진폭 변화는 0.007789/0.000913입니다. 가우시안의 해당 변화는 0.006769/0.003899였습니다.
TM 시간 민감도는 약 4배 줄었지만 TE는 나아지지 않았습니다.
이중 영점 장시간 실행의 변화는 0.004653/0.001063으로, 둘 다 가우시안 대조보다 작지만 여전히 수렴
허용 오차 1e-4보다 훨씬 큽니다.
주기 800의 이중 영점 실행과 해상도 80의 단일 영점 실행은 짧은 200회 갱신 산란 검사를 통과하지만
여전히 상태 감쇠 검사에는 실패합니다. 이런 국소 플래그를 무한 시간 증명으로 취급해서는 안 됩니다.
해상도 80의 이중 영점 실행도 그 짧은 검사를 통과하지만, TE 오차는 단일 영점 실행보다 크고 TM
오차는 가우시안보다 큽니다. 투과 쪽에서 들어오는 TE/TM 차수 -1 진폭은 0.007336/0.002005로,
성긴 격자에서 보였던 들어오는 TE의 감소가 세분화하면 유지되지 않습니다.

여기서 물리 문턱에 영점을 두면 요청하지 않은 반송파도 함께 사라집니다. 대역만 쓰는 산란에는
유효하지만, 공통 장면 어댑터는 그 소스로 반송파 정규화 시간 기록을 하는 것을 거부합니다. 이것은
요청한 두 주파수 중 어느 하나를 조명하지 못하는 경우와는 다른 문제입니다.

측정한 대조는 선택적인 소스 성형 도구를 공개하고 가우시안 기본값을 유지하는 근거가 됩니다. 그러나
레일리 근처의 정확도 한계를 해결하거나 자동 스펙트럼 보정을 정당화하지는 않습니다. 장시간, 메시,
그리고 독립적인 경계/소스 위치 대조가 여전히 필요합니다.

## 재현

```shell
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --source-only
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case single40
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case double40
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case physical40
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case long40
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case double-long40
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case single80
python -m studies.fdtd.pulse_notches.fdtd_pulse_notches --case double80
```

연구의 기본 백엔드는 CPU의 배정밀도 JAX입니다. `--backend numpy`도 같은 시간 영역 방정식을
씁니다. 각 실행은 실제 소스 스펙트럼, 영점 주파수, 메시, 들어오는 성분과 비교 창을 보고합니다.
연구에는 이중 영점 장시간/고해상도 대조도 있습니다. 외부 생성기 사용법은 체크아웃의
`tests/references/interface/README.md`에 있습니다. GPU 실행은 이 측정의 범위 밖입니다.
