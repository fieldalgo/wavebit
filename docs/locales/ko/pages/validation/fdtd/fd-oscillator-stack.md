## 요약

**이 범위를 한정한 확장은 떨어져 있는 평평한 박막들을 합성하며, 각 박막에는 정확히 하나의 수동 Drude 또는
Lorentz 극점이 있습니다. 필수 수치 관문은 통과합니다.** 박막마다 명시적으로 다른 진동자 종류를 써도 됩니다.
모든 구성원은 기존의 [단일 박막 축약](fd-single-pole-film.md), 점화식, 에너지 가중치를 재사용합니다. 각 구성원의
패딩한 지지 영역은 다른 구성원과 겹치지 않으며, 메모리도 따로 유지됩니다. 박막 안의 합이나 새로운 진동자 축약은
도입하지 않습니다.

재료 안정성 속도는 완전한 구성원 속도들의 최댓값이며, 박막 위치에 걸친 합이 아닙니다. 모든 구성원은 가능한 내부
Lorentz 공진을 포함해 기존의 전 대역 벌크 검사를 받습니다. 이 해석적 항등식들은 합성을 정당화하지만, 그것만으로
측정된 정확도, 백엔드 일치, 수렴을 확립하지는 않습니다. 완료된 등록 실험은 복소 셀 48개를 모두 유지합니다. 고정된
민감도 규칙에 따라 자기 차수 47개와 최종 직접 차수 43개가 2차로 분류됩니다. 그 밖의 모든 분류도 아래에 그대로
보입니다. 일반 C8은 아직 완료되지 않았고, [C7 메타표면 판정](fd-metasurface-validation.md)도 통과하지 못한 상태로
남아 있습니다.

## 범위를 한정한 계약

| 항목 | 허용되는 경우 |
| --- | --- |
| 선언 | 일반 `Scene(structures=(...))` 튜플이 정확한 `Dispersive` 재료를 두 개 이상 담고, 각각은 정확한 `Drude` 또는 `Lorentz` 극점을 정확히 하나 가집니다. Drude만, Lorentz만, 박막 간 혼합 모두 같은 경로를 씁니다. |
| 형상 | 각 구성원은 회전하지 않고 범위를 두지 않은 구체적인 voxel `Box`이며, 단일 박막의 돌출과 함께 같은 두 가로축에 걸치고, 공통 법선 방향으로 두께가 최소 `dx`입니다. x, y, z 법선 박막을 구조적으로 지원합니다. |
| 분리 | 실제로 패딩한 반열린 격자 지지 영역이 공통 법선 방향으로 쌍마다 서로 겹치지 않아야 합니다. 물리적으로 닿지 않는다는 것이나 셀 단위로 잰 공칭 틈만으로는 부족합니다. 두 지지 구간은 셀을 공유하지 않으면서 반열린 경계에서 만날 수 있습니다. |
| 호스트와 여유 | 일반 등방성 무손실 비자성 `Material` 호스트 하나. 각 지지 영역은 법선 방향 도메인 벽과 모든 흡수층에서 떨어져 있습니다. 기존 소스, 특징 크기, TFSF 껍질 제한은 그대로 유효합니다. |
| 매개변수 | 구체적이고 유한한 양의 등방성 고주파 유전율, `mu=1`, 음이 아닌 감쇠와 세기, 양의 선언 Drude/Lorentz 진동수. 기존 단일 박막의 유도값 범위 검사도 그대로 적용됩니다. |
| 지속 시간 | 고정된 `Run` 시간, 단계 수 또는 주기 수. `Decay`와 공개 초기 필드는 거부합니다. |
| 미분 | Torch 순방향 쌍대수를 포함해, 기하, 재료, 소스, 스펙트럼 선언에 실린 미분은 이 범위 밖입니다. |
| 준비된 재사용 | 순서가 있는 적층 전체, 정확한 경계 선언, 순서가 있는 재료/소스 항 튜플 전체가 일치해야 합니다. 구성원을 바꾸거나, 소스를 추가하거나, 메모리를 빠뜨리면 새 계획이 필요합니다. |

새 경로는 박막 안의 다극점 합, Debye를 포함한 적층, 일반 유전체 또는 전도성 구성원, 물리적으로 맞닿은 박막이나
겹치는 지지 영역, 곡면 물체, 분산 또는 손실 호스트, 이방성, 자성, 접합을 제외합니다. 기존 단일 박막 경로와 셀 스냅
경로는 각자의 계약을 유지합니다. 세기가 0인 Lorentz 선언도 자신의 정체성과 메모리 슬롯을 유지합니다. 그 공칭
진동수의 제곱은 여전히 유한한 양의 float64 값이어야 하며, 재사용하는 단일 박막에서와 마찬가지로 보수적인 안정성
한계에 계속 들어갑니다. 이 확장은 단일 박막이 거부하는 극단적인 비활성 진동수를 허용하지 않습니다.

## 국소 응답과 합성

구성원 하나에 대해 Lorentz이면 `d=omega_0**2`, `S=strength`로, Drude이면 `d=0`, `S=omega_p**2`로 씁니다.
`s=-i*omega`, 박막 비율 `f`, `g=1-f`, 박막 고주파 유전율 `a`, 호스트 유전율 `b`, `A=f*b+g*a`로 두면 다음과
같습니다.

```text
L(s) = s*s + gamma*s + d
eps_film(s) = a + S/L(s)

eps_t(s) = f*a + g*b + f*S/L(s)
eps_n(s) = b*(a*L(s)+S)/(A*L(s)+g*S)
         = a*b/A + (f*b*b*S/A**2)/(L(s)+g*S/A).
```

| 전기 성분 | `eps_inf_eff` | `S_eff` | `Omega_squared` |
| --- | --- | --- | --- |
| 접선 방향 | `f*a+g*b` | `f*S` | `d` |
| 법선 방향, 혼합 | `a*b/A` | `f*b*b*S/A**2` | `d+g*S/A` |

조화/산술 계면 법칙과 그 유도는 [단일 박막 기록](fd-single-pole-film.md#exact-complex-mixture)에 문서화되어
있습니다. 정확히 비어 있거나 가득 찬 비율에는 각각 호스트와 원래 박막을 쓰며, 양의 혼합 비율은 스냅으로 없애지
않습니다. 합성기는 완전한 단일 박막 프로파일을 서로 겹치지 않는 지지 영역에서 호스트에 붙여 넣으므로, 큰 호스트
값을 뺐다가 다시 더하는 일을 피합니다. 공간적으로 떨어진 Drude와 Lorentz 구성원은 추가적인 국소 재료 결합을
만들지 않습니다.

각 `oscillator_stack[i]` 항은 일반 진동자 슬롯 하나와 기존의 `P`, `previous`, `delta` 배열을 가집니다. 계수는
같은 중심 점화식을 씁니다.

```text
h = gamma*dt/2
step_gain = (2-Omega_squared*dt**2)/(1+h)
hold = (1-h)/(1+h)
drive = S_eff*dt**2/(1+h)
P_next = step_gain*P - hold*P_previous + drive*E.
```

평소의 `-(dx/dt)*delta` 항이 필드 갱신 전에 전기 curl에 들어갑니다. 소스, 커널, 에너지 관측자, 단일 박막 수치
축약기는 합성으로 바뀌지 않습니다.

## 저장과 시간 간격 한계

활성 구성원 셀에서 기존 전기 저장은 관측자의 기존 정규화와 인덱싱 아래에서 `eps_inf_eff*|E|**2`에 다음을
더합니다.

```text
(|P_next-P|**2/dt**2 + Omega_squared*Re(P_next*conj(P)))/S_eff
    - Re(E*conj(P_next-P))
```

공간 역세기, 공진 대 세기, 활성 가중치는 단일 박막 축약기가 직접 공급합니다. 비활성 슬롯은 공칭 공진에서도 저장
기여가 0이며, `0/0`을 계산하지 않습니다. 전역 전자기 항은 한 번만 세고, 서로 겹치지 않는 국소 저장 항은 더합니다.
`gamma*dt=2`에서 점화식의 `hold`가 0이 되어도 그것은 Debye 극점이 아니라 진동자로 남습니다.

정규화한 결합 `q**2=S_eff/eps_inf_eff`로 두면, 국소 재료 블록은 `Omega_squared+q**2 <= d+S/a`를 따릅니다. 법선
값은 정확히 `d+S/a`이고, 접선 값은 그보다 크지 않습니다. 지지 영역이 서로 겹치지 않으므로 국소 재료 블록은 직합이
됩니다. 따라서 기존 curl/재료 노름 논증으로 다음을 얻습니다.

```text
rate = max_i(d_i + S_i/a_i)
dt < 1/sqrt(1/dt_vacuum**2 + rate/4).
```

curl 한계는 호스트를 포함한 물리 고주파 유전율과 기존 경계 미분 한계를 씁니다. 각 구성원의 합은 단일 박막
기술자의 float 값에서 정확한 유리수로 만든 뒤 유한한 float64 속도로 올림합니다. 비활성 Lorentz의 `d_i` 기여는
보수적으로 유지합니다. 이 규칙은 요청한 `dt`를 다시 계산하지 않으며, 기존 PML 안정성 계약을 확장하지도 않습니다.

## 벌크 스펙트럼 하한

`x=omega**2`로 두면 단일 박막의 삼각 부등식 한계는 다음과 같습니다.

```text
|k|**2 <= a*x_max + S*max R(x)
R(x) = x/sqrt((d-x)**2 + gamma**2*x).
```

두 끝점 외에 가능한 유일한 내부 최댓값은, 분모가 양수이고 후보가 대역 안에 있을 때
`x=2*d**2/(2*d-gamma**2)`입니다. 모든 구성원과 호스트를 검사합니다. 대역 안의 감쇠 없는 활성 Lorentz 공진에는
유한한 한계가 없으므로 거부합니다. 비활성 Lorentz 극점은 그 진동수에서도 일반 유전체 응답을 씁니다. 이것은 기존의
해석적 한계를 일반 유한 부동소수점 산술로 계산해 재사용하는 것이며, 바깥쪽으로 반올림한 새 스펙트럼 인증서가
아닙니다.

소스 대역은 구체적이고 유한한 양의 진동수 구간을 정의해야 합니다. 모니터, `Resolution`, 명시적 PML 파장은 각각
위상 파장당 최소 8셀, 표피 깊이당 최소 1셀인지 검사하며, 각각 12셀과 2셀 미만이면 범위가 명시된 경고를 냅니다.
선언된 파장도 소스 대역도 없으면 추론된 인증서가 아니라 경고를 냅니다. 벌크 하한이 모든 계면 공진, 산란 오차,
점근 수렴을 한정하지는 않습니다.

## 등록한 수치 허용

새 사례 161개와 관련 사례 1363개가 모두 통과합니다. 실제 제품 소스 결함 14개가 각자 의도한 단언에서 실패하고,
정확히 복원하면 새 사례 161개가 모두 통과합니다. 전체 비느린(non-slow) 회귀는 바뀌지 않은 과거 건너뜀 8개와 함께
4486개 사례를 통과하고, 별도의 느린 계층은 81개를 통과합니다. 고정 배열 1141개 전부가 읽기 전용 비교 네 번을 거쳐
비트 단위로 재현됩니다. 이 개수들은 원시 노드 목록, 로그, 완료된 부모 프로세스 영수증에서 다시 재생한 것입니다.

등록한 물리 목록은 박막 계열 두 개, 배치 두 개, 두 편광, 파장 세 개를 가집니다. 허용된 지속 시간 대체 0개를 포함해
작업자 실행 40개를 완료하며, 복소 셀 48개가 모두 보고서에 남아 있습니다. 작업자 수는 동시 실행 수가 아닙니다.

| 항목 | 등록한 범위 |
| --- | --- |
| 계열 | Drude/Lorentz 쌍 하나와 Lorentz 셋 하나. 뒤의 것은 비활성 구성원을 유지합니다. |
| 공간 단계 | 기준 파장당 진공 셀 `n=40,80,160`. |
| 배치와 표본 | 비율 `0.3`과 `0.1`, `s`와 `p`, 파장 `0.9`, `1.0`, `1.1`, 복소 `r`과 `t`. |
| 기본 목록 | 작업자 실행 40개: 계열/배치/편광 조합마다 실행 다섯 개. 이것은 실행 개수이며 동시 실행이 아닙니다. |
| 조합당 실행 다섯 개 | `40/base120/PML24`, `80/base120/PML24`, `80/long240/PML24`, `80/long240/PML48`, `160/base120/PML24`. |
| 보고한 셀 | 낮음, 혼합, 미분해 분류를 포함해 계열/배치/편광/파장/진폭 셀 48개 전부. |
| 알려진 사례 보정 | 성긴 `p`, 비율 `0.3` 행 여섯 개: 두 계열을 NumPy, JAX, Torch에서. 절대 복소 진폭 상한은 이 행들을 공개한 뒤 수용했으며, 알려진 사례 검사로 남습니다. |
| 기준 | 다층 기준에 선언한 연속체 재료와 기하. 재귀 산란이나 단일 박막 Airy 대조로 독립적으로 점검하며, 맞춘 필드 응답은 없습니다. |
| 민감도 | 중간 단계에서의 별도 시간 차이와 흡수층 차이. 물려받은 차수 규칙 아래 경험적 대리값으로 유지하며, 엄밀한 고운 격자 오차 한계가 아닙니다. |

목록과 분류 기준은 공개한 보정과 대상/변형 노출 뒤, 물리 캠페인 전에 등록했습니다. 수치 근거는 완전합니다. 운영
통합에는 추가로 엄격한 문서 빌드와 최종 저장 증거 감사가, 그 실제 완료된 부모 프로세스 종료와 함께 필요합니다. 여기서
뒤의 두 관문 어느 것도 완료되었다고 주장하지 않습니다. 원래의 실패, 경고, 원시 기록, 고정 기준은 보존되어 있습니다.
원시 실행 기록은 아래 보존한 증거에 링크한 것을 제외하고 저장소 밖에 보관되어 있습니다.
성공한 계획이나 안정적인 필드만으로는 이 측정을 대신할 수 없습니다.
