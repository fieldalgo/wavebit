# C8: Debye 극점 두 개를 가진 박막 하나

작성: 2026-10-06

대상: `src/wavebit/fdtd/_prepare/two_debye_film.py`,

## 요약

**등록한 40/80/160 셀 연구는 고정된 민감도 구간 안에서 자기 차수 24개 전부와 직접 쌍 48개 전부를 2차로
분류합니다.** 작업자 20개가 모두 대체나 중단 없이 완료됩니다. 이 결론은 공개한 재료와 두 배치에 해당합니다.
집중 사례 374개 전부와 제품 변이 증거 9개가 통과하고, 이어서 복원한 사례 127개가 통과합니다. 전체 계층은
건너뜀 8개와 함께 3,122개 사례를 통과하고, 느린 계층은 81개 사례 전부를 통과하며, 고정 기준 배열 1,141개 전부가
비트 단위로 재현됩니다.

범위를 한정한 구현과 필요한 수치 관문은 기능 브랜치에서 완료되었습니다. 그 조화 법칙은 선언된 극점들을
결합합니다. 각 극점을 따로 축약하면 다른 재료가 됩니다. 최대 두 개의 수동 법선 이완 모드가 예약된 메모리 슬롯
두 개, 기존의 분할 점화식, 국소 에너지 가중치를 씁니다. 재료 속도 정책은 각 셀에서 두 모드를 더한 뒤, 셀들과
원래 벌크 속도에 걸친 최댓값을 취합니다.

바뀌지 않은 보정 행 상한, 즉 반사 0.005와 투과 0.010은 그 알려진 구성 하나에만 적용됩니다. 다른 캠페인 행은
그 성긴 격자 오차를 넘으며, 그 행들의 등록 기준은 그 보정 임계값이 아니라 세분에 따른 수렴입니다. 계약은 일반
유전체 호스트 안의 구체적인 평평한 `Box` 하나에 정확히 두 개의 수동 Debye 극점을 둔 경우입니다. 임의의 극점
개수나 일반 분산 스무딩은 허용하지 않습니다.

앞선 [단일 Debye 박막](fd-debye-film.md), [Drude/Lorentz 박막](fd-single-pole-film.md),
[전도성 박막](fd-conductive-film.md)은 기록된 재료 범위와 결과를 그대로 유지합니다. 일반 C8 스무딩은 아직
완성되지 않았고, [C7 메타표면 판정](fd-metasurface-validation.md)도 여전히 통과하지 못한 상태입니다.

## 범위를 한정한 계약

공개 선언은
`fd.Structure(fd.Box(...), fd.Dispersive(eps_inf=..., poles=(pole1, pole2)))`
하나이며, 두 극점 모두 정확한 공개 `Debye` 객체이고 이산화는 기본 voxel 경로입니다. 다음 제한은 모두 함께
적용됩니다.

| 항목 | 한정된 경우 |
| --- | --- |
| 형상 | 구체적인 공개 `Box` 정확히 하나, `angle=0`, `range=None`, 짝 구조나 접합 없음. |
| 범위 | 계산 격자의 완전한 축 정확히 두 개가 박막 전체에 걸쳐 균일하고, 각 횡방향 도메인 면 너머로 최소 `dx` 하나만큼 돌출됩니다. |
| 두께 | 남은 법선 방향 범위가 최소 `dx` 하나이므로, 두 면이 같은 전기 쌍대 셀의 내부에 들어가지 않습니다. |
| 여유 | 법선 방향 지지 영역은 도메인 안쪽에 엄격히 놓이고, 지지 영역 전체가 모든 흡수층과 떨어져 있습니다. 횡방향 흡수층은 이 범위 밖입니다. |
| 박막 | 정확한 `Debye` 극점을 정확히 두 개 담은 정확한 `Dispersive`, 유한한 양의 등방성 고주파 유전율, `mu=1`. |
| 극점 | 구체적이고 유한한 증분 `delta_eps >= 0`과 이완 시간 `tau > 0`. 증분 0과 같은 이완 시간도 허용됩니다. |
| 호스트 | 정확한 일반 무손실 `Material`, 구체적이고 유한한 양의 등방성 유전율, `mu=1`. |
| 상태와 재사용 | 초기 필드 없음. 준비된 형상, 재료, 계산 격자, 예약된 메모리 슬롯 두 개가 일치해야 합니다. 다른 계획으로 허용 검사를 우회할 수 없습니다. |

계약은 x, y, z의 순열에 대해 불변입니다. 점유율은 각 전기 성분 고유의 Yee 쌍대 셀에 대한 해석적 구간 겹침입니다.
기하학적으로 정확한 비어 있음/가득 참 끝점은, 0이 아닌 작은 혼합 비율을 잘라 내는 허용 오차 띠 없이 그대로
유지합니다. 기존의 소스, 모니터, 특징 크기, 흡수층 제한은 여전히 적용됩니다.

이 범위는 다른 극점 개수나 극점 종류, 하위 클래스, 손실 또는 분산 호스트, 이방성, 자성, 곡면이거나 회전된 물체,
접합, 그리고 추적되는 형상, 재료, 소스 대역을 제외합니다. 소스 진폭을 포함해 그래디언트의 정확성은 주장하지
않습니다. 기존의 셀 스냅 재료 경로와 스텐실 경로는 각자의 계약을 유지합니다. 이후 범위에서는 박막 하나 안에
Debye 극점 세 개 이상([기록](fd-debye-sum-film.md))과 Debye/진동자 혼합 극점([기록](fd-hybrid-film.md))을
허용하고(2026-10-07), 서로 떨어진 Debye 박막([기록](fd-debye-stack.md), 2026-10-09)도 허용합니다.

## 결합된 조화 축약

저장소의 `exp(-i*omega*t)` 규약을 쓰고 `s=-i*omega`로 둡니다. `f`를 박막 비율, `g=1-f`, `a`를 박막의 고주파
유전율, `b`를 호스트 유전율, `delta_i,tau_i`를 선언된 두 Debye 매개변수라 합니다. 활성 극점에 대해 다음을
정의합니다.

```text
r_i = 1/tau_i
u_i = sqrt(delta_i*r_i)
D = diag(r_1, r_2)
chi(s) = sum_i delta_i/(1 + tau_i*s)
       = u^T * (s*I + D)^(-1) * u
A = f*b + g*a.
```

산술 접선 방향 응답은 다음과 같습니다.

```text
eps_t(s) = f*a + g*b + f*chi(s).
```

반면 법선 방향 조화 응답은 전체가 한꺼번에 축약됩니다.

```text
eps_n(s) = 1/(f/(a + chi(s)) + g/b)
         = a*b/A + (f*b*b/(A*A))*chi(s)/(1 + (g/A)*chi(s))

J = D + (g/A)*u*u^T
eps_n(s) = a*b/A + (f*b*b/(A*A))*u^T*(s*I + J)^(-1)*u.
```

마지막 항등식은 계수 1(rank-one) 역행렬 항등식에서 나옵니다. `D`는 양의 정부호이고 `(g/A)*u*u^T`는 양의
준정부호이므로 `J`는 양의 고유값을 가집니다. 정규직교 고유벡터로 `J*q_j=lambda_j*q_j`라 하고 `w_j=q_j^T*u`로
두면 다음과 같습니다.

```text
eps_inf_n = a*b/A
tau_n_j   = 1/lambda_j
delta_n_j = (f*b*b/(A*A))*w_j*w_j/lambda_j

eps_n(s) = eps_inf_n + sum_j delta_n_j/(1 + tau_n_j*s).
```

모든 모드 증분은 음이 아닙니다. 접선 방향 계수는 단순히 `eps_inf_t=f*a+g*b`, `delta_t_i=f*delta_i`,
`tau_t_i=tau_i`입니다. 축에 정렬된 이 계약에는 피팅한 극점, 잔여 전도도, 대각 밖 구성 연산자가 필요 없습니다.
특히 법선 방향 유수와 이완 시간은 `J`를 통해 원래의 두 극점에 모두 의존합니다.

## 퇴화한 경우와 예약된 슬롯 두 개

물리적으로 활성인 이완 모드의 수는 2보다 작을 수 있습니다. 그래도 메모리 할당은 정확히 슬롯 두 개를 예약하므로,
준비된 계획의 정체성은 특정 증분이 사라지는지에 의존하지 않습니다.

| 극한 | 요구되는 물리 응답 |
| --- | --- |
| 빈 셀, `f=0` | 활성 메모리가 없는 호스트 유전율. |
| 가득 찬 셀, `f=1` | 선언된 벌크 Debye 두 개 응답. |
| 두 증분 모두 0 | 무손실 조화/산술 혼합. 활성 메모리나 재료 속도 없음. |
| 한 증분이 0 | 대응하는 활성 단일 극점 혼합. |
| 같은 이완 시간 | 법선 변환 전에 두 증분을 합한 물리 극점 하나. |

같은 속도 `r_1=r_2=r`에서는 `J=r*I+(g/A)*u*u^T`입니다. `u`에 평행한 모드만 구동되고, 직교 모드의 유수는 0입니다.
따라서 그 법선 법칙은 반올림으로 생긴 서로 다른 공명 한 쌍이 아니라, 정확히 `delta=delta_1+delta_2`인 단일
Debye 공식입니다.

활성 법선 모드는 유효 이완 시간이 커지는 순서로 정렬합니다. 세기가 정확히 0이거나 시간이 정확히 같아 축퇴하는
경우, 남은 활성 응답에는 슬롯 0을 쓰고 두 번째 슬롯은 유지합니다. 비활성 슬롯은 구동항과 에너지 가중치가 0입니다.
0이 아닌 작은 유수를 epsilon 임계값으로 버리지 않습니다. 축퇴는 이완 시간이 정확히 같을 때만 일어나며, 서로 다른
인접 float64 시간은 서로 다른 채로 남습니다. 구현은 작은 최종 모드 증분을 이진 스케일 곱으로 계산하므로, 중간
정규화 가중치 때문에 표현 가능한 최종 극점이 지워지지 않습니다. 유한하지 않거나 언더플로한 활성 계수와 역 에너지
가중치는 명시적으로 거부합니다. 이것이 수학적으로 유한한 모든 매개변수 조합의 허용을 약속하지는 않습니다.

증분 0은 비활성 역수 시간이나 시간 제곱을 만들기 전에 처리합니다. 따라서 유한하지만 극단적인, 쓰이지 않는 `tau`가
가짜 활성 메모리를 만들 수 없습니다. 아래의 집중 시험은 이러한 표현 요구 사항을 물리적 수렴과 별도로 검사합니다.

## 분할 점화식과 국소 에너지

증분 `delta`와 시간 `T`를 가진 각 활성 유효 모드는 기존의 사다리꼴 Debye 분할을 씁니다. 다음을 정의합니다.

```text
m = max(T, dt/2)
left = T/m
right = (dt/2)/m
u = left/(left+right)
v = right/(left+right)

gain = u-v
c = delta*v
drive = 2*delta*u*v
hold = 0
Q = P-c*E
Q^(n+1) = gain*Q^n + drive*E^n.
```

여기서 스칼라 분할 비율 `u,v`는 조화 유도에 나온 두 성분 결합 벡터와 관계가 없습니다. 필드 업데이트 유전율은
`eps_inf_eff+sum_j c_j`입니다. 모든 모드 증분은 기존 분극 점화식을 통해 Ampere 법칙에 들어갑니다. `E^(n+1)`을
포함하는 사다리꼴 항 전체는 즉시 이동으로 보존되며, 물리적 Debye 방정식에서 빠지지 않습니다.

관측자 시간 수준에서 국소 에너지 보정은 활성 슬롯에 대한 다음 합입니다.

```text
sum_j (|Q_j^n + c_j*E^n|**2/delta_j - c_j*|E^n|**2).
```

기존 공간 Debye 가지는 셀, 성분, 잘린 영역을 합하기 전에 각 역 증분과 즉시 이동을 적용합니다. 이 뺄셈은 전기장
가중치에 이미 들어 있는 이동을 상쇄합니다. 비활성 가중치는 0입니다. 이것은 이산 재료 에너지 항등식이며, 전파나
장시간 안정성 측정이 아닙니다.

계수 수준의 주파수 오라클은 같은 정확한 혼합을 `omega_hat=2*tan(omega*dt/2)/dt`에서 계산합니다. 반면 물리적
박막 연구는 실제 주파수에서의 연속체 재료를 쓰고 솔버의 공간 및 시간 오차를 포함해야 합니다.

## 합산 재료 속도 정책

저장소의 보수적인 Debye 정책은 셀의 활성 극점을 더합니다.

```text
R_bulk = (delta_1*r_1*r_1 + delta_2*r_2*r_2)/a
R_cell = sum_j delta_eff_j/(eps_inf_eff*tau_eff_j*tau_eff_j)
R_film = max(R_bulk, max_actual_cells_and_components(R_cell))
dt_bound = 1/sqrt(1/dt_nondispersive**2 + R_film/4).
```

가장 큰 개별 극점만 취하면 동시에 활성인 기여가 빠집니다. 반대로 벌크 속도와 변환된 속도를 더하면 같은 박막을 두
번 세게 됩니다. 최댓값은 실제 Yee 성분 점유율을 씁니다. 법선 셀에 대해 정확한 항등식은 다음과 같습니다.

```text
W = sum_i delta_i*r_i
R_n = (f*b/(a*A)) * (sum_i delta_i*r_i*r_i + (g/A)*W*W).
```

이것은 `sum_j w_j*w_j*lambda_j=u^T*J*u`에서 나오며, 모드 기여를 서로 무관한 재료로 해석하는 일을 피합니다. 법선
속도는 벌크 합을 넘을 수 있습니다. 접선 방향 합은 `f*sum_i(delta_i*r_i*r_i)/(f*a+g*b)`이며 벌크 값보다 크지
않습니다.

이 조건에 맞는 박막만 일반적인 선언 극점 속도 경로를 건너뛰고 범위를 한정한 합산 정책을 씁니다. 증분 0은 비활성
역수나 제곱을 계산하기 전에 0을 기여합니다. 이 정책은 보수적입니다. 수동 사다리꼴 이완 자체가 본질적으로 이 추가
시간 간격 제한을 요구하지는 않습니다. 흡수층 안정성 계약을 넓히지도 않습니다.

## 단조 벌크 스펙트럼 가드

양의 주파수 벌크 응답과 `x=omega*omega`에 대해 직접 전개하면 다음을 얻습니다.

```text
|eps(omega)|**2 = a*a + C_1/(1 + tau_1*tau_1*x)
                     + C_2/(1 + tau_2*tau_2*x)

C_i = delta_i*delta_i + 2*a*delta_i
    + 2*delta_i*delta_other*tau_i/(tau_i+tau_other).
```

두 계수는 증분 0을 포함해 모두 음이 아닙니다. `|k|**4=x*x*|eps|**2`의 상수가 아닌 각 항은 음이 아닌 미분을
가집니다.

```text
d[x*x*C_i/(1 + tau_i*tau_i*x)]/dx
  = C_i*x*(2 + tau_i*tau_i*x)/(1 + tau_i*tau_i*x)**2.
```

`a*a*x*x` 항 때문에 전체는 `x>0`에서 엄격히 증가합니다. 따라서 모든 양의 소스 대역에서 가장 큰 벌크 크기는 위쪽
끝점에 있습니다. 가드는 그 끝점에서 실제 두 극점 응답을 계산하고, 박막과 호스트 모두에 대해
`dx*|k_max|<=2*pi/8`을 요구합니다.

`f0=1/band.wavelength`, 폭 `df`, `m=band.sigmas`인 소스에서 각주파수 구간은
`[2*pi*(f0-m*df), 2*pi*(f0+m*df)]`이며, 아래쪽 끝점은 양수입니다. 범위를 한정한 계약은 선언된 모든 모니터 파장,
`Resolution` 파장, 명시적 PML 파장도 검사합니다. 표본화한 최솟값은 위상 파장당 8셀, 표피 깊이당 1셀이며, 12와 2
미만에서 내는 기존 경고는 그대로 남습니다. 대역과 파장은 구체적이고 유한한 양수여야 합니다.

이것은 벌크 스케일 분해능 하한입니다. 산란 정확도의 정리도, 모든 유효 계면이나 비스듬한 종방향 스케일에 대한
증명서도, 지속 시간과 흡수층 제어의 대체물도 아닙니다. 쓸 수 있는 스펙트럼 메타데이터가 없으면, 계획기는 벌크

| 40 | 0.007719271817 | 0.010084340268 |

성긴 최댓값은 보정 행 회귀 상한 0.005/0.010을 넘습니다. 그 상한은 알려진 p/비율 0.3 구성에만 속하며, 캠페인 정확도
임계값이 아닙니다. 가장 큰 투과 오차는 비율 0.1, 파장 0.9의 p 편광입니다. 캠페인의 바뀌지 않은 수용 기준은 선언된
잡음 관문을 갖춘 셀별 수렴 구간이며, 모든 배치가 공유하는 절대 오차 상한이 아닙니다.

가장 큰 대리 지표는 비율 0.3, 파장 1.1의 p 반사에서 2.820159e-6이며, 그중 지속 시간 기여는 2.714259e-6, 흡수층 기여는
1.059001e-7입니다. 자기 차수 잡음 비중의 최댓값은 같은 셀에서 0.00825754이고, 직접 차수 비중의 최댓값은 비율 0.3,
파장 0.9의 p 반사에서 0.02586359입니다. 둘 다 고정 한도 0.1 아래에 있습니다. 작업자 전체에서 가장 큰 모니터 감쇠
비율은 1.173587e-8입니다. 이 진단값들은 경험적 대리 지표를 엄밀한 오차 한계로 만들지 않으면서, 선언된 유한 실행
분류를 뒷받침합니다.

알려진 성긴 p/비율 0.3 응답은 기록된 모든 물리 값에서 NumPy 보정과 정확히 일치하며, 다른 것은 타임스탬프와 벽시계
시간뿐입니다. 이것은 여전히 공개한 반복이며, 독립적으로 확증하는 갈래가 아닙니다. 등록은 집중 시험 노출과 변이 노출도
공개합니다.
