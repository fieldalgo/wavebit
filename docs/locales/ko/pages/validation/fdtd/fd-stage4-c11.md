# 대각 밖 구성 칸 (4단계, C11): 등록한 관문의 결과

작성: 2026-10-27

대상: `src/wavebit/fdtd/_prepare/coefficients.py`, `src/wavebit/fdtd/_prepare/constitutive.py`,
`src/wavebit/fdtd/_prepare/checks.py`, `studies/fdtd/subpixel_tilted_tensor/fdtd_subpixel_tilted_tensor.py`,
`studies/fdtd/subpixel_mie_cylinder/fdtd_subpixel_mie_cylinder.py`,
`studies/fdtd/subpixel_coupled_cylinder/fdtd_subpixel_coupled_cylinder.py`,
`studies/fdtd/subpixel_constitutive/fdtd_subpixel_constitutive.py`.

## 요약

**C11은 작성하지 않았고, 등록한 규칙으로 닫히지도 않습니다. 규칙의 전제가 충족되지
않았으므로 결정은 소유자에게 남깁니다.** 이 기록과 함께 바뀌는 코드는 없습니다.

측정 S1과 S2를 실행하기 전에 등록한 규칙: 대각 밖(off-diagonal) 구성 칸(C11, 5단계 범위)은
**S1과 S2가 실리콘-공기 대비에서 대각 밖 항이 수렴 차수를 하나도 올리지 못한다고 보이면
작성하지 않으며**, 그때는 측정한 대각 투영 비용을 docstring에 적습니다. S1은 기울어진
**평평한** 경계면에서 그렇다고 말합니다. 2차원 Mie 원기둥인 S2는 **곡면**에서 반대로
말합니다. 대비 12의 TE 갈래에서 대각 규칙은 차수를 놓치고, 유리 구에서는 교차항을 되살리자
차수가 돌아왔습니다(1.714에서 2.023). 그 교차항은 C11 커밋이 아니라 C3 작업 중에 이미
제품 엔진에 들어가 있습니다. C11이 여전히 더할 것과 작성해야 하는지는 측정되지 않았고,
질문은 아래에 적습니다.

## 규칙이 읽는 근거

**S1, 기울어진 평평한 경계면** (`studies/fdtd/subpixel_tilted_tensor/`,
[기록](fd-subpixel-occupancy.md#s1-results-and-what-they-decide)).
대비 12, 주기당 16/32/48칸에서 대각 규칙의 맞춤 차수는 14.036, 26.565, 45도에서 0.999,
1.012, 0.864입니다. 자기수반(self-adjoint) 전체 텐서 비교기는 첫 각도에서 0.929이고 나머지
두 각도에서는 단조롭지 않습니다(서술적 맞춤값 0.387, -2.452). 기록의 판정: 표본으로 잰
텐서 대안들은 차수의 일반적 개선을 확립하지 못한다. **S1은 아니라고 말합니다.**

**S2, 2차원 Mie 원기둥, TM 다음 TE** (`studies/fdtd/subpixel_mie_cylinder/`,
[기록](fd-mie-validation.md#measured-cylinder-results)).
대각 규칙으로, 파장당 20/28/40/56칸에서 여덟 위치:

| 경우 | 평균 맞춤: 차수 / 흩어짐 |
| --- | ---: |
| TM, 유전율 1.2 | 2.058 / 6.09% |
| TM, 유전율 12 | 2.119 / 3.04% |
| TE, 유전율 1.2 | 1.827 / 4.46% |
| TE, 유전율 12 | -0.888 / 48.25% (단조롭지 않음, 실패한 맞춤) |

경계면 법선이 필요 없는 TM은 예비 단계로서 요구된 대로 2차를 보입니다. 대비 12의 TE는
표본 범위에서 수렴하지 않습니다. **S2는 대각 규칙이 고대비 곡면에서 차수를 놓친다고
말합니다.** TM은 수렴하고 TE는 실패하는 이 모양은 설계가 미리 대각 밖 항의 부재로 돌린
모양입니다.

**곡면에서의 교차항** ([기록](fd-mie-validation.md)):

| 측정 도구 | 대각만 | 교차항 포함 |
| --- | ---: | ---: |
| 유리 구, 통제된 비교기, 파장당 20/28/40칸 | 1.714 | **2.023** |
| 제품 구, 유전율 1.1 / 2.25 / 12 | -- | 2.075 / 2.023 / 1.827 |
| 제품 원기둥, TE, 유전율 12, 여덟 위치, 40/56/80 | (실패, 위) | **1.603** (1.8 미달) |
| 대칭 모서리/면 연구 비교기, 같은 원기둥 | -- | 1.825 |
| 확장 스텐실(`discretisation='stencil'`), 같은 원기둥 | -- | 2.138 |

즉 대각 밖 항은 유리 구에서 차수를 하나 올립니다. 고대비 원기둥에서 제품의 교차항 구현은
대각 규칙의 실패한 맞춤을 개선하지만 1.8 아래에 머뭅니다. 거기서 통과하는 것은 확장
스텐실뿐입니다.

## 규칙이 정하는 것과 정하지 않는 것

규칙의 "작성하지 않음" 갈래는 S1 **과** S2가 모두 아니라고 해야 합니다. S2가 그렇지 않으므로
**C11은 등록한 규칙으로 닫히지 않습니다.** 함께 등록한 반대 갈래(5단계에서 자기수반 구현과
비에르미트성 관문으로 칸을 엶)는 일부가 일찍 실현되었습니다.
`src/wavebit/fdtd/_prepare/constitutive.py`와 커널의 구성 항은 매끈한 물체 주변의 작은
영역에서 D와 B를 적분하고 공통 마디에 수반(adjoint) 교차 계수를 더합니다
([제품 구성 결합](fd-mie-validation.md#production-constitutive-coupling-and-energy)).
이 실현은 C11 초안이 피하려던 D/B 상태 필드를 가진다는 점에서 다르고, **등방성** 매질만
다룹니다.

이 결과에 대한 소유자의 지시에 따라 여기서는 아무것도 만들지 않습니다. 대각 규칙의 측정된
비용은 이미 `coefficients.mix`의 docstring에 있습니다(위의 S1 차수).

## 소유자 결정에 빠진 것

1. **범위.** C11을 (a) C3 시기의 교차 결합으로 실현된 것으로 닫을지, (b) 아직 거부되는
   것, 곧 매끈한 칸 안의 **이방성 재료**(`checks.check_smoothed`의 4번 문)로 범위를 다시
   잡을지. (b)를 잰 측정은 없습니다. S1과 S2 모두 등방성 매질을 썼습니다.
2. **고대비 원기둥.** 제품 교차항을 쓴 복셀 경로는 TE 유전율 12 원기둥에서 여전히 1.8선에
   못 미칩니다(1.603). 다른 대각 밖 구현이 통과할지는 측정되지 않았습니다. 확장 스텐실은
   이미 통과합니다.
3. **C11에 등록한 관문.** 1e-12 미만의 비에르미트성 단언이 C11 자체의 관문이었습니다. 제품
   결합은 구성상 자기수반(수반 평균)이며 비균질 수반 항등식과 조밀한 유한 연산자 시험으로
   확인합니다. 이것을 C11의 관문으로 칠지는 소유자가 정합니다.
