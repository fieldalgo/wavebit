# 실험을 바꾸지 않는 반공간 미분

작성: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `src/wavebit/fdtd/_periodic/grid.py`
- `src/wavebit/fdtd/_periodic/legacy.py`
- `tests/fdtd/test_fdtd_halfspace_gradients.py`
- `tests/references/interface/meep_halfspace.py`
- `tests/references/test_meep_halfspace.py`

요약: 양의 실수인 위/아래 epsilon과 mu가 이제 명시적 백엔드 장면 엔진을 거치면서 미분을
유지합니다. 정적인 명목값 `mesh_indices`가 패딩과 등급화(grading)를 선택하고, 실제 재료는 CPML을
포함한 물리 계산과 보정 계산 전체를 결정합니다. 서로 독립인 계수 미분, 같은 격자에서의 유한
차분, 자기 Airy 세분화, 공개 API를 통한 Meep 섭동이 계약의 서로 다른 부분을 검사합니다.

## 기하는 따로 선택해야 합니다

이전에는 반공간 계수를 Python 복소수로 바꾸는 과정에서 그 그래프가 끊겼습니다. 또한 그렇게
얻은 굴절률이 패딩 셀 개수와 등급화된 셀 폭을 선택할 수 있었습니다. 변환만 없애면 메시가 미분
대상 데이터에 의존하게 됩니다. 그렇다고 그 값을 분리(detach)해 평가할 때마다 새 메시를 만들면
서로 다른 이산 실험을 비교하게 됩니다.

그래서 [사용 계약](../../guide/fdtd/time-domain.md#half-space-material-derivatives)은 바깥 계수 중
하나라도 배열이면, 명시적인 양의 정적 쌍 `mesh_indices`와 회절 창을 요구합니다. 이 명목 굴절률은
기하만 제어합니다. 스칼라 호스트 재료는 이전의 기본 메시 정책을 유지합니다. 명목 배경 진단과
실제 배경 진단 모두 아래쪽 조명을 포함해 원래의 위/아래 순서를 씁니다.

미분에는 경계 셀 재료 평균, Maxwell 갱신, 재료에 의존하는 CPML 계수, 입사 매질 기준 실행,
방향별 어드미턴스 투영, 계면 위상 기준과 전력 정규화가 포함됩니다. theta/phi를 고정하면 입사
굴절률이 가로 방향 Bloch 벡터를 바꾸고, 중심 파장에서의 각도는 보존됩니다. 비스듬한 입사의
미분을 다른 솔버와 비교할 때는 이 점을 포함해야 합니다.

실행 시간과 CFL 검사는 실제 재료를 씁니다. 실제 광학 이동 시간이 늘어나면, 다른 조건이 고정된
실행도 무효가 될 수 있습니다. 솔버가 몰래 갱신 단계를 더하지는 않습니다. 구체적인 잘못된 입력은
예외를 일으킵니다. 추상적인 JAX 위반은 `stable`을 무효로 만들고 산란 결과와 정규화된
모니터/기록 필드를 마스킹합니다.
출사 굴절률을 연속 스펙트럼 차단점 너머로 바꾸어도 양쪽에서 JIT 추적 하나와 메시 하나가
유지됩니다. 정확히 스치듯 입사하는 유지 채널은 거부하거나 마스킹합니다. 이 보호 장치는 차단점
근처의 수렴을 보장하지 않습니다.

## 흡수층은 미분하는 계산의 일부입니다

이제 native API는 살아 있는 `pml_background` 쌍도 받습니다. 정적인 물리 기하와 프로필 세기는
따로 남습니다. 굴절률 `n = sqrt(epsilon*mu)`에 대해 기존 좌표 늘림은 `sigma_max`가 `1/n`에
비례하므로, 다른 변수를 고정했을 때 각 계수는 `d sigma / d epsilon = -sigma/(2*epsilon)`와
`d sigma / d mu = -sigma/(2*mu)`를 따릅니다.
테스트는 두 끝 층 모두에 대해, 서로 다른 물리 두께와 정확히 항등인 내부 계수까지 포함해 지수
점화식과 몫을 독립적으로 미분합니다. 값과 야코비안은 두 AD 백엔드 모두에서 `2e-15` 안에서
일치합니다. 어떤 백엔드도 Maxwell 방정식을 따로 복제하지 않습니다.

Native 전체 루프 테스트는 균일 메시와 비균일 메시에서 바깥 계수 네 개를 모두 변화시킵니다. 두
유한 차분 간격 `2e-5`와 `1e-5`로 전력, 기록된 전기장, 최종 자기장을 `rtol=2e-6`,
`atol=2e-9`에서 검사합니다. CPML 가장자리 계수와 인접한 내부 계수는 여전히 입력한 배경과
일치해야 하며, 전도도나 0이 아닌 극점 세기를 가질 수 없습니다.

장면 그래프 테스트는 여기에 더해, 교차하는 아래쪽 조명 장면에서 입사 theta와 Lorentz 세기를
변화시킵니다. 이 장면에는 등급화/정렬된 z 기하, 서로 다른 가로 방향 표본화, 스펙트럼 소스 영점,
서로 독립인 소스 위치와 추출 위치, 복소 Jones 진폭, 잘라 낸 이력, 내부 모니터와 접두 구간 수렴
진단이 포함됩니다. 전기장 추출과 방향별 추출 모두 간격 `2e-4`와 `1e-4`의 결과와
`rtol=6e-5`, `atol=4e-8`에서 일치합니다.

## 독립적인 광학과 외부 미분

측정에는 macOS arm64 CPU, NumPy, JAX x64, Torch float64를 씁니다. 평면 사례는 위쪽 epsilon/mu가
`(1.2,1.1)`, 아래쪽이 `(1.6,1.15)`, 두께 0.2 박막 안쪽이 `(2.25,1.12)`입니다. 파장은 수직
입사에서 0.98과 1.02입니다. 연속체 기준(oracle)은 자기 어드미턴스 `sqrt(epsilon/mu)`를 쓴 두
계면 Airy 식입니다. 그 네 계수 미분은 Wavebit의 전파, 보정, CPML 보조 함수가 아니라, 그 해석식의
독립적으로 수렴시킨 차분에서 얻습니다.

FDTD 세분화는 해상도 40/80, 정렬된 층, 주기 0.05, 물리 PML 두께 1, 가우시안 폭 3, 실행 시간
65를 씁니다. 복소 진폭과 R/T를 모두 미분합니다. 세분화는 값 오차와 미분 오차의 최댓값을 2배보다
많이 줄여야 하며, 해상도 80에서 각각 0.005보다 작아야 합니다.

| 해상도 | 실수 출력 최대 오차 | 야코비안 최대 오차 |
| --- | ---: | ---: |
| 40 | 0.00495837 | 0.00525952 |
| 80 | 0.00123219 | 0.00129845 |

각 최댓값은 두 파장 모두에서 r/t의 실수부/허수부와 R/T를 포함합니다. 야코비안 최댓값은 바깥
계수 네 개 전체에 걸친 값이기도 합니다. 셀 폭을 절반으로 줄이면 두 오차 모두 약 4배 줄어듭니다.

Meep 1.34.0은
[문서화된 공개 API](https://meep.readthedocs.io/en/latest/Python_User_Interface/)를 통해 실행했습니다.
구현은 읽거나 복사하지 않았습니다. 프로젝트가 소유한 생성기는 길이 10, 해상도 80인 고정된 1차원
셀에서, 매개변수 섭동마다 물리 슬래브 실행 하나와 입사 매질 기준 실행 하나를 돌립니다.
PML 두께는 1이고, 소스는 z=-3에 있으며, Ex 측정 평면은 -1과 1.2에 있습니다. 폭 1.2인 가우시안
사인 전류는 시간 6에서 최고점에 이르고 12에서 끝납니다.
균질 Yee 분산으로 측정 평면을 계면까지 역보정(de-embed)합니다.

| 외부 기준 대조 | 최대 절대 차이 |
| --- | ---: |
| 진폭, 실행 시간 50 대 70 | 저장 정밀도에서 0 |
| 미분, 실행 시간 50 대 70 | 저장 정밀도에서 0 |
| 미분, 섭동 1e-3 대 5e-4 | 5.79e-8 |
| Meep 진폭 대 연속체 Airy | 0.001293 |
| Meep 미분 대 연속체 Airy | 0.001763 |

일반 테스트는 Meep을 가져오지 않고 고정된 기준값을 읽습니다. Wavebit의 복소 진폭은 0.003 안에서,
JAX 야코비안은 0.005 안에서 일치해야 합니다. 측정된 최대 차이는 진폭에서 `0.000768690`, 야코비안에서
`0.00250055`입니다. 외부 매개변수 방향 네 개는 각각 진폭 기울기 최댓값이 0.1보다 커서, 그래프가
없는 경우가 이 허용 오차를 통과하지 못하게 합니다.
이것은 서로 다른 격자/시간 간격과 PML 정식화 사이의 비교이며, 두 유한 차분 알고리즘이 같다는
주장이 아닙니다.

외부 기준값은 따로 설치한 Meep 인터프리터로만 다시 생성하고, 독립 대조를 그대로 유지하세요.

```shell
"$MEEP_PYTHON" tests/references/interface/meep_halfspace.py --output artifacts/meep-halfspace.npz
```

## 한계

유한 격자 미분은 정확하더라도 물리적 답은 여전히 충분히 분해되지 않았을 수 있습니다. 명목 메시
굴절률은 넓은 재료 범위에서의 정확도를 보장하지 않습니다.
[Meep PML 문서](https://meep.readthedocs.io/en/latest/Perfectly_Matched_Layer/)도 두께 수렴 검사와,
의미 있는 소멸파 필드로부터 떨어뜨릴 것을 요구합니다. 설계를 실제로 쓸 범위에서는 해상도, 물리
PML 두께, 패딩과 실행 시간을 세분화하세요.

이번 확장은 양의 실수 스칼라이며 분산이 없는 바깥 매질을 다룹니다. 손실/분산 반공간, 기하 미분,
임의의 PML 이방성, 차수 개수 변화를 지나는 미분은 추가하지 않습니다. 외부 사례는 평면이고 수직
입사이므로, 일반적인 conical 미분이나 문턱 근처의 미분을 검증하지 않습니다. CPU 미분과 선택한
회귀 테스트만으로는 GPU 동작, Torch compile 지원, 솔버 전체의 일치를 확립하지 못합니다.
