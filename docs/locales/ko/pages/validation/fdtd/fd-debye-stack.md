# C8: 떨어져 있는 Debye 박막들

작성: 2026-10-09

대상: `src/wavebit/fdtd/_prepare/debye_stack.py`, `src/wavebit/fdtd/_prepare/plan.py`, `src/wavebit/fdtd/_prepare/params.py`, `src/wavebit/fdtd/_prepare/coefficients.py`, `src/wavebit/fdtd/_prepare/checks.py`.

## 현재 상태

범위를 한정한 구현의 수치 관문이 완료되었습니다. 새 사례 147개 전부와 관련 사례 1314개가 통과합니다. 실제
제품 소스 변이 13개가 각자 의도한 단언에서 실패하고, 정확히 복원한 뒤에는 새 사례 147개 전부가 통과합니다.
전체 FDTD 비느린(non-slow) 계층은 기존 건너뜀 8개와 함께 4324개 사례를 통과하고, 별도의 느린 계층은 81개를
통과하며, 동결 배열 1141개 전부가 비트 단위로 재현됩니다.

등록한 연구는 작업자 40개를 완료하고 복소 셀 48개 전부를 유지합니다. 고정된 민감도 구간 기준은 자기 차수
42/48개와 최종 직접 차수 48/48개를 2차로 분류합니다. 아래 표는 다른 모든 결과도 그대로 유지합니다. 이 측정
픽스처들이 허용되는 모든 적층에 대해 2차 수렴을 확립하지는 않습니다.

새 경로는 패딩한 격자 지지 영역이 서로 겹치지 않는, 평행한 Debye 박막 두 개 이상을 합성합니다. 각 구성원은
기존의 Debye 하나, 둘 또는 유한 합 구현을 그대로 유지합니다. 일반 C8 스무딩과
[C7 메타표면 판정](fd-metasurface-validation.md)은 아직 열려 있습니다.

## 범위를 한정한 공개 계약

일반 Scene structures 튜플에 Box 형상과, 극점이 모두 정확한 Debye 선언인 Dispersive 재료를 쓰세요. 새 공개 적층
생성자는 없습니다.

| 항목 | 허용되는 경우 |
| --- | --- |
| 구성원 | 정확한 Dispersive 재료 두 개 이상. 각각 정확한 수동 Debye 선언을 하나 이상 담습니다. 선언 개수가 서로 다른 재료가 한 장면에 함께 있어도 됩니다. |
| 형상 | 회전하지 않고 범위를 두지 않은 구체적인 voxel Box 박막. 모두 같은 법선 축을 가집니다. |
| 범위 | 각 박막은 기존의 한 셀 돌출과 함께 두 횡방향 축 전체에 걸치고, 법선 방향 두께가 최소 dx이며, 도메인 벽과 모든 흡수층에서 떨어져 있습니다. |
| 분리 | 실제로 패딩한 반열린 지지 구간이 쌍마다 서로 겹치지 않아야 합니다. 물리적으로 닿지 않는다는 사실만으로는 허용되지 않습니다. |
| 재료 | 유한한 양의 등방성 고주파 유전율, 유한한 음이 아닌 증분, 유한한 양의 이완 시간, mu=1. |
| 호스트 | 정확한 일반 양의 등방성 무손실 비자성 Material 하나. |
| 실행 | 고정된 지속 시간, 초기 필드 없음, 추적되는 형상/재료/대역 값 없음. 새 경로는 Decay를 거부합니다. |
| 계획 | 순서가 있는 구성원 서명, 선언된 슬롯 개수, 경계 선언이 일치해야 합니다. 빠지거나, 순서가 바뀌거나, 중복되거나, 다른 데서 온 메모리 항은 거부합니다. |

세기가 0인 선언과 시간이 정확히 같은 선언도 예약된 슬롯을 유지합니다. 형상과 분리 제한은 완전히 비활성인
구성원에도 적용됩니다. 공간 순서가 선언 순서와 달라도 진단에는 원래 구조 인덱스가 나타납니다. 기존 소스와
모니터 계약은 그대로 유효합니다. 특히 이것으로 TFSF의 층 배경 범위가 넓어지지는 않습니다.

곡면 손실 물체, 맞닿은 박막, 접합, 손실/분산 호스트, Debye와 다른 재료 계열을 섞은 적층, 미분은 이 확장의
범위 밖입니다. 단일 박막 축약기는 각자의 유한 범위 거부와 작업량 예산 거부를 유지합니다.

## 계면 법칙과 합성

저장소 규약 exp(-i*omega*t)를 쓰고 s=-i*omega로 둡니다. 구성원 하나에 대해 epsilon(s)=a+chi(s),
chi(s)=sum(delta_i/(1+tau_i*s)), 호스트 유전율 b, 박막 비율 f, 호스트 비율 g=1-f로 쓰면 다음과 같습니다.

~~~text
A = f*b + g*a
alpha = g/A
kappa = f*b*b/A**2
epsilon_t(s) = f*(a+chi(s)) + g*b
epsilon_n(s) = a*b/A + kappa*chi(s)/(1+alpha*chi(s)).
~~~

조화 법선 법칙은 감수율 합 전체를 변환합니다. 기존 [단일 Debye](fd-debye-film.md), [Debye 둘](fd-two-debye-film.md),
[유한 합](fd-debye-sum-film.md) 축약기가 그 수동 메모리를 바꾸지 않고 공급합니다. 어느 축약기를 고를지는 활성 모드
수가 아니라 선언된 개수를 따릅니다. 다극점 법선 법칙을 근사적으로 합치거나 독립적인 단일 극점으로 근사하지
않습니다.

각 전기 성분은 단일 박막에서의 Yee 셀 비율을 유지합니다. 패딩한 지지 영역이 서로 겹치지 않으므로, 합성기는 각
단일 박막의 완전한 업데이트 프로파일을 호스트에 붙여 넣고 잘라 낸 극점 매개변수를 재사용할 수 있습니다. 어떤 E
노드도 재료 업데이트를 두 번 받지 않습니다. 자기 매질은 균일하고 비자성으로 유지됩니다.

기존의 분할 Debye 점화식과 저장 관측자를 재사용합니다. 재료 저장 보정은 서로 겹치지 않는 지지 영역에 걸쳐
더하고, 전역 전기/자기 저장은 한 번만 셉니다. 선언된 각 극점은 자기 잘린 영역 위에서 세 성분을 가진 이력 세 개를
유지합니다. 상태 바이트 보고는 명목상의 슬롯 개수만이 아니라 실제 할당기로 확인해야 합니다.

## 안정성과 벌크 스펙트럼 검사

M1=sum(delta_i/tau_i), M2=sum(delta_i/tau_i**2)로 둡니다. 독립적인 국소 재료 속도 항등식은 다음과 같습니다.

~~~text
bulk:       M2/a
tangential: f*M2/(f*a+g*b)
normal:     kappa*(M2+alpha*M1**2)/(a*b/A).
~~~

구현은 반올림된 유효 계수까지 포함해 각 단일 박막 정책을 재사용한 뒤, 구성원들에 걸친 최댓값을 취합니다. 한
구성원 안에서 서로 다른 극점의 속도는 공간 최댓값을 구하기 전에 더합니다. 떨어져 있는 구성원의 최댓값끼리는
더하지 않습니다. 기존 물리 고주파 유전율이 curl 상한을 공급합니다. 이것은 저장소의 보수적인 정책을 유지하는
것이며, 새로운 필요 안정성 조건이나 PML 정리가 아닙니다.

모든 구성원과 호스트를 요청된 모든 모니터, Resolution, 명시적 PML 파장에서, 그리고 모든 소스 대역에 걸쳐
검사합니다. 수동 Debye 합에 대해 x=omega**2로 둡니다. 다음 항등식은

~~~text
|epsilon|**2 = a**2 + sum(C_i/(1+tau_i**2*x))
C_i = delta_i**2 + 2*a*delta_i
      + sum(j != i, 2*delta_i*delta_j*tau_i/(tau_i+tau_j))
~~~

음이 아닌 C_i를 가집니다. 각 x**2/(1+t*x)는 양의 x에서 증가하므로, 벌크 |k|는 소스 대역의 위쪽 끝점에서 가장
큽니다. 끝점 산술은 표현된 공개 부동소수점 상수에 대해 정확한 유리수를 씁니다. 각각 위쪽으로 검증한 제곱근 두
개가 그 결과인 네제곱근을 위에서 묶습니다. 표현할 수 없는 중간값은 명시적으로 거부합니다. 입력이 유한하다는
것만으로 모든 극단적인 스케일에서 허용된다고 약속하지는 않습니다.

물려받은 위상/표피 강제 하한은 8/1 셀이고, 경고 하한은 12/2입니다. 요청된 스펙트럼 데이터가 없으면 추론된 벌크
증명서도 없습니다. 이 검사들은 계면 정확도, 적층 공명 분해능, 충분한 지속 시간, 흡수층 품질, 보편적인 수렴 차수를
확립하지 않습니다.

## 독립 검증과 등록한 물리 연구

시험은 모든 법선 축, 선언 개수 1/2/N, 실제 점화식을 거친 독립적인 유리수 직렬/병렬 응답, 독립적으로 계산한 셀
채움, 저장과 닫힌 Yee 손실, 실제 상태 할당, 단일 박막과의 동등성, 모든 구성원의 CFL/스펙트럼 검사, 그리고 완전한
범위/계획 거부를 다룹니다. 실제 제품 소스 변이는 바이트 단위로 정확히 복원하기 전에 의도한 단언을 일으켜야
합니다.

고정된 물리 측정 장치는 복소 반사와 투과를 기존 연속체 다층 특성 행렬과 비교합니다. 선언된 Debye 유전율, 모든
호스트 틈, 바깥 면 기준 위상은 명시적입니다. 독립적인 역방향 Fresnel 재귀와 복소 단일 박막 Airy 제어가 필드 측정
전에 기준값을 검사합니다.

비대칭 픽스처 두 개는 각각 1+2개와 3+4+1개의 선언 극점을 담습니다. 뒤의 것에는 세기 0인 선언과 완전히
비활성인 구성원이 들어 있습니다. 공개한 보정은 성긴 p 편광 구성 두 개를 NumPy, JAX, Torch에서 씁니다. 6개 행
모두 유한한 양의 에너지와 안정적인 진단으로 완료됩니다. 복소 진폭의 최대 절대 오차는 반사에서 0.00413897832,
투과에서 0.00792802502입니다. 공개와 독립적인 스칼라 기준 재실행을 거친 뒤, 알려진 사례 회귀 상한을 0.005와
0.01로 정했습니다. 이 값들은 상대 전력 오차나 보지 않은 데이터에 대한 정확도 관문이 아닙니다. 일치하는 성긴 캠페인
행은 알려진 반복이며, 독립적인 확증이 아닙니다. 전후 시험과 유일한 docstring/상한 전환은 수용 기록에 남아 있습니다.

별도의 작업자 40개 연구는 파장 0.9/1.0/1.1, 횡방향 파수 벡터를 고정한 중심 각도 35도, s/p 편광, 배치 0.3/0.1, 해상도
40/80/160을 고정합니다. 각 배치/편광에는 중간 격자 제어 두 개, 즉 주기 240과 PML 셀 48이 들어 있습니다. 기본 실행은
주기 120과 PML 셀 24를 씁니다. 사전 등록한 지속 시간 미안정화 대체만 허용하며, 결과를 보고 고른 형상, 파장, 추가 단계는
허용하지 않습니다.

복소 셀 48개, 자기 차수 48개, 직접 쌍 96개가 모두 보이도록 남아 있습니다. 물려받은 지속 시간/PML 민감도 구간은 혼합,
낮음, 미분해 사례를 남길 수 있습니다. 측정 장치가 완료되었다는 것과 2차라는 판정은 별개입니다.

제품 통합에는 추가로 엄격한 문서 빌드와 독립적인 저장 증거 감사가, 그 실제 부모 프로세스 종료와 함께 필요합니다.
위의 수치 개수는 완료된 원시 기록에서 가져온 것입니다. 기존 증거와 기준 배열은 바뀌지 않습니다.
