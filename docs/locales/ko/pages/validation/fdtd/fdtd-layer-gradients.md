# 고정 메시 위의 내부 층 미분

작성: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `tests/fdtd/test_fdtd_layer_gradients.py`
- `studies/fdtd/layer_gradients/fdtd_layer_gradients.py`
- `tests/references/test_meep_layer_thickness.py`

- `examples/fdtd/fdtd_layer_optimization.py`

요약: 명시적 백엔드 장면은 정적 `mesh_thickness`와 함께 미분 가능한 층 두께를 받습니다. 실제 길이는
양수로 유지되며 공칭 전체 깊이를 보존합니다. 내부 계면은 아래쪽 조명, 기록, 전기 극점 마스크를
포함하여 고정된 Yee 메시 하나 위에서 움직입니다. JAX/Torch 미분은 유한 차분과 일치합니다. 평면 미분은
독립적으로 섭동한 Meep 실행과 가깝게 일치하지만, 두 이산화 모두 상당하고 위치에 따라 달라지는 연속체
미분 오차를 지닙니다.

## 실제 형상과 공칭 메시

`thickness`는 RCWA와 공유 `Stack`에서와 같은 의미, 즉 각 층의 실제 물리 길이를 유지합니다. 별도의 FDTD
형상 표현은 없습니다. `mesh_thickness`는 셀 수, 맞춘 공칭 면, 단계형 패딩을 선택합니다. 층마다 양의
정적 실수 길이 하나를 가집니다. 공칭 전체 깊이가 D일 때, 허용되는 2층 설계는 0 < d < D에 대해
`[d, D-d]`입니다. 다층 설계는 D로 정규화한 양의 비율을 쓸 수 있습니다. 이처럼 전체 깊이가 일정한 경로를
따른 미분만 지원하며, 전체 깊이를 독립적으로 바꾸는 것은 이 API의 미분 계약 밖입니다.

소스, PML, 추출 평면, 모니터 좌표, 기록 선택, 시간 간격, 업데이트 횟수는 고정됩니다.
`align_layers=True`는 **공칭** 계면을 맞춥니다. 실제 내부 계면은 그 노드를 가로지를 수 있습니다. 두
바깥 면은 정확히 0과 D로 유지되므로, 반사와 투과는 명시된 계면 위상 기준을 유지합니다. 아래쪽 조명은
공칭 메시와 실제 층을 따로 뒤집은 다음, 원래 좌표의 진단값을 복원합니다. `layer_planes`는 실제 백엔드
그래프를 유지하며, 진단값의 `mesh_thickness`는 원래 순서의 정적 튜플입니다.

JAX/Torch 두께 배열에는 명시적 `mesh_thickness`가 필요합니다. 새 메시를 만들려고 즉시 실행 배열을
조용히 분리하는 일은 없습니다. 일반 호스트 두께는 이 옵션을 생략하면 기존 메시 선택을 유지합니다. 이
옵션에는 `subpixel=True`가 필요합니다. 점 표본화로는 계면이 불연속적으로 건너뛰며 움직이기 때문입니다.
유효하지 않은 구체 길이나 전체 깊이는 스텝을 진행하기 전에 예외를 발생시킵니다. JAX JIT 아래에서는
유효하지 않은 길이나 합계가 `stable=False`와 NaN 산란 및 정규화 필드를 만듭니다. 전체 깊이 검사는 합의
반올림 오차를 위해 D의 기계 엡실론 32배까지 허용하며, 두 바깥 면은 정적 공칭 위치에 고정됩니다.
표현된 경계는 그 면들 안에서 엄격한 순서를 유지해야 하므로, 합 허용 오차 때문에 양수이지만 분해할 수
없는 마지막 층이 조용히 사라질 수는 없습니다.

## 무엇을 미분하는가

고정 셀 [L,R]과 움직이는 층 [a,b]에 대해 정규화하지 않은 겹침은
`max(0, min(R,b) - max(L,a)) / (R-L)`입니다. 이 비율들은 두 바깥 매질을 포함하여 음이 아닌 분할을
이룹니다. 같은 백엔드 계산이 전기 및 자기의 산술/접선, 조화/법선 평균과, 산술 전기 극점 채움 비율에
공급됩니다. 외부 구현, 분리된 형상, straight-through 추정기는 쓰지 않습니다.

이 이산화는 연속이고 구간별로 미분 가능합니다. 셀 면을 가로지르는 지점에서는 한쪽 미분값이 서로 다를
수 있습니다. 꺾인 점에서의 백엔드 하위 그래디언트는 유일한 연속체 형상 미분이 아닙니다. 유한 차분은
그런 교차점에서 떨어진 곳에서 검사하고, 연속체 오차는 여러 경계 위치에서 평가하세요. 극점 마스크
미분은 기존의 평균화된 ADE 모델을 올바르게 미분하지만, 그것이 일반적인 분산 계면 균질화 정리를
확립하지는 않습니다.

[Meep 서브픽셀 스무딩 문서](https://meep.readthedocs.io/en/latest/Subpixel_Smoothing/)는 접선 산술
평균과 법선 조화 평균, 그리고 날카로운 모서리, 계면, 분산 재료 근처의 한계를 설명합니다. 이 문서는 공개
이론 문서로 참고했습니다. Meep 구현 코드는 열거나 복사하지 않았습니다. 앞서 제외한 Meep 유래 FDTDX
투영 구현도 살펴보지 않았습니다.

## 이산 그래프 검사

겹침 테스트는 세 백엔드 모두에 대해 크기가 다른 셀에서 독립적으로 계산한 비율과 계면 미분을
검사합니다. 장면 전체 테스트는 CPU에서 JAX x64와 Torch float64를 써서, 교차된 타입 `Stack` 안에서
두께, 래스터 epsilon, 극점 세기, 바깥 epsilon을 함께 바꿉니다. 여기에는 위/전기 추출과 아래/방향
추출, 서로 다른 공칭 층 길이와 비균일 맞춤 메시, Jones 입력, 두 파장, 펄스 노치, 사용자 필드 평면,
잘라 낸 시간 기록, 접두 수렴 출력이 포함됩니다. 두 중심 차분 간격 2e-5와 1e-5는 rtol 5e-5, atol
4e-8에서 AD와 일치합니다.

JIT 테스트는 한 번의 추적 안에서 내부 계면을 셀 사이로 움직입니다. 별도의 검사는 계산 격자, 시간 설정,
소스/기준 위치를 보존하고, 공칭 두께에서 이전 순방향 결과를 재현하며, 유효하지 않은 입력을 거부합니다.
이 검사들은 유한 계산의 미분을 확립할 뿐, 임의 형상이나 분산 패턴에 대한 연속체 정확도를 확립하지
않습니다.

측정에는 macOS arm64, Python 3.12.9, NumPy 2.5.1, JAX 0.11.0, Torch 2.13.0을 사용했습니다. GPU 실행은
이 검사에 포함되지 않았습니다.

## 연속체 세분화는 위치에 따라 다릅니다

독립적인 Fresnel/Airy 급수는 위쪽 `(epsilon,mu)=(1.2,1.1)`, 박막 `(2.25,1.12)`, 기판 `(1.6,1.15)`를
사용합니다. 박막은 [0,d]를 차지하고, 기판 스페이서가 고정 출력 평면 D=0.4까지 이어집니다. 투과에는
스페이서 위상이 포함됩니다. 그 두께 미분을 빼면 서로 다른 기준 평면을 비교하게 됩니다. 파장은 수직
입사에서 0.98과 1.02입니다. 장면은 방향 추출, 물리 PML 두께 1, 펄스 폭 3, 지속 시간 65를 사용합니다.
오라클의 두 섭동 크기는 8.4e-9 이내로 일치합니다.

이 기준 좌표는 조명된 위쪽 면에서 아래로 향하는 과거의 z축을 사용합니다. 현재 공개 좌표인 위쪽 z에서는
`z_public = D - z_report`이며, 박막은 `[D-d, D]`, 기판 스페이서는 `[0, D-d]`를 차지합니다.

두 파장에서 r/t의 실수부/허수부와 전력 R/T 전체에 걸친 최대 절대 오차:

| 분해능 | d=0.163 값 / 미분 | d=0.173 값 / 미분 | d=0.183 값 / 미분 |
| --- | --- | --- | --- |
| 20 | 0.02810 / 0.28545 | 0.02763 / 0.57148 | 0.02864 / 0.44209 |
| 40 | 0.006394 / 0.35055 | 0.006778 / 0.04671 | 0.006718 / 0.17227 |
| 80 | 0.001660 / 0.003936 | 0.001681 / 0.04804 | 0.001665 / 0.10869 |

여기서 값은 일관되게 좋아집니다. 개별 미분 오차는 단조롭게 줄지 않습니다. 세분화하면 셀 안에서의 계면
위치가 바뀌기 때문입니다. 표본으로 뽑은 미분 오차의 최댓값은 0.5715에서 0.3505, 0.1087로 줄어듭니다.
이 세 위치는 측정한 표본이며, 모든 두께에 대한 최악의 경우 상한이 아닙니다. 작은 R/T 오차로부터 미분
정확도를 추론하거나, 유난히 유리한 계면 위치만 골라서는 안 됩니다.

저장소 루트에서 측정을 재현합니다.

```shell
python -m studies.fdtd.layer_gradients.fdtd_layer_gradients --output artifacts/layer-gradients.json
```

## 독립 Meep 섭동

`golden_meep_layer_thickness.npz`는 Meep 1.34.0의 문서화된 공개 API로, 고정된 1차원 셀에서 분해능 80,
d=0.173으로 생성했습니다. 두 섭동(1e-3, 5e-4), 두 지속 시간(50, 70), 복소 r/t, 실험 메타데이터를
담고 있습니다. 셀 길이는 10, PML 두께 1, Courant 비율 0.4, 소스 z=-3, E 평면 z=-1과 1.2입니다. 폭 1.2인
Gaussian 전류가 6에서 최대가 되고 12에서 끝납니다. 각 섭동은 기준 시뮬레이션과 실제 시뮬레이션을
반복하며, 위상은 0과 D=0.4를 기준으로 합니다.

두 지속 시간 변화는 저장 정밀도에서 모두 0입니다. 섭동을 줄이면 미분이 최대 2.32e-6만큼 바뀝니다.
Wavebit은 Meep과 복소 진폭에서 7.67e-4, 복소 두께 미분에서 9.24e-4만큼 다릅니다. Meep 자체의 Airy 대비
최대 미분 차이는 0.0510입니다. 따라서 유한 격자 사이의 가까운 일치는 그 연속체 미분이 0.001까지
정확하다는 것을 보여 주지 않습니다. 이 기준은 수직 입사 자성 박막 하나를 다루며, 패턴이 있거나
비스듬하거나 손실 있는 형상 민감도는 다루지 않습니다.

```shell
"$MEEP_PYTHON" tests/references/interface/meep_halfspace.py --parameter thickness --output artifacts/meep-layer-thickness.npz
```

## 설계 활용과 남은 범위

[코팅 예제](../../../examples/fdtd/fdtd_layer_optimization.py)는 공유 타입 `Stack`과 JAX 그래디언트를
써서, 보상용 기판 스페이서와 함께 반사를 줄입니다. 백트래킹은 측정된 개선만 받아들이며, 최종 설계는
두 배 분해능에서, 그리고 1/4 파장 광학과 비교하여 검사합니다. 이는 범위가 한정된 단일 매개변수
예제이며, 임의 다층 최적화의 수렴에 대한 증거가 아닙니다.

분해능 40에서 받아들인 업데이트 20번이 코팅을 0.12에서 0.203802로 옮깁니다. 그 메시에서 반사는
0.014673에서 약 3.05e-8로 떨어집니다. 같은 최종 설계는 분해능 80에서 1.61e-7, Airy에서 2.57e-7을 주며,
정확한 1/4 파장 두께는 0.204124입니다. 최종 설계는 물리적 최적값에 가깝지만, 학습 격자에서의 더 작은
반사만 보면 물리적 성능을 과대평가하게 됩니다.

이후의 [계면 평균화 확장](fdtd-layer-smoothing.md)은 고정된 물리 평균 폭을 쓰는 선택적 C1 표본화를
추가합니다. 위의 기본 날카로운 겹침 측정은 바뀌지 않았습니다. 전체 깊이 변화, 횡방향 형상/래스터 경계
미분, 이방성 형상 균질화, GPU 실행은 이 변경의 범위 밖에 남습니다. 같은 2026-09-09 늦게
`variable_depth=True`가 전체 깊이 미분을 추가했고([기록](fdtd-variable-depth.md)), 횡방향 직사각형
미분이 반영되었습니다([기록](fdtd-rectangle-gradients.md)). 전체 깊이를 고정한 층 미분은 기존 각도/재료
미분과 결합할 수 있지만, 새로운 물리 영역마다 여전히 광학 및 그래디언트 세분화 검사가 필요합니다.
