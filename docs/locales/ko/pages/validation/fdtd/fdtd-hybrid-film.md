## 요약

**범위를 한정한 구현, 여섯 행의 보정, 대상 검사 918개, 실제 변이 증거 13개가 완료되었습니다.**
소스를 정확히 복원한 뒤 234개 경우의 기준선이 통과합니다. 등록한 작업자 40개 캠페인이 완료되었습니다.
자기 차수 48개 중 47개가 2차이고 하나가 혼합이며, 최종 직접 쌍 48개 중 47개가 2차이고 하나가 잡음으로
판정 불가입니다. 전체 회귀는 3,669개 경우를 통과하고 8개를 건너뛰며, 별도의 느린 단계는 81개를 모두
통과하고, 동결 기준 관문 네 개는 모두 비트 단위로 정확합니다. 이 기능은 수동 Debye 이완과 수동
Drude/Lorentz 진동자를 함께 가지는, 고립된 평평한 박막 하나를 다루며, 선언한 개수는 유한하고 진동자 감쇠는
서로 달라도 됩니다. 보정은 공개된 알려진 데이터이며, 수렴 결과나 임의 재료에 대한 정확도 주장이
아닙니다.

구현은 Debye의 쌍선형 주파수 기호와 진동자의 중심 차분 주파수 기호를 유지하면서 물리 분극 좌표를
결합합니다. 반 시간 간격 Debye 상태와 아핀 전기장 분할로 갱신을 명시적으로 만듭니다. 관측기에는 음의
힘 제곱 보정을 포함한 다른 이산 저장 에너지가 필요합니다. 선언한 극점마다 벡터 배열 네 개를 두어, 특이할
수도 있는 시간 갱신의 역을 구하지 않고 필요한 시계를 보존합니다.

정확한 산술에서 성립하는 닫힌 계 에너지 항등식이 회전 더하기 진동자의 충분 CFL 조건을 뒷받침합니다.
구현은 의도적으로 음이 아닌 Debye 정책 예산을 추가로 유지하며, 회전 한계에는 물리적 고주파 유전율을
씁니다. 그 증명도, 보수적인 벌크 스펙트럼 하한도 부동소수점 수동성, PML 안정성, 유한 시간 안정화,
산란 정확도를 확립하지 않습니다.

이전의 단일 계열 경로와 그 근거는 기존 범위를 유지합니다. 범위를 한정한 이 혼합 계열 확장은 곡면 분산
계면, 분산/손실 있는 바탕 매질, 접합, 기하/재료/대역 미분을 허용하지 않습니다. C8을 완료하지 않으며,
통과하지 못한 C7 판정을 바꾸지도 않습니다.

디스패치는 선언한 계열을 기준으로 하며, 세기가 정확히 0인 Debye나 Lorentz 선언도 포함합니다. 슬롯은 선언한
순서와 개수를 유지하며, 중복된 매개변수를 합치지 않습니다. 한 계열이 완전히 비활성인 혼합 선언은 이 새
구현의 끝점에 그대로 남습니다. Debye만 선언한 목록과 진동자만 선언한 목록은 이전 경로를 유지합니다. 추적된
0은 구체적인 비활성 선언으로 받지 않습니다. 구체적인 기하, 재료, 대역 보호 장치는 소스 진폭 미분에 관한
어떤 주장도 하지 않습니다.

## 결합된 물리 응답

`f`를 성분의 박막 채움 비율, `g=1-f`, `a`를 박막의 물리적 고주파 유전율, `b`를 바탕 매질 유전율이라고
하겠습니다. 다음과 같이 둡니다.

```text
A = f*b + g*a
eta = a*b/A,       alpha = g/A,       kappa = f*b*b/A**2       (normal)
eta = f*a + g*b,   alpha = 0,         kappa = f               (tangent).
```

Debye 세기 `Delta_i`와 진동자 세기 `S_j`에 대해 다음을 정의합니다.

```text
chi(s) = sum_D Delta_i/(1+tau_i*s)
         + sum_O S_j/(s*s+gamma_j*s+d_j)
epsilon_eff(s) = eta + kappa*chi(s)/(1+alpha*chi(s)).
```

여기서 Drude는 `d_j=0`, `S_j=omega_p**2`이고, Lorentz는 `d_j=omega_0**2`와 선언한 세기를 씁니다. 법선
표현식은 `1/(f/(a+chi)+g/b)`와 같고, 접선 표현식은 `f*(a+chi)+g*b`입니다. 이 축약은 감수율 합 전체를
결합하며, 계열별로 따로 평균할 수 있다고 가정하지 않습니다.

물리 Debye 위치 `m_i`, 진동자 위치 `q_j`, `P=sum(m)+sum(q)`로 쓰면 연속 실현은 다음과 같습니다.

```text
tau_i*m_i' + m_i + alpha*Delta_i*P = kappa*Delta_i*E
q_j'' + gamma_j*q_j' + d_j*q_j + alpha*S_j*P = kappa*S_j*E.
```

양의 채움에서 활성인 슬롯만 가중 방정식에 들어갑니다. `rho=alpha/kappa`로 두면 대응하는 가중치는 다음과
같습니다.

```text
R_D = diag(tau_i/(kappa*Delta_i))
M_O = diag(1/(kappa*S_j)),     R_O = diag(gamma_j/(kappa*S_j))
K = diag(1/(kappa*Delta_i), d_j/(kappa*S_j)) + rho*1*1^T.
```

`K`는 양의 준정부호이며, Debye 주 블록은 양의 정부호입니다. 계수 1 퍼텐셜은 두 계열에 걸쳐 한 번만
포함됩니다. 서로 다른 대각 감쇠는 이 강성과 교환하지 않아도 됩니다.

## 두 이산 기호와 명시적 예측자

`h=dt`로 쓰겠습니다. Debye 보조 위치 `D`는 반 시간 간격에 있고, 정수 시각의 물리 출력은
`m^n=(D^(n+1/2)+D^(n-1/2))/2`입니다. 진동자 위치는 정수 시간 간격에 남습니다.

```text
R_D*(D^(n+1/2)-D^(n-1/2))/h + K_DD*m^n + K_DO*q^n = 1_D*E^n

M_O*(q^(n+1)-2*q^n+q^(n-1))/h**2
 + R_O*(q^(n+1)-q^(n-1))/(2*h)
 + K_OO*q^n + K_OD*m^n = 1_O*E^n.
```

이웃한 Debye 방정식을 평균하면 물리 `m`에 대한 사다리꼴 방정식이 나옵니다. `z=exp(-i*omega*h)`에 대해
의도한 감수율은 다음과 같습니다.

```text
s_D = (2/h)*(z-1)/(z+1)
Q_j = (z-2+1/z)/h**2 + gamma_j*(z-1/z)/(2*h) + d_j
chi_h = sum_D Delta_i/(1+tau_i*s_D) + sum_O S_j/Q_j
P/E = kappa*chi_h/(1+alpha*chi_h).
```

`z=-1`에서는 Debye 물리 출력의 0 극한을 씁니다. 이는 모든 보조 좌표가 사라질 것을 요구하지 않습니다.
특이한 정상 상태 분모를 유한한 비교값으로 다루어서는 안 됩니다. 모든 계열에 공통 중점 갱신을 쓰면 진동자
기호가 바뀌므로, 그것은 이 후보의 갱신이 아닙니다.

양의 Debye 국소 행렬은 `L_D=2*R_D/h+K_DD`입니다. 대각 더하기 계수 1 형태이므로 선언한 개수에 선형인
작업량으로 다룰 수 있습니다. 구현이 쓰는 구체적인 스칼라 형태는 다음과 같습니다.

```text
t_i = 2*tau_i/(2*tau_i+h)
bare_i = kappa*Delta_i*h/(2*tau_i+h)
c_i = bare_i/(1+rho*sum_D bare_i)
c = sum_D c_i
T = sum_D t_i*D_i^(n-1/2)
m_i^n = t_i*D_i^(n-1/2) + c_i*(E^n-rho*(T+sum_O q_j^n)).
```

`y_i^n=m_i^n-c_i*E^n`으로 두고, `D_i^(n+1/2)=2*m_i^n-D_i^(n-1/2)`를 예측하고, 모든 진동자를 같은 이전
물리 `P^n`으로 진행합니다. `den_j=1+gamma_j*h/2`로 두면,

```text
q_j^(n+1) = ((2-d_j*h*h)*q_j^n - (1-gamma_j*h/2)*q_j^(n-1)
             + kappa*S_j*h*h*E^n - alpha*S_j*h*h*P^n)/den_j.
```

그다음 새 반 시간 간격 상태와 새 진동자 합 전체로 다음 변환 Debye 출력을 예측합니다.

```text
y_i^(n+1) = t_i*D_i^(n+1/2)
            - rho*c_i*(sum_D t_k*D_k^(n+1/2)+sum_O q_j^(n+1)).
```

이 예측자에는 미래의 전기장이 들어가지 않습니다. Ampere 식은 다음이 됩니다.

```text
(eta+c)*(E^(n+1)-E^n) + sum_D(y^(n+1)-y^n)
                         + sum_O(q^(n+1)-q^n) = h*C*H^(n+1/2).
```

기존 `before_E` 스케일은 `dx/dt`로 남습니다. 갱신 유전율은 `eta+c`이고, 물리적 고주파 유전율은 `eta`로
남습니다. 대응하는 이력을 바꾸기 전에 이전 합을 모두 계산해 두어야 합니다.

## 극점마다 배열 네 개와 관측기 시계

제안한 항은 `P`, `previous`, `delta`, `aux` 튜플을 예약하며, 각 튜플은 선언한 극점마다 세 성분의 압축
영역 배열 하나를 가집니다. `E^n`에 대응하는 관측기 읽기 시점에서:

| 메모리 | Debye 슬롯 | 진동자 슬롯 |
| --- | --- | --- |
| `P` | 예측한 `y^(n+1)` | 예측한 `q^(n+1)` |
| `previous` | `y^n` | `q^n` |
| `delta` | `y^(n+1)-y^n` | `q^(n+1)-q^n` |
| `aux` | `D^(n+1/2)` | `vbar^n=(q^(n+1)-q^(n-1))/(2*h)` |

물리 Debye 출력은 예측한 `P`가 아니라 **previous** 더하기 `c_i*E^n`으로 재구성합니다. 전기장 갱신 뒤의
진행 단계는 `E^(n+1)`로 다음 예측과 중심 속도를 만든 다음에 이전 진동자 이력을 덮어씁니다. 유효한
`gamma*h=2`에서 사라질 수 있는 `1-gamma*h/2`로 나누는 일은 결코 없습니다.

따라서 재료 탑재량은 벡터 배열 `4*(N_D+N_O)`개, 즉 논리 바이트로
`12*(N_D+N_O)*number_of_support_cells*dtype_itemsize`입니다. 정확히 비활성인 선언도 배열을 예약합니다. 이는
구체적인 배치이며, 최소 메모리 정리나 프로세스/장치 전체 메모리가 아닙니다. 별도로 제안한 보고서 수정은
보통의 세 배열 극점 메모리를 셉니다. 혼합 통합에는 네 배열 메타데이터와 할당 오라클이 추가로 필요합니다.
소스, 관측기, 진단, 임시 공간, 할당기 부담은 그 보고서 필드 밖에 남습니다.

## 수정한 저장 에너지와 그 한계

`theta=h*h/4`, `P^n=sum(m^n)+sum(q^n)`으로 두고, 가중 진동자 힘 잔차를 다음과 같이 정의합니다.

```text
F_j^n = d_j*q_j^n/(kappa*S_j) + rho*P^n - E^n.
```

저장소의 두 배 에너지 규약에서, 전기 가중치 `eta+c`에 대한 새 재료 보정은 다음과 같습니다.

```text
sum_D |m_i^n|**2/(kappa*Delta_i)
 + sum_O d_j*|q_j^n|**2/(kappa*S_j)
 + rho*|P^n|**2
 + sum_O (1+theta*gamma_j**2)*|vbar_j^n|**2/(kappa*S_j)
 - theta*sum_O kappa*S_j*|F_j^n|**2
 - c*|E^n|**2.
```

모든 가중치와 합은 셀이나 성분에 대해 축약하기 전에 국소적으로 작용합니다. 공유하는 물리 합과 힘을 만들기
전에 비활성/계열 마스크를 적용하고, 필드, 메모리, 브로드캐스트 가중치에 같은 성분/영역 선택을 적용합니다.
공유하는 계수 1 퍼텐셜은 한 번만 나타납니다. 이전 진동자의 `-Re(E*Delta P)` 보정이나 모두 중점인 에너지를
다시 쓰면 이 저장 에너지가 나오지 않습니다.

닫힌 격자 전체의 저장 에너지 `W^n`은 위의 양의 재료 퍼텐셜, 수정한 운동 에너지 항, 음의 힘 제곱 항에
물리적 `eta*|E^n|**2`와 `Re(<H^(n-1/2),H^(n+1/2)>)`를 더한 것입니다. 소스가 없는 수반 Yee 회전에 대해
정확한 산술에서의 손실 항등식은 다음과 같습니다.

```text
W^(n+1)-W^n = -2*h*sum_D tau_i/(kappa*Delta_i)
                         * |(m_i^(n+1)-m_i^n)/h|**2
             -h*sum_O gamma_j/(kappa*S_j)
                         * (|vbar_j^(n+1)|**2+|vbar_j^n|**2).
```

복소 필드에는 Hermitian 곱과 실수 교차항을 씁니다. 이것은 전역 닫힌 계 항등식이며, 잘라 낸 관측 영역은
플럭스를 주고받을 수 있습니다. 음이 아닌 서로 다른 감쇠는 손실의 부호를 보존합니다. Drude의 어두운 분극
방향은 복원 퍼텐셜이 0일 수 있습니다. 이 진술은 임의의 어두운 위치가 유계라는 것이나 모든 메모리 좌표에서
엄격한 양수성을 보장하지 않습니다. 활성 Debye 계열은 진동자 감쇠 계수가 모두 0이어도 에너지를 소산할 수
있습니다. 그래서 무손실 보존 대조군은 비활성 Debye 계열과 0인 진동자 감쇠를 가지며, 활성 Debye와 0인
진동자 감쇠를 가진 소산 대조군과 구별됩니다.

비활성 Debye 끝점에서 물리 진동자 점화식은 이전의 중심 차분 점화식으로 축약됩니다. 그 에너지 읽기는
일반적으로 다릅니다.

```text
W_hybrid - T_existing = h*sum_O gamma_j/(kappa*S_j)*|vbar_j|**2.
```

진동자 감쇠가 0이면 두 값이 일치합니다. 따라서 점화식이나 물리 전달의 동등성을 감쇠가 있는 관측값의
동등성으로 바꾸어서는 안 됩니다. 비활성 진동자 끝점에서 물리 Debye 전달은 이전의 쌍선형 법칙을 유지하지만,
모드 축약과 내부 메모리 좌표가 비트 단위로 같을 필요는 없습니다. 이전의 선언 계열 경로는 따로 보존합니다.

## 물리 유전율 CFL과 유지한 Debye 정책

정확한 산술에서의 충분한 양수성 조건은 다음과 같습니다.

```text
h*h*(c_C+r_O) < 4
c_C = ||eta^(-1/2)*C||**2
r_O = max_active d_j + sum_active S_j/a.
```

진동자 부분은 법선 항등식 `alpha+kappa/eta=1/a`에서 나오며, 접선 계수는 이보다 크지 않습니다. 수정한
퍼텐셜 전체의 증명은 양의 준정부호 이차 형식 행렬을 인수분해하며, Drude 영공간 방향의 역을 구하지
않습니다. 회전 한계에는 물리 `eta`를 써야 합니다. 더 큰 갱신 값 `eta+c`로 바꾸면 조건이 잘못 약해질 수
있습니다.

구현은 그 증명이 주는 최소 충분 재료 예산을 쓰지 않고 더 엄격한 정책을 유지합니다. Debye 모멘트
`M1=sum_active Delta_i/tau_i`와 `M2=sum_active Delta_i/tau_i**2`를 정의하면,

```text
r_D = max(M2/a, max_actual_Yee_nodes [kappa/eta*(M2+alpha*M1*M1)])
r_policy = r_O + r_D.
```

추가한 `r_D`는 물려받은 보수적 정책이며, 혼합 저장 에너지 증명이 요구하는 추가 항이 아닙니다. 이 값은
실제 성분 채움과 벌크 Debye 합에 대한 최대값이며, 개별 극점의 최대값이 합을 대신하지 않습니다. 비활성
계열은 쓰지 않는 역수나 주파수 제곱을 계산하지 않고 정확히 0을 기여합니다. 정책 합은 정확한 유리수
산술로 계산한 뒤 위쪽으로 float64 변환합니다.

이 조건은 닫힌 Yee/재료 계에 관한 것입니다. 흡수층/PML 안정성 계약을 확장하거나, 시간 주파수 정확도를
보장하거나, 고른 소스 지속 시간이 강성 이완을 안정화한다고 약속하지 않습니다.

## 표현 가능성과 벌크 스펙트럼 하한

구현은 서로 다른 각 구체적 채움의 스칼라 계수를 최종 부동소수점 변환 전에 정확한 분수로 계산합니다. 활성
양의 구동, Debye 이동, 역 에너지 가중치, 필요한 힘/결합 가중치는 양의 유한 값으로 남아야 합니다. 쓰지 않는
끝점은 역수 산술 전에 갈라지며, 양수 언더플로를 조용히 잘라 내지 않습니다.

활성 Debye 이득 `2*t_i-1`은 반올림한 값이 -1과 1 사이에 엄격히 있어야 합니다. 어느 한 끝점으로 반올림되면,
입력 `tau`가 양의 유한 값이더라도 구현은 이를 이름을 밝혀 거부합니다. 이 규칙에는 허용 오차 차단값이 없으며
활성 선언과 비활성 선언을 합치지 않습니다. 표현 가능성 검사만으로는 계산한 행렬 스펙트럼, 작은 출력
증분의 상쇄, 수정한 저장 에너지의 float64 비음수성을 증명하지 못합니다.

`x=omega**2`에 대한 충분한 연속체 벌크 파수 한계는 다음과 같습니다.

```text
K_bound**2 = a*x_high
 + sum_D Delta_i*x_high/sqrt(1+tau_i**2*x_high)
 + sum_O S_j*max_band[x/sqrt((d_j-x)**2+gamma_j**2*x)].
```

각 Debye 항은 양의 x에서 증가합니다. 각 진동자 최대값은 두 대역 끝점과, 분모가 양수이고 대역 안에 있을 때의
내부 후보 `2*d_j*d_j/(2*d_j-gamma_j*gamma_j)`를 씁니다. 혼합 계열을 합친 크기가 단조라고 가정하지
않습니다. 후보 판정과 제곱한 한계는 정확한 유리수 산술을 쓰며, 제곱근의 위쪽 변환은 바깥쪽으로 검사합니다.
대역 안에 있는 감쇠 없는 활성 공진은 거부하고, 세기가 정확히 0인 경우는 특이한 분모를 계산하기 전에
건너뜁니다.

양의 구체적 소스 대역은 모두 박막과 바탕 매질에서 `dx*K_bound<=2*pi/8`을 만족해야 합니다. 요청한 모든
모니터, Resolution, 명시적 PML 파장은 각각 최소 위상 셀 8개와 표피 깊이 셀 1개가 필요하며, 12/2 경고 정책을
유지합니다. 기하/재료/대역 추적기는 계속 제외합니다. 소스도 요청 파장도 없으면, 증명한 스펙트럼 척도가 없다는
경고를 내야 합니다. 이것은 벌크 척도 하한이며, 모든 법선 계면 공진, 비스듬한 종방향 척도, 측정한 r/t 오차에
대한 한계가 아닙니다.
