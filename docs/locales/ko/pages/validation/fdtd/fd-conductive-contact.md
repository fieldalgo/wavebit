# C8: 정확히 맞닿은 두 전도성 박막

작성: 2026-10-18

대상: `src/wavebit/fdtd/_prepare/conductive_contact.py`,
`src/wavebit/fdtd/_prepare/conductive_stack.py`, `src/wavebit/fdtd/_prepare/checks.py`,
`src/wavebit/fdtd/_prepare/junction.py`, `tests/fdtd/test_fd_conductive_contact.py`,
`tests/fixtures/fdtd/conductive_contact.py`.

한 셀 안에 있는 두 수동 도체의 국소 조화 평균 구성 법칙은 DC 전도도 하나와 유도된 Debye 이완 하나로 정확하게
실현됩니다. 이로써 정확히 맞닿은 평면 쌍에 대해 수동적인 셀 갱신을 얻습니다. 아래의 국소 구성 항등식과
에너지 항등식은 검증되었습니다. 파동 정확도는 완전히 수용되지 **않았습니다**.
[Accuracy status](#accuracy-status)와 [issue #51](https://github.com/fieldalgo/wavebit/issues/51)을 보세요.

## 한정된 계약

| 입력 | 계약 |
| --- | --- |
| 기하 | 회전하지 않고 범위를 지정하지 않은 voxel `Box` 구조 정확히 두 개. 두 격자 축 방향으로 균일하고, 세 번째(법선) 축을 공유합니다. 계산된 물리적 면 좌표가 정확히 같아야 합니다. |
| 두께 | 각 박막은 적어도 격자 셀 하나 두께여서, Yee 평균 셀 하나에 재료가 많아야 두 개 들어갑니다. |
| 재료 | 양의 등방성 실수 유전율, 음이 아닌 등방성 전도도, 단위 투자율을 가진 `ConductiveMaterial`(또는 `Conductor`). 공개 API에서 전도도 단위는 S/m입니다. |
| 호스트 | 양의 값을 가진 등방성, 무손실, 비자성 일반 `Material` 하나. |
| 경계 | 두 박막의 지지 영역이 모두 허용된 내부 영역 안에 머물며, 흡수층과 법선 방향 영역 벽에서 떨어져 있습니다. |
| 제외 | 곡면이나 회전한 계면, 재료 세 개가 든 셀, 손실 있는 호스트, 선언한 분산, 초기 필드, 재료나 기하 미분, GPU 적격성 확인. |

접촉 허용 오차는 없습니다. 아주 작은 양의 틈이나 겹침을 조용히 접촉으로 바꾸지 않습니다. 패딩한 지지
영역이 서로 떨어져 있으면 기존 [떨어진 적층 경로](fd-conductive-stack.md)가 그대로 적용됩니다. 두 상자는
정확하게 표현할 수 있는 공통 면 좌표 하나로 만들고 `fdtd.check`를 확인하세요. 기본값이 아닌
`Structure(junction=...)` 규칙은 이 재료 경로를 선택하지 않습니다. 계획 단계는 이 페이지를 가리키는
`SubpixelAccuracyWarning`을 냅니다.

## 구성 법칙 유도

정규화한 솔버 단위와 `s = -i omega`를 씁니다. 두 매질을 `a + u/s`와 `b + v/s`라 하고, 셀 안의 비율을
`f`와 `g = 1-f`라 합니다. 접선 방향 응답은 산술 평균입니다. 법선 성분에 대해서는 다음과 같이 정의합니다.

```text
A = f*b + g*a
B = f*v + g*u
1 / (f/(a+u/s) + g/(b+v/s))
    = eps_inf + sigma_dc/s + delta/(1+s*tau)
eps_inf = a*b/A
sigma_dc = u*v/B
tau = A/B
delta = f*g*(a*v-b*u)^2 / (A*B^2)
```

이 분해의 성질은 다음과 같습니다.

- `B > 0`이면 모든 저장 계수와 소산 계수가 음이 아닙니다.
- 두 전도도가 모두 0이면 응답은 실수 유전율의 조화 평균으로 줄어듭니다.
- 순수한 셀은 원래 재료를 유지합니다.
- `a*v = b*u`이면 유도된 이완은 사라지지만, DC 전도도는 남을 수 있습니다.
- 한쪽 전도도를 0으로 두면 도체–유전체 공식이 다시 나옵니다.

분리된 분극은 `P_tilde = P - c*E`를 저장하며, 여기서 `c = delta*dt/(2*tau+dt)`입니다. 갱신은
`eps_inf + c`, DC 전도도, 사다리꼴 Debye 점화식을 사용합니다. 메모리 항 하나가 바깥 호스트 계면 두 개를
포함하여 두 박막의 합집합 전체를 덮습니다. 잘린 셀은 정확히 하나의 이완만 받으므로, 저장 에너지가 두 번
계산되는 일은 없습니다. 에너지 관측기는 `1/delta`와 `c`를 명시적으로 사용합니다. 보수적인 재료 CFL 기여는
바깥 계면을 포함한 국소 `f*g*(a*v-b*u)^2/(A^2*a*b)`의 최댓값입니다.

준비된 서명은 원래 두 구성원, 그 순서, 기하, 재료 값, 전체 메모리 집합을 묶습니다. 빠졌거나, 다른 곳에서
왔거나, 오래된 메모리는 하위 단계로 내리기 전에 거부합니다. 전역 필드 저장 공간은 한 번만 계산합니다.

## 검증한 항목

`tests/fdtd/test_fd_conductive_contact.py`는 실제 메모리 전진과 주입 전류를, 독립적인 복소 직렬/병렬 법칙과
세 축 모두와 다섯 가지 셀 내부 배치에서 비교합니다. 다음도 다룹니다.

- 손실 0, 동일한 재료, 같은 이완 비율;
- 잘못된 계수를 쓴 대조군과 준비된 계획의 거부;
- 공개 SI 재료를 하위 단계로 내리는 과정과 할당된 메모리;
- 유리 다항식 긴 나눗셈으로 물리적 저장 에너지를 유도한 이산 에너지 수지. NumPy, JAX, PyTorch에서 전도성
  소산과 Debye 소산을 함께 검증합니다.

이것들은 국소적인 CPU 검사입니다. 일반적인 3차원 파동 정확도나 미분의 근거는 아닙니다.

## Accuracy status

**등록한 파동 고정 사례.** `tests/fixtures/fdtd/conductive_contact.py`는 35도의 고정된 가로 파수에 박막 두
개를 놓습니다.

- eps 4 / sigma 8 박막이 eps 2.25 / sigma 4 박막 위에 있으며, 각각 0.125 L0 두께입니다.
- 세 파장 .9 / 1 / 1.1 L0, 두 편광.
- 독립적인 연속체 특성 행렬 기준과 비교합니다.

격자 위상 .375, 120주기, 시간 간격 절반 검사로 등록한 p 편광 40/80/160 셀 측정 묶음은 전체로서 통과하지
**못했습니다**. 그 결과는 그대로 남겨 둡니다.

- **반사 차수.** 복소 반사 계수의 직접 수렴 차수는 2.50–2.63으로, 미리 등록한 창 [1.8, 2.3]보다 높습니다.
- **투과 차수.** 2.00–2.01로, 창 안에 있습니다.
- **시간 간격.** 시간 간격을 절반으로 줄인 검사는 모든 채널에서 통과합니다.
- **넓은 대역.** df = .1 펄스 묶음은 등록한 기준을 통과하지 못합니다.

더 좁은 df = .07 묶음은 따로 등록했습니다. 이 묶음도 같은 반사 차수 관문에서 멈췄습니다.

**도구 간 비교.** 같은 물리 사례를 n80(dx = L0/80, dt = .2 dx/√3, 24셀 PML, 120주기)에서 계산하고 세
파장에 대한 최댓값을 취했습니다.

| | abs r 오차 | abs t 오차 | 60→120주기 변화, df .1 |
|---|---|---|---|
| Wavebit | 2.5e-4 | 1.8e-3 | 1.8e-6 |
| Meep 1.34.0, `eps_averaging` 켬 | 2.5e-3 | 1.5e-3 | 2.4e-7 |
| Meep 1.34.0, `eps_averaging` 끔 | 1.75e-2 | 1.6e-3 | 2.4e-7 |
| FDTDx 0.6.2와 0.6.3, voxel 계단 근사 | 3.2e-2 | 1.9e-3 | 2.2e-7 |

표 읽는 법은 다음과 같습니다.

- **n80에서의 오차.** Wavebit의 반사 오차가 세 도구 중 가장 작습니다. 투과 오차는 다른 도구들과 같은
  수준입니다.
- **배치 민감도.** 외부 결과는 격자 배치와 스무딩에 크게 의존합니다. Meep은 반 셀 이동에서 최대 4×까지
  바뀝니다. 이 결과들은 기준이 아니라 맥락이며, 다른 도구에서 비슷한 오차가 나온다고 해서 공통 한계가
  확립되지는 않습니다.
- **넓은 대역 잔차.** df = .1의 늦은 시간 변화는 Wavebit에서 5–12× 더 큽니다. 외부 실행은 부드러운 전류
  시트를 주입하는 반면 Wavebit은 자체 평면파 소스를 씁니다. 이것이 솔버 결함인지 소스의 성질인지는 그 원래
  비교에서 풀리지 않았습니다. 아래 후속 측정을 보세요.

이 비교들은 관리자들이 측정했으며 독립적으로 검토되지 않았습니다.

**열린 질문.** 반사 차수와 넓은 대역 잔차는 모두
[issue #51](https://github.com/fieldalgo/wavebit/issues/51)에서 추적합니다. 그것이 해결될 때까지는 자신의
사례에 대해 공간, 시간, 경계 수렴을 검증하세요. 이 경로를 위해 허용 오차, 골든 값, 수용 창을 바꾸지
않았습니다.

## Original-bandwidth follow-up (2026-10-22)

현재의 미분 전류 p 입사를 원래의 `df=.1, cutoff=1e-6`에서, 같은 박막, 고정된 가로 파수 벡터, 연속체 기준을
써서 시험했습니다. 따로 등록한 점근 기준이 s/p 두 편광과 두 격자 위상 .375/.125 모두에서 통과했습니다.
이것이 원래의 성긴 격자 실패를 다시 쓰거나 일반적인 파동 지원을 확립하지는 않습니다.

각 그룹은 60주기에서 40/80/160/320 셀을 쓰고, 여기에 n80 120주기 기록, 두 배 PML, 절반 시간 간격을
더했습니다. 추가 n320 대조군 두 개는 120주기와 PML 셀 24개 및 48개를 썼습니다. 모두 합쳐 새 CPU 기록
36개입니다. 모두 원래의 고정 사례와 수치 예산을 그대로 유지했습니다.

점근 기준은 안정된 복소 h² 계수(80/160 및 160/320 h²+h³ 맞춤 사이에서 5% 이내), [1.8, 2.3] 안에 드는
분해된 가장 세밀한 쌍의 차수 구간, 그리고 시간/경계 불확도와 반 간격 검사를 따로 요구합니다. 원래의 40→80
차수는 그 창 밖에 있더라도 계속 보고합니다.

여섯 r/t 채널 각각에 대해 e_n = |q_n − q_ref|, d_ab = |q_a − q_b|라 합니다. 등록한 잡음 대리량은
eta = |q80,T120 − q80,T60| + |q80,T120,PML48 − q80,T120,PML24|입니다.
모든 오차와 연속 차이는 1e-10보다 커야 하고,
2 eta <= .1 min(e320, d160,320)이어야 합니다. n80 반 간격 차이는
<= .1 min(d80,160, d160,320)이어야 합니다. 세밀한 격자 확장은 n320 시간 쌍과 PML 쌍을 써서 같은
2 eta_fine 상한을 적용합니다. 구간 [log2((e160−eta)/(e320+eta)),
log2((e160+eta)/(e320−eta))]에서 max(eta, eta_fine)을 사용하며, 인수가 양수가 아니면 실패입니다. 모든
행은 유한한 양의 에너지로 안정해야 하고, 모니터 감쇠가 1e-5 미만이어야 하며, 소스 이후 적격성 확인을
완료해야 하고, 증가 경고가 없어야 합니다. 두 위상 모두 통과해야 합니다.

| 편광 / 격자 위상 | 가장 세밀한 반사 차수 구간, 모든 파장 | 가장 큰 h² 계수 변화 | 결과 |
|---|---:|---:|---|
| s / .375 | 1.891–2.139 | 1.180% | PASS |
| s / .125 | 1.997–2.002 | .177% | PASS |
| p / .375 | 1.958–2.175 | 1.470% | PASS |
| p / .125 | 1.997–2.001 | .168% | PASS |

투과도 통과했습니다. 모든 행이 소스 이후의 완전한 근거를 갖추었고, 원래의 유한 에너지, 안정 실행, 감쇠
요구 조건을 만족했습니다. 추가한 세밀한 격자의 시간+경계 불확도는 고정 예산의 최대 .148을 썼으며, 성긴
격자와 세밀한 격자 중 더 큰 불확도를 써도 차수 창을 통과했습니다. 성긴 격자에서 반사 차수가 높게 나온 것은
2차 수렴을 잃었기 때문이라기보다, 선두 h² 항의 상쇄와 점근 이전의 h³ 기여와 일치합니다. 이 관찰은 이 두
위상과 이 재료/각도 고정 사례에만 해당합니다. 이는 새 소스에 대한 Linux JAX CPU 근거이며, 새로 실행한 외부
솔버 결과, 다른 플랫폼 검증, 독립 검토가 아닙니다.

소스 적격성 확인과 별도의 넓은 펄스 PML 한계는
[PlaneWave 수용 기준](fd-planewave-acceptance.md)을 보세요. 위의 원래 실패한 측정 묶음과 그 외부 도구 측정은
과거의 근거로 남습니다. 이 후속 측정에서 재료 알고리즘, 기본 경계, 골든 값, 수치 허용 오차는 바뀌지
않았습니다.
