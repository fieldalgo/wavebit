# PlaneWave 수용 기준: 정확도와 측정 유효성

짧은 stage-2 `plane_wave`와 stage-3 `bloch_stack` / `conical` 골든은 기록된
계산의 변화를 잡습니다. 300/500 step 실행은 의도적으로 안정화 전에 끝납니다.
기존 fixture와 회귀 오차 한계를 유지하되, 골든 일치만으로 물리 정확도를 인정하지 않습니다.

비스듬한 p column은 중심 주파수에서 정규화한 두 노드 차분 전류를 사용합니다.
`tests/fdtd/test_fd_planewave.py`의 독립 이산 전달식은 주어진 입력 파형과 실제 장을
대조합니다. 실수 주파수 2e-6, 감쇠 주파수 3e-6, 역방향 누설·교차 편광 1e-13,
DC 1e-6 한계를 유지합니다. 측정 입사장으로 산란장을 정규화하면 광원 이득 오류가
상쇄될 수 있으므로 이 검사는 산란 정확도 검사와 함께 필요합니다.

## 고정 오차와 별도 불확실성 한도

`test_fd_diffraction.py`의 평면 구조 진폭·크기·위상·파워·보존·감쇠와
20/40/80 해상도 수렴 기준, `test_fd_axis1d.py`의 원뿔 입사 진폭·차수별 파워·보존·
기준해 수렴과 20/40 개선 기준을 유지합니다. p 평면 구조 위상은 기존의 1차 기준을
유지하며 2차 수렴을 새로 요구하지 않습니다.

추가 수동 실행은 모든 p 해상도의 측정 유효성을 아래 관측량별 고정 한도 tau로 검사합니다.

| 관측량 | 평면 구조 | 원뿔 입사 |
|---|---:|---:|
| 복소 진폭 | 20/40셀 .015, 80셀 .005 | .0355 |
| 차수별 파워 | .0012 | .01 |
| 전체 R + T | .0001 | .001 |
| 동일 편광 상대 크기 | .02 | — |
| 동일 편광 위상 (라디안) | .06 | — |
| 교차 편광 진폭 | 1e-12 | 복소 진폭에 포함 |

평면 20셀의 한도는 불확실성 검사에만 쓰고, 정확도는 기존 격자 수렴 시험으로
판정합니다. 원뿔 입사 40셀은 기존의 1.8배 오차 개선 조건도 충족해야 합니다.
수동 실행은 기존 시험을 대체하지 않습니다.

1. 기존 T의 1, 1.25, 1.5, 1.75, 2배를 독립 실행합니다. 평면 T는 20주기,
   원뿔 입사는 160주기입니다. 모든 10개 쌍의 차이가 관측량마다 0.1 tau 이하여야 합니다.
2. 2T에서 PML을 12→24셀로 늘리는 실행과, 구조에서 PML 안쪽 면까지의 하단 .8·
   상단 1.4 간격을 각각 두 배로 늘리는 실행을 따로 합니다. 구조 계면·광원·모니터·
   횡방향 파수·기준면은 고정합니다. 기준 실행과 두 변형의 모든 쌍 차이는 0.1 tau 이하입니다.
3. 균일 구조 RCWA 절단 차수 0/1, 원뿔 입사 15/30의 채널별 차이는 .05 tau 이하입니다.
   각도는 FDTD 관측값 대신 입력 횡방향 파수로 계산합니다.
4. 관측량·내부 에너지가 유한하고 실행이 stable이어야 합니다. 기록 종료 이전의 알려진
   광원 종료 시점과 완전한 내부 에너지 기록이 있어야 하며 성장 경고가 없어야 합니다.
   유한한 내부 성장률이 있으면 진단을 인정합니다. 성장률이 없어도 광원 종료 후
   장면에 선언한 가장 긴 주기의 4배 이상을 기록했고 후반의 네 1/8 구간에 모두 표본이 있으며 원래 신호가
   0이 아니고 마지막 1/4 구간 에너지 최대값이 전체 최대값의 1e-7 이하면 인정합니다.
   이는 엔진이 문서화한 감쇠 하한 조건입니다. 기록 누락·짧은 기록·비유한값은
   여전히 차단합니다. 순간 에너지가 엄격히 단조 감소할 필요는 없습니다.

10%와 5%는 명시적으로 선택한 공학적 허용 배분이며 무한 시간 안정성의 증명이 아닙니다.
관측한 격자·시간 차이로 정확도 한도를 늘리지 않습니다. 복소 비교로 위상을 보며,
양 끝값이 같아도 중간 시점의 변동을 놓치지 않습니다.

접촉 전도막 fixture는 n80, 격자 위상 .375, PML 24셀, Courant .2, df .1,
cutoff 1e-6에서 60/90/120주기를 추가 실행합니다. 모든 쌍의 복소 r/t 차이는 2e-7
이하여야 합니다. 이 잔류 검사는 과거 공간 수렴 차수 시험의 실패를 뒤집지 않습니다.

## 판정과 재현

실행·진단 누락, 비유한값, 과도한 불확실성은 `BLOCKED`입니다. 유효한 측정이 정확도
한도를 벗어나면 `FAIL`, 고정 한도 안이면 `PASS`입니다. 집계에서는 확인된 실패가
증거 부족보다 우선합니다.

설정한 소스 checkout에서 실행합니다.

```sh
PYTHONPATH=src:. python -m tests.fdtd.check_planewave_acceptance --output artifacts/planewave-acceptance
python -m pytest tests/fdtd/test_fd_acceptance.py
```

새 출력 디렉터리에 입력 해시·버전·각 실행 기록과 진단·채널 이름·한도 대비 비율을
남깁니다. 중단된 실행에는 최종 결과가 없으며 통과로 인정하지 않습니다. 수동 실행의
PASS는 이 측정 검사만 뜻합니다. 광원·기존 정확도/수렴·backend·미분·비대상 회귀
검사는 별도로 충족해야 합니다.

모든 필수 검사를 통과한 뒤 변경 키 목록, 비대상 불변, 기존 골든 허용오차 내 재현성을
확인해야 재고정할 수 있습니다. 새 알고리즘이 실패했다는 이유만으로 오차를 넓히지 않습니다.
과거 외부 solver 측정은 당시 입력·버전 범위에서만 유효하며 저장 기준값을 읽는 것은
새 외부 실행이 아닙니다.

초기 판정기는 성장률이 없으면 모두 증거 누락으로 처리했습니다. 기존 진단의
문서화된 동작을 확인해 오류를 찾았습니다. 충분히 표본화했고 에너지가 기존 하한

## 안정화 측정 protocol

기존 광대역 campaign은 당시 결과로 보존한다. `--protocol stabilized`는
별도 검증 fixture를 선택한다. 기준 T는 평면80·원뿔320주기, PML48셀과
`stabilize=3e-3`, 두께 대조는96셀이다. 다섯 시간 배수·별도 경계 거리 대조,
광원 대역폭·기준해·모든 정확도/불확실성 한도는 동일하다. PML 셀을 늘릴
때는 도메인을 바깥으로 확장하여 안쪽 면과 물리 관측 좌표를 유지한다.
명시한 protocol은 실험 변경을 원래 실패의 재해석과 구분한다. 어느
protocol도 무한 시간 안정성을 보장하지 않는다. 독립 CPU 프로세스 수는
`--workers 5`로 지정할 수 있고 수치 조건은 바뀌지 않는다.

holding-column 진단 회귀는 시험 범위 안에서 과거 hard 광원을 명시적으로
주입한다. 갇힌 모드·성장 한도·진단 mutant 검증을 유지하기 위해서다.
별도 시험은 실제 current 광원에서 종료 후 quiet window를 확인한다.
grazing `adds-p`는320/640주기의 반사 .001369600/.001369955를 독립 모델
.001370과 비교한다. 기존160주기 current 측정은 .001349794였다.
긴 두 실행은 기존 상대1e-3 pin 한도에서 일치해야 하고, 모델 비교 한도와
통과/거부 기준도 유지한다.
