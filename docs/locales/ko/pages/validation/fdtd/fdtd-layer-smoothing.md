요약: 양수 `layer_smoothing`은 Yee 셀 샘플링에 앞서 내부 계면 위치를 고정된 물리 폭에 걸쳐
평균합니다. 그 결과 얻는 비율은 1차 미분이 연속입니다. 이 실험에서 한 셀 폭의 평균은 샘플링한
날카로운 막의 미분 오차를 줄였지만, 폭을 고정하면 연속체 재료 분포도 바뀝니다. 기본값은 여전히
0입니다. 최적화한 설계에는 세분화와 독립적인 날카로운 계면 검사가 여전히 필요합니다.

## 기하와 미분 계약

이것은 [총 두께를 고정한 층 미분](fdtd-layer-gradients.md)을 확장하며, RCWA와 같은 `Stack`과
`thickness` 표기를 씁니다. 정적 `mesh_thickness`가 모든 격자 기하를 정하고, 실제 길이는 그 총합 D를
보존합니다. 소스, PML, 시간 간격, 기록 좌표, 두 바깥 기준 평면은 고정됩니다. 입력 검증과 최적화
명령은 [사용 계약](../../guide/fdtd/time-domain.md#continuous-first-derivatives-at-internal-interfaces)을
보세요.

폭 h > 0에 대해, 모든 내부 계면을 [-h/2,h/2]에 균일하게 분포한 같은 보조 변위 u만큼 옮기고,
기하학적 셀 비율을 u에 대해 평균합니다. 두 바깥 면은 옮기지 않습니다. 내부 계면은 그 면들에서
적어도 h/2 떨어져 있어야 합니다. 이웃한 내부 평균 영역은 겹칠 수 있습니다. 폭과 변위를 공유하므로
순서, 음이 아닌 비율, 그리고 비율의 합이 1이 되는 분할이 보존됩니다. 층이 하나뿐인 적층에는 평균할
내부 면이 없습니다.

이것은 재료 샘플링의 정칙화입니다. h에 대해 미분하지 않고, 고정 메시를 바꾸지 않고, 가로 래스터
경계를 옮기지 않고, D를 바꾸지 않습니다. 더 높은 차수 미분의 연속성이나, 불리언 유효성 플래그와
임의의 사용자 손실 함수의 미분 가능성은 약속하지 않습니다.

## 독립 유도

고정된 Yee 셀 [L,R]과 내부 면 b에 대해 다음을 정의합니다.

```text
             0                    x <= -h/2
G_h(x) =     (x+h/2)^2 / (2h)     -h/2 < x < h/2
             x                    x >= h/2

C_h(b) = [G_h(R-b) - G_h(L-b)] / (R-L)
```

C는 b 오른쪽의 평균 비율입니다. a와 b 사이 층의 가중치는 C(a)-C(b)입니다. 날카로운 바깥 면은
보통의 잘린 계단 비율을 씁니다. G와 그 1차 미분이 두 이음점에서 모두 맞으므로, 이 가중치는 각 내부
면 위치에 대해 C1입니다. 움직이는 면 뒤의 층에서 그 앞의 층으로 넘어가는 속도를 독립적으로 계산하면
다음과 같습니다.

```text
[clip((R-b)/h + 1/2, 0, 1) - clip((L-b)/h + 1/2, 0, 1)] / (R-L).
```

공통 Array API 구현은 이 가중치를 기존의 접선 방향 산술 평균과 법선 방향 epsilon/mu 조화 평균,
그리고 산술 평균 전기 극점 채우기에 넘깁니다. 분리(detach)한 기하, 사용자 정의 그래디언트,
straight-through 추정기는 쓰지 않습니다. 기본값 h=0은 이전의 겹침 경로를 유지합니다.

[Meep 이론 문서](https://meep.readthedocs.io/en/latest/Subpixel_Smoothing/)는 접선/법선 평균과
모서리 및 분산 계면에서의 한계를 설명합니다. 위의 추가 계면 위치 평균은 여기서 유도한 것이며 Meep에서
복사한 구현이 아닙니다. Meep 구현이나, 앞서 배제한 Meep 파생 FDTDX 투영 소스는 열어 보지 않았습니다.
기존 ADE 채우기를 미분한다고 해서 일반적인 분산 계면 균질화 정리가 확립되지는 않습니다.

## 계산 그래프와 셀 경계 통과 검사

비율 오라클은 변위 적분을 모든 셀/면 교차점에서 나누어, 옮긴 날카로운 기하를 적분합니다. 구간별
선형인 피적분 함수는 구간 중점으로 정확히 적분되며, 제품 코드의 기본 연산을 전혀 공유하지 않습니다.
NumPy, JAX, Torch는 크기가 다른 셀과 겹치는 내부 지지 영역에서 이 오라클과 일치합니다. 해석적 미분,
각 기본 연산 이음점의 양쪽, 부피 보존, 반사, 길이 단위 배율, 그리고 변하지 않는 단일 층 산란이 별도의
검사가 됩니다.

장면 전체에 대한 JAX/Torch 테스트는 두께, 래스터 epsilon, 전기 극점 세기, 바깥 epsilon을 함께
미분합니다. 형식을 지정한 교차 장면, 위쪽/전기장 추출과 아래쪽/방향별 추출, 단계형 격자, 명목 정렬,
같지 않은 가로 샘플링, 노치 펄스, 필드 모니터, 잘라 낸 기록, 수렴 prefix 출력을 포함합니다. 두 유한
차분 간격이 AD와 일치합니다. JIT 검사는 한 번의 trace에서 계면을 옮기고, 유효하지 않은 바깥 여유를
마스킹하기도 합니다.

해상도 20에서 아래의 자성 막은 전기장 셀 면 d=0.175를 지납니다. d-delta와 d+delta에서의 전체 산란
미분 사이의 최대 차이는 다음과 같습니다.

| 폭 | delta=1e-4 | delta=1e-6 |
| --- | ---: | ---: |
| 0 | 1.29267 | 1.29182 |
| 0.05 (한 셀) | 0.00633085 | 0.0000633094 |

날카로운 겹침의 도약은 그대로 남습니다. 평균한 응답의 차이는 오프셋과 함께 줄어드는데, 1차 미분이
연속일 때 기대되는 대로입니다. 이것은 유한 계산의 성질이며, 연속체 미분 정확도와는 별개입니다.

## 날카로운 연속체 기준과 단계형 연속체 기준

수직 입사 자성 막은 epsilon/mu = 2.25/1.12를 쓰고, 위쪽은 1.2/1.1, 아래쪽은 1.6/1.15입니다. 내부
면은 d=0.163, 0.173, 0.183을 취하고, 기판 스페이서가 D=0.4를 고정합니다. 파장은 0.98과
1.02입니다. 장면은 방향별 추출, 명목 길이 [0.2,0.2], 맞춘 셀, 물리 단위 1의 CPML, 펄스 폭 3,
실행 시간 65를 씁니다.

날카로운 기준은 독립적인 Fresnel/Airy 급수입니다. 양수 h에 대해 단계형 기준은 균질한 전달 행렬
조각 512개를 써서 h에 걸친 선형 접선 방향 epsilon/mu 경사를 적분합니다. 그 평행 이동 미분은
해석적입니다. 경사 주변의 균일한 막과 기판 길이만 바뀝니다. AD나 FDTD 가중치는 쓰지 않습니다.
조각을 1024개로 두 배 늘려도 이 실험 전체에서 보고한 가장 큰 값이나 미분은 최대 1.26e-6만큼
바뀝니다. h=0에서는 반올림 오차 수준까지 Airy와 일치하고, 두 유한 차분 간격이 해석적 미분을
검증하며, 균일 재료 대조 실험의 평행 이동 민감도는 0입니다.

이것은 평면형 무손실 자성 장면 하나입니다. 비스듬한 패턴, 얇은 손실 금속, 모서리, 겹치는 분산
계면에 대해 같은 오차 범위를 확립하지 않습니다. h=0 미분은 여전히 위치에 따라 달라지며, 개별 계면
위치마다 단조롭게 개선될 필요는 없습니다.

## 독립적인 Meep 재료 함수 비교

고정해 둔 Meep 1.34.0 기준은 문서화된
[재료 함수 API](https://meep.readthedocs.io/en/latest/Python_User_Interface/#medium)를 씁니다.
전역 함수 하나가 z=0의 날카로운 위쪽 계면과 d 주변의 선형 epsilon/mu 전이를 돌려줍니다.
`do_averaging` 속성은 서브픽셀 적분을 켜고, `extra_materials`는 자성 매질을 선언합니다. 구현 소스는
살펴보지 않았습니다. 주기 3D 셀이 균일한 가로 평면파를 실어 나르며, 가로 방향마다 셀은 하나입니다.
이것도 여전히 평면형 수직 입사 물리 실험입니다.

해상도 80, d=0.173, h=0.0125에서 생성기는 실행 시간 50과 70에서 d를 독립적으로 1e-3과 5e-4만큼
섭동합니다. 복소 r/t는 Wavebit와 같은 고정 바깥 기준 평면을 씁니다. 기준은 셀 길이 10, CPML 두께
1, Courant 0.4, 소스 z=-3, E 모니터 z=-1과 1.2, 그리고 시각 6을 중심으로 시각 12에 끝나는 폭 1.2의
가우시안 펄스를 씁니다. `golden_meep_layer_smoothing.npz`의 메타데이터가 이 선택을 기록하며, 짝이
되는 `golden_meep_layer_smoothing_refined.npz`는 평균 허용 오차를 1e-8에서 1e-9로 조입니다.

| 검사 | 복소 진폭 또는 미분의 최대 차이 |
| --- | ---: |
| 실행 시간 50에서 70으로, 값과 미분 | 저장된 배열에서 0 |
| 섭동 1e-3에서 5e-4로, 미분 | 1.49e-5 |
| 평균 허용 오차 1e-8에서 1e-9로, 값 | 1.58e-11 |
| 평균 허용 오차 1e-8에서 1e-9로, 미분 | 3.65e-8 |
| 가로 축마다 셀 하나에서 넷으로, 값 | 5.32e-16 |
| 가로 축마다 셀 하나에서 넷으로, 미분 | 1.78e-12 |
| Wavebit 대 Meep, r/t | 0.000767 |
| Wavebit AD 대 Meep 유한 차분 | 0.000916 |
| Meep 대 단계형 연속체, 미분 | 0.003781 |
| Wavebit 대 단계형 연속체, 미분 | 0.003980 |

이 비교는 예전의 날카로운 계면 골든 값을 기준으로 삼지 않고 새로운 정칙화 분포를 검사합니다. 이
경우 유한 격자 미분끼리의 일치는 어느 솔버의 연속체 정확도보다도 더 촘촘합니다. 패턴이 있거나 분산이
있는 형상 미분에 대해 Meep과의 일반적인 동등성을 확립하지는 않습니다. 기존의 날카로운 막과 반공간
아카이브를 확장한 래퍼로 다시 생성해도 그 데이터는 보존됩니다.

```shell
"$MEEP_PYTHON" tests/references/interface/meep_halfspace.py --parameter thickness --smoothing .0125 --output artifacts/meep-layer-smoothing.npz
"$MEEP_PYTHON" tests/references/interface/meep_halfspace.py --parameter thickness --smoothing .0125 --subpixel-tol 1e-9 --output artifacts/meep-layer-smoothing-refined.npz
"$MEEP_PYTHON" tests/references/interface/meep_halfspace.py --parameter thickness --smoothing .0125 --transverse-cells 4 --output artifacts/meep-layer-smoothing-transverse.npz
```

## 마지막에 날카로운 검사를 하는 코팅 최적화

```shell
python -m examples.fdtd.fdtd_layer_optimization --smoothing-cells 1
```

epsilon 1.5인 코팅이 공기와 epsilon 2.25인 기판 사이에 있습니다. JAX 백트래킹이 해상도 40,
h=0.025에서 보정용 기판 스페이서와 함께 그 두께를 최적화합니다. 갱신 20번으로 d가 0.12에서
0.2038164로 움직이고, 훈련 반사는 0.0146115에서 1.484e-7로 줄어듭니다.

해상도 80에서 h를 0.0125로 줄이면 반사는 1.465e-7입니다. 그 더 고운 메시에서 날카로운 계면 FDTD
검사는 1.446e-7을 주고, 날카로운 Airy 결과는 2.337e-7입니다. 정확한 1/4 파장 두께는
0.2041241입니다. 이렇게 서로 다른 검사를 두면 유한 격자 훈련 목적 함수가 정확한 물리 성능으로
보고되는 일을 막을 수 있습니다.

이것은 여전히 범위를 한정한 단일 매개변수 예제입니다. 총 깊이 변화, 가로 형상 미분, 이방성 형상
균질화, GPU 실행은 별도의 구현과 근거가 필요합니다. 총 깊이와 가로 직사각형 미분은 나중에
2026-09-09에 그 근거를 얻었습니다([가변 깊이](fdtd-variable-depth.md),
[직사각형](fdtd-rectangle-gradients.md)).
