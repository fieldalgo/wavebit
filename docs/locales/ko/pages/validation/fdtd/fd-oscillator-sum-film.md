# C8: 박막 하나 안의 유한한 Drude/Lorentz 합

작성: 2026-10-07

대상: `src/wavebit/fdtd/_prepare/oscillator_sum_film.py`,
`src/wavebit/fdtd/_prepare/oscillator_sum_resolution.py`, `src/wavebit/materials/_time_domain.py`,
`src/wavebit/fdtd/_kernel/poles.py`, `src/wavebit/fdtd/_kernel/observe.py`,
`src/wavebit/fdtd/_prepare/checks.py`.

## 요약

**고립된 평평한 박막 하나 안에 수동 Drude/Lorentz 극점이 두 개 이상 있는 경우에 대해, 감쇠율이
서로 다른 경우를 포함하여 범위를 한정한 구현을 마쳤습니다. 공개한 보정 행 여섯 개가 NumPy, JAX,
Torch에서 끝까지 실행되고, 대상 사례 684개가 모두 통과합니다. 실제 변이 증거 10개가 모두
받아들여졌고, 소스는 정확히 복원되었으며 148개 사례 기준선이 통과합니다. 작업자 40개 캠페인이
끝났습니다. 자기 차수 48개 중 45개가 2차, 2개가 혼합, 1개가 미결정이고, 최종 직접 쌍 48개 중
44개가 2차, 4개가 미결정입니다. 전체 회귀는 3,434개 사례가 통과하고 8개를 건너뛰며, 별도의 느린
단계는 81개 모두 통과하고, 고정 기준 관문 네 개가 모두 비트 단위로 정확합니다.** 법선 방향 계면
응답은 물리 분극 메모리들을 그 합을 통해 결합합니다. 이 좌표를 유지하면 복원 행렬과 감쇠 행렬을
함께 대각화할 수 있다고 가정하지 않아도 됩니다.

선언된 극점 하나는 메모리 슬롯 하나를 유지합니다. 점화식은 선언된 개수에 비례하는 작업량으로
계수 1(rank-one) 결합을 더합니다. 에너지는 이동하지 않은 극점별 공진 항과, 합한 분극에 대한 항
하나를 더 씁니다. 감쇠가 음수가 아니면 해당 이산 에너지는 소산합니다. 명시한 무손실 호스트 박막
계약 안에서는 기존의 합산 재료 CFL 상한으로 충분합니다.

범위는 앞선 구체적인 축 정렬 박막 기하를 유지하고, 기존 단일 진동자 경로를 보존합니다. Debye
극점과 2차 극점을 결합하거나, 분산 호스트를 허용하거나, 곡면 물체, 접합부, 기하/재료/대역 미분을
검증하지는 않습니다. Debye/진동자 혼합 박막은 나중에 자체 범위를 얻었습니다
([기록](fd-hybrid-film.md), 2026-10-07). 앞선
[단일 진동자](fd-single-pole-film.md),
[유한 Debye 합](fd-debye-sum-film.md),
[전도성 박막](fd-conductive-film.md) 기록은 각자의 범위와 한계를 유지합니다. 일반 C8 스무딩은 아직
완성되지 않았고 [C7 메타표면 판정](fd-metasurface-validation.md)도 여전히 통과하지 못했습니다.

## 범위를 한정한 계약

| 항목 | 허용 조건 |
| --- | --- |
| 기하 | 정확히 하나의 구체적인 공개 `Box`, `angle=0`, `range=None`, voxel 이산화. 짝이나 접합부 없음. |
| 범위 | 정확히 두 축이 가로 방향으로 적어도 `dx` 하나만큼 넘치며 격자 전체에 걸침. 법선 방향 두께는 적어도 `dx`. |
| 여유 | 법선 방향 지지 구간은 도메인 안쪽에 엄격히 포함되고, 모든 지지 구간은 모든 흡수층과 떨어져 있음. |
| 박막 | 정확히 `Dispersive`, 유한한 양의 등방성 `eps_inf`, `mu=1`, 그리고 정확한 공개 `Drude` 또는 `Lorentz` 극점 두 개 이상. |
| 극점 | 공개 생성자를 만족하는 구체적이고 유한한 수동 매개변수. 모든 감쇠율은 음수가 아님. 세기가 0인 비활성 Lorentz 극점은 슬롯을 유지하지만 구동이나 에너지에 기여하지 않음. |
| 호스트 | 정확히 평범한 무손실 `Material`, 유한한 양의 등방성 유전율과 `mu=1`. |
| 상태 | 초기 필드 없음. 준비된 기하, 재료, 격자, 선언된 순서/개수와 모든 메모리 슬롯이 낮추기(lowering) 시점에 일치해야 함. |

기하 규칙은 x, y, z의 순열에 대해 불변입니다. 점유율은 각 전기장 성분 자신의 Yee 쌍대 셀에서
평가합니다. 정확히 빈 끝점과 가득 찬 끝점은 보존되며, 0이 아닌 작은 채움을 스냅해 없애지
않습니다.
이것이 수학적으로 유한한 모든 매개변수 조합을 표현하겠다는 약속은 아닙니다. 활성 계수, 역수 에너지
가중치와 계획 비율은 수치 표현 안에 들어가야 하며, 그렇지 않으면 이름 붙은 거부를 받습니다.

극점이 하나인 Drude/Lorentz 사례는 기존 구현을 그대로 거칩니다.
새 경로는 독립적인 유효 Lorentz 모드에 대한 맞춤이 아니며, 유한 개수마다 다른 구현을 필요로 하지
않습니다. 반복된 극점 매개변수는 선언된 메모리 할당을 바꾸지 않고 기약 가능한(reducible) 물리
응답을 기술할 수 있습니다. 기존 소스 및 모니터 제한은 여전히 적용됩니다. 소스 진폭 그래디언트의
정확성은 주장하지 않습니다.

## 정확한 결합 조화 응답

저장소의 `exp(-i*omega*t)` 규약에 맞춰 `s=-i*omega` 를 씁니다. 선언된 벌크 박막은 다음과
같습니다.

```text
eps_film(s) = a + chi(s)
chi(s) = sum_j S_j/(s*s + gamma_j*s + d_j).
```

Drude 극점에서는 `d_j=0`, `S_j=omega_p_j**2` 입니다. Lorentz 극점에서는
`d_j=omega0_j**2`, `S_j=strength_j` 입니다. `f` 를 박막 비율,
`g=1-f`, `b` 를 호스트 유전율이라 하고 다음을 정의합니다.

```text
A = f*b + g*a
alpha = g/A
kappa = f*b*b/(A*A)
eps_inf_normal = a*b/A.
```

조화 법선 응답은 다음과 같습니다.

```text
eps_n(s) = 1/(f/(a+chi(s)) + g/b)
         = eps_inf_normal + kappa*chi(s)/(1+alpha*chi(s)).
```

`P=sum_j p_j` 인 물리 성분 분극 `p_j` 를 도입하고, 선언된 감쇠 좌표를 유지합니다.

```text
p_j'' + gamma_j*p_j' + d_j*p_j + alpha*S_j*P = kappa*S_j*E.
```

주파수 영역에서 합하면
`P=chi*(kappa*E-alpha*P)` 가 되므로, 정확히 필요한 조화 응답이 나옵니다.
접선 방향 법칙은 `alpha=0`, `kappa=f`,
`eps_inf_tangent=f*a+g*b` 이며, 독립적인 메모리들이 산술 감수율 `f*chi` 를 줍니다.

활성 극점에 대해 `u_j=sqrt(S_j)`,
`q_j=p_j/sqrt(kappa*S_j)`, `D=diag(d_j)`,
`Gamma=diag(gamma_j)` 로 정의합니다. 법선 방정식은 다음이 됩니다.

```text
q'' + Gamma*q' + J*q = v*E
J = D + alpha*u*u^T
v = sqrt(kappa)*u.
```

`J` 는 대칭 양의 준정부호이고, `Gamma` 는 대각 양의 준정부호입니다. 감쇠가 서로 다르면 일반적으로
모드 회전 하나로 둘을 함께 대각화할 수 없으며, 그래서 이 구성은 결합된 물리 메모리를 유지합니다.
정확한 혼합 항등식에는 같은 감쇠도, 유수(residue) 맞춤도 필요하지 않습니다.

## 점화식과 커널의 시간 이동

각 물리 분극 방정식에서 두 미분을 모두 중앙 차분으로 둡니다.
`den_j=1+gamma_j*dt/2` 로 두면, 구현한 점화식은 다음과 같습니다.

```text
gain_j = (2-d_j*dt*dt)/den_j
hold_j = (1-gamma_j*dt/2)/den_j
drive_j = kappa*S_j*dt*dt/den_j
coupling_j = alpha*S_j*dt*dt/den_j

p_j^(m+1) = gain_j*p_j^m - hold_j*p_j^(m-1)
          + drive_j*E^m - coupling_j*sum_k p_k^m.
```

어느 극점을 전진시키기 전에, 이전 메모리 전체에서 합을 계산합니다.
합을 만드는 동안 이전 값을 새로 전진한 값으로 바꾸면 순서에 의존하는 갱신이 생깁니다. 공유 합 하나를
계산한 뒤 극점마다 갱신을 한 번씩 하면 선언된 개수에 대해 선형 작업량이 들며, 시간 간격마다 셀별
조밀 풀이가 필요하지 않습니다.

기존 `before_E` 연산은 회전(curl) 누산기에서
`(dx/dt)*sum_j(p_j^(m+1)-p_j^m)` 를 뺍니다. 필드 계수에는 이미 `dt/(dx*eps_inf)` 가 들어 있으므로,
진동자 방정식에 새로운 `dx` 인자나 순간 유전율 이동을 넣지 않습니다.

커널은 시간 간격의 끝에서 메모리를 전진시킵니다. `E^n` 과 연결된 에너지 읽기 시점에서 메모리 `P` 는
`p^(n+1)` 을, `previous` 는 `p^n` 을 담고 있습니다. 같은 쌍이 다음 전기장 갱신에도 쓰입니다.
점화식은 NumPy, JAX, Torch에서 그 이동을 보존해야 합니다.

`gamma_j*dt=2` 여서 `hold_j=0` 이 되더라도 명시적인 진동자 에너지 메타데이터는 유지해야 합니다.
그 값이 2차 극점을 Debye 완화로 바꾸지는 않습니다. 세기가 0인 셀과 빈 셀은 역수 `kappa*S_j` 나
계수 1 에너지 가중치를 만들기 전에 가려야 합니다.

낮추기 단계는 서로 다른 구체적인 채움 값마다 정확한 유리수 산술로 계수 식을 평가한 뒤, 유한한
결과를 float64로 변환합니다. 활성 구동과 역세기 가중치는 양수이고 유한해야 합니다. `d_j>0` 일 때의
퍼텐셜, `alpha>0` 일 때의 결합, 필요할 때의 계수 1 가중치도 마찬가지입니다. 표현할 수 없는 활성
양은 이름 붙은 거부를 받습니다. 빈/가득 찬 끝점과 비활성 끝점은 쓰이지 않을 나눗셈 전에 분기합니다.
아래 대상 점검이 이 계약을 시험합니다.
전체 단계와 별도의 느린 단계가 통과하고, 고정 기준 관문 네 개가 모두 비트 단위로 정확합니다.
측정한 전파 한계는 아래에 있습니다.

## 이산 에너지: 계수 1 항 하나

관측기의 `E^n` 수준에서
`delta_p_j=p_j^(n+1)-p_j^n`, `P^n=sum_j p_j^n` 로 둡니다.
저장소의 에너지 정규화에서 재료 보정은 다음과 같습니다.

```text
sum_active_j [
    |delta_p_j/dt|**2/(kappa*S_j)
  + d_j*Re(p_j^(n+1)*conj(p_j^n))/(kappa*S_j)
  - Re(E^n*conj(delta_p_j))
]
+ (alpha/kappa)*Re(P^(n+1)*conj(P^n)).
```

1/2 인자는 없습니다. 기존 필드 에너지와 진동자 에너지가 이미 이 두 배 정규화를 쓰기 때문입니다.
극점별 퍼텐셜은 이동하지 않은 선언값 `d_j` 를 씁니다. 만약 `d_j+alpha*S_j` 를 쓰면서 계수 1 항도
더하면 결합의 대각 성분을 두 번 세게 되어, 활성 극점이 하나인 축소에서도 이미 틀립니다.

마지막 계수 1 항은 각 셀에서 분극을 합한 뒤 극점 집합마다 한 번 더합니다. 그 공간 계수는 셀,
성분 또는 잘린 관측 영역을 축약하기 전에 적용해야 합니다. 따로 축약한 분극 합들의 곱이 아닙니다.
기존의 극점별 필드 결합 항을 합하면 `-Re(E^n*conj(P^(n+1)-P^n))` 이 됩니다.

`J_j^(n+1/2)=delta_p_j/dt` 로 두면, 에너지 차이에 대한 감쇠 기여는 다음과 같습니다.

```text
-(dt/2)*sum_active_j gamma_j/(kappa*S_j)
         * |J_j^(n+1/2)+J_j^(n-1/2)|**2.
```

이것은 감쇠율이 같든 다르든 음이 아닌 감쇠율이면 양수가 아닙니다.
이것은 재료 소산 항등식입니다. 완전한 에너지 균형에는 소스 일과 경계 플럭스도 포함해야 합니다.
가중 강성은
`diag(d_j/(kappa*S_j))+(alpha/kappa)*1*1^T` 로 대칭이고, 가중 감쇠는 대각 양의 준정부호입니다.
이 에너지 항등식에는 두 정규화 행렬의 교환 가능성이 필요하지 않습니다.

Drude 극점은 복원 주파수가 0입니다. 따라서 결합된 합에 직교하는 정적 분극 조합은 복원 에너지가 0일
수 있습니다.
에너지는 그 메모리 방향에서 준정부호이며, 가능한 모든 분극 상태에 대해 엄격한 양의 정부호는
아닙니다. 이것은 물리 필드나 전류가 커지는 것과는 다릅니다. 범위를 한정한 경우는 메모리를 정지
상태에서 시작하며, 여전히 명시적인 유한 에너지 검증과 전파 검증이 필요합니다.

## 기존 합산 CFL 상한

전기장을 국소 고주파 유전율로 정규화하고, 그에 해당하는 이산 회전을 `C_eps` 라고 합시다. 무손실
결합계에서 관련 블록 연산자는 다음과 같이 쓸 수 있습니다.

```text
B = [[C_eps, -v^T/sqrt(eps_inf_eff)],
     [0,      sqrt(J)                ]].
```

`B*B^*` 를 회전 블록과 셀 국소 인자로 나누면 다음을 얻습니다.

```text
||B||**2 <= ||C_eps||**2
         + max_cells lambda_max(J + v*v^T/eps_inf_eff).
```

법선 성분에 대해서는

```text
alpha + kappa/eps_inf_normal = 1/a
J + v*v^T/eps_inf_normal = D + u*u^T/a
lambda_max(D + u*u^T/a) <= max_j d_j + sum_j S_j/a.
```

입니다. 접선 성분에서는 `kappa/eps_inf_tangent=f/(f*a+g*b)<=1/a` 이므로 같은 상한이 적용됩니다.
범위를 한정한 정책은 `max_active d_j + sum_active S_j/a` 를 쓰며, 이를 정확한 유리수 합으로 평가해
float64로 올림합니다. 모두 비활성인 선언은 정확히 0을 기여합니다. 쓰이지 않는 극단 주파수와
감쇠는 항등식 안에 남지만 이 비율에는 들어가지 않습니다.
일반적인 엄격한 조건 `dt*||B||<2` 가 감쇠 없는 leapfrog 에너지를 통제하고, 중앙 차분한 음이 아닌
감쇠는 새로운 감쇠율 CFL 불이익 없이 위의 소산 항을 더합니다.
이 논증은 기존 흡수층/PML 안정성 계약을 확장하지 않습니다.

## 보수적인 벌크 스펙트럼 하한

Drude/Lorentz 합은 소스 대역 안에 공진을 가질 수 있으므로, 수동 Debye 합에 대한 단조 상단 끝점
정리는 적용되지 않습니다. 새 스펙트럼 보호 장치는 메시를 허용하기 전에 각 양의 소스 구간 전체에서
선언된 합 전체의 상한을 정합니다. 그 목적은 벌크 위상/표피 분해이며, 계면 정확도나 산란 정확도에
대한 정리가 아닙니다.

보수적인 대역 전체 상한은 `x=omega**2` 와 다음을 씁니다.

```text
R_j(x) = x/sqrt((d_j-x)**2 + gamma_j**2*x)
K_bound**2 = a*x_high + sum_active_j S_j*max_band R_j(x)
|k(omega)|**2 <= K_bound**2.
```

각 극점에 대해 두 끝점과, 분모가 양수이고 그 점이 대역 안에 있을 때 가능한 내부 임계점을 시험합니다.

```text
x_critical = 2*d_j*d_j/(2*d_j-gamma_j*gamma_j),
```

이는 `R_j**2` 를 미분해서 얻습니다. 극점에서 떨어진 곳에서 그 미분의 부호는
`x*((gamma_j**2-2*d_j)*x+2*d_j**2)` 의 부호와 같습니다. 감쇠 없는 대역 내 극점의 세기가 양수이면
유한한 상한이 없으므로 명시적으로 거부합니다.
세기가 0인 극점은 분모를 시험하기 전에 제거합니다.

구현은 임계점과 제곱 비를 정확한 유리수 산술로 계산하고, 제곱근 상한을 결합하기 전에 바깥쪽으로
반올림합니다. 내부 공진을 몇 개의 주파수 표본으로 근사하지 않습니다. 삼각 부등식은 복소 감수율
사이의 상쇄에 기대지 않으므로 상한을 보수적으로 만들 수 있습니다. 대상 최고점/표본 점검과 아래의
내부 최고점 변이가 이 보호 장치를 시험하지만, 산란 차수를 확립하지는 않습니다.

모든 소스 대역과 선언된 모니터, `Resolution` 과 명시적 PML 파장은 구체적인 양수여야 합니다. 앞선
8셀 위상 거부 하한과 1셀 표피 깊이 거부 하한, 그리고 12/2 경고는 물려받은 정책입니다. 이 스펙트럼
하한이 모든 유효 계면 공진이나 비스듬한 종방향 스케일을 통제하지는 않습니다.
