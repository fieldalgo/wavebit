# 가로 메시 하나 위의 방위각 미분

작성: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `src/wavebit/_common/conventions.py`
- `src/wavebit/fdtd/_periodic/api.py`
- `tests/fdtd/test_fdtd_scene_azimuth.py`

요약: 명시적 백엔드 장면 어댑터가 이제 phi를 theta 및 재료 매개변수와 함께 미분합니다. 배열 phi는 0에서도
y 주기 전체를 표본화하므로, 각도 스윕이 하나의 이산 실험 위에 머뭅니다. 계산 그래프에는 파수 벡터뿐 아니라
회전하는 전류 기저와 입사 편광 보정도 들어 있습니다. 정확한 이산 분산, 필드 회전, 축 교환, 그리고 두 가지
유한 차분 간격으로 결과를 검사합니다.

## 배열과 스칼라의 구분이 중요한 이유

이전의 y 불변 지름길은 phi가 0일 때 셀 두 개를 썼지만, 0이 아닌 phi에서는 선언한 y 주기 전체를
표본화했습니다. 그 분기를 통해 미분하면 0에서의 갱신마다 메시, 시간 간격, 실행 시간이 바뀌게 됩니다.
또한 배열 모양이 추적된(traced) 데이터에 의존하게 됩니다.
[JAX 변환 문서](https://docs.jax.dev/en/latest/notebooks/Common_Gotchas_in_JAX.html#dynamic-shapes)가
이 제약을 설명합니다.

그래서 [공개 계약](../../guide/fdtd/time-domain.md#incidence-angle-derivatives)은 배열 phi를 주기 전체에
걸친 고정 메시에 대한 요청으로 취급합니다. 즉시 실행 NumPy나 Torch에서도 배열의 현재 값에 의존하는 분기는
없습니다. 모든 배열 각도에는 명시적인 회절 창이 필요합니다. 스칼라 TE/TM 규약은 x-z 평면을 고정하므로,
배열 phi에는 Jones/psi 편광도 필요합니다.

| 선언한 Ly=0.5, Ry=10인 한 행 장면 | y 셀 수 |
| --- | ---: |
| 일반 스칼라 phi=0 | 2, 원래 지름길 유지 |
| 일반 스칼라 phi=0.2 | 5 |
| 배열 phi=-0.2, 0, 또는 0.2 | 세 실행 모두 5 |

x 주기만 선언하면 보조 y 주기는 셀 두 개짜리 `2/Ry`로 남습니다. 교차 래스터는 이미 선언한 y 주기 전체를
씁니다. 검사한 장면들에서 0이 아닌 스칼라 각도와 그에 대응하는 배열 각도는 똑같은 NumPy 산란 결과를
냅니다. 배열 각도는 0을 지날 때 메시 노드, 소스/PML/측정 위치, 시간 간격, 갱신 횟수를 유지합니다. JIT
테스트 하나가 한 번의 트레이스로 음수, 0, 양수 방위각을 모두 지나가며, 각 점에서 그 미분은 같은 메시의
유한 차분과 일치합니다.

이 변경은 y 불변 모니터 단면을 전체 y 기록으로 바꾸지 않으며, 단위 y당 전력이라는 규약도 바꾸지 않습니다.
이 측정들은 반공간 계수를 고정해 두며, 이후 [반공간 확장](fdtd-halfspace-gradients.md)이 그 미분을
추가합니다. 기하, 메시 목표치, 파장은 정적으로 남습니다. 방위각 매개변수를 위해 native Maxwell/ADE/CPML
갱신을 복제하거나 바꾸지 않았습니다.

## 파수 벡터뿐 아니라 소스도 회전하기

theta를 고정하면 phi는 가로 Bloch 벡터와 입사 s/p 좌표계를 회전시킵니다. 두 전류 기저가 모두 회전해야
하고, 각 균일 매질 기준 실행을 입사 s/p 진폭으로 바꾸는 변환도 회전해야 합니다. 그중 어느 하나라도
상수로 두면 다른 실험을 미분하게 됩니다.

theta=0에서는 모든 phi에 대해 가로 Bloch 벡터가 0입니다. 그래도 입사 편광은 회전합니다. 단위 s파의 접선
방향 E는 `(-sin(phi), cos(phi))`에 비례합니다. 테스트는 이 독립적인 항등식을 주파수 모니터와, 반송파로
보정하고 잘라 낸 시간 기록에 대해 양쪽 입사 방향에서 사용합니다. 균일 평면 매질의 스칼라 투과율은 일정하게
유지되더라도, 그 미분은 `(-cos(phi), -sin(phi))`처럼 회전해야 합니다.

출사하는 실수 파수 벡터 좌표계는 [theta 확장](fdtd-scene-angles.md)의 좌표축 처리를 그대로 유지합니다.
원점에서는 명시적으로 지정한 phi가 좌표계를 회전시킵니다. 이는 방향이 없는 가로 벡터의 임의적인 미분이
아닙니다.

## 독립적인 이산·연속체 검사

여기의 모든 측정은 macOS arm64 CPU, NumPy, JAX x64, Torch float64를 사용합니다. 균일 매질 오라클은
솔버의 전파나 투영 도우미를 호출하지 않고 Yee 분산식을 직접 미분합니다. theta와 phi, 그리고 광대역 각도
진단을 모두 포함합니다. theta를 고정했을 때 phi에 대해 `d kx/d phi = -ky`, `d ky/d phi = kx`입니다.
가장 큰 Jacobian 절대 불일치는 각 입사 방향에 대해 JAX에서 `3.99e-12`, Torch에서 `3.96e-12`였습니다.

진공 사례는 theta=0.6, phi=0.6, 파장 0.98/1.02, 깊이 0.2, 주기 0.2/0.3, z 해상도 10, x/y 목표치 20/5를
씁니다. PML은 셀 10개이고, 가우시안 폭은 4, 실행 시간은 중심 주기 80개입니다. 방향별 추출을 사용합니다.
셀 크기가 서로 달라 정확한 이산 방위각 미분이 충분히 크므로, phi 그래프가 빠지면 비교 허용 오차를 통과할 수
없습니다. 더 넓은 포락선과 더 긴 실행은 처음 시도한 폭 2, 50주기 실험에서 보인 잔차를 피합니다. 그
실험은 `1.76e-5`의 오차로 `2e-6` 위상 기준을 넘지 못했습니다. 미분 비교를 해석하기 전에 소스 대역 안의
스치듯 지나는(glancing) 주파수와 유한한 실행 시간을 통제해야 합니다.

| 검사 | 기준 |
| --- | --- |
| 균일 이산 전파, 양쪽 입사 방향과 두 AD 백엔드 | 실수/허수 s/p 투과율과 각도 Jacobian이 독립적인 분산 미분과 `2e-5` 안에서 일치합니다. |
| 수직 입사 필드 회전, 양쪽 방향과 두 AD 백엔드 | 보정한 모니터/기록 값이 `2e-11` 안에서, 미분이 `2e-10` 안에서 일치합니다. |
| x/y를 맞바꾼 교차 자성 장면 | 대각 Jones 진폭은 보존되고 비대각 진폭은 부호가 바뀝니다. 그 phi 미분도 각도 연쇄 법칙과 함께 같은 항등식을 `1e-10` 안에서 따릅니다. |
| 비균일화, 소스 영점, 3x3 차수 창과 기록을 가진 교차 분산 바닥 장면 | theta/phi/epsilon/극점의 결합 Jacobian이 간격 `2e-4`와 `1e-4`의 유한 차분과 상대 `5e-5`, 절대 `3e-8`에서 일치합니다. 전기장 추출과 방향별 추출을 모두 검사합니다. |
| 유한하지 않은 phi와 방위각에 따라 정확히 스치는 경우 | 즉시 실행 입력 가드나 JIT `stable=False`가 그럴듯해 보이는 산란 결과를 막습니다. 유효하지 않은 정규화 필드도 가려집니다. |

등방성 평면 연속체는 방위각에 의존하지 않지만, 셀 크기가 다른 Yee 격자는 유한 해상도에서 그 불변성을
깨뜨립니다. 별도의 자성 Airy 테스트는 epsilon=2.25, mu=1.1, depth=0.2, theta=0.55, phi=0.41, 파장
0.98/1.02, x 주기 0.05, x/y 목표치 `(1.5R, 0.75R)`, 층 경계 맞춤, 방향별 추출을 사용합니다. PML 두께는
길이 단위 하나이고, 펄스 폭은 3, 실행 시간은 60주기입니다. 가중 복소 진폭 목적 함수는 s/p 반사와 투과를
모두 포함하며, 그 연속체 phi 미분은 정확히 0입니다.

| z 해상도 R | Airy 대비 목적 함수 오차 | 계산한 라디안당 phi 미분 |
| --- | ---: | ---: |
| 40 | 0.0069072082 | -1.8007846e-5 |
| 80 | 0.0017150987 | -4.4806241e-6 |

두 오차 모두 약 4배 줄어듭니다. 따라서 유한 격자에서 0이 아닌 평면 phi 민감도는 올바르게 미분된 이산화
오차일 수 있습니다. 격자/시간 수렴을 독립적으로 확인하는 일은 여전히 필요합니다. 자동 미분이 유한 차분과
일치한다는 사실만으로는 물리적 정확도가 확립되지 않습니다.

이 검사들은 분해되지 않은 회절 문턱, 날카로운 분산 모서리, 오래 지속되는 공진 근처의 민감도를 확립하지
않습니다. Float32, Torch 컴파일, 실제 GPU 실행은 여전히 이 근거의 범위 밖입니다. 이 확장을 위해 외부 솔버
구현을 참고하거나 포함하지 않았습니다. 기존 Meep 공개 API 데이터는 계속 장면 회귀 테스트의 일부로 남아
있습니다.
