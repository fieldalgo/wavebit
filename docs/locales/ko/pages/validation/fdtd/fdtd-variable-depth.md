# 움직이는 바깥 기준면을 쓴 전체 두께 미분

작성: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `src/wavebit/manifest.py`
- `studies/fdtd/variable_depth/fdtd_variable_depth.py`
- `tests/fdtd/test_fdtd_variable_depth.py`
- `tests/fdtd/test_fdtd_variable_depth_optics.py`
- `tests/references/interface/meep_halfspace.py`
- `tests/references/test_meep_variable_depth.py`

요약: `variable_depth=True` 는 고정된 공칭 메시 위에서 서로 독립적인 양의 층 길이를 허용합니다.
복소 진폭은 위상 미분을 포함해 물리 적층 면을 따라갑니다. 두 입사 쪽 모두 실험실 좌표를
보존합니다. 스무딩한 자성 박막의 미분은 독립적인 전달 행렬 광학으로 세분 수렴하며, 새로 추가한
공개 API Meep 차분이 움직이는 출구 규약을 확인합니다. 유한 격자 오차와 스무딩 편향은 따로
남습니다.

## 기하와 기준면은 함께 움직여야 합니다

원래의 `mesh_thickness` 옵션은 내부 경계를 움직이되 그 합은 고정합니다. 새 옵션은 같은 정적 메시
선택을 유지하면서, 계속 추적되는 전체 두께 D를 포함해 물리 면을 `[0, cumsum(thickness)]` 에
둡니다.
노드, 시간 간격, 소스, PML 또는 측정 인덱스를 고르기 위해 텐서를 그래프에서 떼어 내지 않습니다.
모든 물리 길이는 양수로 남아야 하고, 표현된 면들은 서로 구별되어야 합니다. 계면과 평균 지지
구간은 시간 진행 전에 고정된 회절 스텐실과 겹치지 않아야 합니다.

예전의 전체 두께 검사를 그냥 없애는 것은 옳지 않습니다. 고정 기준면이 D0에 있다면, 물리 출구까지의
투과는 다음을 따릅니다.

```text
t(D) = t_fixed(D) exp[-i kb (D0-D)]
dt/dD = exp[-i kb (D0-D)] [dt_fixed/dD + i kb t_fixed(D)].
```

각도나 반공간 재료가 함께 바뀌면 kb도 바뀌며, 그 미분은 백엔드 그래프에 남습니다. 바탕이 되는
순방향/역방향 평면파 위상은 공개된
[Meep 모드 분해 이론](https://meep.readthedocs.io/en/latest/Mode_Decomposition/#theoretical-background)에
설명된 표준 규약입니다.
공개 문서와 API 실행만 사용했습니다. Meep 구현이나, 제외 대상인 Meep 파생 FDTDX 구현은 살펴보거나
복사하지 않았습니다.

균일 메시는 이산 Yee 종방향 전파 상수를 씁니다. 맞춘 메시나 불균일 메시는 각 정적 셀의 위상을
지나간 비율만큼 적분합니다. 노드에서는 오른쪽 셀이 한쪽 위치 미분을 제공합니다.
이 규약은 서로 다른 셀 폭과 독립적으로 지정한 복소 위상 변화율로 직접 시험합니다. 이웃한 셀의
폭이 다르면 위상 기울기에 꺾임이 생길 수 있으며, 재료 스무딩만으로는 이 이산화 효과가 없어지지
않습니다.
이웃한 적분 구간은 저장된 노드 좌표를 공유합니다. 각 오른쪽 끝점을 `node+width` 로 따로 다시
만들면 반올림 오차 때문에 이웃 구간과 겹쳐, 한 노드에서 위치 미분을 두 번 셀 수 있습니다. 별도의
균일 위상 회귀 테스트가 JAX/Torch에서 그 정확한 공유 노드 위치를 확인합니다.

## 아래쪽 입사 좌표를 고정하기

아래쪽 풀이는 계속 추적되는 D가 아니라 공칭 전체 두께 D0을 기준으로 반사합니다.
그 물리 면은 `D0 - reverse(original_faces)` 가 됩니다. 따라서 메시는 고정된 채로 입사 면이
움직일 수 있습니다. 입사 보정과 반사/투과 위상 보정 모두 계속 추적되는 반사된 면을 씁니다.
진단을 같은 D0을 기준으로 다시 반사하면 사용자 모니터와 기록 좌표가 원래 좌표계에서 보존됩니다.

테스트는 한 JAX 추적 안에서 전체 두께를 바꾸고, 노드, 소스 위치, 모니터 좌표와 잘라 낸 기록
좌표가 바뀌지 않기를 요구합니다.
추적된 기하가 유효하지 않으면 `stable=False` 로 두고, 복소 산란과 정규화한 기록/모니터를 NaN으로
가립니다. 별도의 균일 매질 테스트는 두 입사 쪽과 JAX/Torch 모두에서 정확한 이산 투과
`exp(i kz D)` 와 미분 `i kz exp(i kz D)` 를 요구합니다. 이 테스트들은 자동 미분이 똑같이 잘못된
유한 차분 계산과 일치하더라도 기준면 미분이 빠진 것을 잡아냅니다.

## 움직이는 바깥 면 평균하기

`layer_smoothing` 이 양수이면, 움직이는 바깥 면은 내부 계면과 같은 정적 평행 이동 상자에 걸쳐
평균합니다. z=0의 고정 면은 날카롭게 남습니다. 첫 층과 마지막 층은 한 층짜리 박막을 포함해 폭의
절반 이상이어야 합니다. 내부 평균 영역은 서로 겹쳐도 됩니다.
불균일 프로파일은 물리 출구 기준면을 지나 폭의 절반만큼 더 이어지며, 진폭은 그 전이 구간의
중심으로 외삽합니다.

독립적인 구간별 구적법이 재료 비율과 그 반사를 확인합니다. 균일 메시 통과 테스트는 계속 남는
날카로운 미분 도약과, 평균한 응답에서 사라지는 양쪽 차이를 구별합니다.
결합 테스트는 서로 다른 맞춘 셀 폭을 포함해 두께, 유전율과 conical 입사에 대해 JAX/Torch를 NumPy
섭동 간격 두 개와 비교합니다.
별도의 회전 레시피 사례는 두 층 길이, 가로 폭과 회전을 결합합니다. 이것들은 고정 격자 미분
점검이며, 임의의 패턴 설계에 대한 연속체 정확도 주장이 아닙니다.

## 독립적인 자성 박막 정확도

박막은 epsilon 2.25, mu 1.12, 두께 0.173입니다. 원래의 위/아래 좌표계에서 입사 쪽 매질은
`(epsilon,mu)=(1.2,1.1)` 과 `(1.6,1.15)` 입니다.
파장은 수직 입사에서 0.98과 1.02입니다. 움직이는 박막/기판 전이 구간은 고정된 평균 폭 0.025를
가지며, 입구는 날카롭습니다.

독립적인 전달 행렬 기준은 선형 epsilon/mu 경사를 지나는 일정한 조각 512개를 적분합니다. 앞선
고정 출구 기준에서 기판 스페이서 위상을 제거하고, 그 제거를 미분합니다.
무손실 상반성(reciprocity)이 반대쪽 입사를 주며, 스무딩이 0일 때 매질을 바꾼 Airy 공식으로
독립적으로 확인합니다. 섭동 간격 두 개와 조각 1024개로 기준의 미분과 적분을 통제합니다.

Wavebit은 물리 층 하나, 공칭 메시 두께 0.2, 정렬한 공칭 셀, PML 물리 두께 1, 지속 시간 65,
펄스 폭 3과 방향별 E/H 추출을 씁니다. 아래 최댓값은 두 파장의 복소 반사/투과 계수에 걸친
값입니다. 미분은 모델 길이 단위당 값이며 백분율이 아닙니다.

| 입사 | 길이당 셀 수 | 복소 진폭 오차 | 복소 두께 미분 오차 | 최대 에너지 잔차 |
| --- | ---: | ---: | ---: | ---: |
| 위 | 20 | 0.0176799 | 0.253646 | 0.00661942 |
| 위 | 40 | 0.00420258 | 0.0539120 | 0.00159626 |
| 위 | 80 | 0.00104281 | 0.0143617 | 0.000395485 |
| 아래 | 20 | 0.0191737 | 0.241769 | 0.00657346 |
| 아래 | 40 | 0.00451114 | 0.0538182 | 0.00159362 |
| 아래 | 80 | 0.00112005 | 0.0134188 | 0.000395458 |

두 방향 모두 미리 정한 세밀 격자 예산을 충족합니다. 진폭 0.002, 두께 미분 0.02, 에너지 잔차
0.001입니다. 이산 미분 그래프가 올바른데도 성긴 격자의 미분 오차는 상당히 큽니다.

세밀 격자 실행을 65에서 85로 늘리면 복소 진폭은 최대 3.83e-15, 그 미분은 7.47e-14만큼
바뀝니다. 따라서 이 사례에서 표의 오차를 주로 설명하는 원인에서 실행 길이를 배제합니다.

고정된 평균 폭은 물리 문제 자체도 바꿉니다. 불균일 연속체 기준과 날카로운 연속체 기준을 비교하면
진폭/미분 편향은 위쪽 입사에서 0.000802116/0.0159141, 아래쪽 입사에서
0.000807975/0.00467628입니다. 이 편향은 폭을 고정하고 메시를 세분해도 남습니다. 불균일 미분을
날카로운 박막의 정확한 미분으로 다루지 마세요.

## 독립적인 Meep 섭동

공개 생성기의 새 `--parameter depth` 모드는 출력 위상 기준을 섭동한 각 박막 두께에 둡니다. 예전
`thickness` 모드는 출력을 0.4에 두며 예전 동작을 유지합니다. 새 모드는 Meep 수반법이 아니라
중앙 유한 차분을 씁니다.

Meep 1.34.0은 공개 전역 재료 함수를 통해 같은 선형 epsilon/mu 프로파일을 쓰며, 가로 축마다 셀
하나인 주기 3D 셀, z 셀 길이 10, PML 물리 두께 1, Courant 0.4를 씁니다. 소스는 -3에 있고 고정된
E 필드 측정 평면은 -1과 1.2에 있습니다. 가우시안 포락선 폭 1.2, 최고점 시각 6인 사인 반송파는
시각 12에서 멈추며, DFT 표본화는 모든 시간 간격을 씁니다. 별도의 균일 매질 실행으로 소스를
보정합니다.
독립적인 균질 Yee 전파로 바깥 위상을 제거합니다.

각 보관 파일에는 지속 시간 50/70과 섭동 1e-4/5e-5가 저장되어 있습니다. 실행 시간에 따른 최대
변화는 진폭에서 저장 정밀도 수준의 0이고, 미분에서 1.58e-12입니다. 차분 간격을 절반으로 줄이면
미분은 최대 2.02e-6만큼 바뀝니다. 가로 셀 수를 두 배로 늘리면서 재료 평균 허용 오차를 1e-8에서
1e-10으로 조이면 진폭은 1.79e-11, 미분은
2.29e-7만큼 바뀝니다. 이 대조들은 후보 파일을 고정하기 전에 확인했습니다.

| Meep 길이당 셀 수 | 복소 진폭 오차 | 복소 두께 미분 오차 |
| ---: | ---: | ---: |
| 40 | 0.00444142 | 0.0399470 |
| 80 | 0.00110346 | 0.0104899 |

해상도 80에서 두 FDTD 계산은 복소 진폭에서 0.000765581, 복소 두께 미분에서 0.00746733만큼
다릅니다. 두 계산의 일치는 각 솔버 자체의 불균일 연속체 오차에 더해 따로 확인하며, 어느 비교도
다른 비교를 대신하지 않습니다.

이 외부 비교는 선택한 자성 박막의 위쪽 수직 입사를 다룹니다. 아래쪽 입사에는 독립적인 전달 행렬,
Airy, 상반성과 고정 격자 점검이 있습니다. 이 상한들이 모든 패턴, 분산, 공진 또는 비스듬한
조합을 검증하지는 않습니다.

## 재현

측정은 arm64 CPU, Python 3.12.9, NumPy 2.5.1, JAX 0.11.0 x64, Torch 2.13.0 float64를 썼습니다.
별도의 Meep 환경은 Python 3.12.14, NumPy 2.5.2, Meep 1.34.0을 씁니다. GPU나 성능에 관한 주장은
따라 나오지 않습니다.
입력과 좌표 계약은 [API 가이드](../../guide/fdtd/time-domain.md#changing-the-total-stack-depth)를
보세요.

```shell
python -m studies.fdtd.variable_depth.fdtd_variable_depth --output artifacts/variable-depth.json
pytest -q tests/fdtd/test_fdtd_variable_depth.py tests/fdtd/test_fdtd_variable_depth_optics.py
pytest -q tests/references/test_meep_variable_depth.py
```

별도의 Meep 환경에서 후보 기준값을 생성합니다.

```shell
python tests/references/interface/meep_halfspace.py --parameter depth --smoothing .025 --resolution 40 --output artifacts/meep-variable-depth-coarse.npz
python tests/references/interface/meep_halfspace.py --parameter depth --smoothing .025 --resolution 80 --output artifacts/meep-variable-depth.npz
python tests/references/interface/meep_halfspace.py --parameter depth --smoothing .025 --resolution 80 --subpixel-tol 1e-10 --transverse-cells 2 --output artifacts/meep-variable-depth-refined.npz
```

보관 파일을 바꾸기 전에 실제 후보 데이터를 보관하고, 실행 시간, 섭동, 적분과 물리 기준 점검을
확인하세요. Wavebit의 정확도는 통제된 연속체 기준에 대해 따로 확인합니다.
