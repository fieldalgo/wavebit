요약: 명시적 FDTD 경로는 이제 축에 정렬된 직사각형과 정사각형 레시피를 RCWA의 기존 형상 규약을
통해 읽습니다. 중심, 크기, 스칼라 epsilon/mu는 주기적 칠하기와 셀 적분을 거치면서도
NumPy/JAX/Torch 그래프를 유지합니다. 선택적인 가로 방향 평행 이동 평균은 셀 경계 통과를
매끄럽게 합니다. 측정한 격자에서 이 평균은 독립적인 푸리에 광학에 대한 폭/위치 미분 오차를
줄였습니다. 실제로 칠한 형상이 맞닿는 곳에는 여전히 물리적인 꺾임이 있을 수 있고, 두 FDTD 솔버
모두에서 날카로운 유한 격자 미분은 산란 진폭보다 훨씬 덜 정확합니다.

## 하나의 기하 규약

공유 `shape_geometry` 판독기가 형상 종류, 절대 길이, 중심 기준 좌표, `l` 약칭을 담당합니다. 공통
키 검사기는 알 수 없거나 쓰이지 않는 필드를 거부합니다. FDTD 어댑터는 정적 각도가 0인 직사각형과
정사각형을 받아들이며, 곡면/회전 형상, 레시피에 붙은 래스터 분산 레이블, 별도의 래스터 mu는
거부합니다. 자성 레시피 재료는 기존 `Material(epsilon, mu=...)` 전달자를 씁니다.
[사용 계약](../../guide/fdtd/time-domain.md#transverse-rectangle-shape-derivatives)에는 실행 가능한
JAX 예제와 지원하는 모든 제약이 있습니다. 2026-09-09 뒤늦게 `shape_integration='area'`가 회전한
직사각형([기록](fdtd-rotation-gradients.md)), 원([기록](fdtd-circle-gradients.md)), 타원
([기록](fdtd-ellipse-gradients.md))을 받아들이게 되었지만, 기본 분리형 경로는 여전히 이들을
거부합니다.

모든 주기 면은 직사각형 셀 안으로 접혀 들어온 뒤 정렬됩니다. 그 결과 재료 분할은 항목 수가
고정되며, 경계는 움직이지만 Yee 메시는 움직이지 않습니다. 형상별 면 사건(event)이 구간 소속을
정합니다. 형상을 입력 순서대로 적용하므로, 겹치는 재료 대비를 더하는 것이 아니라 칠하기가
구현됩니다. 물리 레시피와 Yee 셀 적분 사이에 고정 해상도의 보조 이미지는 끼워 넣지 않습니다.

폭이 0인 분할 구간은 미분에 중요합니다. 서로 떨어진 두 형상이, 또는 다른 층에 있는 형상들이 물리적
접촉 없이 투영된 x 또는 y 경계를 공유할 수 있습니다. 이런 폭 0 구간을 중점으로 분류하면 임의의
재료를 고르게 되어 미분을 잃습니다. 순서가 정해진 면 사건은 그런 구간을 지나며 일관된 해석적 확장을
유지합니다. 겹침 가중치는 0 가지의 미분을 보존합니다. `max(weight,0)`을 쓰면 JAX/Torch에서 0에서
미분이 갈라집니다. 엄밀하게 음수인 반올림 오차만 잘라 냅니다.
독립적인 셀 유한 차분과 정확한 면적 미분이 이 경우를 검사합니다.

정적인 전체 높이 직사각형은 래스터 격자와 같은 한 행짜리 y 불변 지름길을 씁니다. 살아 있는 높이는
현재 값이 주기와 같더라도 y 표본을 모두 유지합니다. 형상 개수/종류, 칠하는 순서, 주기, 파장, 소스,
PML과 시간 간격은 정적입니다. 살아 있는 내부 z 두께는 기존의 전체 두께 고정 `mesh_thickness` 계약을
써서 함께 쓸 수 있습니다. 여기서는 주기, 격자, 전체 깊이 미분을 도입하지 않습니다.

## 셀 적분과 정규화

고정된 셀 [L,R]에서 면 b의 오른쪽에 있는 비율을 F(b)라 합시다.
날카로운 계면에서는 F(b)=clip((R-b)/(R-L),0,1)입니다. 재료 구간 [a,b]는 F(a)-F(b)만큼 기여하며,
주기 이미지 세 개가 표본화되는 모든 셀을 덮습니다.
접선 계수는 산술 평균을, 법선 계수는 조화 평균을 쓰며, 순서는 기존 래스터 구현과 같습니다.
모서리에서는 여전히 분리 가능한 대각 근사입니다.

평균 폭 h>0에 대해, 칠한 층 전체를 [-h/2,h/2]에 균일하게 분포한 공통 평행 이동으로 평균합니다.
그러면 셀 비율은 다음과 같습니다.

```text
G_h(x) = 0                       x <= -h/2
         (x+h/2)^2 / (2h)        -h/2 < x < h/2
         x                       x >= h/2

F_h(b) = [G_h(R-b) - G_h(L-b)] / (R-L).
```

가로 방향 축마다 독립적인 공통 평행 이동을 씁니다. 공개 `shape_smoothing` 스칼라 또는 `(x,y)` 쌍이
전체 물리 폭을 지정합니다.
기본값은 0이고, 각 폭은 [0,period] 안에 있어야 합니다. 물리 단위의 폭은 표본화된 재료 프로필을
바꿉니다. 의도한 날카로운 기하를 확인할 때는 메시를 세분화하면서 폭도 줄이세요. 이것은 모든 편광에
대해 일반적으로 등방적인 점진 재료를 약속하지 않습니다.

기하 오라클(oracle)은 평행 이동 적분을 셀/면 교차점마다 나누어, 평행 이동한 날카로운 구간을
독립적으로 적분합니다. 중점 규칙은 그렇게 나뉜 각 선형 조각을 정확히 적분합니다. 세 백엔드 모두
서로 다르거나 반복되는 경계, 주기 이음매, 면적 0 구간, 한 주기 전체에 해당하는 평균 폭에서
일치합니다. 면적, 재료 칠하기, 주기 평행 이동은 서로 별개의 불변량을 줍니다. 정렬된 자성 레시피도
양쪽에서의 완전한 conical Jones 풀이를 통해, 정확히 동등한 래스터와 일치합니다.

셀 경계를 지날 때 날카로운 미분에는 지속되는 도약이 있습니다. 폭 0.1인 셀과 h=0.08에서 오프셋
±delta에서의 미분 차이는 정확히 2 delta/(0.08*0.1)이며, 두 AD 백엔드 모두 이 연속 극한을
재현합니다.
반대로 나중 형상이 앞선 형상을 덮기 시작할 때는, 실제로 칠해진 면적의 한쪽 미분이 서로 다를 수
있습니다. 테스트에 명시한 접촉은 기울기가 0과 -0.75입니다. 평행 이동 평균으로 이런 물리적 위상
변화를 없앨 수는 없습니다. 임의의 접촉에서 유일한 미분, 크기 범위, 일반적인 고차 기하 미분은
주장하지 않습니다.

## 푸리에 기준과 격자 세분화

측정한 막대는 폭 0.43, 두께 0.2, epsilon 2.25, mu=1이며, 층 배경은 1입니다. 위쪽 epsilon은 1,
기판 epsilon은 1.21, 주기는 [1.3,0.05], 파장은 1입니다. 중심은 셀 중심에서 0.071, 0.083, 0.095입니다.
차수 -1,0,+1만 복사합니다. 전체 전력만이 아니라 TE와 TM의 복소 r/t를 모두 검사합니다.

RCWA는 해석적 직사각형 변환과 차수 ±32를 쓰며, ±48로 자체 수렴을 확인합니다. 복소 진폭의 최대
변화는 1.07e-5이고 폭 미분의 최대 변화는 0.000321118입니다. 두 폭 섭동 크기 1e-5와 5e-6의 결과는
최대 8.63e-9만큼 다릅니다. 위치 미분에는 더 강한 독립 기준이 있습니다. 구조를 c만큼 평행 이동하면
회절 차수 m에 exp(-2 pi i m c/P)가 곱해지므로, 그 미분은 진폭에 (-2 pi i m/P)를 곱한 값입니다.
RCWA 자체의 유한 차분도 이 위상 법칙을 만족합니다.

FDTD는 고정 격자, 맞춘 z 층, 물리 단위 1의 PML, 펄스 폭 3, 실행 시간 65와 방향별 추출을 씁니다.
공통 백엔드는 float64/complex128을 씁니다. 표는 세 위치, 네 복소 진폭 채널, 세 차수 전체에 걸친
최대 절대 오차를 보여 줍니다. 크기 미분과 위치 미분은 물리 길이 단위당 값입니다.

| 격자 | 평균 폭 | 진폭 오차 | 폭 미분 오차 | 위치 미분 오차 |
| --- | --- | ---: | ---: | ---: |
| 20 | 0 | 0.00886885 | 0.0944707 | 0.171510 |
| 20 | 셀 1개 | 0.00892673 | 0.0179284 | 0.0361959 |
| 30 | 0 | 0.00375536 | 0.0455949 | 0.130404 |
| 30 | 셀 1개 | 0.00377353 | 0.0102142 | 0.0137596 |
| 40 | 0 | 0.00204149 | 0.0423246 | 0.110497 |
| 40 | 셀 1개 | 0.00205371 | 0.00582625 | 0.0128695 |

셀 하나 폭의 평행 이동 평균은 진폭 오차를 조금만 바꾸면서 이 미분 오차들을 크게 개선합니다. 이것은
양의 등방성 격자에 대한 유한한 측정 집합이며, 모서리, 맞닿는 형상, 임의의 재료, 최적화된 설계에
대한 일반적인 정확도 보장이 아닙니다. 별도의 JAX/Torch 테스트는 아래쪽, conical, 복소 Jones 조명
아래에서 형상/재료/z 두께 매개변수 일곱 개를 함께 변화시킵니다. 메시 좌표, 소스/PML 배치, 타이밍을
고정한 채 두 유한 차분 간격이 AD와 일치합니다.

## 독립적인 Meep 측정

생성기는 Meep 1.34.0의 문서화된 공개 API만 씁니다. 날카로운 기하는 2D Block을 쓰며, Ez는
Wavebit의 TE 전기장에 해당하고, x는 주기 경계, y 방향으로 PML을 둡니다. 기판은 계산 셀 경계에서
정확히 끝납니다. 길이 10인 셀, -3의 소스, -1과 1.4의 모니터 평면, Courant 0.4, 단위 1의 PML을
명시합니다. 구적법은 DFT 모니터가 돌려주는 좌표와 가중치를 씁니다. 이산 Yee 전파로 r은 z=0, t는
z=0.2를 기준으로 삼습니다. 출력에는 나가는 s 좌표계의 부호와, Meep의 셀 중심 푸리에 원점을
Wavebit의 꼭짓점 원점으로 바꾸는 변환이 포함됩니다.

최종 가우시안 창 소스는 폭 3, 최고점 시간 15, 종료 시간 30입니다.
실행 시간 100과 140, 중심 차분 간격 1e-4와 5e-5로 기준 오차를 대조합니다.
고정된 날카로운 기하 보관 파일에는 두 격자, 두 실행 시간, 두 간격이 모두 남아 있습니다.

| 날카로운 기준 검사 | 격자 40 | 격자 80 |
| --- | ---: | ---: |
| 실행 시간 변화, 복소 진폭 | 2.81e-6 | 2.67e-6 |
| 실행 시간 변화, 미분 | 1.24e-5 | 1.27e-5 |
| 섭동 크기 변화, 미분 | 2.71e-8 | 2.89e-8 |
| RCWA 대비 진폭 오차 | 0.00319276 | 0.000444645 |
| RCWA 대비 폭 미분 오차 | 0.0239755 | 0.0192671 |
| 평행 이동 법칙 대비 위치 미분 오차 | 0.0895620 | 0.0599772 |

격자 40에서 날카로운 Wavebit과 Meep은 복소 진폭에서 최대 0.00196359, 두 변수 야코비안에서
0.0883470만큼 다릅니다. 각 국소 미분은 반복해도 같게 나오지만, 후자는 상당한 유한 격자
불일치입니다.
산란 진폭이 일치한다고 해서 정확한 형상 그래디언트가 확립되지는 않습니다.
독립적인 푸리에 기준은 두 FDTD 방법 모두의 오차를 드러냅니다.

폭 1.2인 조명과 실행 시간 40/60을 쓴 이전 기준 탐색은 진폭을 0.00113, 미분을 0.00539만큼
바꾸었으므로 확정된 오라클로 쓰지 않았습니다. 격자 80에서 간격 1e-3/5e-4는 셀 경계를 넘어가
날카로운 미분을 0.17866만큼 바꾸었습니다. 더 작은 최종 간격은 국소 미분을 잴 뿐, 그 연속체 오차를
없애지는 않습니다. 이런 대조는 설계 그래디언트가 물리적으로 정확한지 판단하는 일과는 별개입니다.

격자 40의 평균한 TE 사례에서는 전역 주기 재료 함수가 폭 0.025의 같은 선형 가로 방향 epsilon
프로필을 구현합니다.
그다음 Meep의 문서화된 `do_averaging` 옵션이 셀 적분을 수행합니다.
비교 결과 진폭 차이는 0.00116054, 미분 차이는 0.00153202입니다. Meep의 평균 허용 오차를 1e-8에서
1e-9로 조이면 진폭은 1.24e-11, 미분은 4.34e-7만큼 바뀝니다. 실행 시간 변화는 최대 2.81e-6과
1.36e-5이고, 섭동 크기를 바꾸면 미분이 최대 6.94e-6만큼 바뀝니다. 두 평균 허용 오차의 결과는 별도의
보관 파일에 모두 남아 있습니다.
이 비교는 필드가 두 계면 모두에 접선 방향인 TE로 한정됩니다. 법선 방향 TM 계수에 대해 등방성
프로필과 동등하다고 주장하지 않습니다.

[Meep 스무딩 이론](https://meep.readthedocs.io/en/latest/Subpixel_Smoothing/)은 접선/법선 평균의
구분과 모서리에서의 한계를 설명합니다.
[공개 API](https://meep.readthedocs.io/en/latest/Python_User_Interface/)는 Block, 재료 함수, DFT
구적법을 문서화합니다. Meep 구현이나, 앞서 배제한 Meep 유래 FDTDX 투영 파일은 열거나 복사하지
않았습니다.

## 재현

arm64 CPU에서 Python 3.12.9, NumPy 2.5.1, JAX 0.11.0 x64, Torch 2.13.0 float64로 측정했습니다.
이 실험은 GPU 실행이나 임의 형상 호환성을 확립하지 않습니다. 저장소 루트에서 실행하세요.

```shell
python -m studies.cross_solver.rectangle_gradients.fdtd_rectangle_gradients --output artifacts/rectangle-gradients.json
pytest -q tests/fdtd/test_fdtd_rectangles.py tests/references/test_meep_rectangle.py
```
