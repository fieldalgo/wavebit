# 독립적인 가로 메시와 축별로 일관된 재료 평균

작성: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `src/wavebit/fdtd/_periodic/api.py`
- `tests/fdtd/test_fdtd_transverse_resolution.py`
- `studies/fdtd/transverse_resolution/fdtd_transverse_resolution.py`
- `studies/fdtd/lattice_reference/fdtd_lattice_reference.py`
- `studies/fdtd/rayleigh/fdtd_rayleigh.py`

요약: `transverse_resolution`은 x/y 샘플링을 z 메시와 독립적으로 만듭니다.
측정한 차단(cutoff) 근처 격자에서는 z만 세분화하는 것보다 x를 세분화하는 편이 훨씬 유용합니다.
선택한 x 세분 메시는 같은 지속 시간에서 셀 수는 약 절반, 셀 갱신 횟수는 36%만으로 등방적으로
촘촘한 격자의 정확도에 가까워집니다. 이것은 작업량 비교이지, 실제 소요 시간 단축을 주장하는 것이
아닙니다. 별도의 수정으로 가로 방향 재료 평균이 기본 메시를 포함해 x/y 교환을 존중하게 됩니다.

## 계약과 실제로 고정되는 것

[가이드](../../guide/fdtd/time-domain.md#independent-transverse-resolution)는 양의 정적 스칼라 또는
(x,y) 쌍, 반올림, y 불변 규약을 정의합니다.
`resolution`은 계속 z를 제어합니다. 가로 방향 목표값을 다르게 지정해도 z 노드, 층 계면, 소스 평면과
회절 평면, PML 면은 고정됩니다.
시간 간격은 실제 셀 폭 전체로부터 다시 계산되므로, 갱신 횟수와 이산 주파수 응답은 일반적으로
달라집니다.

기본 목표값은 두 방향 모두 여전히 스칼라 `resolution`입니다.
이전 목표값을 명시적으로 선택하면 위와 아래에서 입사할 때 모두 기본 평면 결과와 동일한 결과가
나옵니다. 직사각, conical, 비균일(graded), 층 정렬 장면은 각자의 좌표 규약을 유지합니다. 기존
Nyquist 검사는 요청한 가로 메시에 맞지 않는 회절 창을 거부합니다. 메시 크기는 정적으로 유지되며,
이 기능이 기하나 격자 좌표에 대한 미분을 도입하지는 않습니다.

## 이전부터 있던 가로 평균 비대칭

x/y 교환 테스트는 별개의 래스터화 결함을 드러냈습니다. 이전 구현은 항상 x를 처리한 뒤 y를
처리했습니다. Ex에서는 x 방향 조화 평균 뒤에 y 방향 산술 평균이, Ey에서는 x 방향 산술 평균 뒤에 y
방향 조화 평균이 적용되었다는 뜻입니다. 교차한 재료 모서리와 겹치는 셀에서는 이 연산들이 교환되지
않습니다. 따라서 축을 바꾸어도 같은 이산화 재료가 회전되지 않았습니다.

이제 가로 평균은 필드 성분을 따릅니다. epsilon과 mu 모두에 대해 법선 방향 조화 평균을 먼저, 그다음
접선 방향 산술 평균을 적용합니다. Ez/Hz는 두 가로 방향 모두에서 산술 평균을 유지하고, z 방향 평균은
바뀌지 않았습니다. 극점 채움 비율은 산술 평균으로 남습니다. 이 수정은 `transverse_resolution`을
생략하더라도 교차 모서리 셀의 Ey/Hy 계수를 바꿉니다. 이것은 공통 장면 래스터화기의 수정이며, 레거시
솔버나 Maxwell/ADE/CPML 갱신은 바뀌지 않았습니다.

법선 방향 조화 평균과 접선 방향 산술 평균의 구분은
[Meep의 공개 서브픽셀 스무딩 문서](https://meep.readthedocs.io/en/latest/Subpixel_Smoothing/)에
설명되어 있습니다. 그 문서의 완전한 유효 텐서 구성은 계면 법선도 고려합니다.
현재의 대각, 분리형 래스터 규칙은 그 구성을 구현하지 않으며, 일반적인 모서리나 분산 계면의 정확도를
입증하지 않습니다.
Meep 구현은 열어 보거나 복사하지 않았습니다.

수치 반례는 2×3 비대칭 epsilon 래스터와 독립적으로 변하는 mu 래스터, 주기 (0.4,0.3), z 해상도 10,
가로 목표값 (12,13), theta 0.25, phi 0.31, 아래쪽 입사를 사용합니다. x/y, 주기와 목표값을 서로 바꾸고
phi를 pi/2-phi로 바꾸면 Jones 대각 성분은 보존되고 비대각 성분은 부호가 뒤집혀야 합니다. 수정 전에는
s에서 s로의 반사 하나만 해도 3.2441e-4만큼 달랐습니다. 수정 후에는 그 변환 아래에서 모든 복소 r/t
열이 1e-11까지 일치합니다. 테스트는 점 샘플링과 서브픽셀 평균을 기본 가로 목표값과 독립 가로
목표값에서 모두 다룹니다.
별도의 계수 검사는 2×2 래스터 `[[1,4],[9,16]]`의 동일한 겹침을 사용합니다. 두 법선 방향 조화 평균은
1.8과 6.4이고, 그 접선 방향 산술 평균은 4.1입니다. 엇갈린(staggered) Ey와 Hy 재료 계수 모두 그 값을
재현합니다. 연산 순서를 뒤집으면 4.16667이 나오므로, 단지 대칭적으로 보이는 산란 예제와 달리 수정된
규칙을 구별해 냅니다.

## 독립 수치 검사

잘못된 형식의 제어값과 불충분한 샘플링은 시간 진행 전에 거부합니다.
직사각 격자 테스트는 실제 셀 개수, 폭, CFL을 선언한 주기와 대조하고, z 위치는 바뀌지 않음을
확인합니다. x/y/z 해상도가 서로 다른 자성 conical 슬래브는 세분화할수록 독립적인 Airy 진폭에
가까워집니다. 세분화는 같은 축 해상도 비율을 유지하며, 파장 대역 전체에서 두 편광 열을 모두
유지합니다.

비대칭 교차 장면 하나는 새 메시, 아래쪽 조명, 방향별 추출, 소스 스펙트럼 영점, 독립적으로 배치한
소스, 잘라 낸 시간 기록을 결합합니다. 그 재료, 투자율, 극점 세기 미분은 JAX와 Torch CPU에서 중심
유한 차분과 일치하고, 값은 NumPy와 일치합니다. 이 검사들은 새 메시를 거치는 기존 재료 그래프를
검증할 뿐, 해상도나 기하에 대한 미분을 검증하는 것이 아닙니다.
비대칭 자성 교차 래스터는 **두** 가로 축 모두에서 반폭 3/5를 사용해 RCWA와도 비교합니다. 기준 열들은
0.001 미만으로 차이 납니다. x 해상도를 z의 1.5배로 두고 z를 20에서 40으로 세분화하면 전체 Jones
진폭 오차가 40% 넘게 줄어 0.008 아래가 됩니다.
이것은 정확한 축 교환 테스트에 패턴이 있는 기하의 물리 검사를 더합니다.

## 차단 근처 사례에서 어느 축이 한계일까?

[조화 격자 연구](fdtd-lattice-reference.md)는 유한 펄스나 CPML 오차가 없는 독립적인 출사 경계 기준을
제공합니다. 그 연구의 이진 격자(epsilon 2.25/1, 주기 0.8, 두께 0.2), 파장 0.95808/0.96192, 고정된
가로 파동벡터를 그대로 사용합니다. 오차는 차수 -1/0에 걸친 RCWA 차수 32와의 최대 절대 복소 r/t
차이이며, TE와 TM에 대해 따로 구합니다. 아래의 모든 조화 풀이는 CPU에서 NumPy/SciPy 배정밀도를
사용합니다.

| z / x / y 해상도 | 자동 dt | TE 격자 오차 | TM 격자 오차 |
| --- | ---: | ---: | ---: |
| 40 / 40 / 40 | 0.0115470 | 0.0278171 | 0.0507211 |
| 40 / 80 / 40 | 0.00816497 | 0.00563022 | 0.00950680 |
| 40 / 160 / 40 | 0.00471405 | 0.00312578 | 0.00333279 |
| 40 / 320 / 40 | 0.00246183 | 0.00302786 | 0.00335224 |
| 80 / 40 / 40 | 0.00816497 | 0.0311428 | 0.0580543 |
| 160 / 40 / 40 | 0.00471405 | 0.0336961 | 0.0635874 |
| 80 / 80 / 40 | 0.00666667 | 0.00603292 | 0.0105481 |
| 80 / 80 / 80 | 0.00577350 | 0.00658717 | 0.0115905 |

x만 세분화하는 것은 유용하지만, 그에 따라 바뀌는 dt도 이 비교의 일부입니다.
반대로 z만 세분화하면 답이 나빠지는 것처럼 보이는데, 부분적으로는 더 작은 시간 간격이 공간 이산화와의
상쇄 일부를 없애기 때문입니다.
두 번째 조화 전용 대조는 모든 격자에 대해 dt=0.0024로 고정합니다. 이 값은 모든 자동 시간 간격보다
작습니다.

| z / x / y 해상도 | TE 오차, 고정 dt | TM 오차, 고정 dt |
| --- | ---: | ---: |
| 40 / 40 / 40 | 0.0353937 | 0.0666274 |
| 40 / 80 / 40 | 0.00862966 | 0.0150868 |
| 40 / 160 / 40 | 0.00334229 | 0.00463279 |
| 40 / 320 / 40 | 0.00302893 | 0.00335298 |
| 80 / 40 / 40 | 0.0348318 | 0.0659356 |
| 160 / 40 / 40 | 0.0347075 | 0.0657677 |
| 80 / 80 / 40 | 0.00796988 | 0.0141573 |
| 80 / 80 / 80 | 0.00796988 | 0.0141573 |

고정 시간 간격 대조는 여기서 x 해상도가 더 큰 한계임을 확인해 줍니다. x 해상도 320에서는 바뀌지 않은
z 메시가 추가 개선을 제한합니다.
마지막 두 행은 조화 오차가 동일합니다. y가 불변이므로, 그 간격은 자동 CFL 시간 간격에는 영향을
주지만 dt를 고정했을 때 이 고정 주파수 스칼라 연산자에는 영향을 주지 않습니다. 0이 아닌 y 미분을
가진 conical 또는 교차 필드에는 이것이 적용되지 않습니다.

## 일반 속도 벤치마크가 아닌, 셀과 갱신 횟수

소스 z=-1, 패딩 1, PML 폭 1.2, 명목 목표값 1e-160인 실제 시간 격자에서 800주기 작업량은 다음과
같습니다.

| 격자 | 모양 (z,y,x) | 실행당 갱신 횟수 | 네 번 실행의 셀 갱신 |
| --- | --- | ---: | ---: |
| 등방 40 | 264, 2, 32 | 66511 | 4.49508e9 |
| x 80, z/y 40 | 264, 2, 64 | 94061 | 1.27140e10 |
| 등방 80 | 520, 2, 64 | 133022 | 3.54158e10 |

선택적 메시는 촘촘한 등방 메시 셀의 50.8%, 셀 갱신 횟수의 35.9%를 가집니다. 같은 보존 설정에서 필드
저장량은 셀 개수에 비례하며, 전체 메모리 사용량에는 스펙트럼, 체크포인트, 소스 샘플, 기록도
포함됩니다. 이 횟수들은 최대 메모리를 측정하거나 비례적인 실행 시간 개선을 증명하지 않습니다. x만
세분화한 조화 답은 자동 dt에서는 약간 더 좋고 맞춘 dt에서는 약간 더 나쁩니다. 이것도 비용 대비
정확도에서 보편적인 승자를 선언하지 말아야 할 또 하나의 이유입니다.

## 실제 유한 시간 비교

선택한 x-80/z-y-40 메시도 같은 소스와 PML 기하, 가우시안 폭 60, 이산 차단 1.04150007042에 둔 두 소스
영점으로 1600주기 동안 진행했습니다. 실행당 갱신 횟수는 188121입니다. 유한 CPML 조화 기준은 측정한
두 파장에서 정확한 외부 조건을 쓴 대응 기준과 TE 1.62672e-9, TM 1.68460e-9만큼만 차이 납니다.

| 시간 실행 | 유한 CPML 극한 대비 오차, TE / TM | RCWA 대비 오차, TE / TM | 네 번 실행의 셀 갱신 |
| --- | --- | --- | ---: |
| x 80, z/y 40, 1600주기 | 2.65211e-5 / 8.86595e-6 | 0.00561200 / 0.00950666 | 2.54279e10 |
| 등방 80, 800주기, 이전에 측정한 대조 | 8.00971e-4 / 2.68474e-4 | 0.00720676 / 0.0117110 | 3.54158e10 |

두 번째 행은
[이전 조화 연구](fdtd-lattice-reference.md#actual-time-evolution-with-the-improved-boundary)의 소스/PML이
일치하는 대조입니다.
선택한 메시는 그 행 셀 갱신 횟수의 71.8%로 두 배의 물리 지속 시간을 허용합니다. 이 특정 비교에서는
실제 오차도 더 작습니다.
고정 dt 표가 보여 주듯이, 이것이 두 메시 사이의 공간 정확도에 보편적인 순서가 있다거나 실제 소요
시간이 측정상 단축되었음을 보여 주는 것은 아닙니다.

긴 실행의 94060번 갱신 접두부는 800주기 직전에 끝납니다. 그 시간 오차는 7.21807e-4/2.44177e-4이고,
마지막 94061번 갱신 동안의 최종값 빼기 접두부 진폭 변화는 7.48229e-4/2.53009e-4입니다. 그 긴 구간
동안 산란 수렴과 상태 감쇠 판정은 둘 다 거짓으로 남습니다. 최종적으로 독립 측정한 시간 오차는 작지만,
그렇다고 소급해서 비교 창 전체가 조용했던 것이 되지는 않습니다. 투과 쪽으로 되돌아오는 차수 -1
진폭은 1.94373e-5/9.81683e-6입니다. 여기의 어떤 결과도 임의의 차단, 금속 모서리, GPU 실행, 메시
설정에 대한 미분을 검증하지 않습니다.

## 재현

```shell
python -m studies.fdtd.transverse_resolution.fdtd_transverse_resolution
python -m studies.fdtd.transverse_resolution.fdtd_transverse_resolution --fixed-dt 0.0024
python -m studies.fdtd.transverse_resolution.fdtd_transverse_resolution --case x80 --cpml
python -m studies.fdtd.transverse_resolution.fdtd_transverse_resolution --case x80 --time --periods 1600
```

처음 두 명령은 여덟 개의 출사 경계 조화 메시를 모두 비교합니다.
`--cpml`은 선택한 사례에 대해 유한 CPML도 추가로 풉니다. `--time`은 실제 펄스를 실행하고, 기본적으로
배정밀도 JAX CPU를 사용하며, 명시적인 사례 하나를 요구합니다. `--backend numpy`는 NumPy를 선택합니다.
가우시안 폭 60과, 그 메시의 이산 진공 차단에 다시 맞춘 영점 두 개를 사용합니다. 긴 실행은 후반부 전체를
비교하고, 800주기 실행은 마지막 100주기를 비교합니다.
JSON에는 최종/접두부 진폭 전체, 수렴 플래그, 경계 오차와 시간 오차, 격자/갱신 횟수, 컴파일을 포함한
경과 시간이 남습니다.
`--fixed-dt` 옵션은 조화 전용 실험이며, 새로운 공개 장면 제어가 아닙니다.
