# PlaneWave 수용 기준: 정확도와 측정 유효성

짧은 stage-2 `plane_wave`와 stage-3 `bloch_stack` / `conical` 골든은 기록된
계산의 변화를 잡습니다. 300/500 step 실행은 의도적으로 안정화 전에 끝납니다.
기존 픽스처와 회귀 오차 한계를 유지하되, 골든 일치만으로 물리 정확도를 인정하지 않습니다.

비스듬한 p column은 중심 주파수에서 정규화한 두 노드 차분 전류를 사용합니다.
`tests/fdtd/test_fd_planewave.py`의 독립 이산 전달식은 주어진 입력 파형과 실제 장을
대조합니다. 실수 주파수 2e-6, 감쇠 주파수 3e-6, 역방향 누설·교차 편광 1e-13,
DC 1e-6 한계를 유지합니다. 측정 입사장으로 산란장을 정규화하면 광원 이득 오류가
상쇄될 수 있으므로 이 검사는 산란 정확도 검사와 함께 필요합니다.

## 고정 오차와 별도 불확실성 한도

`tests/fdtd/test_fd_diffraction.py`는 평면 구조의 진폭·크기·위상·파워·닫힘·감쇠와
20/40/80셀 수렴 기준을 유지합니다. `tests/fdtd/test_fd_axis1d.py`는 원뿔 입사 격자의
진폭·차수별 파워·닫힘·기준해 수렴과 20/40셀 개선 기준을 유지합니다. 특히 p 평면 구조
위상은 1차 기준이며, 이번 실행은 이 기존 시험을 2차 수렴 요구로 바꾸지 않습니다.

추가 수동 실행은 모든 p 해상도의 측정 유효성을 아래 관측량별 고정 한도(`tau`로 표기)로
검사합니다.

| 관측량 | 평면 구조 | 원뿔 입사 |
|---|---:|---:|
| 복소 진폭 | 20/40셀 .015, 80셀 .005 | .0355 |
| 차수별 파워 | .0012 | .01 |
| 전체 R + T | .0001 | .001 |
| 동일 편광 상대 크기 | .02 | — |
| 동일 편광 위상 (라디안) | .06 | — |
| 교차 편광 진폭 | 1e-12 | 복소 진폭에 포함 |

평면 20셀의 한도는 불확실성 검사에만 쓰고, 정확도는 기존 수렴 시험으로
판정합니다. 원뿔 입사 40셀은 기존의 측정 개선 배수 1.8도 충족해야 합니다.
수동 실행은 보조 검사이며 기존 시험을 대체하지 않습니다.

1. T의 1, 1.25, 1.5, 1.75, 2배에서 독립 기록을 실행합니다. T는 평면 픽스처에서 20주기,
   원뿔 입사 픽스처에서 160주기입니다. 10개 쌍 차이의 최대값이 관측량마다 0.1 tau 이하여야 합니다.
2. 2T에서 PML을 12→24셀로 늘리는 실행과, 구조에서 PML 안쪽 면까지의 하단 .8·
   상단 1.4 길이 단위 간격을 두 배로 늘리는 실행을 따로 합니다. 구조 계면·광원·모니터·
   횡방향 파수·기준면은 고정합니다. 세 구성의 모든 쌍 차이도 0.1 tau 이하여야 합니다.
3. 균일 구조 RCWA 기준해는 절단 차수 0/1, 원뿔 입사 기준해는 15/30에서 확인하며
   채널별 차이는 .05 tau 이하여야 합니다. 각도는 FDTD 측정 결과가 아니라 입력한 고정
   횡방향 파수로 계산합니다.
4. 관측량·내부 에너지가 유한하고 실행이 stable이어야 합니다. 기록 종료 이전의 알려진
   광원 종료 시점과 완전한 내부 에너지 기록이 있어야 하며 성장 경고가 없어야 합니다.
   유한한 내부 성장률이 있으면 진단을 인정합니다. 성장률이 없어도 광원 종료 후 전체
   구간이 장면에 선언한 가장 긴 주기의 4배 이상이고 후반의 네 1/8 구간에 모두 표본이 있으며 원래 신호가
   0이 아니고 마지막 1/4 구간 에너지 최대값이 전체 최대값의 1e-7 이하면 인정합니다.
   이는 엔진이 문서화한 감쇠 하한 조건입니다. 기록 누락·짧은 기록·비유한값은
   여전히 수용을 차단합니다. 순간 에너지가 단조 감소할 필요는 없습니다.

10%와 5%는 명시적으로 선택한 공학적 허용 배분이며 점근적 안정성의 증명이 아닙니다.
관측한 격자·시간 차이로 정확도 한도를 늘리지 않습니다. 복소 비교로 위상을 보며,
양 끝값이 같아도 중간 시점의 변동을 놓치지 않습니다.

접촉 전도막 픽스처는 n80, 격자 위상 .375, PML 24셀, Courant .2, df .1,
cutoff 1e-6에서 60/90/120주기를 추가 실행합니다. 모든 쌍의 복소 r/t 차이 최대값은 2e-7
이하여야 합니다. 이는 잔류 시간 의존성을 검사하며, 이 픽스처의 과거 공간 수렴 차수
시험 실패를 뒤집지 않습니다.

과거 광원의 골든은 과거 동작 기록입니다. 의도한 광원 변경에서 해당 장면의
불일치는 변경 범위를 보여주며 독립적인 물리 오류 판정은 아닙니다. 재고정
전에는 독립 광원·정확도·유효성 검사, backend 간 일치, 미분, 비대상 장면의
pin을 확인합니다. 근거를 확보해 재고정한 뒤에는 새 대상 장면 pin과 의도적
오류 변이 검사도 통과해야 합니다. 이 순서는 새 광원이 옛 광원의 과도장을 그대로
재현해야 한다는 요구를 피합니다.

## 안정화 측정 protocol

아래의 기존 광대역 펄스 campaign은 과거 근거로 보존합니다. `--protocol stabilized`는
별도 검증 픽스처를 선택합니다. 기준 T는 평면 80주기·원뿔 입사 320주기이고, PML 48셀과
`stabilize=3e-3`, 두께 대조 96셀을 씁니다. 다섯 시간 배수·별도의 더 먼 경계,
광원 대역폭·기준해 계산·모든 정확도/불확실성 한도는 동일합니다. 셀을 늘릴
때는 도메인을 바깥으로 확장하여 PML 안쪽 면과 물리 관측 좌표를 유지합니다.
명시한 protocol은 실험 변경을 원래 실패 결과의 재해석과 구분합니다. 어느
protocol도 무한 시간 안정성을 주장하지 않습니다.

holding-column 진단 회귀는 시험 범위 안에서 과거 hard 광원을 명시적으로
주입합니다. 이렇게 하면 제품 p 광원이 바뀐 뒤에도 갇힌 모드·성장 한도·진단 변이가
계속 검사됩니다. 별도 시험은 제품 current 광원을 쓰고 확인된 광원 종료 후 quiet
window를 요구합니다. grazing `adds-p` 대조는 320/640주기를 쓰며, 반사는 0.001369600과
0.001369955로 독립 층 모델 0.001370과 비교합니다. 기존 160주기 current 구동 측정은
0.001349794였습니다. 긴 두 실행은 기존 상대 1e-3 pin 허용 오차 안에서 일치해야 하고,
모델 비교와 통과/거부 기준은 그대로입니다.

## 요청 주파수 중심의 측정 protocol

`--protocol spectral`은 안정화 조건의 안쪽 좌표·실행 길이를 유지하되 검증
펄스에 `df=.05, cutoff=1e-6`를 쓰고 PML 물리 두께 2.4를 유지합니다. 즉 파장당
20/40/80셀에서 48/96/192셀이며, 두께 대조는 각각 두 배입니다. 모든 해상도에서
48셀을 유지하면 해상도마다 물리 두께가 절반으로 줄어, 40셀 평면 경계 차이가
고정 불확실성 한도의 1.532배로 남았습니다. 이 실패한 실험은 보존하며, 물리 두께 대조는
한도를 완화하지 않습니다. 요청 파장·물성 계면·횡방향 파수·관측면·모든
기준값과 허용 오차는 그대로입니다. 작은 시작 절단은 Gaussian을 갑자기 켤 때의 스펙트럼
누설을 줄이고, 좁은 펄스는 요청 주파수 밖에서 원뿔 입사 격자의 장수명 모드가
여기되는 것을 줄입니다. 이것은 요청 주파수의 선형 산란 측정을 검증합니다. 원래
광대역 펄스를 증명하거나 문서화된 PML 한계를 없애지는 않습니다.
광대역 펄스 광원 전달식과 기존 정확도 검사는 별도로 유지합니다.

각 해상도에서 2T, `df=.07, cutoff=1e-6` 대조도 실행합니다. 그 관측값은 기준 2T와
0.1 tau 이내로 일치해야 하며, 진단이 유효하고 같은 절대 정확도 한도를 만족해야 합니다.
모든 요청 입사 진폭은 유한하고 최소 크기가 최대의 5% 이상이어야 합니다.
입사 신호가 약하면 정규화 오차 한도를 느슨하게 하는 대신 수용을 차단합니다.
따라서 전체 protocol은 변경 없는 접촉막 잔류 실행 3회를 포함해 독립 실행 43회입니다.
원뿔 입사 fine 격자의 최대 복소 오차는 coarse 격자보다 기존 배수 1.8 이상 개선되어야 합니다.

`--backend jax`는 CPU에서 실행하며 기본값은 NumPy입니다. 안정화 원뿔 입사 40셀,
320주기 대조에서 NumPy와 JAX CPU는 모든 관측 채널에서 8.9e-16 이내로 일치했습니다
(사전에 정한 절대 비교 한도 5e-10). 각 campaign은 실제 backend와 입력 해시를 기록합니다.
이것은 GPU 검증이 아닙니다.

## 판정과 재현

실행 누락, 비유한값, 진단 누락, 과도한 불확실성은 `BLOCKED`입니다. 유효한 측정이 정확도
한도를 벗어나면 `FAIL`이며, 고정 한도 안의 유효한 측정만 `PASS`입니다. 집계에서는 확인된 실패가
차단된 증거보다 우선합니다.

설정한 소스 checkout에서 요청 주파수 중심 campaign을 실행합니다. 기본
protocol은 과거 재현을 위해 여전히 `original`입니다.

```sh
PYTHONPATH=src:. python -m tests.fdtd.check_planewave_acceptance --protocol spectral --backend jax --workers 2 --output artifacts/planewave-spectral
PYTHONPATH=src:. python -m tests.fdtd.check_planewave_acceptance --output artifacts/planewave-acceptance
PYTHONPATH=src:. python -m tests.fdtd.check_planewave_acceptance --protocol stabilized --workers 5 --output artifacts/planewave-stabilized
python -m pytest tests/fdtd/test_fd_acceptance.py
```

출력 디렉터리는 새 디렉터리여야 합니다. 여기에 입력 해시·버전·각 기록과 진단·채널 이름·
고정 배분 대비 비율을 남깁니다. 중단된 실행에는 최종 결과가 없으며 수용할 수 없습니다.
수동 `PASS`는 이 측정 campaign만 뜻합니다. 광원·기존 정확도/수렴·backend·미분·비대상
장면 회귀 시험은 별도로 충족해야 합니다.

모든 필수 검사를 통과한 뒤 검토한 변경 키 목록, 비대상 장면 불변, 기존 골든 허용 오차 내 재현을
확인해야 재고정할 수 있습니다. 새 알고리즘이 실패했다는 이유만으로 한도를 넓히지 않습니다.
과거 외부 solver 측정은 당시 입력·버전 범위에서만 유효하며 저장 기준값을 읽는 것은
새 외부 실행이 아닙니다.

이 결과는 잔류 검사에만 해당합니다.

초기 판정기는 성장률이 없으면 모두 증거 누락으로 처리했습니다. 기존 진단의
문서화된 동작을 확인해 이 오류를 찾았습니다. 충분히 표본화했고 에너지가 기존 하한

저장된 기록에 적용했습니다. 물리값·기준값·수치 비율·정확도 한도는 모두 같고,
초기의 접촉막 BLOCKED 판정도 보존했습니다.

광원 검사 120개, 기존 평면/원뿔 입사 정확도·수렴 9개, 공개 Torch CPU 광원 오라클
5개가 통과했습니다. stage2/3 backend·그래디언트·감쇠·grazing 시험은 452 passed/18 failed입니다.
실패는 예전 골든 불일치 14개와 이전 구동에 의존하는 픽스처/pin 4개(holding-column
시험 3개, grazing `adds-p` pin)입니다. 그래디언트 두 모듈 136개는 모두 통과했습니다.
NumPy stage 0–3 캡처의 573개 배열 중 변경 60개는 의도한 세 장면에만 있었고 나머지
513개는 바이트 동일하며 두 캡처 모두 스스로 재현됐습니다. 커밋된 골든은 변경하지
않았습니다. Linux CPU 근거는 GPU·다른 OS·전체 CI·독립 검토의 수용을 뜻하지 않습니다.

## 물리 두께 유지 protocol CPU 결과 (2026-10-22)

요청 주파수 중심 protocol의 필수 기록 43개가 모두 통과했습니다. 새 실행 27개와,
입력이 같은 완결된 20셀 사례 두 개에서 재사용한 기록 16개입니다. 재사용은 장면 표현,
solver·픽스처 해시, 버전, 기록·판정 함수의 동일성을 확인했고 모든 판정을

### 원래 광대역 PML 후속 검증 (2026-10-22)

원뿔 입사 p 대조 16개를 추가로 실행하며 `df=.15`, `n=40`, 기존 관측면을 유지했습니다.
경계 선택마다 160/320주기를 실행했습니다. 더 깊은 PML(96셀)은, `stabilizing_loss=.003`을

안쪽 경계를 이동한 대조는 고정 경계 민감도 한도를 통과했습니다. 그러나 시간 차이는 여전히
`0.1 tau`의 4.54–4.86배를 넘었습니다. 안정화 손실을 `.03`으로 키우면 96/192셀의 시간

손실 `.003`에서는 4e-13 미만이었습니다(기존 안정성 한도 1e-9).
이 작은 무광원 사례가 모든 구동 광대역 장면의 안정성이나 시간 수렴을 증명하지는
않습니다. 원래 광대역 사례는 여전히 미수용이며, 이 두 시간 대조는 위의 다섯 시간
수용 절차를 대체하지 않습니다. 이번 후속 검증에서 solver·골든·허용 오차는

## 광대역 장시간 기록과 중간 시점 검사 (2026-10-22)

원래 원뿔 입사 대역폭 `df=.15`를 파장당 40셀에서 유지했고, cutoff `1e-6`, PML 96셀
