# 고정 격자에서의 입사각 민감도

작성일: 2026-09-09

대상:
- `src/wavebit/fdtd/_periodic/scene.py`
- `src/wavebit/_common/conventions.py`
- `src/wavebit/fdtd/_periodic/api.py`
- `tests/fdtd/test_fdtd_scene_angles.py`

요약: 명시적 백엔드 장면 어댑터는 이제 격자와 방위각을 고정한 채 스칼라 `theta`를 미분합니다.
계산 그래프에는 소스, Bloch 경계, 출사파 분해, 입사 보정이 포함됩니다. 독립적인 균일 격자 분산 관계와
미분한 Airy 식으로 그 결과 민감도를 점검합니다. 실수 출사 s/p 좌표계도 이제 어느 가로축 위에서든 미분을
유지합니다. 이전에는 각도 비 표현이 그곳에서 미분을 버렸습니다.

## 고정하는 것

[사용 계약](../../guide/fdtd/time-domain.md#incidence-angle-derivatives)은 배열 값인 theta마다
명시적인 회절 창을 요구합니다. 미분 가능한 스칼라에서 차수 개수를 추론해서는 안 됩니다. 일반 스칼라 숫자는
자동 선택을 유지합니다. 이 theta 측정은 phi, 기하 구조, 반공간, 셀 개수, 소스/모니터 위치, PML,
시간 간격, 실행 길이를 고정합니다. 이후의 [방위각 확장](fdtd-scene-azimuth.md)은 phi도 미분하고,
[반공간 확장](fdtd-halfspace-gradients.md)은 명시적인 공칭 메시 인덱스로 외부 계수를 미분합니다.
기하 구조는 정적으로 남습니다. 배열로 주어진 기하 구조라고 해서 덩달아 미분 가능해지지는 않습니다.

가로 파수 벡터는 입사 매질의 굴절률과 요청한 대역의 중간 파장을 씁니다. 따라서 파장마다 물리적 각도가
다르고, theta가 바뀌면 모두 함께 바뀝니다. 이것은 [Meep 공개 FAQ](https://meep.readthedocs.io/en/latest/FAQ/)에
설명된 고정 파수 벡터 펄스 규약입니다. 이 변경을 위해서는 공개 설명 문서만 참고했으며, Meep 구현은 참고하거나
가져오지 않았습니다.

## 고정할 수 없는 항

| 항 | 각도 미분 중에 이 항을 고정했을 때의 결과 |
| --- | --- |
| 엇갈린 소스 위상과 가로 Bloch 감기 | 발사된 필드가 더 이상 요청한 가로 운동량을 따르지 않습니다. |
| 공간 푸리에 변환과 Yee 보간 | 바뀐 필드가 옛 회절 기저에 사영됩니다. |
| 이산 E/H 어드미턴스와 전파 위상 | 방향 분리나 위상 기준이 다른 각도에 반응합니다. |
| 입사 두 기저 보정 | 미분에 단위 입사 E 대신 변하는 소스 진폭이 들어갑니다. |
| 출사 s/p 좌표계와 전력 인자 | 카르테시안 성분이나 가중하지 않은 진폭을 물리적 산란 민감도로 오인합니다. |
| 시간 기록 반송파 보정 | 조명이 바뀌는 동안 기록된 필드가 고정된 정규화를 유지합니다. |

이 항들은 모두 재료에 의존하는 필드와 같은 Array API 경로를 씁니다. JAX나 Torch 전용 Maxwell 구현은
추가하지 않았습니다. 정적 래스터 겹침, 소스 타이밍, 메시 구성은 여전히 호스트 산술을 씁니다.
유효하지 않은 추상 각도는 장면 유효성 플래그에 누적됩니다. 그러면 산란, 정규화된 모니터, 시간 기록이
마스킹되며, 이는 바탕이 되는 시간 갱신 안정성 검사만으로는 통과했을 경우에도 마찬가지입니다.

## 축 통과

실수 가로 벡터에서 좌표계는 바로
`(cos(varphi), sin(varphi)) = (kx, ky) / sqrt(kx**2 + ky**2)`입니다.
`(kx, ky) = (0, 2)`에서 그 코사인을 kx로 미분한 값은 `1/2`입니다. 상수 직각 대체값을 쓰는 atan 비는
그곳에서 올바른 값을 돌려주지만 미분은 0입니다. 정규화는 JAX와 Torch 모두에서 시험의 `1e-15` 절대 허용
오차 안으로 `1/2`을 주며, 음의 y축과 x축 위의 해당 사인 미분도 마찬가지입니다.

원점에서는 호출자의 phi가 좌표계를 정합니다. theta 검사는 phi를 고정하고, phi 미분은 좌표계를
회전시킵니다. 구현은 쓰이지 않는 노름 0 제곱근을 보호하여, 그 정의되지 않은 미분이 유효한 그래디언트를
오염시키지 못하게 합니다. 이것은 고정된 입사 광선을 따른 미분이며, 원점에서의 임의의 2차원 섭동에 대한
정의가 아닙니다. 복소 각도 RCWA 좌표계 도우미는 바뀌지 않았습니다.

## 검증과 범위

검사는 macOS arm64 CPU에서 NumPy, JAX x64, Torch float64로 실행합니다. 균일 매질 오라클은 이산 분산
관계를 직접 미분합니다. `Omega = 2 sin(omega dt/2)/dt`, `Kx = 2 sin(kx dx/2)/dx`, 그리고 Ky도 같은
방식으로 두면 `kz = 2 asin(dz sqrt(Omega**2 - Kx**2 - Ky**2)/2)/dz`입니다. 이 기대값은 FDTD 추출이나
전파 도우미에서 얻지 않습니다.

| 검사 | 기준 |
| --- | --- |
| 균일 진공, 두 파장, conical 조명, 서로 다른 x/y 셀, 두 입사 쪽, 두 AD 백엔드 | 실수부/허수부 s/p 투과 미분이 독립적인 Yee 분산과 `2e-5` 이내로 일치하고, 파장-각도 미분이 고정 파수 벡터 식을 따릅니다. |
| 자성 슬래브, epsilon 2.25, mu 1.1, 두께 0.2, theta 0.3, phi 0.4, 파장 0.98/1.02 | z 해상도를 40에서 80으로 올리면 가중 복소 진폭 목적 함수와 그 각도 미분이 독립적으로 미분한 Airy 값에 다가갑니다. |
| 교차된 분산성 아래쪽 장면, 차등 메시, 독립적인 x/y 셀, 소스 영점, 유지한 3x3 차수 창 | theta/epsilon/mu/극점 결합 야코비안이 상대 `4e-5`, 절대 `2e-8`에서 중심 유한 차분과 일치하며, 정규화된 모니터, 잘라낸 기록, 접두 진단도 포함합니다. 두 추출 방법을 모두 점검합니다. |
| 교차된 장면에서의 수직 입사 | 0이 아닌 회절 축 미분이 2차 한쪽 각도 차분과 일치하고, 스칼라 평면 전력은 유한한 0 미분을 가집니다. |
| 유효하지 않은 범위, 정확한 물리/이산 차단, 전파하지 않는 광대역 입사 | 구체 호출은 요청을 거부하고, JIT 호출은 안정적인 산란을 보고할 수 없습니다. |
| 하나의 명시적 창 위의 두 각도 | 메시, 소스, 평면, 시간 간격, 단계 수, 차수 인덱스가 동일합니다. |

균일 매질 위상 미분의 가장 큰 오차는 각 입사 쪽과 각 AD 백엔드마다 `6.02e-9`였습니다. Airy 목적 함수는
`0.1558465179662445`였고, 그 미분은 라디안당 `-0.4148107334364167`이었습니다.

| z 해상도 | 목적 함수 절대 오차 | 각도 미분 절대 오차 |
| --- | ---: | ---: |
| 40 | 0.0078263190 | 0.0025780961 |
| 80 | 0.0019437343 | 0.0006402016 |

메시를 두 배로 세분하면 두 오차 모두 약 4분의 1로 줄어듭니다. 이 미분 비교는 같은 격자의 유한 차분 검사와
독립적입니다. 구현은 자신의 잘못된 순방향 모델을 정확히 미분할 수도 있기 때문입니다.

Airy 검사에서 가로 목표는 `(1.5R, 0.75R)`, x 주기는 0.05, PML 두께는 1 길이 단위, 가우시안 폭은 3,
지속 시간은 중심 주기 60개입니다. 층은 정렬되어 있고 E/H 추출은 방향별입니다. 목적 함수는 시험에 지정한
복소 가중치로 두 파장에서의 s/p 반사와 투과를 모두 결합합니다. 이로써 진폭 민감도뿐 아니라 위상 민감도도
점검합니다.

유한 차분 일치는 특정한 이산적, 유한 지속 시간 실험의 미분을 확립합니다. 연속체 수렴이나 무한 시간 수렴을
확립하지는 않습니다. Airy 세분화는 별도의 제한된 검사입니다. 레일리 근처 문턱, 오래 지속되는 모드, 날카로운
금속 모서리, 일반 분산 계면, float32 민감도, 실제 GPU 실행에는 각각의 근거가 필요합니다. 불리언 채널
분류는 바뀌는 통과 대역을 가로지르는 미분을 정의하지 않습니다.
