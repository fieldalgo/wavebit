# C8: 박막 하나 안의 유한한 Debye 합

작성: 2026-10-07

대상: `src/wavebit/fdtd/_prepare/debye_sum_film.py`,
`src/wavebit/fdtd/_prepare/debye_sum_resolution.py`, `src/wavebit/materials/_time_domain.py`,

`src/wavebit/fdtd/_prepare/checks.py`.

## 요약

**사전 등록한 극점 네 개 연구는 고정된 민감도 구간 기준에 따라 자기 차수 24개 전부와 직접 쌍 48개 전부를
2차로 분류합니다.**
작업자 20개가 모두 대체나 중단 없이 완료됩니다. 이 결과는 지정한 재료, 두 배치, 40/80/160 셀 사다리에 관한
것이며, 허용되는 모든 유한 합에 대한 수렴 보장이 아닙니다.

유한한 수동 Debye 합 실현은 기존의 고립된 평평한 박막 기하에 대해 구현되어 있습니다. 집중 사례 536개가 모두
통과하며, 실제 제품 코드 변형 아홉 개가 잡히고, 그 뒤 복원한 사례 162개가 통과합니다.
전체 계층은 3,285개 통과, 8개 건너뜀으로 통과하고, 별도의 느린 계층은 81개 전부를 통과하며, 고정 기준 배열
1,141개 전부가 비트 단위로 재현됩니다.
범위를 한정한 구현과 그에 필요한 수치 관문은 완료되었습니다.
새 경로는 선언한 Debye 극점이 세 개 이상인 경우를 다룹니다.
기존의 [극점 하나](fd-debye-film.md) 경로와
[극점 두 개](fd-two-debye-film.md) 경로는 각자의 산술과 기록된 증거를 유지합니다.

법선 방향 계면 법칙은 감수율 합 전체를 결합합니다. 극점 하나용 변환을 선언한 각 극점에 독립적으로 적용하면 다른
재료를 기술하게 됩니다. 양의 대칭 이완 연산자는 정확한 조화 혼합의 유한한 수동 실현을 줍니다. 접선 방향 법칙은
산술 평균으로 남습니다. 활성인 모든 실효 이완은 기존의 분할 메모리, 국소 에너지, 합산 재료 비율 정책에
기여합니다.

범위는 여전히 일반 유전체 호스트 안에 놓인, 구체적이고 축에 정렬된 박막 하나입니다. Debye 극점 수가 유한하다는
것은 임의의 극점 계열이나 임의의 기하를 뜻하지 않습니다. 곡면 분산 몸체, 계열이 섞인 합, 손실 또는 분산
호스트, 접합, 기하/재료/대역 미분은 이 확장의 범위 밖입니다. Debye/진동자 혼합 박막은 나중에 자체 범위를
얻었으며([기록](fd-hybrid-film.md), 2026-10-07), 떨어진 Debye 박막도 마찬가지입니다
([기록](fd-debye-stack.md), 2026-10-09). 일반 C8 스무딩은 아직 완성되지 않았고,
[C7 메타표면 판정](fd-metasurface-validation.md)도 여전히 통과하지 못한 상태입니다.

## 범위를 한정한 계약

선언은 여전히 단일
`fd.Structure(fd.Box(...), fd.Dispersive(eps_inf=..., poles=(...)))`입니다.
선언한 튜플은 정확히 공개 `Debye` 객체를 유한한 양의 개수만큼 담습니다. 개수가 1과 2이면 기존 구현을 선택하며,
새 실현은 개수 3부터 적용됩니다.

| 항목 | 한정된 경우 |
| --- | --- |
| 기하 | 정확히 구체적인 `Box` 하나, `angle=0`, `range=None`, voxel 이산화 사용. 상대 물체나 접합 없음. |
| 범위 | 정확히 두 격자 축 전체가 박막을 지나며 균일하고, 각 가로 방향 영역 면 너머로 최소 `dx` 하나만큼 돌출합니다. |
| 두께 | 법선 방향 범위가 최소 `dx` 하나여서, 두 면이 같은 전기 쌍대 셀 내부에 들어가지 않습니다. |
| 여유 | 법선 방향 지지 영역은 계산 영역 안에 엄격히 들어가며, 모든 지지 영역이 모든 흡수층과 떨어져 있습니다. |
| 박막 | 정확히 `Dispersive`, 유한하고 양수인 등방 고주파 유전율, `mu=1`. |
| 이완 | 모든 극점은 정확히 `Debye`이며, 구체적이고 유한한 `delta_eps >= 0`과 `tau > 0`을 가집니다. 증분 0과 정확히 같은 시간은 허용됩니다. |
| 호스트 | 정확히 일반 무손실 `Material`, 유한하고 양수인 등방 유전율, `mu=1`. |
| 상태 | 초기 필드 없음. 재사용하는 계획은 기하, 재료, 격자, 선언한 극점 수, 예약한 메모리 표현과 일치해야 합니다. |

이 제한은 격자 축의 순열에 대해 불변입니다.
점유율은 각 전기 성분 자신의 Yee 쌍대 셀에서의 해석적 겹침을 씁니다. 비어 있는 끝점과 가득 찬 끝점은 정확하며,
허용 오차가 작은 양의 혼합 비율이나 극점 세기를 지워서는 안 됩니다.

선언한 개수가 실행 전에 메모리 할당을 고정합니다. 세기 0이나 같은 시간으로 인한 축약은 물리적으로 활성인 모드
수를 줄일 수 있지만, 준비된 계획의 슬롯 수를 조용히 바꿔서는 안 됩니다. 이것은 구체적인 재료 변환이지, 추적된
고유값 계산이 아닙니다.
기존의 소스, 모니터, 특징 크기, 흡수층 제한은 계속 적용됩니다. 소스 진폭을 포함해 그래디언트 정확성은 주장하지
않습니다.

## 조화 법칙은 합 전체를 결합합니다

저장소 규약 `exp(-i*omega*t)`에서 `s=-i*omega`, 박막 비율 `f`, 호스트 비율 `g=1-f`, 박막 고주파 유전율 `a`,
호스트 유전율 `b`라고 합시다. 선언한 활성 이완마다 다음을 정의합니다.

```text
r_i = 1/tau_i
u_i = sqrt(delta_i*r_i)
D = diag(r_i)
chi(s) = sum_i delta_i/(1 + tau_i*s)
       = u^T * (s*I + D)^(-1) * u
eps_film(s) = a + chi(s)
A = f*b + g*a.
```

산술 평균 접선 응답과 조화 평균 법선 응답은 다음과 같습니다.

```text
eps_t(s) = f*a + g*b + f*chi(s)
eps_n(s) = 1/(f/(a + chi(s)) + g/b)
         = a*b/A + (f*b*b/A**2)*chi(s)/(1 + (g/A)*chi(s)).
```

랭크 1 역행렬 항등식으로 다음을 얻습니다.

```text
J = D + (g/A)*u*u^T
eps_n(s) = a*b/A + (f*b*b/A**2)*u^T*(s*I + J)^(-1)*u.
```

이완 시간이 양수이면 `D`는 양의 정부호입니다. 랭크 1 항은 양의 준정부호이므로 `J`는 양의 정부호입니다.
`lambda_j`와 `q_j`가 그 고유값과 정규직교 고유벡터라면, 정확한 수동 모드 표현은 다음과 같습니다.

```text
tau_eff_j = 1/lambda_j
delta_eff_j = (f*b*b/A**2)*(q_j^T*u)**2/lambda_j
eps_inf_normal = a*b/A.
```

각 실효 증분은 음이 아닙니다. 투영이 0이면 물리적 이완을 담지 않습니다. 선언한 시간이 같으면 축약 전에 정확히
합칠 수 있지만, 서로 다른 시간은 가깝다는 이유만으로 합쳐서는 안 됩니다. 접선 방향 표현은 선언한 시간을
유지하고, `eps_inf_tangent=f*a+g*b`와 함께 증분 `f*delta_i`를 씁니다.

이 행렬 항등식은 재료 법칙을 확립할 뿐, 특정 고유값 풀이기나 근 찾기의 수치 정확도를 확립하지 않습니다. 구현은
작은 활성 잔류(residue)를 보존하고, 정확한 축약과 수치적인 모드 손실을 구별하며, 유한 정밀도 표현으로 담을 수
없는 활성 유도량은 거부해야 합니다. 수학적으로 유한한 모든 매개변수 조합을 허용한다고 약속하지는 않습니다.

## 인증된 수치 실현

구현은 준비 시점 축약 동안 제공된 각 2진 부동소수점 값을 정확한 유리수로 다룹니다. 정확히 0인 세기는 활성 계산에서
제거하고, 정확히 같은 이완 시간은 합칩니다. 서로 다른 극점을 합치는 데 근사적 같음을 쓰지 않습니다. 선언한 개수는
여전히 슬롯을 예약하며, 활성 실효 모드는 이완 시간이 커지는 순서로 정렬합니다.

실제로 혼합된 법선 셀에서는 `alpha=g/A`,
`kappa=f*b*b/A**2`, `w_i=delta_i*r_i`로 둡니다. 거의 평행한 부동소수점 고유벡터를 빼서 작은 잔류를 복원하는 대신,
유리수 구간으로 스칼라 영년 방정식(secular equation)을 풉니다.

```text
F(lambda) = 1 + alpha*sum_i w_i/(r_i-lambda) = 0
delta_eff = kappa/(lambda*alpha**2*sum_i w_i/(r_i-lambda)**2)
tau_eff = 1/lambda.
```

정확한 축약 뒤에는 활성 비율들이 서로 다르고 가중치가 양수입니다. 근은 비율들과 번갈아 놓이며, 마지막 근은
`max(r_i)+alpha*sum_i w_i`보다 크지 않습니다. 따라서 이분법으로 서로소인 근 구간을 세분할 수 있습니다. 허용 검사는
결과로 나온 시간과 증분을 모두 구간으로 감싸고, 각 구간이 하나의 동일한 양의 유한 float64 값으로 반올림될 때만
모드를 받아들입니다. 작은 잔류는 표현 가능하면 유지합니다. 표현 가능한 결과를 얻지 못하면 세기 0 근사가 아니라
거부입니다.

정밀도 예산은 활성 모드마다 이분 4,096번이며, 그래도 구간이 해소되지 않으면 이름 붙은 거부가 뒤따릅니다. 이것은
수치 작업량 한계이지, 선언한 극점 수의 상한이 아닙니다. 순수 호스트/가득 찬 박막 끝점과 정확한 축약은
`alpha=0`에서 혼합 셀 공식을 계산하는 일을 피합니다.
최대 128개의 불변 법선 모드 축약을 구체적인 박막/호스트 유전율, 면 비율, 정규화한 활성 극점 튜플을 키로 캐시합니다.
셀 배열도 추적된 값도 그 캐시에 들어가지 않습니다. 접선 방향 셀과 가득 찬 박막 셀은 영년 방정식 풀이가 필요
없습니다.

## 분할 메모리와 국소 에너지

각 실효 증분 `delta`와 이완 시간 `T`에 대해 기존의 스케일한 사다리꼴 분할을 씁니다.

```text
m = max(T, dt/2)
left = T/m
right = (dt/2)/m
u_split = left/(left+right)
v_split = right/(left+right)
gain = u_split-v_split
c = delta*v_split
drive = 2*delta*u_split*v_split
Q = P-c*E
Q^(n+1) = gain*Q^n + drive*E^n.
```

전기장 갱신은 `eps_inf_eff+sum_j c_j`를 씁니다. 관측 시간 수준에서 재료 보정은 다음과 같습니다.

```text
sum_active_j (|Q_j^n + c_j*E^n|**2/delta_j - c_j*|E^n|**2).
```

가중치는 성분이나 잘린 관측 영역으로 축약하기 전에 각자의 공간 셀에서 적용합니다.
비활성 슬롯은 가중치와 구동이 0입니다.
뺄셈은 전기 에너지에 이미 포함된 순간 이동분을 상쇄합니다. 이 대수 항등식이 전파, 유한 에너지, 장시간 검사를
대신하지는 않습니다.

점화식 주파수 오라클은 정확한 혼합을
`omega_hat=2*tan(omega*dt/2)/dt`에서 계산합니다. 물리적 연속체 기준은 대신 실제 주파수를 써서, 시간 및 공간
이산화 오차가 드러나게 둡니다.

## 합산 재료 비율 정책

보수적 정책은 벌크 합산 비율과 각 Yee 성분에서의 실제 변환된 합 중 최댓값을 취합니다.

```text
R_bulk = sum_i delta_i*r_i*r_i/a
R_cell = sum_j delta_eff_j/(eps_inf_eff*tau_eff_j*tau_eff_j)
R_film = max(R_bulk, max_actual_cells_and_components(R_cell))
dt_bound = 1/sqrt(1/dt_nondispersive**2 + R_film/4).
```

동시에 활성인 모든 모드가 기여합니다. 가장 큰 극점만 취하면 재료 응답의 일부를 잃고, 벌크 비율과 변환된 비율을
더하면 같은 박막을 두 번 세게 됩니다. 법선 셀에서 정확한 모멘트 항등식은 다음과 같습니다.

```text
W = sum_i delta_i*r_i
R_normal = (f*b/(a*A))*(sum_i delta_i*r_i*r_i + (g/A)*W*W).
```

이는 `u^T*J*u`에서 나옵니다. 법선 비율은 벌크 합을 넘을 수 있습니다.
일치하는 허용된 박막만이 일반적인 선언 극점 비율 경로를 이 정책으로 대체합니다. 증분 0은 쓰이지 않는 역수 시간이나
제곱 비율을 계산하기 전에 0을 기여합니다. 이 보수적인 저장소 정책은 수동 사다리꼴 이완만의 안정성 필요조건이
아니며, 흡수층 안정성 계약을 확장하지 않습니다.

## 유한 합의 벌크 스펙트럼 하한

`x=omega*omega`에 대해 완전한 수동 합을 전개하면 다음을 얻습니다.

```text
|eps(omega)|**2 = a*a + sum_i C_i/(1 + tau_i*tau_i*x)
C_i = delta_i*delta_i + 2*a*delta_i
    + 2*sum_(j != i) delta_i*delta_j*tau_i/(tau_i+tau_j).
```

모든 `C_i`는 음이 아닙니다.
`|k|**4=x*x*|eps|**2`의 각 항은 미분이 음이 아니며, `a*a*x*x` 때문에 양의 `x`에서 합이 엄격히 증가합니다.
따라서 양의 소스 대역에서 가장 큰 벌크 파동벡터 크기는 대역의 위쪽 끝점에서 나옵니다.
보호 검사는 그곳에서 박막과 호스트 모두에 대해 선언한 응답 전체를 계산하고 `dx*|k_max| <= 2*pi/8`을
요구합니다.

선언한 모든 모니터 파장, `Resolution` 파장, 명시적 PML 파장도 위상 파장당 셀 여덟 개, 표피 깊이당 셀 하나라는
위상/표피 하한을 유지합니다. 열둘과 둘 아래에서의 기존 경고도 남아 있습니다. 대역과 표본 파장은 구체적이고 유한한
양수여야 합니다.

이것은 벌크 척도 해상도 하한이지, 산란 정확도 정리나 모든 계면 또는 비스듬한 종방향 척도에 대한 인증서가
아닙니다.
측정된 수렴을 위해서는 지속 시간 제어와 흡수층 제어가 여전히 필요합니다.
